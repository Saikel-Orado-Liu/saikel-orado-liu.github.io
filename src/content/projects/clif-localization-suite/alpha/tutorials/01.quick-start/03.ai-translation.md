# 第一次 AI 翻译

AI 翻译是插件内置的三段式管线：**导出 CLIF → DeepSeek 翻译 → 导入 CLIF**。AI 只负责生成译文文本，写回仍然由官方 `FLocTextHelper` 与 `.locres` 生成器完成；已经有人工译文（`reviewed` / `final`）的条目永不被覆盖。

## 前置条件

1. 已完成一次 [CLIF 导出与导入](../dashboard-workflow)，确认管线可用
2. 准备 DeepSeek API Key

### 配置 API Key

Key 的解析优先级：**环境变量 `DEEPSEEK_API_KEY` 优先，其次才是插件设置中的字段**。

- 推荐（不落盘）：设置系统环境变量 `DEEPSEEK_API_KEY`，然后重启编辑器
- 备选：**编辑 > 项目设置 > 插件 > CLIF Localization Suite > AI Translation > DeepSeek API Key**

> [!WARNING]
> 项目设置中的 Key 会以明文写入 `Config/DefaultEditor.ini`（UE `UDeveloperSettings` 的行为）。**提交仓库前请清空该字段**，改用环境变量。

### 测试连接

两个入口，使用同一套逻辑：

- **项目设置** → AI Translation 分类 → **测试连接** 按钮
- 控制台命令：

```text
ClifLocalizationSuite.AI.TestConnection
```

测试内容：读取 Key → 发送一条极小请求 → 输出成功/失败、HTTP 状态、模型名与耗时。Key 缺失时的提示为 `AI 翻译缺少 DeepSeek API Key；请设置 DEEPSEEK_API_KEY 环境变量或插件设置。`

## 开始翻译

1. 在 **本地化 Dashboard** 中选中一个 Target
2. 点击工具栏 **AI 翻译**
3. 在弹出的 **AI 自动翻译** 窗口中选择目标语言（**可多选**，只列出该 Target 的非原生 Culture）

    <figure class="img-placeholder"><figcaption>images/clif-ai-translation-dialog.png — “AI 自动翻译”模态窗口：Culture 复选框列表与“开始翻译 / 取消”按钮 — The "AI 自动翻译" modal window with the culture checkbox list and the Start / Cancel buttons</figcaption></figure>

4. 点击 **开始翻译** —— 官方同款进度窗口依次执行四个任务：

```text
Export Translations      导出到 Saved/ClifAITranslate/<Target>/
AI 翻译                  DeepSeek 分批翻译缺失 target 的条目并写回 .clif
Import Translations      走官方 ClifImport 步骤写 manifest / archive，并编译 .locmeta / .locres
Generate Reports         官方字数报告，刷新 Dashboard 统计
```

    <figure class="img-placeholder"><figcaption>images/clif-ai-progress.png — AI 翻译进度窗口：四个任务依次执行，日志实时滚动 — The AI translation progress window running the four tasks with a streaming log</figcaption></figure>

5. 完成后日志给出统计（候选 / 成功 / 跳过 / 失败 / 批次 / 修复次数），Dashboard 字数随即刷新

> [!NOTE]
> 翻译的工作目录是 `Saved/ClifAITranslate/<Target>/`，每次执行前会被清空重建。管线结束时会**把翻译后的 `.clif` 拷回 Target 的数据目录**（`Content/Localization/<Target>/`），即使后续导入步骤因源码管理等原因失败，译文文件也不会丢。

## 哪些条目会被翻译

| 条目状态 | 是否进入请求 |
|:---|:---|
| `status: initial`（无 `target`） | ✅ 翻译 |
| 无 `target` 字段 | ✅ 翻译 |
| `status: translated` 且 `target == source`、源文本语种不属于目标语言（自翻译） | ✅ 重译（`Retranslate Self Translations` 开启时，默认开启） |
| `status: translated` / `reviewed` / `final` 且已有正常译文 | ⛔ 跳过，绝不覆盖 |
| `reviewed` / `final`（人工已审/锁定） | ⛔ 永不触碰 |

原生 Culture 不参与翻译；同一次任务里可以勾选多个目标语言，**多个语言并发请求**（每语言一条独立对话，并发上限 `Max Concurrent Cultures`，默认 4）。

## 命令行等价用法

```text
ClifLocalizationSuite.AITranslate <targetName> <culture1,culture2,...>
```

例如：

```text
ClifLocalizationSuite.AITranslate Game ja,ko,zh-Hans
```

AI 翻译、Key 读取、批量与重试策略与 GUI 完全一致；Key 不会出现在命令行里，只从环境变量或插件设置读取。

## 结果检查

1. **日志**：进度窗口底部日志逐文件输出翻译结果；`Copy Log` 可整段复制，`Save Log...` 可存盘归档
2. **CLIF 中间产物**：`Content/Localization/<Target>/<Culture>/<Clan>.clif` 中 `target` 已填充、`status` 变为 `translated`，可以直接人工评审或交给外部工具
3. **Translation Editor**：打开 **窗口 > 本地化 > 翻译编辑器**，确认译文到位且没有「需要检查」误报
4. **PIE**：进入 PIE 确认 UI 文本已切换

> [!TIP]
> 只想先试水？在 AI 翻译窗口里只勾选一个语言，并把 **Batch Size** 设小（如 5）、**Max Retries** 设 1，用少量条目验证提示词与术语是否符合预期，再放开全量。
