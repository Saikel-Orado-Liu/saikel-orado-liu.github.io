# Your First AI Translation

AI translation is a built-in three-stage pipeline: **export CLIF → translate with DeepSeek → import CLIF**. The model only produces translation text; every write still goes through the official `FLocTextHelper` and `.locres` generator, and entries that humans have already reviewed (`reviewed` / `final`) are never overwritten.

## Before you start

1. Complete a [CLIF export and import](../dashboard-workflow) once to prove the pipeline works
2. Obtain a DeepSeek API key

### Configure the API key

Key resolution order: **the `DEEPSEEK_API_KEY` environment variable wins over the plugin setting**.

- Recommended (never on disk): set the `DEEPSEEK_API_KEY` environment variable and restart the editor
- Alternative: **Edit > Project Settings > Plugins > CLIF Localization Suite > AI Translation > DeepSeek API Key**

> [!WARNING]
> A key entered in Project Settings is written in plain text to `Config/DefaultEditor.ini` (standard `UDeveloperSettings` behaviour). **Clear the field before committing**, and prefer the environment variable.

### Test the connection

Two entry points share one implementation:

- **Project Settings** → AI Translation category → the **测试连接** button
- Console command:

```text
ClifLocalizationSuite.AI.TestConnection
```

The test reads the key, sends a minimal request and reports success/failure, HTTP status, model name and elapsed time. With no key the plugin reports `AI 翻译缺少 DeepSeek API Key；请设置 DEEPSEEK_API_KEY 环境变量或插件设置。`

## Run a translation

1. Select a target in the **Localization Dashboard**
2. Click **AI 翻译** on the toolbar
3. In the **AI 自动翻译** window pick the target languages (**multi-select**; only the target's non-native cultures are listed)

    <figure class="img-placeholder"><figcaption>images/clif-ai-translation-dialog.png — “AI 自动翻译”模态窗口：Culture 复选框列表与“开始翻译 / 取消”按钮 — The "AI 自动翻译" modal window with the culture checkbox list and the Start / Cancel buttons</figcaption></figure>

4. Click **开始翻译** — the official progress window runs four tasks in order:

```text
Export Translations      export into Saved/ClifAITranslate/<Target>/
AI 翻译                  DeepSeek translates the entries without a target and writes the .clif back
Import Translations      the official ClifImport step writes manifest / archive and compiles .locmeta / .locres
Generate Reports         the official word-count report, refreshing the Dashboard statistics
```

    <figure class="img-placeholder"><figcaption>images/clif-ai-progress.png — AI 翻译进度窗口：四个任务依次执行，日志实时滚动 — The AI translation progress window running the four tasks with a streaming log</figcaption></figure>

5. When it finishes the log prints the statistics (candidates / translated / skipped / failed / batches / repairs) and the Dashboard word counts refresh

> [!NOTE]
> The working directory is `Saved/ClifAITranslate/<Target>/`, wiped and recreated on every run. When the pipeline ends, the **translated `.clif` files are copied back into the target's data directory** (`Content/Localization/<Target>/`), so the translations survive even if a later import step fails for an unrelated reason such as source control.

## Which entries get translated

| Entry state | Sent to the model |
|:---|:---|
| `status: initial` (no `target`) | ✅ translated |
| no `target` field at all | ✅ translated |
| `status: translated` where `target == source` and the text is not in the target language (a self-translation) | ✅ retranslated when `Retranslate Self Translations` is on (the default) |
| `status: translated` / `reviewed` / `final` with a real translation | ⛔ skipped, never overwritten |
| `reviewed` / `final` (human-approved or locked) | ⛔ never touched |

The native culture is never translated. Several target languages may be selected at once; each language gets **its own conversation and runs concurrently** (capped by `Max Concurrent Cultures`, default 4).

## Command line equivalent

```text
ClifLocalizationSuite.AITranslate <targetName> <culture1,culture2,...>
```

For example:

```text
ClifLocalizationSuite.AITranslate Game ja,ko,zh-Hans
```

The model, key resolution, batching and retry behaviour are identical to the GUI. The key is never passed on the command line — it is read from the environment variable or the plugin setting.

## Checking the result

1. **Log**: the progress window streams per-file results; `Copy Log` copies the whole log and `Save Log...` writes it to disk
2. **CLIF intermediate files**: `Content/Localization/<Target>/<Culture>/<Clan>.clif` now carries `target` values and `status: translated`, ready for review or external tooling
3. **Translation Editor**: open **Window > Localization > Translation Editor** and confirm the translations are present with no spurious “needs review” flags
4. **PIE**: launch PIE and confirm the UI switches language

> [!TIP]
> Trying it out? Select a single culture in the AI translation window, set **Batch Size** low (say 5) and **Max Retries** to 1 to validate the prompt and terminology on a small sample before running the whole project.
