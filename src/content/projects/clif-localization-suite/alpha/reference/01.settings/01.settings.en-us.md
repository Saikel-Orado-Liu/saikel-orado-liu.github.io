# Settings Reference

Every setting lives on `UClifLocalizationSuiteSettings` (the class is `Config = Editor, defaultconfig`), the panel path is **Edit > Project Settings > Plugins > CLIF Localization Suite**, the config section is `[/Script/ClifLocalizationSuite.ClifLocalizationSuiteSettings]`, and by default it is written to `Config/DefaultEditor.ini`.

## Identity

| Field | Type | Default | Description |
|:---|:---|:---|:---|
| `CLIF Namespace`<br>`ClifNamespace` | `FString` | `p-clifl10n-suite` | The `namespace` written into the CLIF header on export; must be lowercase kebab-case. The first segment of a canonical ID |

> [!NOTE]
> The `Clan to Namespace` and other mapping tables in Project Settings are **merged** with the built-in defaults (same key overwrites). An empty table = built-in defaults only.

## Semantic Mapping

| Field | Type | Default | Description |
|:---|:---|:---|:---|
| `Clan to Namespace`<br>`ClanToNamespace` | `TMap<FString, FString>` | See the table below | CLIF clan → UE Namespace; export looks up the clan in reverse |
| `Namespace to Type`<br>`NamespaceToType` | `TMap<FString, FString>` | See the table below | UE Namespace → CLIF `type` |
| `Namespace to Emotion`<br>`NamespaceToEmotion` | `TMap<FString, FString>` | `Dialogue → neutral` | UE Namespace → CLIF `emotion` |

Built-in defaults:

```text
ClanToNamespace     : category → UObjectCategory
                      tooltip → UObjectToolTips
                      short-tooltip → UObjectShortTooltips
                      display-name → UObjectDisplayNames
                      proper-noun → UObjectDisplayNames
                      dialogue → Dialogue

NamespaceToType     : UObjectCategory → label
                      UObjectToolTips → prompt
                      UObjectShortTooltips → prompt
                      UObjectDisplayNames → proper-noun
                      Dialogue → dialogue

NamespaceToEmotion  : Dialogue → neutral
```

Resolution rules and the degradation policy are in [semantic mapping](../../../guides/semantic-mapping/mapping).

## Workflow

| Field | Type | Default | Description |
|:---|:---|:---|:---|
| `Default Import Directory`<br>`DefaultImportDirectory` | `FString` | Empty | Default directory for the import directory dialog; when left empty the Target's localization data directory is used (`<ProjectContent>/Localization` in the TargetSet case) |
| `Default Export Directory`<br>`DefaultExportDirectory` | `FString` | Empty | Default directory for the export directory dialog; when left empty, same as above |

## AI Translation

| Field | Type | Default | Description |
|:---|:---|:---|:---|
| `DeepSeek API Key`<br>`DeepSeekApiKey` | `FString` (password box) | Empty | When left empty the `DEEPSEEK_API_KEY` environment variable is read; **written to DefaultEditor.ini in plain text** |
| `DeepSeek Base URL`<br>`DeepSeekBaseUrl` | `FString` | `https://api.deepseek.com` | API base address; a trailing `/v1` is joined correctly too |
| `DeepSeek Model`<br>`DeepSeekModel` | `FString` | `deepseek-flash` | Model name |
| `Thinking Level`<br>`ThinkingLevel` | `EClifDeepSeekThinkingLevel` | `Off` | `Off` / `Low` / `High` / `Max`; `Off` uses `temperature=1.3` |
| `Request Timeout`<br>`RequestTimeoutSeconds` | `float` | `60.0` | Single-request timeout in seconds, minimum 1 |
| `Max Retries`<br>`MaxRetries` | `int32` | `3` | Per-batch retry count; it also caps the number of "missing target re-run rounds", minimum 0 |
| `Batch Size`<br>`BatchSize` | `int32` | `20` | Entries per batch, minimum 1 |
| `Max Concurrent Cultures`<br>`MaxConcurrentCultures` | `int32` | `4` | Upper bound on concurrent batches, minimum 1 |
| `Translation Standard`<br>`TranslationStandard` | `FString` (multi-line) | Empty | Written into the CLIF header `standard`, and appended to the System Prompt |
| `System Prompt`<br>`SystemPrompt` | `FString` (multi-line) | Empty | When left empty the built-in default prompt is used; when filled in it **completely replaces** it |
| `Auto Repair CLIF`<br>`bAutoRepairClif` | `bool` | `true` | Automatically repair AI-produced CLIF that fails validation |
| `Max Repair Attempts`<br>`MaxRepairAttempts` | `int32` | `2` | Maximum repair rounds per file, minimum 0 |
| `Include Context`<br>`bIncludeContext` | `bool` | `true` | Whether to send SourceLocation / context to the model |
| `Retranslate Self Translations`<br>`bRetranslateSelfTranslations` | `bool` | `true` | Retranslate "self-translation" entries; `reviewed` / `final` are never touched |

### Thinking level enum

| Value | Display name | Request behaviour |
|:---|:---|:---|
| `Off` | Off | `thinking.type = disabled` + `temperature = 1.3` |
| `Low` | Low | `thinking.type = enabled` + `reasoning_effort = low` |
| `High` | High | `thinking.type = enabled` + `reasoning_effort = high` |
| `Max` | Max | `thinking.type = enabled` + `reasoning_effort = max` |

## Read-only API

| Member | Returns | Description |
|:---|:---|:---|
| `GetSemanticMapping()` | `FClifSemanticMapping` | The effective mapping after merging the built-in defaults with Project Settings |
| `ResolveApiKey()` | `FString` | The `DEEPSEEK_API_KEY` environment variable wins, otherwise the settings field is returned |
| `GetDefaultSystemPrompt()` | `FString` (static) | The built-in default System Prompt |
| `BuildSystemPrompt()` | `FString` | `SystemPrompt` (or the default when empty) + `\n\n=== Translation Standard ===\n` + `TranslationStandard` |

## Config example

```ini
; Config/DefaultEditor.ini
[/Script/ClifLocalizationSuite.ClifLocalizationSuiteSettings]
ClifNamespace=my-game
+ClanToNamespace=(("ui", "MyGameUI"))
+NamespaceToType=(("MyGameUI", "label"))
DefaultImportDirectory=G:/Translations/clif
DeepSeekModel=deepseek-flash
ThinkingLevel=Off
BatchSize=20
TranslationStandard=游戏 UI 使用简体中文，保留英文专有名词与品牌名。
```

> [!WARNING]
> Do not put a real API key into an ini that is committed to the repository. Use the `DEEPSEEK_API_KEY` environment variable, or clear the field before committing.
