# 设置参考

全部设置位于 `UClifLocalizationSuiteSettings`（类 `Config = Editor, defaultconfig`），面板路径 **编辑 > 项目设置 > 插件 > CLIF Localization Suite**，配置节 `[/Script/ClifLocalizationSuite.ClifLocalizationSuiteSettings]`，默认写入 `Config/DefaultEditor.ini`。

## Identity

| 字段 | 类型 | 默认值 | 说明 |
|:---|:---|:---|:---|
| `CLIF Namespace`<br>`ClifNamespace` | `FString` | `p-clifl10n-suite` | 导出时写入 CLIF header 的 `namespace`，必须为小写 kebab-case。规范 ID 的第一段 |

> [!NOTE]
> 项目设置里的 `Clan to Namespace` 等映射表会与内置默认表**合并**（同键覆盖）。空表 = 只用默认表。

## Semantic Mapping

| 字段 | 类型 | 默认值 | 说明 |
|:---|:---|:---|:---|
| `Clan to Namespace`<br>`ClanToNamespace` | `TMap<FString, FString>` | 见下表 | CLIF clan → UE Namespace；导出时反向查找 clan |
| `Namespace to Type`<br>`NamespaceToType` | `TMap<FString, FString>` | 见下表 | UE Namespace → CLIF `type` |
| `Namespace to Emotion`<br>`NamespaceToEmotion` | `TMap<FString, FString>` | `Dialogue → neutral` | UE Namespace → CLIF `emotion` |

内置默认值：

```text
ClanToNamespace     : category → UObjectCategory
                      tooltip → UObjectToolTips
                      short-tooltip → UObjectShortTooltips
                      display-name → UObjectDisplayNames
                      proper-noun → UObjectDisplayNames
                      dialogue → Dialogue

NamespaceToType     : UObjectCategory → label
                      UObjectToolTips → prompt
                      UObjectShortTooltips → prompt
                      UObjectDisplayNames → proper-noun
                      Dialogue → dialogue

NamespaceToEmotion  : Dialogue → neutral
```

解析规则与降级口径见 [语义映射](../../../guides/semantic-mapping/mapping)。

## Workflow

| 字段 | 类型 | 默认值 | 说明 |
|:---|:---|:---|:---|
| `Default Import Directory`<br>`DefaultImportDirectory` | `FString` | 空 | 导入目录对话框的默认目录；留空时用 Target 的本地化数据目录（TargetSet 场景为 `<ProjectContent>/Localization`） |
| `Default Export Directory`<br>`DefaultExportDirectory` | `FString` | 空 | 导出目录对话框的默认目录；留空同上 |

## AI Translation

| 字段 | 类型 | 默认值 | 说明 |
|:---|:---|:---|:---|
| `DeepSeek API Key`<br>`DeepSeekApiKey` | `FString`（密码框） | 空 | 留空时读取环境变量 `DEEPSEEK_API_KEY`；**明文写入 DefaultEditor.ini** |
| `DeepSeek Base URL`<br>`DeepSeekBaseUrl` | `FString` | `https://api.deepseek.com` | API 基础地址；带 `/v1` 也能正确拼接 |
| `DeepSeek Model`<br>`DeepSeekModel` | `FString` | `deepseek-flash` | 模型名 |
| `Thinking Level`<br>`ThinkingLevel` | `EClifDeepSeekThinkingLevel` | `Off`（关闭） | `Off` / `Low` / `High` / `Max`；`Off` 时使用 `temperature=1.3` |
| `Request Timeout`<br>`RequestTimeoutSeconds` | `float` | `60.0` | 单请求超时（秒），最小 1 |
| `Max Retries`<br>`MaxRetries` | `int32` | `3` | 单批重试次数，同时决定「缺失目标重跑轮数」上限，最小 0 |
| `Batch Size`<br>`BatchSize` | `int32` | `20` | 每批条目数，最小 1 |
| `Max Concurrent Cultures`<br>`MaxConcurrentCultures` | `int32` | `4` | 并发批次数上限，最小 1 |
| `Translation Standard`<br>`TranslationStandard` | `FString`（多行） | 空 | 写入 CLIF header `standard`，并追加到 System Prompt |
| `System Prompt`<br>`SystemPrompt` | `FString`（多行） | 空 | 留空使用内置默认提示词；填写则**完全替换** |
| `Auto Repair CLIF`<br>`bAutoRepairClif` | `bool` | `true` | AI 产出的 CLIF 校验失败时自动修复 |
| `Max Repair Attempts`<br>`MaxRepairAttempts` | `int32` | `2` | 单文件最大修复轮数，最小 0 |
| `Include Context`<br>`bIncludeContext` | `bool` | `true` | 是否把 SourceLocation / context 发给模型 |
| `Retranslate Self Translations`<br>`bRetranslateSelfTranslations` | `bool` | `true` | 重译「自翻译」条目；`reviewed` / `final` 永不触碰 |

### 思考强度枚举

| 取值 | 显示名 | 请求行为 |
|:---|:---|:---|
| `Off` | 关闭 | `thinking.type = disabled` + `temperature = 1.3` |
| `Low` | 低 | `thinking.type = enabled` + `reasoning_effort = low` |
| `High` | 高 | `thinking.type = enabled` + `reasoning_effort = high` |
| `Max` | 最高 | `thinking.type = enabled` + `reasoning_effort = max` |

## 只读 API

| 成员 | 返回 | 说明 |
|:---|:---|:---|
| `GetSemanticMapping()` | `FClifSemanticMapping` | 内置默认表 + 项目设置合并后的生效映射 |
| `ResolveApiKey()` | `FString` | 环境变量 `DEEPSEEK_API_KEY` 优先，否则返回设置字段 |
| `GetDefaultSystemPrompt()` | `FString`（static） | 内置默认 System Prompt |
| `BuildSystemPrompt()` | `FString` | `SystemPrompt`（空则默认）+ `\n\n=== Translation Standard ===\n` + `TranslationStandard` |

## 配置示例

```ini
; Config/DefaultEditor.ini
[/Script/ClifLocalizationSuite.ClifLocalizationSuiteSettings]
ClifNamespace=my-game
+ClanToNamespace=(("ui", "MyGameUI"))
+NamespaceToType=(("MyGameUI", "label"))
DefaultImportDirectory=G:/Translations/clif
DeepSeekModel=deepseek-flash
ThinkingLevel=Off
BatchSize=20
TranslationStandard=游戏 UI 使用简体中文，保留英文专有名词与品牌名。
```

> [!WARNING]
> 不要把真实 API Key 写进提交到仓库的 ini。请使用环境变量 `DEEPSEEK_API_KEY`，或在提交前清空该字段。
