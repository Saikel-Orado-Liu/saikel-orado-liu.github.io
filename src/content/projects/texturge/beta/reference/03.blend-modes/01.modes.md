# 混合模式参考

Texturge Beta 在每个字形的动画层之间使用 `ETextAnimationBlendMode` 枚举定义的混合模式。混合在 `FPerLayerCurves::Evaluate()` 中以**逐通道**方式执行，每个 `FBakedGlyph` 中的层拥有自己的 `BlendMode` 数组。

## 模式一览

| 枚举值 | 名称 | 行为描述 | 典型场景 |
|--------|------|----------|----------|
| `Additive` | 加法混合 | 将当前层的值加到上一层结果上 | 效果叠加 |
| `Override` | 覆写混合 | 用当前层替换上一层的结果 | 样式切换 |
| `Multiply` | 乘法混合 | 将当前层与上一层的结果相乘 | 强度调制 |
| `CrossFade` | 交叉淡化 | 根据权重在当前层与上一层之间平滑插值 | 层过渡 |

## 各模式详解

### Additive（加法混合）

将当前图层的动画通道值直接叠加到已累积的结果上。

```
Result[channel] = Accumulated[channel] + CurrentLayer[channel]
```

- 后续层在之前所有层的效果之上**累加**
- 适合组合多种效果：例如在一个抖动（shake）动画上叠加摇摆（wobble）效果
- 多层的总效果可能超出合理范围，需要在动画曲线中自行控制幅值

> NOTE
>
> 多层 Additive 累加可能导致数值超出合理范围，建议在动画曲线中设置 Clamp 范围以避免溢出。

### Override（覆写混合）

使用当前图层的值完全替换已累积的结果。

```
Result[channel] = CurrentLayer[channel]
```

- 忽略之前所有层的输出
- 适合在两种互斥的基础动画风格之间切换
- 通常作为首层的默认模式，后续层仅在需要完全替换时使用

### Multiply（乘法混合）

将当前图层的值与已累积的结果逐元素相乘。

```
Result[channel] = Accumulated[channel] × CurrentLayer[channel]
```

- 缩放或衰减上游层效果，而非累加
- 用于强度调制：将淡出（fade）曲线乘以弹跳（bounce）曲线实现渐弱弹跳
- 当 CurrentLayer 的通道值为 1.0 时不影响上游结果；为 0.0 时完全消除

### CrossFade（交叉淡化）

依据层的权重值在当前层与上一层之间执行线性插值。

```
Result[channel] = lerp(Accumulated[channel], CurrentLayer[channel], Weight)
```

- `Weight` 范围 0.0 到 1.0
- Weight = 0.0 时完全保留上层；Weight = 1.0 时完全切换到当前层
- 用于运行时层之间的平滑过渡

## 逐通道执行

混合作用于 `FGlyphAnimationState` 的全部 21 个动画通道，每个通道独立计算。这意味着：

1. 同一条 `FPerLayerCurves` 可以为不同通道指定不同 BlendMode
2. 一个图层的 Location 通道可能使用 Additive，而 Color 通道可能使用 Override
3. `FBakedGlyph` 存储每个层的 `TArray<ETextAnimationBlendMode>` 数组，索引对应通道编号

## 视觉对比表

| 场景 | Additive | Override | Multiply | CrossFade |
|------|----------|----------|----------|-----------|
| 位移叠加 | 抖动 + 摇摆 → 复合偏移 | 只保留摇摆位移 | 抖动 × 摇摆 → 缩小的偏移 | 抖动 → 摇摆 平滑切换 |
| 颜色混合 | 红色 + 蓝色 → 紫色 | 只保留蓝色 | 红色 × 蓝色 → 深紫色 | 红色 → 蓝色 渐变过渡 |
| 缩放调制 | 放大 + 缩小 → 抵消 | 只保留缩小 | 放大 × 0.5 → 半放大 | 放大 → 缩小 插值 |

## 与阶段交叉淡化的交互

动画的阶段系统（参见调度参考）在层面之上独立运行。阶段交叉淡化由 `FStageTransitionConfig` 控制：

- 阶段之间的过渡通过 `UTextAnimationStageController` 触发
- 过渡时长可配置，以秒为单位
- 在交叉淡化过程中，来自退出阶段和进入阶段的 `FBakedGlyph` 层分别经过 `FPerLayerCurves::Evaluate()` 后，再进行阶段级混合

阶段交叉淡化与层混合是**两个独立的混合层级**：层混合基于 `ETextAnimationBlendMode` 在单个阶段内组合多层，阶段交叉淡化在 Intro → Default → Outro 之间平滑过渡。
