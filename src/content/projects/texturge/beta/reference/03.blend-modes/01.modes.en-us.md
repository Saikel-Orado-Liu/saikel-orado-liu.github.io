# Blend Modes Reference

Texturge Beta provides seven blend modes for controlling property composition across multiple tracks. Modes are specified via the `ETexturgeBlendMode` enum.

## Mode Overview

| Enum Value | Name | Formula | Use Case |
|------------|------|---------|----------|
| `Overwrite` | Overwrite | `R = A` | Directly replace the base value |
| `Additive` | Additive | `R = A + B` | Stacking displacement, color offset |
| `Multiply` | Multiply | `R = A * B` | Scale modulation, darkening |
| `AlphaBlend` | Alpha Blend | `R = lerp(A, B, α)` | Cross-fade transitions |
| `Min` | Minimum | `R = min(A, B)` | Upper clamp |
| `Max` | Maximum | `R = max(A, B)` | Lower clamp |
| `CustomWeight` | Custom Weight | `R = A * Wₐ + B * W_b` | Fine-grained blend ratio control |

## Blend Descriptor

```cpp
USTRUCT(BlueprintType)
struct FTexturgeBlendDescriptor
{
    UPROPERTY(EditAnywhere)
    ETexturgeBlendMode Mode = ETexturgeBlendMode::AlphaBlend;

    UPROPERTY(EditAnywhere, meta = (ClampMin = "0.0", ClampMax = "1.0"))
    float Alpha = 0.5f;

    UPROPERTY(EditAnywhere)
    float WeightA = 0.5f;

    UPROPERTY(EditAnywhere)
    float WeightB = 0.5f;
};
```

`Alpha` only applies under `AlphaBlend`; `WeightA` and `WeightB` only apply under `CustomWeight`.

> NOTE
>
> `Alpha`, `WeightA`, and `WeightB` are mode-dependent: unused fields are ignored during evaluation. Setting them under a non-matching mode has no effect.
