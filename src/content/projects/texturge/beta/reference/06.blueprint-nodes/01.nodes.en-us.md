# Blueprint Node Reference

Texturge Beta exposes the following nodes to Blueprints, all located under the `Texturge` category.

## Playback Control

| Node | Inputs | Outputs | Description |
|------|--------|---------|-------------|
| `Play Text Animation` | `Target`, `TrackIndex`, `LoopCount` | — | Plays the specified track animation |
| `Pause Text Animation` | `Target`, `TrackIndex` | — | Pauses the track |
| `Stop Text Animation` | `Target`, `TrackIndex` | — | Stops and resets the track |
| `Seek Text Animation` | `Target`, `TrackIndex`, `Time` | — | Seeks to the given time |

## Track Management

| Node | Inputs | Outputs | Description |
|------|--------|---------|-------------|
| `Create Track` | `Target`, `Descriptor` | `TrackIndex` | Creates a track and returns its index |
| `Remove Track` | `Target`, `TrackIndex` | `bool` | Removes a track; returns success |
| `Get Track Descriptor` | `Target`, `TrackIndex` | `Descriptor` | Retrieves the track descriptor struct |
| `Set Track Descriptor` | `Target`, `TrackIndex`, `Descriptor` | — | Updates the track descriptor |

## State Queries

| Node | Inputs | Outputs | Description |
|------|--------|---------|-------------|
| `Get Playback State` | `Target`, `TrackIndex` | `ETexturgePlayState` | Queries track playback state |
| `Get Progress` | `Target`, `TrackIndex` | `float` | Gets current progress (0–1) |
| `Get Active Track Count` | `Target` | `int32` | Number of currently active tracks |
| `Get Config` | — | `UTexturgeConfig` | Retrieves the plugin config asset |

## Event Dispatchers

All events follow the `On...` naming convention and are exposed as Blueprint Event Dispatchers:

```cpp
UPROPERTY(BlueprintAssignable)
FOnTrackFinished OnTrackFinished;

UPROPERTY(BlueprintAssignable)
FOnTrackStateChanged OnTrackStateChanged;
```

Bind callback logic in Blueprints via the `Bind Event to OnTrackFinished` node.
