# 蓝图节点参考

Texturge Beta 通过多个类向蓝图暴露播放控制、阶段管理和参数设置节点。核心蓝图可访问的类包括 `UAnimatedTextBlock`、`UTextAnimationStageController`、`UTextAnimator` 以及 `UK2Node_PrintWithAnimation`。

## UAnimatedTextBlock

`UAnimatedTextBlock` 是 UMG 中带动画的文本控件，提供以下 `BlueprintCallable` 方法：

### 播放控制

| 节点 | 输入引脚 | 输出引脚 | 说明 |
|------|----------|----------|------|
| `Play` | `Target` | — | 开始播放当前文本动画 |
| `Pause` | `Target` | — | 暂停播放，保留当前进度 |
| `Resume` | `Target` | — | 从暂停位置恢复播放 |
| `Stop` | `Target` | — | 停止播放并重置到初始状态 |
| `SkipToEnd` | `Target` | — | 跳过动画直接显示最终状态 |

### SetBlueprintVariable（6 个重载）

`UAnimatedTextBlock` 暴露 6 个 `SetBlueprintVariable` 重载，每种参数类型一个：

| 重载 | 输入引脚 | 说明 |
|------|----------|------|
| `SetBlueprintVariable (Float)` | `Target`, `Name`, `Value` | 设置浮点类型蓝图变量 |
| `SetBlueprintVariable (Int)` | `Target`, `Name`, `Value` | 设置整型蓝图变量 |
| `SetBlueprintVariable (Bool)` | `Target`, `Name`, `Value` | 设置布尔类型蓝图变量 |
| `SetBlueprintVariable (Vector)` | `Target`, `Name`, `Value` | 设置向量类型蓝图变量 |
| `SetBlueprintVariable (Color)` | `Target`, `Name`, `Value` | 设置线性颜色类型蓝图变量 |
| `SetBlueprintVariable (Vector2D)` | `Target`, `Name`, `Value` | 设置二维向量类型蓝图变量 |

- `Name` 参数对应动画蓝图中定义的变量名称
- 通过 `TAnimParamTraits<T, Owner>` 模板在编译期将类型映射到 `UAnimParameterOverrides` 中相应的 `TMap`

## UTextAnimator

`UTextAnimator` 是控制动画实例的核心对象，提供以下 `BlueprintCallable` 方法：

| 方法 | 输入引脚 | 说明 |
|------|----------|------|
| `Play` | `Target` | 从当前状态开始播放动画 |
| `Pause` | `Target` | 暂停动画评估 |
| `Stop` | `Target` | 停止动画并重置 |
| `SetPlayMode` | `Target`, `PlayMode` | 设置播放模式（Forward / Reverse / PingPong） |
| `SetPlaybackMode` | `Target`, `PlaybackMode` | 设置时间驱动模式（Duration / CPS） |

## UTextAnimationStageController

`UTextAnimationStageController` 管理 Intro → Default → Outro 三阶段转换：

| 方法 | 输入引脚 | 说明 |
|------|----------|------|
| `GoToStage` | `Target`, `Stage` | 切换到指定动画阶段 |
| `GetCurrentStage` | `Target` | 返回当前活跃的 `EAnimationStage` |
| `GetStageState` | `Target` | 返回当前阶段的 `EStagePlaybackState` |
| `SetTransitionDuration` | `Target`, `Duration` | 设置阶段过渡时长（秒） |

## UK2Node_PrintWithAnimation

`UK2Node_PrintWithAnimation` 是一个自定义 `UK2Node` 节点，用于在蓝图中输出带动画效果的调试文本：

- 属于 `UK2Node` 派生类，提供与标准 `Print String` 类似的接口
- 在执行引脚触发时将文本渲染为带动画的字形
- 主要用于开发和调试流程，非生产用途

## UTextAnimInstance

`UTextAnimInstance` 是动画蓝图实例的基类，提供与 `UAnimatedTextBlock` 对称的 `SetBlueprintVariable()` 支持：

| 方法 | 输入引脚 | 说明 |
|------|----------|------|
| `SetBlueprintVariable (Float)` | `Target`, `Name`, `Value` | 设置浮点变量 |
| `SetBlueprintVariable (Int)` | `Target`, `Name`, `Value` | 设置整型变量 |
| `SetBlueprintVariable (Bool)` | `Target`, `Name`, `Value` | 设置布尔变量 |
| `SetBlueprintVariable (Vector)` | `Target`, `Name`, `Value` | 设置向量变量 |
| `SetBlueprintVariable (Color)` | `Target`, `Name`, `Value` | 设置颜色变量 |
| `SetBlueprintVariable (Vector2D)` | `Target`, `Name`, `Value` | 设置二维向量变量 |

## 蓝图变量系统

### EAnimParamType 枚举

定义支持的参数类型，用于运行时类型查询：

| 枚举值 | C++ 类型 | 说明 |
|--------|----------|------|
| `Float` | `float` | 单精度浮点 |
| `Int` | `int32` | 32 位整数 |
| `Bool` | `bool` | 布尔值 |
| `Vector` | `FVector` | 三维向量 |
| `Color` | `FLinearColor` | 线性颜色 (RGBA) |
| `Vector2D` | `FVector2D` | 二维向量 |

### GetAnimParamType

返回 `FName` 对应的 `EAnimParamType`，用于在运行时查询某个已注册变量名的参数类型。

### TAnimParamTraits\<T, Owner\>

模板系统在编译期将 C++ 类型映射到 `UAnimParameterOverrides` 的 `TMap` 成员：

| T 特化 | 映射到的 TMap 成员 |
|--------|-------------------|
| `float` | `FloatParams` |
| `int32` | `IntParams` |
| `bool` | `BoolParams` |
| `FVector` | `VectorParams` |
| `FLinearColor` | `ColorParams` |
| `FVector2D` | `Vector2DParams` |

该模板使得 `SetBlueprintVariable()` 的 6 个重载可以通过统一的方式访问正确的参数存储。

## UAnimParameterOverrides

`UAnimParameterOverrides` 是每个控件实例的参数存储结构：

```cpp
USTRUCT(BlueprintType)
struct UAnimParameterOverrides
{
    UPROPERTY()
    TMap<FName, float> FloatParams;

    UPROPERTY()
    TMap<FName, int32> IntParams;

    UPROPERTY()
    TMap<FName, bool> BoolParams;

    UPROPERTY()
    TMap<FName, FVector> VectorParams;

    UPROPERTY()
    TMap<FName, FLinearColor> ColorParams;

    UPROPERTY()
    TMap<FName, FVector2D> Vector2DParams;
};
```

### 参数覆写的层次结构

参数值按以下优先级解析（高到低）：

1. `UAnimParameterOverrides` —— 每个控件实例在 Details 面板中的覆写值
2. `FAnimationEntry` 的 6 个覆写 TMap —— DataAsset 条目级别的默认覆写
3. `UTextAnimationBlueprint` 动画蓝图中的默认变量值

这允许在 DataAsset 中为所有使用某个标签的场合设定默认值，同时在每个控件实例上进一步覆盖。
