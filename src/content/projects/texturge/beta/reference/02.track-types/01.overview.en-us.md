# Track Types Overview

Texturge Beta provides six core track types, uniformly managed via the `FTexturgeTrackDescriptor` struct. All tracks inherit from `UTexturgeTrackBase`.

## Track Type Table

| Type ID | UClass | Description |
|---------|--------|-------------|
| `Transform` | `UTexturgeTrack_Transform` | Controls per-character position, rotation, scale |
| `Color` | `UTexturgeTrack_Color` | Per-character color gradient and blending |
| `Opacity` | `UTexturgeTrack_Opacity` | Controls character opacity (0–1) |
| `Glyph` | `UTexturgeTrack_Glyph` | Glyph switching and sprite-sheet animation |
| `Layout` | `UTexturgeTrack_Layout` | Dynamic line spacing, tracking, and alignment |
| `Shader` | `UTexturgeTrack_Shader` | Custom material parameter driving |

## Drive Modes

Each track supports the following drive modes:

`ETexturgeDriveMode`
: `Linear` — Time-based linear interpolation
: `Curve` — Driven by `UCurveFloat` / `UCurveVector` assets
: `Expression` — Real-time math expression evaluation (supports `t`, `index`, `count`)
: `Random` — Per-character random offset (seedable)

## Track Descriptor

```cpp
USTRUCT(BlueprintType)
struct FTexturgeTrackDescriptor
{
    UPROPERTY(EditAnywhere)
    TSubclassOf<UTexturgeTrackBase> TrackClass;

    UPROPERTY(EditAnywhere)
    ETexturgeDriveMode DriveMode = ETexturgeDriveMode::Linear;

    UPROPERTY(EditAnywhere)
    float Duration = 1.0f;

    UPROPERTY(EditAnywhere)
    float Delay = 0.0f;
};
```

Multiple tracks can be layered and composed. Execution order is controlled by the `Priority` field; lower values run first.
