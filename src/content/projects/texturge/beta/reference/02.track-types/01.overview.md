# 轨道类型概述

Texturge Beta 的 Sequencer 集成通过专用轨道类型控制 `UGlyphAnimation` 在过场动画中的播放。轨道系统定义于 `Plugins/Texturge/Source/Texturge/Public/Animation/Tracks/`。

## 轨道类型表

| 类型 | 路径 | 说明 |
|------|------|------|
| `UMovieSceneGlyphAnimationTrack` | `Animation/Tracks/MovieSceneGlyphAnimationTrack.h` | Sequencer 中用于驱动 `UGlyphAnimation` 的主轨道 |
| `UMovieSceneGlyphAnimationSection` | `Animation/Tracks/MovieSceneGlyphAnimationSection.h` | 主轨道内的时间区段，定义播放范围 |
| `UMovieSceneTextAnimationSection` | — | 遗留区段类型，保留向后兼容 |
| `FTextAnimationSubTrackData` | — | 子轨道数据结构，用于组织区段内的分层动画 |
| `FTextAnimationTrack` | `Animation/TextAnimationTrack.h` | 旧版轨道类型，已弃用 |
| `ETextAnimationTrackType` | 枚举 | 轨道类型标识枚举 |

### UMovieSceneGlyphAnimationTrack

主轨道类，负责在 `UMovieSceneSequence` 中承载 `UGlyphAnimation` 资源。添加到 Sequencer 时间线后，可以在指定时间范围内驱动文本动画。

关键职责：
- 持有对 `UGlyphAnimation` 资产的引用
- 管理其下的 `UMovieSceneGlyphAnimationSection` 区段
- 将 Sequencer 时间线进度转换为动画评估参数

### UMovieSceneGlyphAnimationSection

区段定义了轨道在时间线上的有效范围。每个区段包含：

| 属性 | 说明 |
|------|------|
| 开始/结束帧 | 区段在 Sequencer 中的时间范围 |
| 关联动画 | 指向要播放的 `UGlyphAnimation` |
| 子轨道数据 | `FTextAnimationSubTrackData` 分层组织 |

### UMovieSceneTextAnimationSection

遗留区段类型，为旧版 `FTextAnimationTrack` 设计。新项目应使用 `UMovieSceneGlyphAnimationSection`。

> NOTE
>
> `UMovieSceneTextAnimationSection` 仅为向后兼容保留，新项目应始终使用 `UMovieSceneGlyphAnimationSection`。

## 子轨道结构

`FTextAnimationSubTrackData` 提供区段内部的层级组织：

1. 一个主轨道可包含多个子轨道
2. 每个子轨道对应一个独立的动画层
3. 子轨道共享父区段的时间范围
4. 支持独立启用/禁用控制

## 动画通道

轨道驱动 `FGlyphAnimationState` 的 21 个通道，按类别分为：

### 变换通道

| 通道 | 类型 | 说明 |
|------|------|------|
| `Location.X` | `float` | 字形水平位置偏移 |
| `Location.Y` | `float` | 字形垂直位置偏移 |
| `Scale.X` | `float` | 字形水平缩放 |
| `Scale.Y` | `float` | 字形垂直缩放 |
| `Rotation` | `float` | 旋转角度（度） |

### 颜色通道

| 通道 | 类型 | 说明 |
|------|------|------|
| `Color.R` | `float` | 红色通道 (0–1) |
| `Color.G` | `float` | 绿色通道 (0–1) |
| `Color.B` | `float` | 蓝色通道 (0–1) |
| `Color.A` | `float` | 不透明度 (0–1) |

### 可见性

| 通道 | 类型 | 说明 |
|------|------|------|
| `Visible` | `float` | 字形可见性（0 隐藏，1 可见） |

### 阴影通道

| 通道 | 类型 | 说明 |
|------|------|------|
| `ShadowOffset.X` | `float` | 投影水平偏移 |
| `ShadowOffset.Y` | `float` | 投影垂直偏移 |
| `ShadowColor.R` | `float` | 投影红色通道 |
| `ShadowColor.G` | `float` | 投影绿色通道 |
| `ShadowColor.B` | `float` | 投影蓝色通道 |
| `ShadowColor.A` | `float` | 投影不透明度 |
| `ShadowVisible` | `float` | 阴影可见性 |

### 排版通道

| 通道 | 类型 | 说明 |
|------|------|------|
| `LetterSpacing` | `float` | 字符额外间距 |
| `LineHeightPercentage` | `float` | 行高乘数 (1.0 = 默认) |
| `HorizontalAlignment` | `float` | 水平对齐偏移 |

### 渐变通道

| 通道 | 类型 | 说明 |
|------|------|------|
| `GradientPosition` | `float` | 渐变效果位置 |
| `GradientColor.R` | `float` | 渐变红色通道 |
| `GradientColor.G` | `float` | 渐变绿色通道 |
| `GradientColor.B` | `float` | 渐变蓝色通道 |

## 驱动模式

轨道播放支持两种时间驱动模式，由 `EPlaybackMode` 枚举控制：

### Duration 模式

动画在固定的时间长度内完成。适用于需要精确与音频或其他动画同步的场景。

- 参数：`Duration`（秒）
- 行为：所有字形动画均匀分布于整个时长内
- 时长固定，不受文本长度影响

### CPS 模式（Characters Per Second）

动画时长根据字符数量动态计算。文本越长，总时长越大。

- 参数：`CPS`（每秒字符数）
- 行为：每个字符在 `1.0 / CPS` 秒内完成其入场动画
- 适合打字机效果或逐字显示的动态文本

## 轨道编辑器

`UGlyphAnimationTrackEditor` 是编辑器专属类，位于 `TexturgeEditor` 模块的 Private 目录：

- 负责在 Sequencer UI 中渲染轨道界面
- 处理区段的创建、拖拽与调整
- 仅在 Editor 构建中可用，不被打包到运行时

## 播放方向

`EPlayMode` 枚举定义轨道的播放方向：

| 枚举值 | 说明 |
|--------|------|
| `Forward` | 正向播放，从起始帧到结束帧 |
| `Reverse` | 反向播放，从结束帧到起始帧 |
| `PingPong` | 往返播放，到达终点后反向 |

`EStagePlayDirection` 枚举在动画阶段（Stage）粒度上定义同样的三个选项。
