# 富文本标签语法

Texturge Beta 使用自定义 XML 风格标签为文本内容绑定动画。标签由 `FTagParser` 解析为 `FTagNode` 树，再由 `FRenderTreeBuilder` 构建渲染树供 `UAnimatedRichTextBlock` 使用。

## 标签结构

### 配对标签

```text
<tagname>内容</tagname>
```

- 标签名 `tagname` 在 `UTextAnimationDataAsset` 中注册
- 开始标签与结束标签必须严格配对
- 内容可以是纯文本或其他嵌套标签

### 自闭合标签

```text
<br/>
```

自闭合标签不需要结束标签。用于插入功能性标记（如换行）。

### 标签语法规则

1. 所有标签使用尖括号 `<>` 包裹
2. 结束标签以 `</` 开头
3. 自闭合标签以 `/>` 结尾
4. 标签名大小写敏感
5. 标签不包含属性 —— 所有参数通过 `FAnimationEntry` 的参数覆写映射传递

## 解析流程

### 第一步：FTagParser

`FTagParser` 将原始富文本字符串解析为 `FTagNode` 树：

1. 逐字符扫描输入文本
2. 遇到 `<` 时进入标签解析模式
3. 识别标签名称，确定是开始标签、结束标签还是自闭合标签
4. 构建父子层级关系
5. 将标签间的文本内容存储为文本节点

### 第二步：FRenderTreeBuilder

`FRenderTreeBuilder` 将 `FTagNode` 解析树转换为渲染树：

1. 遍历 `FTagNode` 树
2. 对每个标签节点查询 `UTextAnimationDataAsset` 中的 `FAnimationEntry` 映射
3. 生成对应的 `FRenderNode` 节点
4. 未匹配到动画的标签原样输出或跳过（取决于配置）

## ERenderNodeType

渲染树中的节点类型由 `ERenderNodeType` 枚举标识：

| 枚举值 | 说明 |
|--------|------|
| `Unknown` | 未识别类型，通常表示解析异常 |
| `AnimationLayer` | 动画层节点，对应一个 `UTextAnimationBlueprint` |
| `StyleLayer` | 样式层节点，对应 UE 富文本样式 |
| `TextContent` | 纯文本内容节点 |
| `Decorator` | 装饰器节点，可自定义注入 |

## UTextAnimationDataAsset

`UTextAnimationDataAsset` 是核心映射资产，将标签名映射到动画蓝图：

| 属性 | 类型 | 说明 |
|------|------|------|
| `Entries` | `TArray<FAnimationEntry>` | 标签→动画蓝图映射数组 |

### FAnimationEntry 结构

| 字段 | 类型 | 说明 |
|------|------|------|
| `TagName` | `FName` | 待匹配的标签名称 |
| `Type` | `TSubclassOf<UTextAnimationBlueprint>` | 指向动画蓝图的类指针 |
| `FloatOverrides` | `TMap<FName, float>` | 浮点参数覆写 |
| `IntOverrides` | `TMap<FName, int32>` | 整型参数覆写 |
| `BoolOverrides` | `TMap<FName, bool>` | 布尔参数覆写 |
| `VectorOverrides` | `TMap<FName, FVector>` | 向量参数覆写 |
| `ColorOverrides` | `TMap<FName, FLinearColor>` | 颜色参数覆写 |
| `Vector2DOverrides` | `TMap<FName, FVector2D>` | 二维向量参数覆写 |

6 个参数覆写映射与 `UAnimParameterOverrides` 的类型结构完全对应。

## UAnimatedRichTextBlock

`UAnimatedRichTextBlock` 是用于显示带动画的富文本的 UMG 控件。标签解析过程：

1. 控件持有 `UTextAnimationDataAsset` 引用
2. 当文本变更时，调用 `FTagParser` 解析
3. `FRenderTreeBuilder` 查询 DataAsset 的 `Entries` 数组
4. 标签名匹配的 `FAnimationEntry` 提供动画蓝图及其参数覆写
5. 构建渲染树，为每个匹配的标签实例化对应的 `UTextAnimInstance`

```cpp
// 典型设置流程
AnimatedRichTextBlock->TextAnimationDataAsset = MyDataAsset;
AnimatedRichTextBlock->SetText(FText::FromString(
    TEXT("Hello <shake>World</shake>!")
));
```

## 嵌套规则

标签支持嵌套，但受以下限制：

1. 嵌套必须合法配对（内部标签的结束标签出现在外部标签的结束标签之前）
2. 空标签（即其名称未在 DataAsset 中找到的标签）的内容作为普通文本处理
3. 嵌套深度没有硬性上限，但过深的结构可能影响解析性能

> NOTE
>
> 嵌套深度无硬性上限，但过深的标签嵌套结构会增加 `FTagParser` 的解析开销，建议控制在 4 层以内以保持解析性能。

### 合法嵌套示例

```text
<wave><color>彩色波浪文字</color></wave>
<typewriter>逐字显示<shake>并抖动</shake>的文字</typewriter>
```

## 自定义装饰器

`ERenderNodeType::Decorator` 类型节点支持自定义渲染行为注入：

1. 创建继承自通用装饰器基类的自定义类
2. 在 `FRenderTreeBuilder` 的构建过程中注入装饰器节点
3. 装饰器节点可访问渲染上下文（字符索引、当前字形状态等）
4. 用于实现标签系统无法覆盖的特殊渲染需求
