# Rich Text Tag Syntax

Texturge Beta extends the UE5 rich text system with custom animation tags. Tags follow the `<tag_name attr="value">content</>` syntax.

## Built-in Tags

| Tag | Attributes | Description |
|-----|------------|-------------|
| `<wave>` | `amp`, `freq`, `phase` | Wave oscillation animation |
| `<shake>` | `intensity`, `decay` | Shake jitter effect |
| `<typewriter>` | `speed`, `cursor` | Typewriter reveal animation |
| `<color>` | `from`, `to`, `duration` | Color gradient animation |
| `<scale>` | `x`, `y`, `duration` | Scale transform animation |
| `<rotate>` | `angle`, `axis`, `speed` | Rotational animation |
| `<pause>` | `time` | Insert a pause of N seconds |

## Tag Structure

```yaml
wave:
  amp: 5.0        # Amplitude in pixels
  freq: 2.0       # Frequency in Hz
  phase: 0.0      # Phase offset

typewriter:
  speed: 0.05     # Interval per character reveal (seconds)
  cursor: "|"     # Cursor glyph; set empty to disable
```

## Custom Tag Injection

Register custom tag handlers via the `RegisterCustomTag` API:

```cpp
Scheduler->RegisterCustomTag(
    TEXT("rainbow"),
    FOnTagEvaluated::CreateLambda([](const FTagContext& Ctx) {
        Ctx.GlyphColor = FLinearColor::MakeFromHSV8(Ctx.CharIndex * 10, 255, 255);
    })
);
```

Tags may be nested; parsing order is depth-first. Maximum nesting depth is `8`; anything beyond is emitted as raw text.
