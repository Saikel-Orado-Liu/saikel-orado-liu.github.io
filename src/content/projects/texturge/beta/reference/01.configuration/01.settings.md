# 配置参考

Texturge Beta 的配置分为插件级设置（`UTexturgeSettings`）、模块依赖（Build.cs）以及资产级配置（`UTextAnimationBlueprint`、`UTextAnimationDataAsset`）三个层面。

## 插件设置（UTexturgeSettings）

`UTexturgeSettings` 是一个继承自 `UDeveloperSettings` 的配置类，定义于：

```
Plugins/Texturge/Source/Texturge/Public/Settings/TexturgeSettings.h
```

### 访问方式

```cpp
const UTexturgeSettings* Settings = UTexturgeSettings::Get();
```

通过静态 `Get()` 方法获取全局单例。由于继承 `UDeveloperSettings`，配置实例由引擎自动管理，无需手动创建。

### 项目设置面板

在编辑器中通过以下路径访问：

1. 打开 **Edit** 菜单
2. 选择 **Project Settings**
3. 导航至 **Plugins > Texturge**

### 当前状态

`UTexturgeSettings` 目前是一个**空壳类** —— 配置结构体已预先定义，但尚未包含任何公开属性。其设计目的是为未来版本预留插件级全局配置入口。所有运行时配置当前通过动画资产（见下文）管理。

## 模块依赖

要使用 Texturge 功能，需在项目或模块的 `Build.cs` 文件中添加对 Texturge 模块的依赖：

```cpp
PublicDependencyModuleNames.AddRange(new string[] {
    "Core",
    "CoreUObject",
    "Engine",
    "Texturge"       // Texturge 核心模块
});
```

模块名称为 `"Texturge"`，而非 `"TexturgeRuntime"`。编辑器工具（如轨道编辑器 `UGlyphAnimationTrackEditor`）位于 `TexturgeEditor` 模块，仅在编辑器构建中可用。

## UTextAnimationBlueprint

`UTextAnimationBlueprint` 是定义文本动画行为的核心资产，继承自 `UBlueprint`。其关键配置属性包括：

| 属性 | 类型 | 说明 |
|------|------|------|
| `ParentClass` | `TSubclassOf<UTextAnimInstance>` | 绑定的动画实例类 |
| `BlendMode` | `ETextAnimationBlendMode` | 默认图层混合模式 |
| `PlayMode` | `EPlayMode` | 播放方向（Forward / Reverse / PingPong） |
| `PlaybackMode` | `EPlaybackMode` | 时间驱动模式（Duration / CPS） |
| `Duration` | `float` | Duration 模式下的固定时长 |
| `CPS` | `float` | CPS 模式下的每秒字符数 |
| `Stages` | `TArray<FStageTransitionConfig>` | 动画阶段（Intro / Default / Outro）配置 |

播放流程分为三阶段系统：可选的 Intro 阶段、必选的 Default 阶段、可选的 Outro 阶段。阶段切换由 `UTextAnimationStageController` 管理。

## UTextAnimationDataAsset

`UTextAnimationDataAsset` 用于将富文本标签名称映射到具体的动画蓝图：

| 属性 | 类型 | 说明 |
|------|------|------|
| `Entries` | `TArray<FAnimationEntry>` | 标签→动画蓝图的映射条目数组 |

每个 `FAnimationEntry` 包含：

| 字段 | 类型 | 说明 |
|------|------|------|
| `TagName` | `FName` | 匹配的富文本标签名称 |
| `Type` | `TSubclassOf<UTextAnimationBlueprint>` | 指向动画蓝图的指针 |
| `FloatOverrides` 等 | 6 个 `TMap<FName, float>` | 六个类型的参数覆写映射 |

该资产供 `UAnimatedRichTextBlock` 引用，用于在运行时将 `<tagname>` 标签解析为对应的动画行为。

## UAnimParameterOverrides

`UAnimParameterOverrides` 是每个控件实例的参数覆写存储结构，包含 6 个 `TMap`，对应 6 种参数类型：

| TMap 成员 | 键类型 | 值类型 |
|-----------|--------|--------|
| `FloatParams` | `FName` | `float` |
| `IntParams` | `FName` | `int32` |
| `BoolParams` | `FName` | `bool` |
| `VectorParams` | `FName` | `FVector` |
| `ColorParams` | `FName` | `FLinearColor` |
| `Vector2DParams` | `FName` | `FVector2D` |

通过 `UAnimatedTextBlock` 或 `UTextAnimInstance` 的 `SetBlueprintVariable()` 方法在蓝图或 C++ 中设置。

## 蓝图变量系统

`EAnimParamType` 枚举定义支持的变量类型：

| 枚举值 | 对应 C++ 类型 |
|--------|---------------|
| `Float` | `float` |
| `Int` | `int32` |
| `Bool` | `bool` |
| `Vector` | `FVector` |
| `Color` | `FLinearColor` |
| `Vector2D` | `FVector2D` |

`TAnimParamTraits<T, Owner>` 模板在编译期将每种类型映射到对应的 `TMap` 成员，支撑 `SetBlueprintVariable()` 的类型安全多重载。
