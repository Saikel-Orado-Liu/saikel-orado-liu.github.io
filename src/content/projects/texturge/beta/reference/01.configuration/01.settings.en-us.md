# Configuration Reference

Texturge Beta manages plugin behavior through Project Settings and configuration assets. All settings can be adjusted in-editor at runtime without engine restart.

## Project Settings

| Category | Parameter | Type | Default | Description |
|----------|-----------|------|---------|-------------|
| Rendering | `Texturge.DefaultFont` | `FSoftObjectPath` | `EngineFont` | Default font asset path |
| Rendering | `Texturge.MaxCharPerDraw` | `int32` | `4096` | Maximum characters per draw call |
| Rendering | `Texturge.AtlasCacheSize` | `int32` | `1024` | Glyph atlas cache size in pixels |
| Animation | `Texturge.TickInterval` | `float` | `0.016` | Animation tick interval in seconds |
| Animation | `Texturge.DefaultFPS` | `float` | `60.0` | Default keyframe sample rate |
| Animation | `Texturge.MaxActiveTracks` | `int32` | `128` | Maximum concurrently active tracks |
| Debug | `Texturge.EnableStats` | `bool` | `false` | Enable performance stats HUD |
| Debug | `Texturge.LogLevel` | `int32` | `2` | Log verbosity (0=Off, 3=Verbose) |

## Configuration Asset

The plugin auto-generates a `TexturgeConfig` DataAsset at `Content/Texturge/Config/`.

```cpp
UCLASS(BlueprintType)
class UTexturgeConfig : public UDataAsset
{
    UPROPERTY(EditAnywhere, Category = "Rendering")
    TSoftObjectPtr<UFont> DefaultFont;

    UPROPERTY(EditAnywhere, Category = "Rendering")
    int32 MaxCharPerDraw = 4096;

    UPROPERTY(EditAnywhere, Category = "Animation")
    float DefaultFPS = 60.0f;
};
```

Retrieve the config instance in Blueprints via the `Get Texturge Config` node.
