# 调度系统参考

调度系统控制每个字形动画的时间线与整体播放状态。核心数据结构为 `FGlyphScheduleInfo`，配合 `UGlyphAnimationLayer` 的分类调度 API 以及动画阶段控制器实现精确的时间管理。

## FGlyphScheduleInfo

每个字形在文本中拥有独立的调度信息，控制其动画的开始时间和行为：

| 字段 | 类型 | 说明 |
|------|------|------|
| `StartDelay` | `float` | 字形动画开始前的基延迟（秒） |
| `InitialDelay` | `float` | 额外逐字形错开延迟（秒） |
| `Skip` | `bool` | 为 `true` 时该字形被排除在动画之外 |
| `Scale` | `float` | 曲线值缩放调整参数 |
| `Offset` | `float` | 曲线值偏移调整参数 |
| `Jitter` | `float` | 曲线值抖动（随机化）参数 |

6 个值调整参数（`Scale`、`Offset`、`Jitter` 等）作用于动画曲线的输出值，允许在不修改原始曲线数据的情况下微调每个字形的动画强度。

### 延迟计算公式

单个字形的实际开始时间：

```
ActualStart = StartDelay + (GlyphIndex × InitialDelay)
```

被 `Skip` 标记的字形不参与动画，其 `InitialDelay` 也不计入后续字形的索引累积（除非另有配置）。

## UGlyphAnimationLayer 调度 API

`UGlyphAnimationLayer` 提供批量与逐字形调度方法：

### 批量调度方法

| 方法 | 签名 | 说明 |
|------|------|------|
| `SetAllGlyphDelay` | `(float Delay)` | 将所有字形（不含已跳过的）的 `StartDelay` 设为指定值 |
| `SkipAllWhitespace` | `(bool bSkip)` | 批量跳过/取消跳过所有空白字符（空格、制表符等） |

### 逐字形调度方法

| 方法 | 签名 | 说明 |
|------|------|------|
| `SetDelayAt` | `(int32 Index, float Delay)` | 设置指定索引字形的 `StartDelay` |
| `SkipAt` | `(int32 Index, bool bSkip)` | 设置指定索引字形的 `Skip` 标志 |

## 字形分类方法

`UGlyphAnimationLayer` 提供按字符类别分类的查询方法，用于为不同字符类别配置不同的延迟策略：

| 方法 | 返回类型 | 说明 |
|------|----------|------|
| `IsWhitespace` | `bool` | 判断是否为空白字符（空格、制表符、换行等） |
| `IsDigit` | `bool` | 判断是否为数字 (0–9) |
| `IsLetter` | `bool` | 判断是否为字母 (A–Z, a–z) |
| `IsPunctuation` | `bool` | 判断是否为标点符号 |
| `IsCJK` | `bool` | 判断是否为 CJK 字符（中日韩统一表意文字） |
| `IsSpecial` | `bool` | 判断是否为特殊字符（非上述类别） |

### 分类调度示例

典型用法：为不同类型字符设置不同的 `InitialDelay`，使数字比字母更快出现：

1. 遍历所有字形
2. 对 `IsDigit` 返回 `true` 的字形设置较小延迟
3. 对 `IsLetter` 返回 `true` 的字形设置中等延迟
4. 对 `IsPunctuation` 返回 `true` 的字形设置较大延迟

## 播放模式

### EPlayMode

控制整个动画的播放方向：

| 枚举值 | 说明 |
|--------|------|
| `Forward` | 正向播放，从第一个字形到最后一个 |
| `Reverse` | 反向播放，从最后一个字形到第一个 |
| `PingPong` | 往返播放，到达终点后反向，到达起点后再正向 |

### EPlaybackMode

控制动画的时间驱动方式：

| 枚举值 | 说明 |
|--------|------|
| `Duration` | 固定时长模式 —— 动画在指定秒数内完成，不受文本长度影响 |
| `CPS` | 逐字速度模式 —— 动画时长 = 字符数 ÷ CPS；文本越长总时长越大 |

## 阶段系统

Texturge Beta 采用三阶段动画系统，每个文本动画包含三个阶段：

| 枚举值 | 说明 |
|--------|------|
| `Intro` | 入场阶段（可选），控制文本出现时的动画 |
| `Default` | 默认阶段（必选），持续的常态动画 |
| `Outro` | 出场阶段（可选），控制文本消失时的动画 |
| `None` | 隐藏状态，文本不可见 |
| `GlyphEditor` | 字形编辑器专用状态，隐藏于运行时 API |

### EStagePlayDirection

阶段级别的播放方向控制：

| 枚举值 | 说明 |
|--------|------|
| `Forward` | 正向播放阶段动画 |
| `Reverse` | 反向播放阶段动画 |
| `PingPong` | 往返播放阶段动画 |

### EStagePlaybackState

阶段当前的播放状态：

| 枚举值 | 说明 |
|--------|------|
| `Stopped` | 阶段已停止，未激活 |
| `Playing` | 阶段正在播放中 |
| `Paused` | 阶段已暂停，可恢复 |
| `Complete` | 阶段播放已完成 |

## FStageTransitionConfig

每个阶段的过渡配置结构体：

| 字段 | 类型 | 说明 |
|------|------|------|
| `Stage` | `EAnimationStage` | 目标阶段类型 |
| `TransitionDuration` | `float` | 进入此阶段的交叉淡化时长（秒） |
| `BlendCurve` | 曲线 | 过渡期间的混合权重曲线 |

阶段过渡由 `UTextAnimationStageController` 管理：

1. 控制器跟踪当前活跃阶段
2. 当新的阶段被请求时，启动过渡过程
3. 在 `TransitionDuration` 期间同时评估退出阶段和进入阶段的动画
4. 按 `BlendCurve` 定义的权重插值输出最终状态
