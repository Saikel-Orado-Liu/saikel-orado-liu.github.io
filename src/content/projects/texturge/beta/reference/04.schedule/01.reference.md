# 调度系统参考

调度系统控制每个字形动画的时间线与播放状态。核心数据结构为 `FGlyphScheduleInfo`，配合 `UGlyphAnimationLayer` / `UGlyphAnimationFactory` 的调度 API、`FAnimationCompiler::BuildScheduleInfos` 与 `UTextAnimationStageController` 实现精确的时间管理。

## FGlyphScheduleInfo

每个字形（Unicode 码点）在编译时拥有独立的调度信息。前 6 个字段由系统预填（BlueprintReadOnly），后 2 个由设计师设置（BlueprintReadWrite）：

| 字段 | 类型 | 读写 | 说明 |
|:---|:---|:---|:---|
| `GlyphIndex` | `int32` | 只读 | 字形在文本中的索引 |
| `GlyphString` | `FString` | 只读 | 单字形字符串（支持 U+FFFC 内嵌对象占位符） |
| `bIsWhitespace` | `bool` | 只读 | 空白字形 |
| `bIsPunctuation` | `bool` | 只读 | 标点符号 |
| `bIsCJK` | `bool` | 只读 | 中日韩文字 |
| `bIsDecorator` | `bool` | 只读 | 内嵌对象装饰器 |
| `StartDelay` | `float` | 读写 | 动画起始延迟（秒） |
| `bSkipAnimation` | `bool` | 读写 | 跳过此字形在本阶段的动画 |

> [!NOTE]
> `FGlyphScheduleInfo` 不再按阶段分离延迟字段——每个 `Build*Animation` 事件独立处理一个阶段，设置 `StartDelay` 即作用于当前构建的阶段。

### 生成方式

```cpp
// C++：静态编译函数
TArray<FGlyphScheduleInfo> Schedule = FAnimationCompiler::BuildScheduleInfos(Text);

// 蓝图：UTextAnimInstance 静态节点「构建调度信息」
// 输入 Text，输出 TArray<FGlyphScheduleInfo>（预填索引、字符与分类）
```

## 字形分类

分类在 `BuildScheduleInfos` 中预填，按 Unicode 码点判定（`Texturge::Unicode` 工具）：

| 分类 | 判定依据 |
|:---|:---|
| `Whitespace` | 空白字符（空格、制表符、换行等） |
| `Punctuation` | 标点符号（含 CJK 标点 `0x3000-0x303F` 等） |
| `CJK` | 中日韩统一表意文字（含扩展 A~I、兼容表意）、假名、谚文音节 |
| `Decorator` | U+FFFC 内嵌对象占位符 |

## Layer / Factory 调度 API

`UGlyphAnimationLayer`（Category `Texturge|层|调度`）与 `UGlyphAnimationFactory`（Category `Texturge|工厂|调度`）提供同构的调度接口。**`Index = -1` 表示作用于全部字形**。

### 批量与逐字形方法

| 蓝图函数 | 签名 | 说明 |
|:---|:---|:---|
| `设置字形延迟`（`SetDelayAt`） | `(int32 Index, float Delay)` | 设置延迟（-1 = 全部，叠加错峰语义） |
| `跳过字形`（`SkipAt`） | `(int32 Index)` | 跳过字形动画（-1 = 全部） |
| `获取起始延迟`（`GetStartDelayAt`） | `(int32 Index) → float` | 查询起始延迟 |
| `设置起始延迟值`（`SetStartDelayAt`） | `(int32 Index, float Value)` | 绝对设置起始延迟（秒） |
| `获取跳过动画`（`GetSkipAnimationAt`） | `(int32 Index) → bool` | 查询跳过标记 |
| `设置跳过动画`（`SetSkipAnimationAt`） | `(int32 Index, bool bSkip)` | 设置跳过标记 |
| `设置动画剪切`（`SetAnimationClipAt`） | `(float FrontTrim, float BackTrim)` | 前端/末端裁剪（秒，播放轴口径，Layer / Factory 均有） |
| `获取字形数`（`GetGlyphCount`） | `() → int32` | 调度数组长度 |
| `获取字形字符串`（`GetGlyphStringAt`） | `(int32 Index) → FString` | 单字形字符串 |
| `是空白字形`（`IsWhitespaceAt`） | `(int32 Index) → bool` | 分类查询 |
| `是标点符号`（`IsPunctuationAt`） | `(int32 Index) → bool` | 分类查询 |
| `是中日韩文字`（`IsCJKAt`） | `(int32 Index) → bool` | 分类查询 |
| `是装饰器字形`（`IsDecoratorAt`） | `(int32 Index) → bool` | 分类查询 |

### 延迟计算公式与调用顺序

```
第 i 个字形实际延迟 = SetStartDelayAt 值 + i × SetDelayAt 值（SetDelayAt(-1, Y) 后）
```

> [!TIP]
> **先 `SetStartDelayAt(-1, X)` 再 `SetDelayAt(-1, Y)`** → 第 i 个字形延迟 = X + i × Y（错峰）。反序调用时 `SetStartDelayAt` 为绝对设置（Set 语义）会覆盖错峰结果，属预期行为。

**蓝图分类调度示例**（跳过所有空白，逐字错峰 0.05s）：

```
[Layer]
    → [设置起始延迟值 (Layer, -1, 0.0)]
    → [设置字形延迟 (Layer, -1, 0.05)]      ← 错峰
    → [跳过字形 (Layer, -1)]                 ← 配合分类：所有字形先跳过，
    → [是空白字形 (Layer, i)] → Branch → 非空白恢复 [设置跳过动画 (Layer, i, false)]
```

## C++ 调度构建工具

`FGlyphScheduleBuilder`（纯静态工具，不暴露蓝图）提供程序化调度：

| 方法 | 说明 |
|:---|:---|
| `AddPerGlyphDelay(Schedule, float DelayPerSec)` | 逐字形均匀错峰 |
| `SkipWhitespace(Schedule)` | 批量跳过所有空白字形 |
| `SetDelayAt(Schedule, int32 Index, float Delay)` | 设置指定索引延迟 |
| `SkipAt(Schedule, int32 Index)` | 跳过指定索引字形 |

## 播放方向与循环

### EPlayMode（层级播放方向）

| 枚举值 | 说明 |
|:---|:---|
| `Forward` | 正向播放 |
| `Reverse` | 反向播放 |
| `PingPong` | 来回交替播放 |

- 层级播放方向存储于 `FPerLayerCurves::PlayDirection`，求值时对 `LocalTime` 做时间包裹
- **循环次数独立控制**：`FPerLayerCurves::NumberOfLoops`（0 = 无限循环；有限循环 = `LayerDuration × Loops`）
- 阶段级方向由 `EStagePlayDirection` 控制（同三个选项）

### EPlaybackMode（播放时序）

由 `UTextAnimator` 的 `SetPlaybackMode` 控制（富文本路径）：

| 枚举值 | 说明 |
|:---|:---|
| `Duration` | 按总时长匀速播放 |
| `CPS` | 每秒字形数模式（`SetCPS`，下限 1.0） |

## 阶段系统

动画阶段由 `EAnimationStage` 枚举定义，由 `UTextAnimationStageController` 推进：

| 枚举值 | 说明 |
|:---|:---|
| `Intro` | 入场阶段 |
| `Default` | 默认阶段 |
| `Outro` | 出场阶段 |
| `None` | 空阶段（Hidden） |
| `GlyphEditor` | 编辑器专用（Hidden） |

### EStagePlayDirection / EStagePlaybackState

```cpp
enum class EStagePlayDirection : uint8 { Forward, Reverse, PingPong };
enum class EStagePlaybackState : uint8 { Stopped, Playing, Paused, Complete };
```

### FStageTransitionConfig

位于 `UTextAnimationBlueprint::StageTransitionConfig`：

| 字段 | 类型 | 默认值 | 说明 |
|:---|:---|:---|:---|
| `IntroToDefaultCrossFade` | `float` | `0.1` | 入场 → 默认过渡时长（秒） |
| `DefaultToOutroCrossFade` | `float` | `0.1` | 默认 → 出场过渡时长（秒） |
| `EasingFunc` | `TEnumAsByte<EEasingFunc::Type>` | `Linear` | 过渡缓动函数 |

阶段切换流程：

1. 控制器跟踪 `CurrentStage` 与 `StageTime`
2. `TickAnimation` 推进时钟，检测阶段边界（`GetNextStageAfter`）
3. 阶段结束调用 `TransitionTo(NextStage)` 切换并广播 `OnStageChanged(From, To)`
4. 全部阶段完成广播 `OnAnimationComplete`
