# Schedule System Reference

The schedule system manages timeline execution, command queuing, and event dispatch for animation tracks. The core class is `UTexturgeScheduler`.

## Schedule Commands

| Command | Parameters | Description |
|---------|------------|-------------|
| `Play` | `TrackIndex`, `LoopCount` | Starts track playback; `LoopCount=-1` for infinite loop |
| `Pause` | `TrackIndex` | Pauses the specified track, retaining current progress |
| `Stop` | `TrackIndex` | Stops the track and resets to origin |
| `Seek` | `TrackIndex`, `Time` | Jumps to a given time point in seconds |
| `Queue` | `TrackIndex`, `Delay` | Enqueues for deferred start after `Delay` seconds |

## Playback States

`ETexturgePlayState`
: `Idle` — Track is inactive
: `Playing` — Forward playback in progress
: `Paused` — Paused and holding
: `Finished` — Playback completed
: `Error` — Execution error

## Event Delegates

```cpp
DECLARE_DYNAMIC_MULTICAST_DELEGATE_OneParam(FOnTrackFinished, int32, TrackIndex);
DECLARE_DYNAMIC_MULTICAST_DELEGATE_TwoParams(FOnTrackStateChanged, int32, TrackIndex, ETexturgePlayState, NewState);
```

| Delegate | Trigger |
|----------|---------|
| `OnTrackFinished` | Track playback finished (non-looping) |
| `OnTrackStateChanged` | Any track state transition |
| `OnGlobalLoop` | Global schedule loop iteration |

The scheduler uses the `TG_DuringPhysics` tick group, independent of the game thread, ensuring animation updates run after any physics simulation.
