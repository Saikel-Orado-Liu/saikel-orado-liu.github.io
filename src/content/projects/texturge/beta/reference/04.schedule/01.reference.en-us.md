# Schedule System Reference

The scheduling system controls each glyph animation's timeline and playback state. The core data structure is `FGlyphScheduleInfo`, combined with the scheduling APIs of `UGlyphAnimationLayer` / `UGlyphAnimationFactory`, `FAnimationCompiler::BuildScheduleInfos`, and `UTextAnimationStageController` for precise time management.

## FGlyphScheduleInfo

Each glyph (Unicode code point) has independent scheduling info at compile time. The first 6 fields are system-prefilled (BlueprintReadOnly); the last 2 are set by the designer (BlueprintReadWrite):

| Field | Type | Access | Description |
|:---|:---|:---|:---|
| `GlyphIndex` | `int32` | read-only | glyph index in the text |
| `GlyphString` | `FString` | read-only | single-glyph string (supports U+FFFC embedded object placeholder) |
| `bIsWhitespace` | `bool` | read-only | whitespace glyph |
| `bIsPunctuation` | `bool` | read-only | punctuation |
| `bIsCJK` | `bool` | read-only | CJK characters |
| `bIsDecorator` | `bool` | read-only | embedded object decorator |
| `StartDelay` | `float` | read/write | animation start delay (seconds) |
| `bSkipAnimation` | `bool` | read/write | skip this glyph's animation in this stage |

> [!NOTE]
> `FGlyphScheduleInfo` no longer separates delay fields per stage — each `Build*Animation` event independently handles one stage; setting `StartDelay` applies to the stage currently being built.

### Generation

```cpp
// C++: static compile function
TArray<FGlyphScheduleInfo> Schedule = FAnimationCompiler::BuildScheduleInfos(Text);

// Blueprint: UTextAnimInstance static node "Build Schedule Info"
// Input Text, output TArray<FGlyphScheduleInfo> (prefilled index, character, classification)
```

## Glyph Classification

Classification is prefilled in `BuildScheduleInfos`, determined per Unicode code point (via the `Texturge::Unicode` utilities):

| Classification | Determination |
|:---|:---|
| `Whitespace` | whitespace characters (spaces, tabs, newlines, etc.) |
| `Punctuation` | punctuation (including CJK punctuation `0x3000-0x303F` etc.) |
| `CJK` | CJK unified ideographs (including Ext A–I, compatibility ideographs), kana, Hangul syllables |
| `Decorator` | U+FFFC embedded object placeholder |

## Layer / Factory Scheduling APIs

`UGlyphAnimationLayer` (Category `Texturge|Layer|Scheduling`) and `UGlyphAnimationFactory` (Category `Texturge|Factory|Scheduling`) provide isomorphic scheduling interfaces. **`Index = -1` applies to all glyphs**.

### Batch & Per-Glyph Methods

| Blueprint function | Signature | Description |
|:---|:---|:---|
| `Set Glyph Delay` (`SetDelayAt`) | `(int32 Index, float Delay)` | set delay (-1 = all, additive stagger semantics) |
| `Skip Glyph` (`SkipAt`) | `(int32 Index)` | skip glyph animation (-1 = all) |
| `Get Start Delay` (`GetStartDelayAt`) | `(int32 Index) → float` | query start delay |
| `Set Start Delay Value` (`SetStartDelayAt`) | `(int32 Index, float Value)` | absolute start delay (seconds) |
| `Get Skip Animation` (`GetSkipAnimationAt`) | `(int32 Index) → bool` | query skip flag |
| `Set Skip Animation` (`SetSkipAnimationAt`) | `(int32 Index, bool bSkip)` | set skip flag |
| `Set Animation Clip` (`SetAnimationClipAt`) | `(float FrontTrim, float BackTrim)` | front/back trim (seconds, playback axis; on both Layer and Factory) |
| `Get Glyph Count` (`GetGlyphCount`) | `() → int32` | schedule array length |
| `Get Glyph String` (`GetGlyphStringAt`) | `(int32 Index) → FString` | single-glyph string |
| `Is Whitespace` (`IsWhitespaceAt`) | `(int32 Index) → bool` | classification query |
| `Is Punctuation` (`IsPunctuationAt`) | `(int32 Index) → bool` | classification query |
| `Is CJK` (`IsCJKAt`) | `(int32 Index) → bool` | classification query |
| `Is Decorator Glyph` (`IsDecoratorAt`) | `(int32 Index) → bool` | classification query |

### Delay Formula & Call Order

```
actual delay of glyph i = SetStartDelayAt value + i × SetDelayAt value (after SetDelayAt(-1, Y))
```

> [!TIP]
> **`SetStartDelayAt(-1, X)` first, then `SetDelayAt(-1, Y)`** → glyph i delay = X + i × Y (staggered). In reverse order, `SetStartDelayAt` uses absolute-set semantics and overwrites the stagger result — expected behavior.

**Blueprint classification scheduling example** (skip all whitespace, stagger 0.05s per glyph):

```
[Layer]
    → [Set Start Delay Value (Layer, -1, 0.0)]
    → [Set Glyph Delay (Layer, -1, 0.05)]      ← stagger
    → [Skip Glyph (Layer, -1)]             ← with classification: skip all first,
    → [Is Whitespace (Layer, i)] → Branch → restore non-whitespace [Set Skip Animation (Layer, i, false)]
```

## C++ Schedule Building Utilities

`FGlyphScheduleBuilder` (pure static utility, not exposed to Blueprint) provides programmatic scheduling:

| Method | Description |
|:---|:---|
| `AddPerGlyphDelay(Schedule, float DelayPerSec)` | uniform per-glyph staggering |
| `SkipWhitespace(Schedule)` | batch skip all whitespace glyphs |
| `SetDelayAt(Schedule, int32 Index, float Delay)` | set delay for the given index |
| `SkipAt(Schedule, int32 Index)` | skip the glyph at the given index |

## Play Direction & Looping

### EPlayMode (Layer-level Play Direction)

| Enum value | Description |
|:---|:---|
| `Forward` | forward playback |
| `Reverse` | reverse playback |
| `PingPong` | alternating forward/reverse playback |

- Layer-level play direction is stored in `FPerLayerCurves::PlayDirection`; evaluation wraps `LocalTime`
- **Loop count is independent**: `FPerLayerCurves::NumberOfLoops` (0 = infinite loop; finite loop = `LayerDuration × Loops`)
- Stage-level direction is controlled by `EStagePlayDirection` (same three options)

### EPlaybackMode (Playback Timing)

Controlled by `UTextAnimator`'s `SetPlaybackMode` (rich text path):

| Enum value | Description |
|:---|:---|
| `Duration` | uniform playback over the total duration |
| `CPS` | glyphs-per-second mode (`SetCPS`, floor 1.0) |

## Stage System

Animation stages are defined by the `EAnimationStage` enum and advanced by `UTextAnimationStageController`:

| Enum value | Description |
|:---|:---|
| `Intro` | intro stage |
| `Default` | default stage |
| `Outro` | outro stage |
| `None` | empty stage (Hidden) |
| `GlyphEditor` | editor-only (Hidden) |

### EStagePlayDirection / EStagePlaybackState

```cpp
enum class EStagePlayDirection : uint8 { Forward, Reverse, PingPong };
enum class EStagePlaybackState : uint8 { Stopped, Playing, Paused, Complete };
```

### FStageTransitionConfig

Located on `UTextAnimationBlueprint::StageTransitionConfig`:

| Field | Type | Default | Description |
|:---|:---|:---|:---|
| `IntroToDefaultCrossFade` | `float` | `0.1` | intro → default transition duration (seconds) |
| `DefaultToOutroCrossFade` | `float` | `0.1` | default → outro transition duration (seconds) |
| `EasingFunc` | `TEnumAsByte<EEasingFunc::Type>` | `Linear` | transition easing function |

Stage transition flow:

1. The controller tracks `CurrentStage` and `StageTime`
2. `TickAnimation` advances the clock and detects stage boundaries (`GetNextStageAfter`)
3. At stage end, `TransitionTo(NextStage)` switches and broadcasts `OnStageChanged(From, To)`
4. When all stages complete, `OnAnimationComplete` is broadcast
