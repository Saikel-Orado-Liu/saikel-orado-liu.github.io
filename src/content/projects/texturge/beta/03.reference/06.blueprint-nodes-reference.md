# Blueprint 节点参考

Texturge Beta 提供的所有 Blueprint 可调用节点与委托的完整参考。

## UAnimatedTextBlock

继承自 UTextBlock，支持逐字动画的 UMG 控件。

### 属性

| 属性 | 类型 | 说明 |
|------|------|------|
| TextAnimationBlueprint | UTextAnimationBlueprint* | 动画蓝图资产 |
| ParameterOverrides | UAnimParameterOverrides* | Blueprint 变量覆盖 |
| bAutoPlay | bool | 是否自动播放 |
| bLoopPlayback | bool | 是否循环播放 |

### 方法

| 方法 | 参数 | 说明 |
|------|------|------|
| **Play** | — | 开始播放动画 |
| **Pause** | — | 暂停动画 |
| **Resume** | — | 恢复播放 |
| **Stop** | — | 停止并重置动画 |
| **SkipToEnd** | — | 跳转到动画末尾 |
| **IsAnimating** | — | 返回是否正在播放 |
| **SetBlueprintVariable** | FName Name, float Value | 更新 float 变量 |
| **SetBlueprintVariable_Int** | FName Name, int32 Value | 更新 int32 变量 |
| **SetBlueprintVariable_Bool** | FName Name, bool Value | 更新 bool 变量 |
| **SetBlueprintVectorVariable** | FName Name, FVector Value | 更新 FVector 变量 |
| **SetBlueprintColorVariable** | FName Name, FLinearColor Value | 更新 FLinearColor 变量 |
| **SetBlueprintVector2DVariable** | FName Name, FVector2D Value | 更新 FVector2D 变量 |
| **GetStageController** | — | 获取 StageController 引用 |

### 委托

| 委托 | 参数 | 说明 |
|------|------|------|
| **OnCharacterRevealedBP** | int32 CharIndex | 字符显示时触发 |
| **OnAnimationCompleteBP** | — | 动画完成时触发 |

## UTextAnimationStageController

运行时动画引擎，管理播放、暂停、求值和阶段转换。

### 方法

| 方法 | 参数 | 说明 |
|------|------|------|
| **Play** | — | 开始播放 |
| **Pause** | — | 暂停 |
| **Resume** | — | 恢复 |
| **Stop** | — | 停止并重置 |
| **RevealAll** | — | 立即显示所有字形 |
| **SetPlayDirection** | EStagePlayDirection | 设置播放方向 |
| **SetLoop** | bool bLoop | 设置是否循环 |
| **TickAnimation** | float DeltaTime | 每帧更新 |
| **EvaluateAllGlyphs** | TArray\<FGlyphAnimationState\>& OutStates | 求值所有字形状态 |
| **IsPlaying** | — | 是否正在播放 |
| **IsComplete** | — | 是否已完成 |
| **GetCurrentStage** | EAnimationStage | 当前阶段 |
| **GetStageTime** | float | 当前阶段时间 |
| **GetRevealedGlyphCount** | int32 | 已显示字形数 |
| **GetTotalGlyphCount** | int32 | 总字形数 |

### 委托

| 委托 | 参数 | 说明 |
|------|------|------|
| **OnGlyphRevealed** | int32 GlyphIndex | 字形显示时触发 |
| **OnStageChanged** | EAnimationStage Old, EAnimationStage New | 阶段变更时触发 |
| **OnAnimationComplete** | — | 动画完成时触发 |

### 枚举

**EStagePlayDirection**：Forward, Reverse, PingPong

**EStagePlaybackState**：Stopped, Playing, Paused, Complete

| **SetPlaybackMode** | EPlaybackMode | 设置播放模式 |
| **SetCPS** | float CPS | 设置打字速度 |
| **SetPlayMode** | EPlayMode | 设置播放方向 |
| **SetPlaySpeedMultiplier** | float | 设置速度倍率 |
| **SetSequentialPlayback** | bool | 设置顺序播放 |
| **SetLayoutSize** | FVector2D | 设置布局尺寸 |
| **SetTextStyle** | FTextBlockStyle | 设置文本样式 |

| **SkipToEnd** | — | 跳转末尾 |
| **IsAnimating** | — | 是否在动画中 |
| **GetCurrentCharIndex** | int32 | 当前字符索引 |
