# Animation Track Types Reference

Texturge supports 10 animation track types covering all dimensions of glyph transformation.

## Track Structure

Each `FTextAnimationTrack` contains these core properties (marked @deprecated in Beta but still readable):

| Property | Type | Description |
|----------|------|-------------|
| TrackId | FGuid | Unique identifier |
| TrackName | FName | Track name |
| TrackType | ETextAnimationTrackType | Track type enum |
| StartTime | float | Start time |
| Duration | float | Duration |
| TrackWeight | float | Track weight (0.0~1.0) |
| bEnabled | bool | Whether enabled |
| BlendMode | ETextAnimationBlendMode | Blend mode |
| KeyFrames | TArray\<FKeyFrame\> | Keyframe array |
| ApplicationMode | ECharacterApplicationMode | Character application mode |
| TimingMode | ETextAnimationTimingMode | Timing mode |

## 10 Track Types

### 1. Opacity

| Item | Value |
|------|-------|
| Type | Float |
| Range | 0.0 ~ 1.0 |
| Default | 1.0 (fully visible) |
| Use | Fade in/out effects |
| Special | bInvertOpacity: inverts logic (1.0→hidden, 0.0→visible) |

### 2. LetterSpacing

| Item | Value |
|------|-------|
| Type | Float |
| Range | Any float (pixels) |
| Default | 0.0 |
| Use | Text expand/shrink effects |

### 3. Rotation

| Item | Value |
|------|-------|
| Type | Float |
| Range | Any angle (degrees) |
| Default | 0.0 |
| Use | Glyph rotation animation |
| Note | Rotates around Pivot point |

### 4. Translation

| Item | Value |
|------|-------|
| Type | FVector2D |
| Range | Any offset (pixels) |
| Default | (0, 0) |
| Sub-channels | TranslationX, TranslationY |
| Use | Slide in/out, bounce effects |

### 5. Scale

| Item | Value |
|------|-------|
| Type | FVector2D |
| Range | Any scale factor |
| Default | (1.0, 1.0) |
| Sub-channels | ScaleX, ScaleY |
| Use | Enlarge/shrink, elastic effects |

### 6. Shear

| Item | Value |
|------|-------|
| Type | FVector2D |
| Range | Any shear value |
| Default | (0, 0) |
| Sub-channels | ShearX, ShearY |
| Use | Skew/italic effects |

### 7. Pivot

| Item | Value |
|------|-------|
| Type | FVector2D |
| Range | 0.0 ~ 1.0 (relative to glyph) |
| Default | (0.5, 0.5) (glyph center) |
| Sub-channels | PivotX, PivotY |
| Use | Control rotation/scale pivot point |

### 8. ShadowOffset

| Item | Value |
|------|-------|
| Type | FVector2D |
| Range | Any offset |
| Default | (0, 0) |
| Sub-channels | ShadowOffsetX, ShadowOffsetY |
| Use | Shadow movement animation |

### 9. Color

| Item | Value |
|------|-------|
| Type | FLinearColor |
| Range | 0.0 ~ 1.0 per channel |
| Default | White (1, 1, 1, 1) |
| Sub-channels | ColorR, ColorG, ColorB, ColorA |
| Use | Color gradient, flicker effects |

### 10. ShadowColor

| Item | Value |
|------|-------|
| Type | FLinearColor |
| Range | 0.0 ~ 1.0 per channel |
| Default | Transparent (0, 0, 0, 0) |
| Sub-channels | ShadowColorR/G/B/A |
| Use | Shadow color gradient |

## Keyframe Interpolation Types

| Type | Description | Curve Shape |
|------|-------------|-------------|
| **Linear** | Linear interpolation | Straight line |
| **Cubic** | Cubic spline interpolation | Smooth curve (adjustable tangents) |
| **Constant** | Constant (no transition) | Step |
| **CubicInOut** | Cubic ease-in-out | S-curve |

## Character Application Modes

| Mode | Description |
|------|-------------|
| **PerCharacter** | Each character independently (offset start time) |
| **Interval** | Applied at intervals (ApplicationInterval) |
| **Random** | Random probability (RandomProbability) determines application |

## Timing Modes

| Mode | Description |
|------|-------------|
| **PerCharacterDuration** | Independent duration per character |
| **TotalDuration** | Total text duration evenly distributed |
