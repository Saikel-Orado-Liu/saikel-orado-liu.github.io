# Blueprint Nodes Reference

Complete reference of all Blueprint-callable nodes and delegates provided by Texturge Beta.

## UAnimatedTextBlock

UMG widget extending UTextBlock with per-character animation support.

### Properties

| Property | Type | Description |
|----------|------|-------------|
| TextAnimationBlueprint | UTextAnimationBlueprint* | Animation blueprint asset |
| ParameterOverrides | UAnimParameterOverrides* | Blueprint variable overrides |
| bAutoPlay | bool | Auto-play on construct |
| bLoopPlayback | bool | Loop playback |

### Methods

| Method | Parameters | Description |
|--------|------------|-------------|
| **Play** | — | Start animation playback |
| **Pause** | — | Pause animation |
| **Resume** | — | Resume playback |
| **Stop** | — | Stop and reset animation |
| **SkipToEnd** | — | Jump to animation end |
| **IsAnimating** | — | Returns whether currently playing |
| **SetBlueprintVariable** | FName Name, float Value | Update float variable |
| **SetBlueprintVariable_Int** | FName Name, int32 Value | Update int32 variable |
| **SetBlueprintVariable_Bool** | FName Name, bool Value | Update bool variable |
| **SetBlueprintVectorVariable** | FName Name, FVector Value | Update FVector variable |
| **SetBlueprintColorVariable** | FName Name, FLinearColor Value | Update FLinearColor variable |
| **SetBlueprintVector2DVariable** | FName Name, FVector2D Value | Update FVector2D variable |
| **GetStageController** | — | Get StageController reference |

### Delegates

| Delegate | Parameters | Description |
|----------|------------|-------------|
| **OnCharacterRevealedBP** | int32 CharIndex | Fired when character revealed |
| **OnAnimationCompleteBP** | — | Fired when animation completes |

## UTextAnimationStageController

Runtime animation engine managing playback, pause, evaluation, and stage transitions.

### Methods

| Method | Parameters | Description |
|--------|------------|-------------|
| **Play** | — | Start playback |
| **Pause** | — | Pause |
| **Resume** | — | Resume |
| **Stop** | — | Stop and reset |
| **RevealAll** | — | Immediately reveal all glyphs |
| **SetPlayDirection** | EStagePlayDirection | Set play direction |
| **SetLoop** | bool bLoop | Set loop |
| **TickAnimation** | float DeltaTime | Per-frame update |
| **EvaluateAllGlyphs** | TArray\<FGlyphAnimationState\>& OutStates | Evaluate all glyph states |
| **IsPlaying** | — | Whether playing |
| **IsComplete** | — | Whether complete |
| **GetCurrentStage** | EAnimationStage | Current stage |
| **GetStageTime** | float | Current stage time |
| **GetRevealedGlyphCount** | int32 | Revealed glyph count |
| **GetTotalGlyphCount** | int32 | Total glyph count |

### Delegates

| Delegate | Parameters | Description |
|----------|------------|-------------|
| **OnGlyphRevealed** | int32 GlyphIndex | Fired when glyph revealed |
| **OnStageChanged** | EAnimationStage Old, EAnimationStage New | Fired on stage change |
| **OnAnimationComplete** | — | Fired when animation completes |

### Enums

**EStagePlayDirection**: Forward, Reverse, PingPong

**EStagePlaybackState**: Stopped, Playing, Paused, Complete
