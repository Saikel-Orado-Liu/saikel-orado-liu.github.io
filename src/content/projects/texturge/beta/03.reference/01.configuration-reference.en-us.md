# Configuration Reference

Complete project settings reference for Texturge Beta, covering `UTexturgeSettings`, `UTextAnimInstance` blueprint settings, and `AnimatedTextBlock` widget properties.

## Project Settings

Path: **Edit → Project Settings → Texturge**

Accessed via `UTexturgeSettings`:

```cpp
UTexturgeSettings* Settings = UTexturgeSettings::Get();
```

| Category | Property | Type | Default | Description |
|----------|----------|------|---------|-------------|
| Editor | bEnableVerboseLogging | bool | false | Enable verbose log output |
| Editor | BakeCacheWarmup | bool | true | Warm bake cache on startup |
| Editor | MaxBakeTimeMs | int32 | 100 | Max bake time per call (ms) |
| Runtime | DefaultCPS | float | 30.0 | Default typing speed (chars/sec) |
| Runtime | MaxSoundsPerTickDefault | int32 | 8 | Default max sounds per tick |
| Runtime | MinFramesBetweenRebakes | int32 | 3 | Min frame cooldown between re-bakes |

## Parameter Overrides

In `UAnimatedTextBlock` or DataAsset, `ParameterOverrides` allows overriding Blueprint variables. As of Beta v2.4, all six parameter types are supported:

```cpp
// Set in BP
ParameterOverrides->SetFloatParameter(FName("Speed"), 2.0f);
ParameterOverrides->SetIntParameter(FName("Count"), 5);
ParameterOverrides->SetBoolParameter(FName("bEnabled"), true);
ParameterOverrides->SetVectorParameter(FName("Direction"), FVector(0,1,0));
ParameterOverrides->SetColorParameter(FName("Tint"), FLinearColor::Red);
ParameterOverrides->SetVector2DParameter(FName("Offset"), FVector2D(10, 20));
```

Supported parameter types:

| Type | Storage Map | Example Use |
|------|-------------|-------------|
| **float** | FloatOverrides | Duration, speed, weight |
| **int32** | IntOverrides | Loop count, counter |
| **bool** | BoolOverrides | Enable/disable toggles |
| **FVector** | VectorOverrides | 3D direction, position |
| **FLinearColor** | ColorOverrides | Color override, gradient factor |
| **FVector2D** | Vector2DOverrides | 2D offset, size |

Parameter overrides use a `TAnimParamTraits<T, Owner>` unified template with CDO copy isolation, ensuring the Blueprint CDO is never modified.
