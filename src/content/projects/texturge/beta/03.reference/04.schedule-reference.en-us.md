# Glyph Schedule Reference

The glyph scheduling system provides per-character independent scheduling parameter control. This is the core mechanism enabling per-character differentiated animation in Texturge Beta.

## FGlyphScheduleInfo

```cpp
USTRUCT(BlueprintType)
struct FGlyphScheduleInfo
{
    // ── System read-only fields ──
    int32 GlyphIndex;        // Index of glyph in text
    FString GlyphString;     // The glyph character itself
    bool bIsWhitespace;      // Whether whitespace character
    bool bIsPunctuation;     // Whether punctuation
    bool bIsCJK;             // Whether CJK character
    bool bIsDecorator;       // Whether decorator character

    // ── Designer writable fields ──
    float StartDelay = 0.0f;          // Animation start delay (seconds)
    bool bSkipAnimation = false;      // Whether to skip animation
    float ValueScale = 1.0f;          // Curve value scale
    float ValueOffset = 0.0f;         // Curve value offset
    bool bRequiresUniqueCurves = false; // Whether independent curves needed
    float SeedJitter = 0.0f;          // Random jitter seed
};
```

## Read-Only Fields: Auto Classification

`BuildScheduleInfos()` automatically analyzes text and sets classification flags per character:

| Field | Detection | Examples |
|-------|-----------|----------|
| bIsWhitespace | Unicode whitespace class | Space, tab, newline |
| bIsPunctuation | Unicode punctuation class | 。，！？.,!? |
| bIsCJK | CJK unified ideographs / kana / hangul | 你日한 |
| bIsDecorator | `<` `>` tag characters | &lt; &gt; |

> [!NOTE]
> CJK classification uses the complete Unicode range detection from the `Texturge::Unicode` namespace.

## Writable Fields: Schedule Control

### StartDelay

Per-glyph animation start time offset.

```cpp
// Basic: incrementally delay all glyphs by 0.1s
FGlyphScheduleBuilder::SetPerGlyphDelay(Schedule, 0.1f);

// Advanced: set delay for specific glyph
Factory->SetStartDelayAt(3, 0.5f);  // 4th glyph delayed by 0.5s
```

### bSkipAnimation

Skipped glyphs render using `DefaultState` (Identity state).

```cpp
// Skip all whitespace characters
FGlyphScheduleBuilder::SkipWhitespace(Schedule);

// Skip specific glyph
Factory->SkipAt(0, true);  // Skip first glyph
```

### ValueScale & ValueOffset

Global scaling and offset of curve values:

```
EffectiveValue = OriginalValue * ValueScale + ValueOffset
```

```cpp
// Amplify all curve values by 2x
Factory->SetValueScaleAt(Index, 2.0f);

// Offset translation by +10 pixels
Factory->SetValueOffsetAt(Index, 10.0f);
```

### bRequiresUniqueCurves

When `true`, generates an independent curve copy for this glyph (rather than shared reference). Suitable for glyphs needing different curve shapes.

```cpp
// CJK characters typically need unique curves
if (Schedule[i].bIsCJK)
    Factory->SetRequiresUniqueCurvesAt(i, true);
```

### SeedJitter

Provides deterministic "pseudo-random" for random effects:

```cpp
// Use glyph index as jitter seed
Factory->SetSeedJitterAt(i, static_cast<float>(i) * 0.1f);
```

Unlike true random numbers, SeedJitter is deterministic — same input produces same output, ensuring bake cache validity.

## FGlyphScheduleBuilder

Static utility class for batch operations on schedule arrays:

| Method | Description |
|--------|-------------|
| `SetPerGlyphDelay(Schedule, Delay)` | Set incremental delay for all glyphs |
| `SkipWhitespace(Schedule)` | Skip all whitespace characters |
| `SetDelayAt(Schedule, Index, Delay)` | Set delay for specific glyph |
| `SkipAt(Schedule, Index, bSkip)` | Set skip state for specific glyph |
| `SetValueScaleAt(Schedule, Index, Scale)` | Set value scale |
| `SetValueOffsetAt(Schedule, Index, Offset)` | Set value offset |
| `SetRequiresUniqueCurvesAt(Schedule, Index, bReq)` | Set unique curve requirement |
| `SetSeedJitterAt(Schedule, Index, Jitter)` | Set jitter seed |

## Schedule & Layer Relationship

Each `UGlyphAnimationLayer` can have an independent schedule array:

```cpp
// Two layers using different scheduling strategies
Layer1->Schedule → All glyphs delayed 0.05s
Layer2->Schedule → Only CJK chars delayed 0.1s
```

When the Factory merges layers, each layer's schedule independently affects that layer's curve data.

## FGlyphCurveOverride (Micro-Adjustment)

In addition to scheduling parameters, `FGlyphCurveOverride` provides curve-level micro-adjustments per glyph:

| Parameter | Type | Description |
|-----------|------|-------------|
| OpacityMultiplier | float | Opacity multiplier |
| LetterSpacingValue | float | Letter spacing value |
| ScaleMultiplier | FVector2D | Scale multiplier |
| TranslationOffset | FVector2D | Translation offset |
| RotationMultiplier | float | Rotation multiplier |
| ShearValue | FVector2D | Shear value |
| PivotValue | FVector2D | Pivot value |
| ShadowOffsetValue | FVector2D | Shadow offset value |
| ColorMultiplier | FLinearColor | Color multiplier |
| ShadowColorMultiplier | FLinearColor | Shadow color multiplier |

## Best Practices

| Recommendation | Reason |
|----------------|--------|
| Use SeedJitter instead of Random | Deterministic results, doesn't break cache |
| Skip spaces and decorators | Save computation resources |
| CJK uses UniqueCurves | Avoid visual conflicts from shared references |
| Delay values consider character position | First char delay 0, increment after |
| Batch use SetPerGlyphDelay | More efficient than setting individually |
