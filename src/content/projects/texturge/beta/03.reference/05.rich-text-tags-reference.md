# 多格式文本标签参考

Texturge 的多格式文本标签系统支持在文本中嵌入自定义标签，为不同段落应用不同的文本动画蓝图。

## 标签语法

### 基本开闭标签

```
<标签名>文本内容</>
```

```xml
<typewriter>这段文本使用打字机效果</>
```

### 使用 id 属性

```
<anim id="标签名">文本内容</>
```

```xml
<anim id="bounce">这段文本弹入</>
```

当使用 `anim id` 语法时，`id` 的值优先级高于标签名称。如果同时存在，以 `id` 为准。

### 自闭合标签

```
<标签名 />
```

```xml
<img id="icon_sword" />
```

自闭合标签无内容，通常用于装饰器（如图片）。

### 属性标签

```
<标签名 属性="值" />
```

```xml
<delay time="0.5" />
```

### 显式闭合

```
<标签名>文本</标签名>
```

```xml
<wave>波浪效果文本</wave>
```

## 标签与数据资产匹配

标签名称（或 `anim id`）必须与 `TextAnimationDataAsset` 中的条目匹配：

| 标签写法 | DataAsset 条目名 | 匹配结果 |
|----------|-----------------|----------|
| `<typewriter>` | `typewriter` | 匹配 |
| `<anim id="typewriter">` | `typewriter` | 匹配（id 优先） |
| `<Typewriter>` | `typewriter` | 不匹配（大小写敏感） |
| `<typewriter>` | `Typewriter` | 不匹配 |

> [!IMPORTANT]
> 标签匹配严格区分大小写。`<Typewriter>` 和 `<typewriter>` 是不同的标签。

## 转义序列

| 序列 | 字符 |
|------|------|
| `&lt;` | `<` |
| `&gt;` | `>` |
| `&amp;` | `&` |

```xml
<typewriter>用 &lt;tag&gt; 表示标签</>
```

渲染结果：`用 <tag> 表示标签`

## 标签嵌套

标签支持嵌套，内层标签影响其范围内的文本：

```xml
<typewriter>
  这是打字机效果
  <bounce>这是打字机中的弹入效果</bounce>
  回到打字机效果
</typewriter>
```

嵌套规则：
- 内层动画标签覆盖外层动画标签
- 样式标签（如 `<Large>`）叠加而非覆盖
- 闭合标签 `</>` 关闭最近打开的标签

## 混合标准样式

Texturge 动画标签可以与 UMG 多格式文本样式标签混用：

```xml
<typewriter><Large>大字打字机</></> <Small>小字</>
```

支持的样式标签取决于配置的 `StyleSet`（标准 UMG RichTextBlock 机制）。

## 渲染节点类型

`FRenderTreeBuilder` 将解析后的标签树分为四种渲染节点：

| 类型 | 枚举 | 说明 |
|------|------|------|
| AnimationLayer | `ERenderNodeType::AnimationLayer` | 动画层节点（有匹配的 DataAsset 条目） |
| StyleLayer | `ERenderNodeType::StyleLayer` | 样式层节点（标准 UMG 样式） |
| TextContent | `ERenderNodeType::TextContent` | 纯文本内容节点 |
| Decorator | `ERenderNodeType::Decorator` | 装饰器节点（图片等） |

## EntryIndex 匹配优先级

1. **id 属性**：`<anim id="typewriter">` → 用 `id` 值匹配 DataAsset
2. **标签名回退**：`<typewriter>` → 用标签名匹配 DataAsset
3. **无匹配**：标签被视为样式标签（StyleLayer）或忽略

## 示例合集

### 基础用法

```xml
<typewriter>你好世界</>
```

### 多动画混合

```xml
<typewriter>正常文字</> <bounce>弹跳文字</> <wave>波浪文字</>
```

### 嵌套效果

```xml
<typewriter>
  打字中...
  <shake>这段在抖动！</>
  恢复正常了
</typewriter>
```

### 混合样式

```xml
<typewriter><Title>标题动画</></>

<normal><Bold>加粗</Bold> 和 <Italic>斜体</Italic> 的文字</>
```

### 图片装饰器

```xml
<typewriter>获得物品：<img id="item_sword"/> 铁剑</>
```

## 解析器容错

`FTagParser` 具有以下容错能力：

| 错误格式 | 处理方式 |
|----------|----------|
| 未闭合标签 `<tag>` | 视为纯文本 |
| 无效转义 | 保留原始字符 |
| 多余的 `</>` | 忽略 |
| 空标签 `<>` | 忽略 |
| 只含属性的标签 | 保留标签文本 |
