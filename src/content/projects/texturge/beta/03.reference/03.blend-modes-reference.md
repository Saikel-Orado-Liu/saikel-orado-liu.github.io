# 混合模式参考

Texturge 支持四种图层混合模式，决定多层动画如何合成最终效果。这些模式在 `UGlyphAnimationLayer` 和轨道中都可配置。

## 混合模式概览

| 模式 | 枚举值 | 公式 | 用途 |
|------|--------|------|------|
| Additive | `ETextAnimationBlendMode::Additive` | Result = Base + Layer | 叠加效果 |
| Override | `ETextAnimationBlendMode::Override` | Result = Layer（有值属性） | 完全替换 |
| Multiply | `ETextAnimationBlendMode::Multiply` | Result = Base * Layer | 强度调制 |
| CrossFade | `ETextAnimationBlendMode::CrossFade` | Result = Lerp(Base, Layer, t) | 渐变过渡 |

## Additive（叠加）

叠加模式将图层的动画值加到底层上。这是最常用的模式。

### 各属性行为

| 属性 | 叠加公式 | 说明 |
|------|----------|------|
| Opacity | `Base.O + Layer.O` | 值域可能超出 [0,1]，被钳制 |
| Translation | `Base.T + Layer.T` | 位移偏移量相加 |
| Rotation | `Base.R + Layer.R` | 旋转角度相加 |
| Scale | `Base.S * Layer.S` | 缩放采用乘法叠加 |
| Shear | `Base.Sh + Layer.Sh` | 切变值相加 |
| Pivot | `Layer.Pivot` 覆盖 | 采用顶层轴心 |
| Color | `Base.C + Layer.C` | RGB 加法混合 |
| ShadowOffset | `Base.SO + Layer.SO` | 阴影偏移相加 |
| ShadowColor | `Base.SC + Layer.SC` | 阴影颜色加法 |
| LetterSpacing | `Base.LS + Layer.LS` | 字间距相加 |

### 典型用法

```
基础层: Opacity 打字机效果 (0→1)
叠加层: Translation 波浪效果 (上下浮动)
结果:   同时具有打字机和波浪效果
```

## Override（覆盖）

覆盖模式下，图层有值的属性完全替代底层，没有值的属性保留底层数值。

### 规则

- 如果图层的某通道有有效曲线（非空/非零），使用图层值
- 如果图层的某通道无有效曲线，保持基础层值
- 对于 Color 类型通道，Alpha=0 视为无值

### 典型用法

```
基础层: Opacity + Translation 综合动画
覆盖层: Color 颜色（只有颜色通道有值）
结果:   保留基础动画，但颜色被替换
```

## Multiply（正片叠底）

所有属性值进行乘法混合。适合暗化、衰减效果。

### 各属性行为

| 属性 | 公式 | 效果 |
|------|------|------|
| Opacity | `Base.O * Layer.O` | 不透明度降低 |
| Scale | `Base.S * Layer.S` | 缩放合并 |
| Color | `Base.C * Layer.C` | 颜色变暗 |
| 其他 | `Base.X * Layer.X` | 值减小 |

> [!TIP]
> Multiply 模式下的默认值是 (1,1,1,1)，而非 (0,0,0,0)。因为 0 乘以任何值都是 0。

## CrossFade（交叉渐变）

在 Base 和 Layer 之间按权重插值。

### 插值公式

```
Result = Lerp(Base, Layer, Weight)

其中 Weight ∈ [0, 1]
  Weight = 0 → 完全使用 Base
  Weight = 1 → 完全使用 Layer
  Weight = 0.5 → 各 50%
```

### 阶段转换应用

CrossFade 主要用于阶段之间的过渡：

```
Intro Stage  ──[CrossFade]──→  Default Stage  ──[CrossFade]──→  Outro Stage
    Weight: 0 → 1                Weight: 0 → 1
```

`FStageTransitionConfig` 管理这些转换：

```cpp
struct FStageTransitionConfig
{
    FRichCurve IntroToDefaultCrossFade;  // 渐变权重曲线
    FRichCurve DefaultToOutroCrossFade;  // 渐变权重曲线
    EAlphaBlendOption EasingFunc;        // 缓动函数
};
```

## 混合模式选择指南

| 场景 | 推荐模式 | 原因 |
|------|----------|------|
| 叠加多种效果 | Additive | 效果自然叠加 |
| 覆盖默认动画 | Override | 干净替换 |
| 强度衰减/暗化 | Multiply | 乘法降低效果 |
| 阶段过渡 | CrossFade | 平滑渐变 |
| 两个不同风格混合 | Additive + 权重 | 精细控制混合比例 |

## 配置混合模式

### 图层配置

```cpp
UGlyphAnimationLayer* Layer = UGlyphAnimationLayer::CreateLayer(
    Animation,
    ETextAnimationBlendMode::Additive,  // 混合模式
    Schedule,
    Forward,
    1
);
```

### 工厂全局设置

```cpp
Factory->SetLayerBlendMode(LayerIndex, ETextAnimationBlendMode::CrossFade);
```

## 注意事项

| 注意点 | 说明 |
|--------|------|
| 值域钳制 | Additive 可能超出合理范围，会被钳制 |
| 多层顺序 | 图层的添加顺序影响最终结果（先添加 = 底层） |
| CrossFade 权重 | 需要在运行时动态更新权重才能看到渐变效果 |
| Override 无值时 | 并非所有属性都有"无值"概念，需注意默认值行为 |
