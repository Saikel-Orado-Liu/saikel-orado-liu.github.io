# Blend Modes Reference

Texturge supports four layer blend modes that determine how multiple animation layers composite into the final result. These modes are configurable in both `UGlyphAnimationLayer` and tracks.

## Blend Mode Overview

| Mode | Enum Value | Formula | Use Case |
|------|-----------|---------|----------|
| Additive | `ETextAnimationBlendMode::Additive` | Result = Base + Layer | Overlay effects |
| Override | `ETextAnimationBlendMode::Override` | Result = Layer (valued props) | Full replacement |
| Multiply | `ETextAnimationBlendMode::Multiply` | Result = Base * Layer | Intensity modulation |
| CrossFade | `ETextAnimationBlendMode::CrossFade` | Result = Lerp(Base, Layer, t) | Gradual transition |

## Additive

Additive mode adds the layer's animation values onto the base. This is the most commonly used mode.

### Per-Property Behavior

| Property | Additive Formula | Notes |
|----------|-----------------|-------|
| Opacity | `Base.O + Layer.O` | May exceed [0,1], clamped |
| Translation | `Base.T + Layer.T` | Offset addition |
| Rotation | `Base.R + Layer.R` | Angle addition |
| Scale | `Base.S * Layer.S` | Multiplicative for scale |
| Shear | `Base.Sh + Layer.Sh` | Shear addition |
| Pivot | `Layer.Pivot` override | Top layer pivot used |
| Color | `Base.C + Layer.C` | RGB additive blending |
| ShadowOffset | `Base.SO + Layer.SO` | Shadow addition |
| ShadowColor | `Base.SC + Layer.SC` | Shadow color additive |
| LetterSpacing | `Base.LS + Layer.LS` | Spacing addition |

### Typical Usage

```
Base layer:  Opacity typewriter effect (0→1)
Additive:    Translation wave effect (vertical float)
Result:      Both typewriter and wave simultaneously
```

## Override

In Override mode, properties with values in the layer completely replace the base; properties without values retain the base values.

### Rules

- If a layer's channel has valid curves (non-empty/non-zero), use layer value
- If a layer's channel has no valid curve, keep base layer value
- For Color channels, Alpha=0 is treated as no value

### Typical Usage

```
Base layer:  Opacity + Translation composite animation
Override:    Color only (only color channels have values)
Result:      Base animation preserved, but color replaced
```

## Multiply

All property values are multiplicatively blended. Suitable for darkening and attenuation effects.

### Per-Property Behavior

| Property | Formula | Effect |
|----------|---------|--------|
| Opacity | `Base.O * Layer.O` | Opacity reduction |
| Scale | `Base.S * Layer.S` | Scale merging |
| Color | `Base.C * Layer.C` | Darkening |
| Others | `Base.X * Layer.X` | Value reduction |

> [!TIP]
> The default value in Multiply mode is (1,1,1,1), not (0,0,0,0). Because 0 multiplied by anything is 0.

## CrossFade

Interpolates between Base and Layer by weight.

### Interpolation Formula

```
Result = Lerp(Base, Layer, Weight)

Where Weight ∈ [0, 1]
  Weight = 0 → Fully use Base
  Weight = 1 → Fully use Layer
  Weight = 0.5 → 50% each
```

### Stage Transition Application

CrossFade is primarily used for transitions between stages:

```
Intro Stage  ──[CrossFade]──→  Default Stage  ──[CrossFade]──→  Outro Stage
    Weight: 0 → 1                Weight: 0 → 1
```

`FStageTransitionConfig` manages these transitions:

```cpp
struct FStageTransitionConfig
{
    FRichCurve IntroToDefaultCrossFade;  // Crossfade weight curve
    FRichCurve DefaultToOutroCrossFade;  // Crossfade weight curve
    EAlphaBlendOption EasingFunc;        // Easing function
};
```

## Blend Mode Selection Guide

| Scenario | Recommended Mode | Reason |
|----------|-----------------|--------|
| Combining multiple effects | Additive | Natural overlay |
| Overriding default animation | Override | Clean replacement |
| Intensity attenuation/darkening | Multiply | Multiplicative reduction |
| Stage transitions | CrossFade | Smooth gradient |
| Blending two different styles | Additive + weight | Fine blend control |

## Configuring Blend Modes

### Layer Configuration

```cpp
UGlyphAnimationLayer* Layer = UGlyphAnimationLayer::CreateLayer(
    Animation,
    ETextAnimationBlendMode::Additive,  // Blend mode
    Schedule,
    Forward,
    1
);
```

### Factory Global Setting

```cpp
Factory->SetLayerBlendMode(LayerIndex, ETextAnimationBlendMode::CrossFade);
```

## Important Notes

| Note | Description |
|------|-------------|
| Range clamping | Additive may exceed reasonable range, will be clamped |
| Multi-layer ordering | Layer add order affects final result (first added = bottom) |
| CrossFade weight | Weight must be dynamically updated at runtime to see gradient |
| Override with no value | Not all properties have a "no value" concept; be mindful of defaults |
