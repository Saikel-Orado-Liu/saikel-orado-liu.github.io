# 配置参考

Texturge Beta 的完整项目设置参考，涵盖 `UTexturgeSettings`、`UTextAnimInstance` 蓝图层设置和 `AnimatedTextBlock` 控件属性。

## 项目设置

路径：**编辑 → 项目设置 → Texturge**

通过 `UTexturgeSettings` 访问：

```cpp
UTexturgeSettings* Settings = UTexturgeSettings::Get();
```

| 分类 | 属性 | 类型 | 默认值 | 说明 |
|------|------|------|--------|------|
| 编辑器 | bEnableVerboseLogging | bool | false | 启用详细日志输出 |
| 编辑器 | BakeCacheWarmup | bool | true | 启动时预热烘焙缓存 |
| 编辑器 | MaxBakeTimeMs | int32 | 100 | 单次烘焙最大时间（毫秒） |
| 运行时 | DefaultCPS | float | 30.0 | 默认打字速度（字符/秒） |
| 运行时 | MaxSoundsPerTickDefault | int32 | 8 | 默认每帧最大音效数 |
| 运行时 | MinFramesBetweenRebakes | int32 | 3 | 重新烘焙最小冷却帧数 |

## 预览视口设置

在 `TextAnimationBlueprint` 的预览设置中配置：

| 属性 | 类型 | 默认值 | 说明 |
|------|------|--------|------|
| PreviewText | FString | "Hello Texturge" | 预览文本 |
| PreviewWidth | float | 500 | 预览宽度 |
| PreviewHeight | float | 200 | 预览高度 |
| bPreviewSizeToContent | bool | false | 自适应文本尺寸 |

## 颜色与外观

| 属性 | 类型 | 默认值 |
|------|------|--------|
| PreviewColorAndOpacity | FLinearColor | White (1,1,1,1) |
| PreviewShadowColorAndOpacity | FLinearColor | Transparent (0,0,0,0) |
| PreviewShadowOffset | FVector2D | (0, 0) |
| PreviewOutlineSize | float | 0 |
| PreviewOutlineColor | FLinearColor | Transparent |

| PreviewFont | FSlateFontInfo | 默认字体 | 预览字体 |

| PreviewFontMaterial | UMaterialInterface* | nullptr | 字体材质 |
| PreviewLineHeightPercentage | float | 1.0 | 行高百分比 |

## 对齐与换行

## 带参数覆盖

在 `UAnimatedTextBlock` 或 DataAsset 中，`ParameterOverrides` 允许覆盖 Blueprint 变量。Beta v2.4 起支持全部六种参数类型：

```cpp
// 在 BP 中设置
ParameterOverrides->SetFloatParameter(FName("Speed"), 2.0f);
ParameterOverrides->SetIntParameter(FName("Count"), 5);
ParameterOverrides->SetBoolParameter(FName("bEnabled"), true);
ParameterOverrides->SetVectorParameter(FName("Direction"), FVector(0,1,0));
ParameterOverrides->SetColorParameter(FName("Tint"), FLinearColor::Red);
ParameterOverrides->SetVector2DParameter(FName("Offset"), FVector2D(10, 20));
```

支持的参数类型：

| 类型 | 存储 Map | 示例用途 |
|------|----------|----------|
| **float** | FloatOverrides | 持续时间、速度、权重 |
| **int32** | IntOverrides | 循环次数、计数 |
| **bool** | BoolOverrides | 启用/禁用开关 |
| **FVector** | VectorOverrides | 3D 方向、位置 |
| **FLinearColor** | ColorOverrides | 颜色覆盖、渐变系数 |
| **FVector2D** | Vector2DOverrides | 2D 偏移、尺寸 |

参数覆盖采用 `TAnimParamTraits<T, Owner>` 统一模板 + CDO 副本隔离方案，确保蓝图 CDO 永不修改。

## 序列化配置

默认保存在 `DefaultGame.ini`：

```ini
[/Script/Texturge.TexturgeSettings]
bEnableVerboseLogging=False
BakeCacheWarmup=True
MaxBakeTimeMs=100
DefaultCPS=30.0
MaxSoundsPerTickDefault=8
MinFramesBetweenRebakes=3
```
