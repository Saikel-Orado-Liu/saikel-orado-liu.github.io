# 动画轨道类型参考

Texturge 支持 10 种动画轨道类型，覆盖字形变换的所有维度。

## 轨道结构

每个 `FTextAnimationTrack` 包含以下核心属性（Beta 中标记为 @deprecated，但继续可读）：

| 属性 | 类型 | 说明 |
|------|------|------|
| TrackId | FGuid | 唯一标识符 |
| TrackName | FName | 轨道名称 |
| TrackType | ETextAnimationTrackType | 轨道类型枚举 |
| StartTime | float | 开始时间 |
| Duration | float | 持续时间 |
| TrackWeight | float | 轨道权重 (0.0~1.0) |
| bEnabled | bool | 是否启用 |
| BlendMode | ETextAnimationBlendMode | 混合模式 |
| KeyFrames | TArray\<FKeyFrame\> | 关键帧数组 |
| ApplicationMode | ECharacterApplicationMode | 字符应用模式 |
| TimingMode | ETextAnimationTimingMode | 计时模式 |

## 10 种轨道类型

### 1. Opacity（不透明度）

| 项目 | 说明 |
|------|------|
| 类型 | Float |
| 值域 | 0.0 ~ 1.0 |
| 默认值 | 1.0（完全可见） |
| 用途 | 渐入/渐出效果 |
| 特殊属性 | bInvertOpacity：反转逻辑（值=1.0→隐藏，0.0→显示） |

### 2. LetterSpacing（字间距）

| 项目 | 说明 |
|------|------|
| 类型 | Float |
| 值域 | 任意浮点数（像素） |
| 默认值 | 0.0 |
| 用途 | 文字展开/收缩效果 |

### 3. Rotation（旋转）

| 项目 | 说明 |
|------|------|
| 类型 | Float |
| 值域 | 任意角度（度） |
| 默认值 | 0.0 |
| 用途 | 字形旋转动画 |
| 说明 | 绕 Pivot 点旋转 |

### 4. Translation（位移）

| 项目 | 说明 |
|------|------|
| 类型 | FVector2D |
| 值域 | 任意偏移量（像素） |
| 默认值 | (0, 0) |
| 子通道 | TranslationX, TranslationY |
| 用途 | 滑入/滑出、弹跳效果 |

### 5. Scale（缩放）

| 项目 | 说明 |
|------|------|
| 类型 | FVector2D |
| 值域 | 任意缩放倍率 |
| 默认值 | (1.0, 1.0) |
| 子通道 | ScaleX, ScaleY |
| 用途 | 放大/缩小、弹性效果 |

### 6. Shear（切变）

| 项目 | 说明 |
|------|------|
| 类型 | FVector2D |
| 值域 | 任意切变值 |
| 默认值 | (0, 0) |
| 子通道 | ShearX, ShearY |
| 用途 | 倾斜/斜体效果 |

### 7. Pivot（轴心）

| 项目 | 说明 |
|------|------|
| 类型 | FVector2D |
| 值域 | 0.0 ~ 1.0（相对字形的比例） |
| 默认值 | (0.5, 0.5)（字形中心） |
| 子通道 | PivotX, PivotY |
| 用途 | 控制旋转和缩放的轴心点 |

### 8. ShadowOffset（阴影偏移）

| 项目 | 说明 |
|------|------|
| 类型 | FVector2D |
| 值域 | 任意偏移量 |
| 默认值 | (0, 0) |
| 子通道 | ShadowOffsetX, ShadowOffsetY |
| 用途 | 阴影移动动画 |

### 9. Color（文本颜色）

| 项目 | 说明 |
|------|------|
| 类型 | FLinearColor |
| 值域 | 0.0 ~ 1.0 每通道 |
| 默认值 | White (1, 1, 1, 1) |
| 子通道 | ColorR, ColorG, ColorB, ColorA |
| 用途 | 颜色渐变、闪烁效果 |

### 10. ShadowColor（阴影颜色）

| 项目 | 说明 |
|------|------|
| 类型 | FLinearColor |
| 值域 | 0.0 ~ 1.0 每通道 |
| 默认值 | Transparent (0, 0, 0, 0) |
| 子通道 | ShadowColorR/G/B/A |
| 用途 | 阴影颜色渐变 |

## 关键帧插值类型

| 类型 | 说明 | 曲线形状 |
|------|------|----------|
| **Linear** | 线性插值 | 直线 |
| **Cubic** | 三次样条插值 | 平滑曲线（可调切线） |
| **Constant** | 常量（无过渡） | 阶梯 |
| **CubicInOut** | 三次缓入缓出 | S 形曲线 |

## 字符应用模式

| 模式 | 说明 |
|------|------|
| **PerCharacter** | 每个字符独立执行动画（偏移起始时间） |
| **Interval** | 按间隔（ApplicationInterval）应用于字符 |
| **Random** | 随机概率（RandomProbability）决定是否应用 |

## 计时模式

| 模式 | 说明 |
|------|------|
| **PerCharacterDuration** | 每个字符独立持续时间 |
| **TotalDuration** | 总文本持续时间均匀分配 |
