# 字形调度参考

字形调度系统为文本中每个字符提供独立的调度参数控制。这是 Texturge Beta 实现逐字差异化动画的核心机制。

## FGlyphScheduleInfo

```cpp
USTRUCT(BlueprintType)
struct FGlyphScheduleInfo
{
    // ── 系统只读字段 ──
    int32 GlyphIndex;        // 字形在文本中的索引
    FString GlyphString;     // 字形字符本身
    bool bIsWhitespace;      // 是否为空白字符
    bool bIsPunctuation;     // 是否为标点符号
    bool bIsCJK;             // 是否为 CJK 字符
    bool bIsDecorator;       // 是否为装饰器字符

    // ── 设计者可写字段 ──
    float StartDelay = 0.0f;          // 动画开始延迟（秒）
    bool bSkipAnimation = false;      // 是否跳过动画
    float ValueScale = 1.0f;          // 曲线值缩放
    float ValueOffset = 0.0f;         // 曲线值偏移
    bool bRequiresUniqueCurves = false; // 是否需要独立曲线
    float SeedJitter = 0.0f;          // 随机抖动种子
};
```

## 只读字段：自动分类

`BuildScheduleInfos()` 自动分析文本并为每个字符设置分类标记：

| 字段 | 判定条件 | 示例 |
|------|----------|------|
| bIsWhitespace | Unicode 空白类 | 空格、制表符、换行 |
| bIsPunctuation | Unicode 标点类 | 。，！？.,!? |
| bIsCJK | CJK 统一表意文字 / 假名 / 谚文 | 你日한 |
| bIsDecorator | `<` `>` 等标签字符 | &lt; &gt; |

> [!NOTE]
> CJK 分类使用 `Texturge::Unicode` 命名空间的完整 Unicode 范围检测。

## 可写字段：调度控制

### StartDelay

每个字形的动画开始时间偏移。

```cpp
// 基础用法：所有字形递增延迟 0.1 秒
FGlyphScheduleBuilder::SetPerGlyphDelay(Schedule, 0.1f);

// 高级用法：为特定字形设置延迟
Factory->SetStartDelayAt(3, 0.5f);  // 第 4 个字形延迟 0.5 秒
```

### bSkipAnimation

跳过动画的字形使用 `DefaultState`（Identity 状态）渲染。

```cpp
// 跳过所有空白字符
FGlyphScheduleBuilder::SkipWhitespace(Schedule);

// 跳过特定字形
Factory->SkipAt(0, true);  // 跳过第一个字形
```

### ValueScale & ValueOffset

对曲线值进行全局缩放和偏移：

```
EffectiveValue = OriginalValue * ValueScale + ValueOffset
```

```cpp
// 将所有曲线值放大 2 倍
Factory->SetValueScaleAt(Index, 2.0f);

// 将位移偏移 +10 像素
Factory->SetValueOffsetAt(Index, 10.0f);
```

### bRequiresUniqueCurves

当为 `true` 时，为该字形生成独立的曲线副本（而非共享引用）。适用于需要不同曲线形状的字形。

```cpp
// CJK 字符通常需要独立曲线
if (Schedule[i].bIsCJK)
    Factory->SetRequiresUniqueCurvesAt(i, true);
```

### SeedJitter

为随机效果提供确定性的"伪随机"：

```cpp
// 使用字形索引作为抖动种子
Factory->SetSeedJitterAt(i, static_cast<float>(i) * 0.1f);
```

不同于真正的随机数，SeedJitter 是确定性的——相同输入产生相同输出，确保烘焙缓存有效。

## FGlyphScheduleBuilder

静态工具类用于批量操作调度数组：

| 方法 | 说明 |
|------|------|
| `SetPerGlyphDelay(Schedule, Delay)` | 所有字形设置递增延迟 |
| `SkipWhitespace(Schedule)` | 跳过所有空白字符 |
| `SetDelayAt(Schedule, Index, Delay)` | 设置指定字形的延迟 |
| `SkipAt(Schedule, Index, bSkip)` | 设置指定字形的跳过状态 |
| `SetValueScaleAt(Schedule, Index, Scale)` | 设置值缩放 |
| `SetValueOffsetAt(Schedule, Index, Offset)` | 设置值偏移 |
| `SetRequiresUniqueCurvesAt(Schedule, Index, bReq)` | 设置独立曲线需求 |
| `SetSeedJitterAt(Schedule, Index, Jitter)` | 设置抖动种子 |

## 调度与图层的关系

每个 `UGlyphAnimationLayer` 可以拥有独立的调度数组：

```cpp
// 两个图层使用不同的调度策略
Layer1->Schedule → 所有字形延迟 0.05s
Layer2->Schedule → 仅 CJK 字符延迟 0.1s
```

Factory 合并图层时，每层的调度独立作用于该层的曲线数据。

## FGlyphCurveOverride（微调参数）

除了调度参数，还可以通过 `FGlyphCurveOverride` 对单个字形进行曲线级别微调：

| 参数 | 类型 | 说明 |
|------|------|------|
| OpacityMultiplier | float | 不透明度倍率 |
| LetterSpacingValue | float | 字间距值 |
| ScaleMultiplier | FVector2D | 缩放倍率 |
| TranslationOffset | FVector2D | 位移偏移 |
| RotationMultiplier | float | 旋转倍率 |
| ShearValue | FVector2D | 切变值 |
| PivotValue | FVector2D | 轴心值 |
| ShadowOffsetValue | FVector2D | 阴影偏移值 |
| ColorMultiplier | FLinearColor | 颜色倍率 |
| ShadowColorMultiplier | FLinearColor | 阴影颜色倍率 |

## 最佳实践

| 建议 | 原因 |
|------|------|
| 使用 SeedJitter 替代 Random | 确定性结果，不破坏缓存 |
| 跳过空格和装饰器 | 节省计算资源 |
| CJK 使用 UniqueCurves | 避免共享引用导致的视觉冲突 |
| 延迟值考虑字符位置 | 第一个字符延迟 0，后续递增 |
| 批量使用 SetPerGlyphDelay | 比逐个设置效率高 |
