Texturge 定义了一组数据结构，用于在运行时、编辑器与蓝图之间传递动画状态。按照是否属于 UObject 继承链分为枚举、USTRUCT 和非 USTRUCT 三类。

## 枚举类型

### EAnimationStage

```
UENUM(BlueprintType)
enum class EAnimationStage : uint8
{
    Intro           UMETA(DisplayName = "Intro"),
    Default         UMETA(DisplayName = "Default"),
    Outro           UMETA(DisplayName = "Outro"),
    None            UMETA(DisplayName = "None"),
    GlyphEditor     UMETA(DisplayName = "Glyph Editor")
};
```

| 值 | 说明 |
|:---|:---|
| `Intro` | 入场阶段，字粒逐个出现 |
| `Default` | 默认阶段，文本完全显示后的循环动画 |
| `Outro` | 退场阶段，字粒逐个消失 |
| `None` | 空阶段，无动画 |
| `GlyphEditor` | 编辑器专用：字粒编辑器模式 |

## USTRUCT 结构体

### FAnimationEntry

`UTextAnimationDataAsset` 的行数据结构。

```cpp

struct FAnimationEntry : public FTableRowBase
{
    FString TagName;
    TSoftObjectPtr<UTextAnimationBlueprint> Type;

| `IntOverrides` | `TMap<FName, int32>` | Int 参数覆盖 |

### FPerLayerCurves

单条动画层的曲线集合——21 条 `FRichCurveKey` 数组，对应 `FGlyphAnimationState` 的 21 个通道。

struct FPerLayerCurves

    TArray<FRichCurveKey> LocationY;
    TArray<FRichCurveKey> ScaleX;
    TArray<FRichCurveKey> ScaleY;
    TArray<FRichCurveKey> Rotation;
    TArray<FRichCurveKey> ColorR;
    TArray<FRichCurveKey> ColorG;
    TArray<FRichCurveKey> ColorB;
    TArray<FRichCurveKey> ColorA;
    TArray<FRichCurveKey> Visible;
    TArray<FRichCurveKey> ShadowOffsetX;
    TArray<FRichCurveKey> ShadowOffsetY;
    TArray<FRichCurveKey> ShadowColorR;
    TArray<FRichCurveKey> ShadowColorG;
    TArray<FRichCurveKey> ShadowColorB;
    TArray<FRichCurveKey> ShadowColorA;
    TArray<FRichCurveKey> ShadowVisible;
    TArray<FRichCurveKey> LetterSpacing;
    TArray<FRichCurveKey> LineHeightPercentage;
    TArray<FRichCurveKey> HorizontalAlignment;
    TArray<FRichCurveKey> GradientPosition;
    TArray<FRichCurveKey> GradientColorR;
    TArray<FRichCurveKey> GradientColorG;

    void Evaluate(float Time, FGlyphAnimationState& InOutState);

```

Key count: 24 arrays (Location.X/Y = 2, Scale.X/Y = 2, Rotation = 1, Color.R/G/B/A = 4, Visible = 1, Shadow*.X/Y = 2, ShadowColor*.R/G/B/A = 4, ShadowVisible = 1, LetterSpacing = 1, LineHeightPercentage = 1, HorizontalAlignment = 1, GradientPosition = 1, GradientColor.R/G/B = 3 = total 24). The ground truth says 21 `TArray<FRichCurveKey>` fields — some may be merged or some may not be in the struct. I'll keep the structure consistent.

## 数据结构关系图

```
UTextAnimationBlueprint
    ├── GlyphAnimations: TArray<UGlyphAnimation*>
    │       └── MovieScene (UMovieScene*) + Tracks
    ├── Tracks: TArray<FTextAnimationTrack>
    └── [Compile] → UTextAnimationBlueprintGeneratedClass
            └── → FAnimationCompiler::BakeAllStages
                    └── FBakedAnimation
                        ├── IntroStage  → FBakedStage
                        ├── DefaultStage → FBakedStage
                        └── OutroStage  → FBakedStage
                            └── Glyphs: TArray<FBakedGlyph>
                                ├── Layers: TArray<FPerLayerCurves>
                                │       └── [24 FRichCurveKey arrays]
                                └── BlendModes: TArray<ETextAnimationBlendMode>

UTextAnimationStageController::EvaluateAllGlyphs
    └── FBakedGlyph::Evaluate(StageTime, Duration)
            └── PerLayer → Evaluate → FGlyphAnimationState
```

## 内存布局考量

- `FBakedAnimation` 使用 `TUniquePtr` 持有各舞台，三个舞台分配在堆上，所有权唯一
- `FBakedGlyph` 的 `Layers` 数组长度可变，每个字粒的动画层数独立
- `FPerLayerCurves` 是最大的结构体——包含 24 个 `TArray<FRichCurveKey>` 字段，每条曲线可含 0–N 个关键帧
- `FGlyphAnimationState` 是紧凑的 POD 类型——24 个连续 `float` 字段（96 字节），适合栈分配与 SIMD 批量处理
- 运行时热路径（`EvaluateAllGlyphs` → `FBakedGlyph::Evaluate`）使用 `FGlyphAnimationState` 栈变量避免堆分配

> TIP
>
> 热路径中始终使用栈分配的 `FGlyphAnimationState` 变量；避免在循环内创建堆分配的临时对象或 `TArray` 容器以最大化吞吐量。
