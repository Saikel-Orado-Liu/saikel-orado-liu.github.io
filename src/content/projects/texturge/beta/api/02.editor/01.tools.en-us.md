The Texturge Editor module provides a complete WYSIWYG animation authoring environment for artists and technical designers, deeply integrated with UE5's editor architecture.

## FTextAnimationBlueprintEditor

Core animation blueprint editor, inheriting from `FBlueprintEditor` (the Kismet base framework). Open by double‑clicking a `UTextAnimationBlueprint` asset.

```cpp
class FTextAnimationBlueprintEditor : public FBlueprintEditor
{
    void InitTextAnimationEditor(...);
    void Compile();
    FSequencer* GetSequencer();
    void ChangeViewedAnimation(int32 Index);
    void SetActivePreviewSource(ETexturgePreviewSource Source);
    FPreviewSourceMediator* GetPreviewSourceMediator();
    STextAnimationDesignerView* GetDesignerView();
};
```

### Seven‑Tab Layout

The editor window contains the following 7 tabs:

| Tab | Description |
|:---|:---|
| **Designer** | WYSIWYG glyph designer view (`STextAnimationDesignerView`) |
| **Graph** | Kismet Blueprint event graph |
| **Timeline** | Sequencer timeline integration (`UGlyphAnimationTrackEditor`) |
| **Details** | Property details panel (`FTextAnimationInstanceDetails` customization) |
| **Compile Results** | Compiler output and diagnostics |
| **Preview** | Real‑time animation preview widget (`STextAnimationPreviewWidget`) |
| **Animation List** | GlyphAnimation asset list and layer management (`SAnimationList`) |

### Workflow

1. Double‑click a `UTextAnimationBlueprint` asset to open the editor
2. Inspect text layout in the **Designer** view; adjust glyph anchors with transform handles
3. Create and manage `UGlyphAnimation` assets in the **Animation List** tab
4. Edit keyframe curves (21 channels) in the **Timeline** Sequencer view
5. Preview animation in real‑time using playback controls in the **Preview** tab
6. Save the asset to trigger: `Compile()` → `FTextAnimationBlueprintCompilerContext` → generate `UTextAnimationBlueprintGeneratedClass`

## STextAnimationDesignerView

WYSIWYG glyph designer, inheriting `SDesignSurface` and `IUMGDesigner`.

```cpp
class STextAnimationDesignerView : public SDesignSurface, public IUMGDesigner
{
    // Viewport operations
    float ZoomLevel;
    FVector2D PanOffset;
    bool bShowGrid;
    bool bShowRuler;

    // Transform handles
    STextAnimationTransformHandle* ActiveHandle;
    TArray<STextAnimationTransformHandle*> Handles;
};
```

| Feature | Description |
|:---|:---|
| **Zoom & Pan** | Scroll‑wheel zoom, middle‑mouse drag pan, fit‑to‑window |
| **Grid** | Custom‑spacing design grid with snap support |
| **Rulers** | Horizontal/vertical rulers (`STextAnimationRuler`) |
| **Transform Handles** | Translation/scale/rotation handles on selected glyphs |
| **Disappearing Bar** | `STextAnimationDisappearingBar` overflow indicator |

Associated Slate widgets:

- `STextAnimationDesignSurface` — Design canvas base
- `STextAnimationPaintSurface` — Paint surface (OnPaint rendering layer)
- `STextAnimationDesignerToolBar` — Toolbar (zoom, grid toggle, preview source selection)
- `STextAnimationGraphPreview` — Graph thumbnail preview
- `STextAnimationPreviewList` — Preview list widget

### Slot Extensions

The designer supports embedding animation widgets into standard UMG panels via slot extensions:

- `SCanvasSlotExtension`
- `SHorizontalBoxSlotExtension`
- `SVerticalBoxSlotExtension`
- `SGridSlotExtension`
- `SStackBoxSlotExtension`
- `SUniformGridSlotExtension`

## FPreviewSourceMediator

Preview source mediator, arbitrating preview data sources and multi‑observer subscriptions.

```cpp
class FPreviewSourceMediator
{
    void RequestSource(ETexturgePreviewSource Source);
    void RegisterObserver(IPreviewObserver* Observer);
    void TickPreview(float DeltaTime);
    void InvalidateBakeCache();
    void SetActiveOverrides(FName Var, float Value);
    void SetActiveOverrides(FName Var, int32 Value);
    void SetActiveOverrides(FName Var, bool Value);
    void SetActiveOverrides(FName Var, FVector Value);
};
```

| Method | Description |
|:---|:---|
| `RequestSource(ETexturgePreviewSource)` | Switch preview source: None/StagePreview/GlyphAnimation |
| `RegisterObserver` | Register a preview observer (editor tabs, preview widgets) |
| `TickPreview` | Advance preview state per frame |
| `InvalidateBakeCache` | Invalidate bake cache after blueprint changes |
| `SetActiveOverrides` | Set active parameter overrides (4 overloads) |

## Sequencer Integration

`UGlyphAnimationTrackEditor` (private class) extends `FMovieSceneTrackEditor`, mapping tracks from `UGlyphAnimation` sequences onto the Sequencer timeline, supporting standard keyframe editing (add/delete/move/curve adjustment).

## Toolbar

`STextAnimationDesignerToolBar` provides the following controls:

| Control | Description |
|:---|:---|
| Zoom slider | 10%–800% zoom range |
| Fit‑to‑window button | One‑click fit |
| Grid toggle | Show/hide design grid |
| Snap toggle | Enable/disable grid snap |
| Preview source dropdown | Select None / StagePreview / GlyphAnimation |
| Playback controls | Play/Pause/Stop buttons |

Transform handles (`STextAnimationTransformHandle`) appear on selected glyphs, supporting translate, rotate, and scale operations with visual feedback (corner and edge handles).
