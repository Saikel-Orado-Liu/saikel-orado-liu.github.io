Texturge 编辑器通过 `IDetailCustomization`、编译器上下文扩展与资产工厂钩子实现深度定制。

## FAnimatedTextBlockDetails

为 `UAnimatedTextBlock` 控件提供自定义 Details 面板。

```cpp
class FAnimatedTextBlockDetails : public IDetailCustomization
{
    // 获取 / 注册自定义
    static TSharedRef<IDetailCustomization> MakeInstance();

    // 控件控件
    void CustomizeDetails(IDetailLayoutBuilder& DetailBuilder) override;

    // 特性
    void OnAnimInstanceClassChanged();
    void RefreshParameterList();
    void OnCompileClicked();
};
```

### 自定义内容

| 区域 | 说明 |
|:---|:---|
| **AnimInstanceClass 选择器** | 筛选 `UTextAnimInstance` 子类，选择后刷新参数列表 |
| **ParameterOverrides 内联编辑** | 展开 `UAnimParameterOverrides` 的 6 组映射表，内联编辑键值对 |
| **编译按钮** | 触发关联蓝图的编译，刷新参数枚举 |
| **播放控制区** | Play/Pause/Stop 按钮（编辑器内预览） |
| **PreviewText 实时预览** | 输入预览文本，实时显示动画效果 |

## FTextAnimationInstanceDetails

为 `UTextAnimInstance` 提供自定义 Details 面板，在编辑器中选择动画实例时显示。

```cpp
class FTextAnimationInstanceDetails : public IDetailCustomization
{
    static TSharedRef<IDetailCustomization> MakeInstance();
    void CustomizeDetails(IDetailLayoutBuilder& DetailBuilder) override;

    void OnBlueprintChanged();
    void RefreshAnimationList();
    void OnAnimationSelected(FName AnimationName);
};
```

| 特性 | 说明 |
|:---|:---|
| **蓝图引用显示** | 显示关联 `UTextAnimationBlueprint` 的只读路径 |
| **动画列表** | 枚举蓝图中引用的所有 `UGlyphAnimation`，支持筛选 |
| **烘焙缓存状态** | 显示 `CachedBakedAnimation` 有效性、文本指纹、蓝图指纹 |
| **参数列表** | 显示当前实例的参数变量及默认值 |

## FAnimationEntryDetails

为 `FAnimationEntry` 结构体（`UTextAnimationDataAsset` 的行数据）提供自定义 Details。

```cpp
class FAnimationEntryDetails : public IDetailCustomization
{
    static TSharedRef<IDetailCustomization> MakeInstance();
    void CustomizeDetails(IDetailLayoutBuilder& DetailBuilder) override;

    void OnTagNameChanged();
    void OnTypeChanged();
    void EditOverrideMap(FName MapName, EAnimParamType ParamType);
};
```

### 结构

`FAnimationEntry` 的 Details 面板按层次组织：

1. **TagName** — 富文本标签名（如 `"<anima=shake>"` 中的 `"shake"`）
2. **Type** — `TSoftObjectPtr<UTextAnimationBlueprint>` 动画蓝图引用
3. **Parameter Overrides** — 6 组覆盖映射表内联编辑，按 `FloatOverrides`/`IntOverrides`/`BoolOverrides`/`VectorOverrides`/`ColorOverrides`/`Vector2DOverrides` 分类

## FTextAnimationBlueprintCompilerContext

Kismet 编译器扩展，在蓝图编译流程中注入 Texturge 特定的编译步骤。

```cpp
class FTextAnimationBlueprintCompilerContext : public FKismetCompilerContext
{
    void Compile() override;

    void CompileGlyphAnimations();
    void CompileTracks();
    void ResolveAnimationReferences();
    void GenerateBakedOutput();
};
```

### 编译流水线

1. 标准 Kismet 编译（父类行为）— 生成 `UTextAnimationBlueprintGeneratedClass`
2. `CompileGlyphAnimations()` — 验证所有 `UGlyphAnimation` 引用，提取轨道类型
3. `CompileTracks()` — 编译 `FTextAnimationTrack` 数组，解析轨道到字粒的映射
4. `ResolveAnimationReferences()` — 解析 `GlyphAnimations` 数组中的交叉引用
5. `GenerateBakedOutput()` — 调用 `FAnimationCompiler::BakeAllStages` 预烘焙

编译输出写入 `UTextAnimationBlueprintGeneratedClass`（`UBlueprintGeneratedClass` 子类），在运行时供 `UTextAnimInstance` 查询。

## 扩展自定义 Detail 面板

插件支持注册外部自定义 Detail 面板。以下是扩展步骤：

1. 创建继承 `IDetailCustomization` 的类
2. 实现 `CustomizeDetails(IDetailLayoutBuilder& DetailBuilder)`
3. 在模块的 `StartupModule()` 中注册：

```cpp
FPropertyEditorModule& PropertyModule = FModuleManager::LoadModuleChecked<FPropertyEditorModule>("PropertyEditor");
PropertyModule.RegisterCustomClassLayout(
    UYourClass::StaticClass()->GetFName(),
    FOnGetDetailCustomizationInstance::CreateStatic(&FYourDetails::MakeInstance)
);
```

4. 在 `ShutdownModule()` 中调用 `UnregisterCustomClassLayout` 取消注册

所有内置 Detail 自定义通过相同的注册机制绑定，确保与引擎的 Details 面板标准化。
