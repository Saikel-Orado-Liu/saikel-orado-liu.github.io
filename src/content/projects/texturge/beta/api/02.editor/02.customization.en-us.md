The Texturge editor achieves deep customization through `IDetailCustomization`, compiler context extensions, and asset factory hooks.

## FAnimatedTextBlockDetails

Custom Details panel for the `UAnimatedTextBlock` widget.

```cpp
class FAnimatedTextBlockDetails : public IDetailCustomization
{
    // Factory / registration
    static TSharedRef<IDetailCustomization> MakeInstance();

    // Widget customization
    void CustomizeDetails(IDetailLayoutBuilder& DetailBuilder) override;

    // Features
    void OnAnimInstanceClassChanged();
    void RefreshParameterList();
    void OnCompileClicked();
};
```

### Custom Content

| Section | Description |
|:---|:---|
| **AnimInstanceClass picker** | Filters `UTextAnimInstance` subclasses; refreshes parameter list on selection |
| **ParameterOverrides inline editing** | Expand the 6 override maps of `UAnimParameterOverrides` for inline key‑value editing |
| **Compile button** | Triggers compilation of the linked blueprint, refreshing parameter enumerations |
| **Playback control area** | Play/Pause/Stop buttons for in‑editor preview |
| **PreviewText live preview** | Enter preview text to see animation results in real‑time |

## FTextAnimationInstanceDetails

Custom Details panel for `UTextAnimInstance`, shown when an animation instance is selected in the editor.

```cpp
class FTextAnimationInstanceDetails : public IDetailCustomization
{
    static TSharedRef<IDetailCustomization> MakeInstance();
    void CustomizeDetails(IDetailLayoutBuilder& DetailBuilder) override;

    void OnBlueprintChanged();
    void RefreshAnimationList();
    void OnAnimationSelected(FName AnimationName);
};
```

| Feature | Description |
|:---|:---|
| **Blueprint reference display** | Read‑only path to the linked `UTextAnimationBlueprint` |
| **Animation list** | Enumerate all `UGlyphAnimation` assets referenced in the blueprint with filtering |
| **Bake cache status** | Display `CachedBakedAnimation` validity, text fingerprint, blueprint fingerprint |
| **Parameter list** | Show current instance parameter variables and default values |

## FAnimationEntryDetails

Custom Details for the `FAnimationEntry` struct (row data of `UTextAnimationDataAsset`).

```cpp
class FAnimationEntryDetails : public IDetailCustomization
{
    static TSharedRef<IDetailCustomization> MakeInstance();
    void CustomizeDetails(IDetailLayoutBuilder& DetailBuilder) override;

    void OnTagNameChanged();
    void OnTypeChanged();
    void EditOverrideMap(FName MapName, EAnimParamType ParamType);
};
```

### Layout

The `FAnimationEntry` Details panel is organized hierarchically:

1. **TagName** — Rich‑text tag name (e.g. `"shake"` in `"<anima=shake>"`)
2. **Type** — `TSoftObjectPtr<UTextAnimationBlueprint>` animation blueprint reference
3. **Parameter Overrides** — 6 override maps with inline editing, categorized by `FloatOverrides`/`IntOverrides`/`BoolOverrides`/`VectorOverrides`/`ColorOverrides`/`Vector2DOverrides`

## FTextAnimationBlueprintCompilerContext

Kismet compiler extension, injecting Texturge‑specific compilation steps into the blueprint compilation pipeline.

```cpp
class FTextAnimationBlueprintCompilerContext : public FKismetCompilerContext
{
    void Compile() override;

    void CompileGlyphAnimations();
    void CompileTracks();
    void ResolveAnimationReferences();
    void GenerateBakedOutput();
};
```

### Compilation Pipeline

1. Standard Kismet compile (parent behavior) — generates `UTextAnimationBlueprintGeneratedClass`
2. `CompileGlyphAnimations()` — validate all `UGlyphAnimation` references, extract track types
3. `CompileTracks()` — compile the `FTextAnimationTrack` array, resolve track‑to‑glyph mappings
4. `ResolveAnimationReferences()` — resolve cross‑references within the `GlyphAnimations` array
5. `GenerateBakedOutput()` — call `FAnimationCompiler::BakeAllStages` for pre‑baking

Compiler output is written into `UTextAnimationBlueprintGeneratedClass` (a `UBlueprintGeneratedClass` subclass) and queried by `UTextAnimInstance` at runtime.

## Extending Custom Detail Panels

The plugin supports registering external custom Detail panels. Steps to extend:

1. Create a class inheriting `IDetailCustomization`
2. Implement `CustomizeDetails(IDetailLayoutBuilder& DetailBuilder)`
3. Register in your module's `StartupModule()`:

```cpp
FPropertyEditorModule& PropertyModule = FModuleManager::LoadModuleChecked<FPropertyEditorModule>("PropertyEditor");
PropertyModule.RegisterCustomClassLayout(
    UYourClass::StaticClass()->GetFName(),
    FOnGetDetailCustomizationInstance::CreateStatic(&FYourDetails::MakeInstance)
);
```

4. Call `UnregisterCustomClassLayout` in `ShutdownModule()`

All built‑in detail customizations are bound through the same registration mechanism, ensuring standardization with the engine's Details panel.
