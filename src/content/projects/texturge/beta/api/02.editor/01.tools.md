Texturge 编辑器模块（`Editor`）为美术与技术策划提供完整的 WYSIWYG 动画创作环境，深度集成于 UE5 编辑器架构。

## FTextAnimationBlueprintEditor

核心动画蓝图编辑器，继承自 `FBlueprintEditor`（Kismet 基础框架）。双击 `UTextAnimationBlueprint` 资产打开。

```cpp
class FTextAnimationBlueprintEditor : public FBlueprintEditor
{
    void InitTextAnimationEditor(...);
    void Compile();
    FSequencer* GetSequencer();
    void ChangeViewedAnimation(int32 Index);
    void SetActivePreviewSource(ETexturgePreviewSource Source);
    FPreviewSourceMediator* GetPreviewSourceMediator();
    STextAnimationDesignerView* GetDesignerView();
};
```

### 七标签页布局

编辑器窗口包含以下 7 个标签页：

| 标签页 | 说明 |
|:---|:---|
| **Designer** | WYSIWYG 字粒设计器视图（`STextAnimationDesignerView`） |
| **Graph** | Kismet 蓝图事件图表 |
| **Timeline** | Sequencer 时间轴集成（`UGlyphAnimationTrackEditor`） |
| **Details** | 属性详情面板（`FTextAnimationInstanceDetails` 自定义） |
| **Compile Results** | 编译器输出与诊断 |
| **Preview** | 实时动画预览控件（`STextAnimationPreviewWidget`） |
| **Animation List** | GlyphAnimation 资源列表与层管理（`SAnimationList`） |

### 工作流

1. 双击 `UTextAnimationBlueprint` 资产打开编辑器
2. 在 **Designer** 视图中查看文本布局，使用变换手柄调整字粒锚点
3. 在 **Animation List** 标签页创建和管理 `UGlyphAnimation` 资源
4. 在 **Timeline** Sequencer 视图中编辑关键帧曲线（21 通道）
5. 使用 **Preview** 标签页的播放控件实时预览动画
6. 保存资产触发 `Compile()` → `FTextAnimationBlueprintCompilerContext` → 生成 `UTextAnimationBlueprintGeneratedClass`

## STextAnimationDesignerView

WYSIWYG 字粒设计器，继承 `SDesignSurface` 和 `IUMGDesigner`。

```cpp
class STextAnimationDesignerView : public SDesignSurface, public IUMGDesigner
{
    // 视口操作
    float ZoomLevel;
    FVector2D PanOffset;
    bool bShowGrid;
    bool bShowRuler;

    // 变换手柄
    STextAnimationTransformHandle* ActiveHandle;
    TArray<STextAnimationTransformHandle*> Handles;
};
```

| 特性 | 说明 |
|:---|:---|
| **缩放与平移** | 滚轮缩放、中键拖动平移，支持缩放至适应窗口 |
| **网格** | 可自定义间距的设计网格，支持吸附 |
| **标尺** | 水平/垂直标尺（`STextAnimationRuler`） |
| **变换手柄** | 选中字粒后显示平移/缩放/旋转手柄 |
| **消失栏** | `STextAnimationDisappearingBar` 溢出指示器 |

关联 Slate 控件：

- `STextAnimationDesignSurface` — 设计画布基类
- `STextAnimationPaintSurface` — 绘制表面（OnPaint 渲染层）
- `STextAnimationDesignerToolBar` — 工具栏（缩放、网格开关、预览源选择）
- `STextAnimationGraphPreview` — 图表缩略预览
- `STextAnimationPreviewList` — 预览列表控件

### 槽位扩展

设计器支持通过槽位扩展将动画控件嵌入标准 UMG 面板：

- `SCanvasSlotExtension`
- `SHorizontalBoxSlotExtension`
- `SVerticalBoxSlotExtension`
- `SGridSlotExtension`
- `SStackBoxSlotExtension`
- `SUniformGridSlotExtension`

## FPreviewSourceMediator

预览源中介器，仲裁预览数据源与多观察者订阅。

```cpp
class FPreviewSourceMediator
{
    void RequestSource(ETexturgePreviewSource Source);
    void RegisterObserver(IPreviewObserver* Observer);
    void TickPreview(float DeltaTime);
    void InvalidateBakeCache();
    void SetActiveOverrides(FName Var, float Value);
    void SetActiveOverrides(FName Var, int32 Value);
    void SetActiveOverrides(FName Var, bool Value);
    void SetActiveOverrides(FName Var, FVector Value);
};
```

| 方法 | 说明 |
|:---|:---|
| `RequestSource(ETexturgePreviewSource)` | 切换预览源：None/StagePreview/GlyphAnimation |
| `RegisterObserver` | 注册预览观察者（编辑器标签页、预览控件等） |
| `TickPreview` | 逐帧推进预览状态 |
| `InvalidateBakeCache` | 蓝图变更后使烘焙缓存失效 |
| `SetActiveOverrides` | 设置活动参数覆盖（4 重载） |

## 时序编辑器集成

`UGlyphAnimationTrackEditor`（私有类）扩展 `FMovieSceneTrackEditor`，将 `UGlyphAnimation` 序列的轨道映射到 Sequencer 时间轴，支持标准的关键帧编辑操作（添加/删除/移动/插值曲线调节）。

## 工具栏

`STextAnimationDesignerToolBar` 提供以下控件：

| 控件 | 说明 |
|:---|:---|
| 缩放滑块 | 10%–800% 缩放范围 |
| 自适应缩放按钮 | 一键缩放至适应窗口 |
| 网格开关 | 切换设计网格显示 |
| 吸附开关 | 切换网格吸附 |
| 预览源下拉 | 选择 None / StagePreview / GlyphAnimation |
| 播放控件 | Play/Pause/Stop 按钮 |

变换手柄（`STextAnimationTransformHandle`）在选中字粒时显示，支持平移、旋转、缩放操作，含视觉反馈（角点与边缘手柄）。
