Texturge 将所有核心运行时功能通过 `BlueprintCallable` 暴露为蓝图节点，归入 `Texturge` 类别。

## 播放控制节点

### 标准播放控制

从 `UAnimatedTextBlock` 和 `UAnimatedRichTextBlock` 暴露的播放控制：

| 蓝图节点 | 目标类 | 说明 |
|:---|:---|:---|
| `Play` | `UAnimatedTextBlock` / `UAnimatedRichTextBlock` | 开始播放动画 |
| `Pause` | `UAnimatedTextBlock` / `UAnimatedRichTextBlock` | 暂停当前动画 |
| `Resume` | `UAnimatedTextBlock` / `UAnimatedRichTextBlock` | 从暂停恢复 |
| `Stop` | `UAnimatedTextBlock` / `UAnimatedRichTextBlock` | 停止播放并重置 |
| `SkipToEnd` | `UAnimatedTextBlock` / `UAnimatedRichTextBlock` | 跳到当前动画末尾 |
| `RevealAll` | `UTextAnimationStageController` | 立即显示所有字粒 |

### 舞台控制节点

从 `UTextAnimationStageController` 暴露的配置与查询：

| 蓝图节点 | 说明 |
|:---|:---|
| `Initialize` | 用 `UTextAnimInstance` 和文本初始化控制器 |
| `SetPlayDirection` | 设置播放方向：Forward/Reverse/PingPong |
| `SetLoop` | 启用/禁用循环播放 |
| `SetCrossfadeEnabled` | 启用交叉淡入淡出并设置时长 |
| `EvaluateAllGlyphs` | 对所有字粒求值，返回 `TArray<FGlyphAnimationState>` |
| `EvaluateGlyph` | 对单个字粒求值 |
| `PublishBakedAnimation` | 注入预烘焙数据 |

### 动画器节点

从 `UTextAnimator` 暴露的富文本动画控制：

| 蓝图节点 | 说明 |
|:---|:---|
| `SetPlainText` | 设置纯文本内容 |
| `SetRichText` | 设置含标签的富文本 |
| `SetAnimationData` | 设置 `UTextAnimationDataAsset` 映射表 |
| `SetAnimationBlueprint` | 设置默认 `UTextAnimationBlueprint` |
| `StartAnimating` | 启动动画，计算 TotalDuration |
| `TickAnimation` | 逐帧推进时间 |
| `GetCurrentFrameData` | 获取当前帧的 `FBakedAnimation` |

## SetBlueprintVariable 节点家族

`UAnimatedTextBlock` 和 `UTextAnimInstance` 均暴露 `SetBlueprintVariable` 的 6 个类型化重载：

### 从 UAnimatedTextBlock 调用（6 重载）

```cpp
UFUNCTION(BlueprintCallable, Category = "Texturge|Variables")
void SetBlueprintVariable(FName VariableName, float Value);

UFUNCTION(BlueprintCallable, Category = "Texturge|Variables")
void SetBlueprintVariable(FName VariableName, int32 Value);

UFUNCTION(BlueprintCallable, Category = "Texturge|Variables")
void SetBlueprintVariable(FName VariableName, bool Value);

UFUNCTION(BlueprintCallable, Category = "Texturge|Variables")
void SetBlueprintVariable(FName VariableName, FVector Value);

UFUNCTION(BlueprintCallable, Category = "Texturge|Variables")
void SetBlueprintVariable(FName VariableName, FLinearColor Value);

UFUNCTION(BlueprintCallable, Category = "Texturge|Variables")
void SetBlueprintVariable(FName VariableName, FVector2D Value);
```

### 从 UTextAnimInstance 调用（5 重载）

```cpp
UFUNCTION(BlueprintCallable, Category = "Texturge|Variables")
void SetBlueprintVariable(FName VariableName, float Value);

UFUNCTION(BlueprintCallable, Category = "Texturge|Variables")
void SetBlueprintVariable(FName VariableName, int32 Value);

UFUNCTION(BlueprintCallable, Category = "Texturge|Variables")
void SetBlueprintVariable(FName VariableName, bool Value);

UFUNCTION(BlueprintCallable, Category = "Texturge|Variables")
void SetBlueprintVariable(FName VariableName, FVector Value);

UFUNCTION(BlueprintCallable, Category = "Texturge|Variables")
void SetBlueprintVariable(FName VariableName, FLinearColor Value);
```

### 使用模式

1. 在事件图表中放置 `AnimatedTextBlock` 引用
2. 拖出引脚 → 搜索 `Set Blueprint Variable`
3. 选择匹配合适类型（Float/Int/Bool/FVector/FLinearColor/FVector2D）的重载
4. 输入 `VariableName`（须与动画蓝图中的参数变量名一致）
5. 连接到调用 `ApplyInstanceOverrides` → `Play`

**典型蓝图图表片段**：

```
[Event BeginPlay]
    → [SetBlueprintVariable] ( "Speed", 2.0 )
    → [ApplyInstanceOverrides]
    → [Play]
```

## UK2Node_PrintWithAnimation

自定义 K2Node，用于在 Kismet 图表中可视化带有动画上下文的字符串打印操作。

```cpp
UCLASS()
class UK2Node_PrintWithAnimation : public UK2Node
{
    // 节点参数
    FString DebugMessage;
    UTextAnimationBlueprint* AnimationContext;

    // K2Node 虚函数
    void AllocateDefaultPins() override;
    void ExpandNode(FKismetCompilerContext& CompilerContext, UEdGraph* SourceGraph) override;
    FText GetNodeTitle(ENodeTitleType::Type TitleType) const override;
    FText GetTooltipText() const override;
    FLinearColor GetNodeTitleColor() const override;
};
```

| 特性 | 说明 |
|:---|:---|
| **标题** | 以当前动画上下文作为图标的"Print with Animation" |
| **输入引脚** | `Execute` 输入 + `Message`（FString）输入 + 目标动画蓝图引用 |
| **输出引脚** | `Then` 执行输出 |
| **展开行为** | 在编译时展开为含动画参数提示的标准 `Print String` 调用 |

## 查询节点

### 舞台控制器查询

| 蓝图节点 | 返回类型 | 说明 |
|:---|:---|:---|
| `Get Current Stage` | `EAnimationStage` | 当前活动的舞台枚举值 |
| `Get Stage Progress` | `float` | 当前舞台播放进度 (0.0–1.0) |
| `Get Playback State` | `EStagePlaybackState` | 当前播放状态 |
| `Get Play Direction` | `EStagePlayDirection` | 当前播放方向 |

### 动画器查询

| 蓝图节点 | 返回类型 | 说明 |
|:---|:---|:---|
| `Is Playing` | `bool` | 是否正在播放 |
| `Is Paused` | `bool` | 是否已暂停 |
| `Get Current Time` | `float` | 当前播放时间 |
| `Get Total Duration` | `float` | 动画总时长 |

## 蓝图动画实例查询

从 `UTextAnimInstance` 暴露：

| 蓝图节点 | 返回类型 | 说明 |
|:---|:---|:---|
| `Get Animation By Name` | `UGlyphAnimation*` | 按名称查找 GlyphAnimation 资产 |
| `Build Schedule Infos` | `TArray<FGlyphScheduleInfo>` | 为文本构建调度信息 |
| `Needs Rebake` | `bool` | 检查是否需要重新烘焙动画 |
| `Resolve Animation References` | — | 解析蓝图中的所有动画引用 |
