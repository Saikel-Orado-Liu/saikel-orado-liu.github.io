Texturge exposes all core runtime functionality as Blueprint‑callable nodes under the `Texturge` category.

## Playback Control Nodes

### Standard Playback Control

Playback control exposed from `UAnimatedTextBlock` and `UAnimatedRichTextBlock`:

| Blueprint Node | Target Class | Description |
|:---|:---|:---|
| `Play` | `UAnimatedTextBlock` / `UAnimatedRichTextBlock` | Start animation playback |
| `Pause` | `UAnimatedTextBlock` / `UAnimatedRichTextBlock` | Pause current animation |
| `Resume` | `UAnimatedTextBlock` / `UAnimatedRichTextBlock` | Resume from pause |
| `Stop` | `UAnimatedTextBlock` / `UAnimatedRichTextBlock` | Stop playback and reset |
| `SkipToEnd` | `UAnimatedTextBlock` / `UAnimatedRichTextBlock` | Jump to end of current animation |
| `RevealAll` | `UTextAnimationStageController` | Reveal all glyphs immediately |

### Stage Control Nodes

Configuration and queries from `UTextAnimationStageController`:

| Blueprint Node | Description |
|:---|:---|
| `Initialize` | Initialize controller with `UTextAnimInstance` and text |
| `SetPlayDirection` | Set play direction: Forward/Reverse/PingPong |
| `SetLoop` | Enable/disable looping |
| `SetCrossfadeEnabled` | Enable crossfade and set duration |
| `EvaluateAllGlyphs` | Evaluate all glyphs, returns `TArray<FGlyphAnimationState>` |
| `EvaluateGlyph` | Evaluate a single glyph |
| `PublishBakedAnimation` | Inject pre‑baked data |

### Animator Nodes

Rich‑text animation control from `UTextAnimator`:

| Blueprint Node | Description |
|:---|:---|
| `SetPlainText` | Set plain‑text content |
| `SetRichText` | Set rich‑text with tags |
| `SetAnimationData` | Set `UTextAnimationDataAsset` mapping table |
| `SetAnimationBlueprint` | Set default `UTextAnimationBlueprint` |
| `StartAnimating` | Start animation; TotalDuration is computed |
| `TickAnimation` | Advance time per frame |
| `GetCurrentFrameData` | Get current frame's `FBakedAnimation` |

### Usage Pattern

1. Place an `AnimatedTextBlock` reference in the Event Graph
2. Drag off the pin → search `Set Blueprint Variable`
3. Select the overload matching the type (Float/Int/Bool/FVector/FLinearColor/FVector2D)
4. Enter `VariableName` (must match a parameter variable name in the animation blueprint)
5. Wire to `ApplyInstanceOverrides` → `Play`

**Typical Blueprint graph fragment**:

```
[Event BeginPlay]
    → [SetBlueprintVariable] ( "Speed", 2.0 )
    → [ApplyInstanceOverrides]
    → [Play]
```

## UK2Node_PrintWithAnimation

Custom K2Node for visualizing string‑print operations with animation context in Kismet graphs.

```cpp
UCLASS()
class UK2Node_PrintWithAnimation : public UK2Node
{
    // Node parameters
    FString DebugMessage;
    UTextAnimationBlueprint* AnimationContext;

    // K2Node overrides
    void AllocateDefaultPins() override;
    void ExpandNode(FKismetCompilerContext& CompilerContext, UEdGraph* SourceGraph) override;
    FText GetNodeTitle(ENodeTitleType::Type TitleType) const override;
    FText GetTooltipText() const override;
    FLinearColor GetNodeTitleColor() const override;
};
```

| Feature | Description |
|:---|:---|
| **Title** | "Print with Animation" with current animation context as icon |
| **Input Pins** | `Execute` input + `Message` (FString) input + target animation blueprint reference |
| **Output Pin** | `Then` execution output |
| **Expansion** | Expands at compile time into a standard `Print String` call with animation parameter hints |

## Query Nodes

### Stage Controller Queries

| Blueprint Node | Return Type | Description |
|:---|:---|:---|
| `Get Current Stage` | `EAnimationStage` | Currently active stage enum value |
| `Get Stage Progress` | `float` | Current stage playback progress (0.0–1.0) |
| `Get Playback State` | `EStagePlaybackState` | Current playback state |
| `Get Play Direction` | `EStagePlayDirection` | Current play direction |

### Animator Queries

| Blueprint Node | Return Type | Description |
|:---|:---|:---|
| `Is Playing` | `bool` | Whether currently playing |
| `Is Paused` | `bool` | Whether paused |
| `Get Current Time` | `float` | Current playback time |
| `Get Total Duration` | `float` | Total animation duration |

## Blueprint AnimInstance Queries

Exposed from `UTextAnimInstance`:

| Blueprint Node | Return Type | Description |
|:---|:---|:---|
| `Get Animation By Name` | `UGlyphAnimation*` | Look up a GlyphAnimation asset by name |
| `Build Schedule Infos` | `TArray<FGlyphScheduleInfo>` | Build schedule info for text |
| `Needs Rebake` | `bool` | Check if animation needs rebaking |
| `Resolve Animation References` | — | Resolve all animation references in the blueprint |
