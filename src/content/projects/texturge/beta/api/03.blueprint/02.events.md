Texturge 通过委托（delegate）与 UFUNCTION 事件将动画生命周期与蓝图系统连接。

## 动画生命周期事件

### 舞台事件（UTextAnimationStageController 委托）

```cpp
DECLARE_DYNAMIC_MULTICAST_DELEGATE_TwoParams(
    FOnStageChanged,
    EAnimationStage, Stage,
    UTextAnimationStageController*, Controller
);
```

| 委托 | 类型 | 触发时机 |
|:---|:---|:---|
| `StageStarted` | `FOnStageChanged` | 新舞台开始播放时触发 |
| `StageCompleted` | `FOnStageChanged` | 当前舞台播放完成时触发 |
| `AllStagesCompleted` | `FSimpleDelegate` | 全部三个舞台（Intro→Default→Outro）完成时触发 |

### 委托参数

| 参数 | 类型 | 说明 |
|:---|:---|:---|
| `Stage` | `EAnimationStage` | 触发事件的舞台（Intro/Default/Outro） |
| `Controller` | `UTextAnimationStageController*` | 触发事件的控制器实例引用 |

### 蓝图绑定步骤

1. 在事件图表中获取 `UTextAnimationStageController` 引用
2. 从控制器引脚拖出 → 搜索 `Assign Stage Started` / `Assign Stage Completed` / `Assign All Stages Completed`
3. 连接红色事件引脚到自定义事件节点
4. 在自定义事件中获取 `Stage` 和 `Controller` 输出参数

**Blueprint 接线示例**：

```
[Controller Ref]
    ├── [Assign Stage Started] ──→ [Custom Event: OnIntroStarted]
    │       → [Print String "Intro stage started"]
    │
    ├── [Assign Stage Completed] ──→ [Custom Event: OnStageDone]
    │       → [Branch] (Stage == Intro ? -> Start Default Logic)
    │
    └── [Assign All Stages Completed] ──→ [Custom Event: OnAllDone]
            → [Destroy Widget / Transition Level]
```

## BuildDefaultAnimation（BlueprintNativeEvent）

`UTextAnimInstance` 中最核心的蓝图事件，允许在蓝图中覆盖默认动画的构建逻辑。

```cpp
UFUNCTION(BlueprintNativeEvent, Category = "Texturge|Animation")
FBakedAnimation BuildDefaultAnimation(int32 GlyphCount, const FString& Text);
```

| 参数 | 类型 | 说明 |
|:---|:---|:---|
| `GlyphCount` | `int32` | 文本中字粒的数量 |
| `Text` | `const FString&` | 完整的文本内容 |
| **Return** | `FBakedAnimation` | 烘焙完成的动画数据（含 Intro/Default/Outro 三阶段） |

### 蓝图覆盖示例

在动画蓝图的事件图表中：

1. 右键图表 → `Override` → `BuildDefaultAnimation`
2. 添加 `Event BuildDefaultAnimation` 节点
3. 使用 `BuildScheduleInfos` 对文本构建调度信息
4. 通过 `UGlyphAnimationLayer` 工厂逐字粒配置动画参数
5. 调用 `Bake()` 生成 `FBakedAnimation`
6. 从返回节点输出烘焙数据

## 变量变更事件（UTextAnimationBlueprint 委托）

```cpp
FSimpleDelegate OnVariableAdded;
FSimpleDelegate OnVariableRemoved;
FSimpleDelegate OnVariableRenamed;
```

| 委托 | 触发时机 |
|:---|:---|
| `OnVariableAdded` | 在动画蓝图变量表中添加新参数变量时触发 |
| `OnVariableRemoved` | 从动画蓝图变量表中删除参数变量时触发 |
| `OnVariableRenamed` | 参数变量被重命名时触发 |

这些委托主要用于编辑器内部刷新而非游戏逻辑驱动。

## BlueprintImplementableEvent 方法

`UTextAnimInstance` 提供以下 `BlueprintImplementableEvent` 方法，可在蓝图中实现而不需要 C++ 基类实现：

### EvaluateBaked Override

```cpp
UFUNCTION(BlueprintImplementableEvent, Category = "Texturge|Evaluation")
FBakedAnimation EvaluateBaked(const FString& Text);
```

在默认实现中，`EvaluateBaked` 检查 `NeedsRebake` 决定是否需要重新烘焙。蓝图覆盖可添加自定义缓存逻辑或修改烘焙流程。

### BuildScheduleInfos Override

```cpp
UFUNCTION(BlueprintImplementableEvent, Category = "Texturge|Scheduling")
TArray<FGlyphScheduleInfo> BuildScheduleInfos(const FString& Text, int32 GlyphCount);
```

允许在蓝图中覆盖字粒调度逻辑——修改各字粒的起始延迟、跳过逻辑与比例因子。

## 事件接线最佳实践

1. **将事件绑定放在初始化之后**：在 `Initialize` 调用之后配置委托绑定，避免空控制器引用
2. **利用 Stage 参数区分舞台**：在 `StageStarted` 和 `StageCompleted` 中检查 `Stage` 参数决定各舞台的游戏逻辑
3. **在 AllStagesCompleted 中清理**：全部动画结束后释放资源、销毁控件或触发关卡切换
4. **使用 ApplyInstanceOverrides 设置参数**：在 `BuildDefaultAnimation` 之前调用覆盖
5. **缓存动画参考**：在 `BeginPlay` 中调用 `GetAnimationByName` 缓存 `UGlyphAnimation` 引用
