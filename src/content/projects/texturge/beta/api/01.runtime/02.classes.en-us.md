The Runtime module exposes the following core classes. All inherit from `UObject` (widget classes inherit from UMG widgets).

## Class Hierarchy

```
UObject
├── UTextAnimationStageController    — Stage controller managing Intro→Default→Outro flow
├── UTextAnimator                     — Animator driving rich‑text animation evaluation
├── UTextAnimationBlueprint           — Animation blueprint asset (inherits UBlueprint)
├── UTextAnimInstance                 — Animation instance holding bake cache
├── UAnimParameterOverrides           — Parameter override table (Instanced per‑widget)
└── UGlyphAnimation                   — Glyph animation sequence (inherits UMovieSceneSequence)
UTextBlock
└── UAnimatedTextBlock                — Text widget with animation support
URichTextBlock
└── UAnimatedRichTextBlock            — Rich text widget with animation support
```

## UAnimatedTextBlock

UMG widget inheriting from `UTextBlock`. Internally owns a `UTextAnimationStageController` and manages its lifecycle automatically.

```cpp
class UAnimatedTextBlock : public UTextBlock
{
    // Properties
    TSubclassOf<UTextAnimInstance> AnimInstanceClass;
    UAnimParameterOverrides* ParameterOverrides;
    FText PreviewText;

    // Playback control
    void Play();
    void Pause();
    void Resume();
    void Stop();
    void SkipToEnd();

    // Parameter setters (6 overloads)
    void SetBlueprintVariable(FName VarName, float Value);
    void SetBlueprintVariable(FName VarName, int32 Value);
    void SetBlueprintVariable(FName VarName, bool Value);
    void SetBlueprintVariable(FName VarName, FVector Value);
    void SetBlueprintVariable(FName VarName, FLinearColor Value);
    void SetBlueprintVariable(FName VarName, FVector2D Value);

    // Override management
    void ApplyInstanceOverrides();
    void RestoreCDOValues();

    // Rendering override
    virtual int32 NativePaint(...) override;
};
```

| Property | Type | Description |
|:---|:---|:---|
| `AnimInstanceClass` | `TSubclassOf<UTextAnimInstance>` | Specifies the animation instance blueprint class |
| `ParameterOverrides` | `UAnimParameterOverrides*` | Instanced parameter override table |
| `PreviewText` | `FText` | Preview text displayed in the editor |

**Usage example**:

```cpp
// Dynamically create and configure at runtime
UAnimatedTextBlock* TextBlock = CreateWidget<UAnimatedTextBlock>(Owner, AnimTextWidgetClass);
TextBlock->AnimInstanceClass = MyAnimationBP->GeneratedClass;
TextBlock->SetText(FText::FromString("Hello World"));
TextBlock->Play();
```

## UAnimatedRichTextBlock

Inherits from `URichTextBlock`, uses `UTextAnimator` internally. Maps rich‑text tags to animation blueprints via `UTextAnimationDataAsset`.

```cpp
class UAnimatedRichTextBlock : public URichTextBlock

    UTextAnimationBlueprint* DefaultAnimationBlueprint;

    // Playback control
    void Play();

    void Resume();
    void Stop();
    void SkipToEnd();

```

| Property | Type | Description |
|:---|:---|:---|
| `AnimationDataAsset` | `UTextAnimationDataAsset*` | Tag‑to‑blueprint mapping table |
| `DefaultAnimationBlueprint` | `UTextAnimationBlueprint*` | Fallback animation for unmatched tags |

## UTextAnimationStageController

The central dispatch unit for runtime animation.

```cpp
class UTextAnimationStageController : public UObject
{
    // Properties
    EAnimationStage CurrentStage;
    EStagePlaybackState PlaybackState;
    EStagePlayDirection PlayDirection;
    bool bLoop;
    bool bCrossfadeEnabled;
    float CrossfadeDuration;
    float StageProgress;

    // Initialization
    void Initialize(UTextAnimInstance* CDO, const FString& Text);

    // Playback control
    void Play();
    void Pause();
    void Resume();
    void Stop();
    void RevealAll();

    // Configuration
    void SetPlayDirection(EStagePlayDirection Direction);
    void SetLoop(bool bEnable);
    void SetCrossfadeEnabled(bool bEnable, float Duration);

    // Per‑frame evaluation
    void TickAnimation(float DeltaTime);
    void EvaluateAllGlyphs(TArray<FGlyphAnimationState>& OutStates);
    void EvaluateGlyph(int32 GlyphIndex, FGlyphAnimationState& OutState);

    // Baked data injection
    void PublishBakedAnimation(FBakedAnimation&& Baked);

    // Delegates
    FOnStageChanged StageStarted;
    FOnStageChanged StageCompleted;
    FSimpleDelegate AllStagesCompleted;
};
```

| Property | Type | Description |
|:---|:---|:---|
| `CurrentStage` | `EAnimationStage` | Currently active stage |
| `PlaybackState` | `EStagePlaybackState` | Playback state: Stopped/Playing/Paused/Complete |
| `PlayDirection` | `EStagePlayDirection` | Play direction: Forward/Reverse/PingPong |
| `bLoop` | `bool` | Whether to loop playback |
| `bCrossfadeEnabled` | `bool` | Whether inter‑stage crossfade is enabled |
| `CrossfadeDuration` | `float` | Crossfade duration in seconds |
| `StageProgress` | `float` | Current stage playback progress (0.0–1.0) |

## UTextAnimInstance

Compiled animation instance holding bake cache and blueprint fingerprints.

```cpp
class UTextAnimInstance : public UObject
{
    // Properties
    UTextAnimationBlueprint* Blueprint;
    FBakedAnimation CachedBakedAnimation;
    FString CachedTextFingerprint;
    FString CachedBlueprintFingerprint;

    // BlueprintNativeEvent
    UFUNCTION(BlueprintNativeEvent)
    FBakedAnimation BuildDefaultAnimation(int32 GlyphCount, const FString& Text);

    // Scheduling & evaluation
    TArray<FGlyphScheduleInfo> BuildScheduleInfos(const FString& Text, int32 GlyphCount);
    FBakedAnimation* EvaluateBaked(const FString& Text);
    bool NeedsRebake(const FString& Text);

    // Queries
    UGlyphAnimation* GetAnimationByName(FName Name);

    // Parameter setters (5 overloads)
    void SetBlueprintVariable(FName VarName, float Value);
    void SetBlueprintVariable(FName VarName, int32 Value);
    void SetBlueprintVariable(FName VarName, bool Value);
    void SetBlueprintVariable(FName VarName, FVector Value);
    void SetBlueprintVariable(FName VarName, FLinearColor Value);

    // Reference resolution
    void ResolveAnimationReferences();
};
```

| Property | Type | Description |
|:---|:---|:---|
| `CachedBakedAnimation` | `FBakedAnimation` | Last‑compiled baked animation data |
| `CachedTextFingerprint` | `FString` | Fingerprint hash of the text content |
| `CachedBlueprintFingerprint` | `FString` | Fingerprint hash of the blueprint |

`EvaluateBaked` checks `NeedsRebake`. If text or blueprint has changed, it calls `BuildDefaultAnimation` to rebake and returns the valid `FBakedAnimation` for the controller to consume.

## UAnimParameterOverrides

Instanced per‑widget parameter override object.

```cpp
class UAnimParameterOverrides : public UObject
{
    TMap<FName, float>      FloatOverrides;
    TMap<FName, int32>      IntOverrides;
    TMap<FName, bool>       BoolOverrides;
    TMap<FName, FVector>    VectorOverrides;
    TMap<FName, FLinearColor> ColorOverrides;
    TMap<FName, FVector2D>  Vector2DOverrides;
};
```

Set on a widget and injected into the bound `UTextAnimInstance` via `UAnimatedTextBlock::ApplyInstanceOverrides()`.
