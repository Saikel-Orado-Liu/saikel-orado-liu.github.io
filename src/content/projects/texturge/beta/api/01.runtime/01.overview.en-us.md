The Runtime module is the core subsystem of Texturge, driving text animation loading, compilation, evaluation, and rendering during gameplay. It integrates seamlessly with UE5's tick pipeline, UMG rendering, and Sequencer.

## Core Concepts

| Concept | Description |
|:---|:---|
| `UTextAnimationStageController` | Stage controller managing the Intro→Default→Outro three‑stage flow and crossfade |
| `UTextAnimator` | Text animator driving per‑frame evaluation for `UAnimatedRichTextBlock` |
| `UTextAnimationBlueprint` | Animation blueprint asset defining glyph animation tracks and GlyphAnimation references |
| `UTextAnimInstance` | Animation instance, output of blueprint compilation, holding cached baked animation data |
| `UGlyphAnimation` | Glyph animation sequence asset (based on `UMovieSceneSequence`), storing track keyframe data |
| `FBakedAnimation` | Baked animation data containing three `FBakedStage` instances (Intro/Default/Outro) |
| `FGlyphAnimationState` | Glyph animation state, 21‑channel float properties (position/scale/rotation/color/shadow etc.) |

## Initialization Flow

The controller is created from a `UTextAnimInstance` produced by `UTextAnimationBlueprint` compilation:

```cpp
// Create an animation instance from a Blueprint
UTextAnimInstance* AnimInstance = AnimationBlueprint->CreateAnimInstance();

// Create and initialize the stage controller
UTextAnimationStageController* Controller = NewObject<UTextAnimationStageController>(this);
Controller->Initialize(AnimInstance, MyDisplayText);
Controller->Play();
```

`UAnimatedTextBlock` encapsulates the full init‑and‑bind flow internally — developers simply set `AnimInstanceClass` and the text; the widget auto‑creates the controller and handles ticking.

## Playback Control

The controller and animator share a unified playback lifecycle:

| Method | Description |
|:---|:---|
| `Play()` | Start playback from the current stage start |
| `Pause()` | Pause time progression, hold current state |
| `Resume()` | Resume playback from pause point |
| `Stop()` | Stop playback and reset to initial state |
| `SkipToEnd()` | Immediately jump to end of current animation |
| `RevealAll()` | Reveal all glyphs (stage controller only) |

`UTextAnimationStageController::TickAnimation(float DeltaTime)` is driven by the host widget's `OnPaint` or manual ticking, advancing time each frame and calling `EvaluateAllGlyphs`.

## Stage System

Animation is divided into three stages (`EAnimationStage`), advancing sequentially:

1. **Intro** — Entrance animation, glyphs appear one by one
2. **Default** — Default looping animation, plays continuously after the text is fully revealed
3. **Outro** — Exit animation, glyphs disappear one by one

Each stage corresponds to `FBakedStage` baked data. The controller maintains `CurrentStage` state, with `StageProgress` tracking progress (0.0–1.0). Stage transitions are notified via the `StageCompleted` delegate.

## Crossfade

When `bCrossfadeEnabled` is `true`, adjacent stages blend evaluation over the `CrossfadeDuration` time window. `ETextAnimationBlendMode::CrossFade` is handled in `FBakedGlyph::Evaluate` for inter‑layer blending.

## Widget Binding

Two UMG widgets integrate with the runtime:

- **`UAnimatedTextBlock : public UTextBlock`** — Internally owns a `UTextAnimationStageController`. Specify the blueprint class via `AnimInstanceClass`; override parameters via `ParameterOverrides`.
- **`UAnimatedRichTextBlock : public URichTextBlock`** — Internally uses `UTextAnimator`. Map rich‑text tags to animation blueprints via `AnimationDataAsset`. Supports `<anima>`‑tagged regions.

Both widgets drive animation ticking through `OnPaint` overrides. All runtime classes are written in C++; performance‑critical paths use pre‑baking and caching to avoid per‑frame recompilation.

## Parameter Overrides

`UAnimParameterOverrides` provides six override maps (`FloatOverrides`, `IntOverrides`, `BoolOverrides`, `VectorOverrides`, `ColorOverrides`, `Vector2DOverrides`). These are injected into the `UTextAnimInstance` before playback via `ApplyInstanceOverrides()`. After playback ends, `RestoreCDOValues()` restores defaults.
