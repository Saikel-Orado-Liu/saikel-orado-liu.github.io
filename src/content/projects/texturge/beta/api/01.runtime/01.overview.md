运行时模块（`Runtime`）是 Texturge 插件的核心子系统，在游戏运行期间驱动文字动画的加载、编译、求值与渲染。它与 UE5 Tick 管线、UMG 渲染及 Sequencer 无缝集成。

## 核心概念

| 概念 | 说明 |
|:---|:---|
| `UTextAnimationStageController` | 文字动画舞台控制器，管理 Intro→Default→Outro 三阶段流程与交叉淡入淡出 |
| `UTextAnimator` | 文字动画器，驱动 `UAnimatedRichTextBlock` 的逐帧动画求值 |
| `UTextAnimationBlueprint` | 动画蓝图资产，定义字粒动画轨道与 GlyphAnimation 引用 |
| `UTextAnimInstance` | 动画实例，由蓝图编译输出，持有 baked animation 缓存 |
| `UGlyphAnimation` | 字粒动画序列资产（基于 `UMovieSceneSequence`），存储轨道关键帧数据 |
| `FBakedAnimation` | 烘焙后的动画数据，包含 Intro/Default/Outro 三个 `FBakedStage` |
| `FGlyphAnimationState` | 字粒动画状态，21 通道浮点属性（位置/缩放/旋转/颜色/阴影等） |

## 初始化流程

控制器由 `UTextAnimationBlueprint` 编译产生的 `UTextAnimInstance` 创建：

```cpp
// 通过 UTextAnimationBlueprint 创建动画实例
UTextAnimInstance* AnimInstance = AnimationBlueprint->CreateAnimInstance();

// 创建舞台控制器并初始化
UTextAnimationStageController* Controller = NewObject<UTextAnimationStageController>(this);
Controller->Initialize(AnimInstance, MyDisplayText);
Controller->Play();
```

`UAnimatedTextBlock` 内部封装了完整的初始化与绑定流程——开发者只需设置 `AnimInstanceClass` 与文本，控件自动创建控制器并处理 Tick。

## 播放控制

控制器与动画器提供统一的播放生命周期：

| 方法 | 说明 |
|:---|:---|
| `Play()` | 从当前舞台起始点开始播放 |
| `Pause()` | 暂停时间推进，保持当前状态 |
| `Resume()` | 从暂停点恢复播放 |
| `Stop()` | 停止播放，重置到初始状态 |
| `SkipToEnd()` | 立即跳到当前动画末尾 |
| `RevealAll()` | 显示所有字粒（舞台控制器附加） |

`UTextAnimationStageController::TickAnimation(float DeltaTime)` 由宿主 Widget 的 `OnPaint` 或手动 Tick 驱动，每帧推进时间并调用 `EvaluateAllGlyphs`。

## 舞台系统

动画分为三个舞台（`EAnimationStage`），按顺序推进：

1. **Intro** — 入场动画，字粒逐个出现
2. **Default** — 默认循环动画，在文本完全显示后持续播放
3. **Outro** — 退场动画，字粒逐个消失

每个舞台对应 `FBakedStage` 烘焙数据。控制器维护 `CurrentStage` 状态，`StageProgress` 跟踪当前舞台进度（0.0–1.0）。舞台切换由 `StageCompleted` 委托通知。

## 交叉淡入淡出

当 `bCrossfadeEnabled` 为 `true` 时，相邻舞台之间通过 `CrossfadeDuration` 指定的时间窗进行混合求值。`ETextAnimationBlendMode::CrossFade` 在 `FBakedGlyph::Evaluate` 中处理层间混合。

## 控件绑定

有两个 UMG 控件接入运行时：

- **`UAnimatedTextBlock : public UTextBlock`** — 内部拥有 `UTextAnimationStageController`，通过 `AnimInstanceClass` 属性指定蓝图类，`ParameterOverrides` 提供参数覆盖
- **`UAnimatedRichTextBlock : public URichTextBlock`** — 内部使用 `UTextAnimator`，通过 `AnimationDataAsset` 映射富文本标签到动画蓝图，支持 `<anima>` 标签标记的动画区域

两个控件均通过重写 `OnPaint` 驱动动画 Tick。所有运行时类以 C++ 编写，性能关键路径通过预烘焙与缓存避免每帧重编译。

## 参数覆盖

`UAnimParameterOverrides` 提供 6 组覆盖映射（`FloatOverrides`、`IntOverrides`、`BoolOverrides`、`VectorOverrides`、`ColorOverrides`、`Vector2DOverrides`），在动画播放前通过 `ApplyInstanceOverrides()` 注入到 `UTextAnimInstance`。播放结束后调用 `RestoreCDOValues()` 恢复默认值。
