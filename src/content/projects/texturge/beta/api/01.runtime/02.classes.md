运行时模块提供以下核心类，所有类均继承自 `UObject`（控件类继承自 UMG 控件）。

## 类层级

```
UObject
├── UTextAnimationStageController    — 舞台控制器，管理 Intro→Default→Outro 三阶段
├── UTextAnimator                     — 动画器，驱动富文本动画求值
├── UTextAnimationBlueprint           — 动画蓝图资产（继承 UBlueprint）
├── UTextAnimInstance                 — 动画实例，持有烘焙缓存
├── UAnimParameterOverrides           — 参数覆盖表（Instanced 每个控件）
└── UGlyphAnimation                   — 字粒动画序列（继承 UMovieSceneSequence）
UTextBlock
└── UAnimatedTextBlock                — 带动画支持的文本控件
URichTextBlock
└── UAnimatedRichTextBlock            — 带动画支持的富文本控件
```

## UAnimatedTextBlock

继承自 `UTextBlock` 的 UMG 控件，内部持有 `UTextAnimationStageController` 并自动管理其生命周期。

```cpp
class UAnimatedTextBlock : public UTextBlock
{
    // 属性
    TSubclassOf<UTextAnimInstance> AnimInstanceClass;
    UAnimParameterOverrides* ParameterOverrides;
    FText PreviewText;

    // 播放控制
    void Play();
    void Pause();
    void Resume();
    void Stop();
    void SkipToEnd();

    // 参数设置（6 重载）
    void SetBlueprintVariable(FName VarName, float Value);
    void SetBlueprintVariable(FName VarName, int32 Value);
    void SetBlueprintVariable(FName VarName, bool Value);
    void SetBlueprintVariable(FName VarName, FVector Value);
    void SetBlueprintVariable(FName VarName, FLinearColor Value);
    void SetBlueprintVariable(FName VarName, FVector2D Value);

    // 参数覆盖管理
    void ApplyInstanceOverrides();
    void RestoreCDOValues();

    // 渲染重写
    virtual int32 NativePaint(...) override;
};
```

| 属性 | 类型 | 说明 |
|:---|:---|:---|
| `AnimInstanceClass` | `TSubclassOf<UTextAnimInstance>` | 指定动画实例蓝图类 |
| `ParameterOverrides` | `UAnimParameterOverrides*` | 实例化参数覆盖表 |
| `PreviewText` | `FText` | 编辑器中显示的预览文本 |

**使用示例**：

```cpp
// 代码中动态创建并配置
UAnimatedTextBlock* TextBlock = CreateWidget<UAnimatedTextBlock>(Owner, AnimTextWidgetClass);
TextBlock->AnimInstanceClass = MyAnimationBP->GeneratedClass;
TextBlock->SetText(FText::FromString("Hello World"));
TextBlock->Play();
```

## UAnimatedRichTextBlock

继承自 `URichTextBlock`，使用 `UTextAnimator` 驱动动画。通过 `UTextAnimationDataAsset` 将富文本标签映射到动画蓝图。

```cpp
class UAnimatedRichTextBlock : public URichTextBlock
{
    // 属性
    UTextAnimationDataAsset* AnimationDataAsset;
    UTextAnimationBlueprint* DefaultAnimationBlueprint;

    // 播放控制
    void Play();
    void Pause();
    void Resume();
    void Stop();
    void SkipToEnd();
};
```

| 属性 | 类型 | 说明 |
|:---|:---|:---|
| `AnimationDataAsset` | `UTextAnimationDataAsset*` | 标签到动画蓝图的映射表 |
| `DefaultAnimationBlueprint` | `UTextAnimationBlueprint*` | 未匹配标签时的默认动画 |

## UTextAnimationStageController

舞台控制器是运行时动画的中央调度单元。

```cpp
class UTextAnimationStageController : public UObject
{
    // 属性
    EAnimationStage CurrentStage;
    EStagePlaybackState PlaybackState;
    EStagePlayDirection PlayDirection;
    bool bLoop;
    bool bCrossfadeEnabled;
    float CrossfadeDuration;
    float StageProgress;

    // 初始化
    void Initialize(UTextAnimInstance* CDO, const FString& Text);

    // 播放控制
    void Play();
    void Pause();
    void Resume();
    void Stop();
    void RevealAll();

    // 配置
    void SetPlayDirection(EStagePlayDirection Direction);
    void SetLoop(bool bEnable);
    void SetCrossfadeEnabled(bool bEnable, float Duration);

    // 逐帧求值
    void TickAnimation(float DeltaTime);
    void EvaluateAllGlyphs(TArray<FGlyphAnimationState>& OutStates);
    void EvaluateGlyph(int32 GlyphIndex, FGlyphAnimationState& OutState);

    // 烘焙数据注入
    void PublishBakedAnimation(FBakedAnimation&& Baked);

    // 委托
    FOnStageChanged StageStarted;
    FOnStageChanged StageCompleted;
    FSimpleDelegate AllStagesCompleted;
};
```

| 属性 | 类型 | 说明 |
|:---|:---|:---|
| `CurrentStage` | `EAnimationStage` | 当前活动的舞台 |
| `PlaybackState` | `EStagePlaybackState` | 播放状态：Stopped/Playing/Paused/Complete |
| `PlayDirection` | `EStagePlayDirection` | 播放方向：Forward/Reverse/PingPong |
| `bLoop` | `bool` | 是否循环播放 |
| `bCrossfadeEnabled` | `bool` | 是否启用舞台间交叉淡入淡出 |
| `CrossfadeDuration` | `float` | 交叉淡入淡出持续时长（秒） |
| `StageProgress` | `float` | 当前舞台播放进度 (0.0–1.0) |

## UTextAnimInstance

编译后的动画实例，持有烘焙缓存与蓝图指纹。

```cpp
class UTextAnimInstance : public UObject
{
    // 属性
    UTextAnimationBlueprint* Blueprint;
    FBakedAnimation CachedBakedAnimation;
    FString CachedTextFingerprint;
    FString CachedBlueprintFingerprint;

    // 蓝图原生事件
    UFUNCTION(BlueprintNativeEvent)
    FBakedAnimation BuildDefaultAnimation(int32 GlyphCount, const FString& Text);

    // 调度与求值
    TArray<FGlyphScheduleInfo> BuildScheduleInfos(const FString& Text, int32 GlyphCount);
    FBakedAnimation* EvaluateBaked(const FString& Text);
    bool NeedsRebake(const FString& Text);

    // 查询
    UGlyphAnimation* GetAnimationByName(FName Name);

    // 参数设置（5 重载）
    void SetBlueprintVariable(FName VarName, float Value);
    void SetBlueprintVariable(FName VarName, int32 Value);
    void SetBlueprintVariable(FName VarName, bool Value);
    void SetBlueprintVariable(FName VarName, FVector Value);
    void SetBlueprintVariable(FName VarName, FLinearColor Value);

    // 引用解析
    void ResolveAnimationReferences();
};
```

| 属性 | 类型 | 说明 |
|:---|:---|:---|
| `CachedBakedAnimation` | `FBakedAnimation` | 上次编译的烘焙动画数据 |
| `CachedTextFingerprint` | `FString` | 文本内容的指纹哈希 |
| `CachedBlueprintFingerprint` | `FString` | 蓝图的指纹哈希 |

`EvaluateBaked` 检查 `NeedsRebake`，若文本或蓝图变更则调用 `BuildDefaultAnimation` 重新烘焙，最终返回有效的 `FBakedAnimation` 供控制器使用。

## UAnimParameterOverrides

Instanced per‑widget 的参数覆盖对象。

```cpp
class UAnimParameterOverrides : public UObject
{
    TMap<FName, float>      FloatOverrides;
    TMap<FName, int32>      IntOverrides;
    TMap<FName, bool>       BoolOverrides;
    TMap<FName, FVector>    VectorOverrides;
    TMap<FName, FLinearColor> ColorOverrides;
    TMap<FName, FVector2D>  Vector2DOverrides;
};
```

在控件上设置后，通过 `UAnimatedTextBlock::ApplyInstanceOverrides()` 注入到绑定的 `UTextAnimInstance`。
