## 关键 BlueprintNativeEvent

### BuildDefaultAnimation

这是 Beta 版本最强大的扩展点：

```cpp
UFUNCTION(BlueprintNativeEvent, Category = "Texturge|Animation")
FBakedStage BuildDefaultAnimation(int32 GlyphCount, const FString& Text);
```

**蓝图覆盖签名**:

```
输入:
  GlyphCount (int32) — 文本中的字形数量
  Text (String) — 源文本字符串

输出:
  ReturnValue (FBakedStage) — 烘焙后的动画阶段数据
```

### 蓝图中的使用方式

1. 打开 `UTextAnimationBlueprint` 派生类的 Event Graph
2. 在 Functions 列表中右键 → Override → `BuildDefaultAnimation`
3. 实现自定义动画生成逻辑

### 典型实现流程

```
Event BuildDefaultAnimation
  │
  ├─ BuildScheduleInfos(Text) → ScheduleInfos 数组
  │
  ├─ 创建 UGlyphAnimationLayer（选择基础动画资产）
  │
  ├─ 创建 UGlyphAnimationFactory
  │
  ├─ 遍历字形进行自定义：
  │   ├─ SetStartDelayAt（延迟）
  │   ├─ SetTranslationAt（位移）
  │   ├─ SetScaleAt（缩放）
  │   ├─ SetRotationAt（旋转）
  │   └─ SetGlyphColor / SetGlyphOpacity / ...（其他微调）
  │
  └─ Factory->Bake() → 返回 FBakedStage
```

## Blueprint 可调用 USTRUCT

### FBakedStage

```cpp
USTRUCT(BlueprintType)
struct FBakedStage
{
    UPROPERTY(BlueprintReadOnly)
    EAnimationStage StageType;

    UPROPERTY(BlueprintReadOnly)
    int32 GlyphCount;

    UPROPERTY(BlueprintReadOnly)
    float TotalDuration;

    UPROPERTY(BlueprintReadOnly)
    TArray<FBakedGlyph> Glyphs;

    bool IsValid() const;
    int32 GetStartedGlyphCount(float StageTime) const;
};
```

### FBakedGlyph

```cpp
USTRUCT(BlueprintType)
struct FBakedGlyph
```

### FGlyphAnimationState

```cpp
USTRUCT(BlueprintType)
struct FGlyphAnimationState
{
    UPROPERTY(BlueprintReadWrite) FVector2D PositionOffset = (0,0);
    UPROPERTY(BlueprintReadWrite) FVector2D Scale = (1,1);
    UPROPERTY(BlueprintReadWrite) float Rotation = 0.0f;
    UPROPERTY(BlueprintReadWrite) FVector2D Shear = (0,0);
    UPROPERTY(BlueprintReadWrite) FVector2D Pivot = (0.5,0.5);

    UPROPERTY(BlueprintReadWrite) FVector2D ShadowOffset = (0,0);

```

### FGlyphScheduleInfo

```cpp
USTRUCT(BlueprintType)
struct FGlyphScheduleInfo
{
    // 只读
    UPROPERTY(BlueprintReadOnly) int32 GlyphIndex;
    UPROPERTY(BlueprintReadOnly) FString GlyphString;
    UPROPERTY(BlueprintReadOnly) bool bIsWhitespace;
    UPROPERTY(BlueprintReadOnly) bool bIsPunctuation;
    UPROPERTY(BlueprintReadOnly) bool bIsCJK;
    UPROPERTY(BlueprintReadOnly) bool bIsDecorator;

    // 读写
    UPROPERTY(BlueprintReadWrite) float StartDelay;
    UPROPERTY(BlueprintReadWrite) bool bSkipAnimation;
    UPROPERTY(BlueprintReadWrite) float ValueScale;
    UPROPERTY(BlueprintReadWrite) float ValueOffset;
    UPROPERTY(BlueprintReadWrite) bool bRequiresUniqueCurves;
    UPROPERTY(BlueprintReadWrite) float SeedJitter;
};
```
