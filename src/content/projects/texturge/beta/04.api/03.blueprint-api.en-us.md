## Key BlueprintNativeEvent

### BuildDefaultAnimation

This is Beta's most powerful extension point:

```cpp
UFUNCTION(BlueprintNativeEvent, Category = "Texturge|Animation")
FBakedStage BuildDefaultAnimation(int32 GlyphCount, const FString& Text);
```

**Blueprint Override Signature**:

```
Inputs:
  GlyphCount (int32) — Number of glyphs in the text
  Text (String) — Source text string

Output:
  ReturnValue (FBakedStage) — Baked animation stage data
```

### How to Use in Blueprints

1. Open the Event Graph of a `UTextAnimationBlueprint` derived class
2. Right-click in the Functions list → Override → `BuildDefaultAnimation`
3. Implement custom animation generation logic

### Typical Implementation Flow

```
Event BuildDefaultAnimation
  │
  ├─ BuildScheduleInfos(Text) → ScheduleInfos array
  │
  ├─ Create UGlyphAnimationLayer (choose base animation asset)
  │
  ├─ Create UGlyphAnimationFactory
  │
  ├─ Iterate glyphs for customization:
  │   ├─ SetStartDelayAt (delay)
  │   ├─ SetTranslationAt (translation)
  │   ├─ SetScaleAt (scale)
  │   ├─ SetRotationAt (rotation)
  │   └─ SetGlyphColor / SetGlyphOpacity / ... (other tweaks)
  │
  └─ Factory->Bake() → Return FBakedStage
```

## Blueprint-Callable USTRUCTs

### FBakedStage

```cpp
USTRUCT(BlueprintType)
struct FBakedStage
{
    UPROPERTY(BlueprintReadOnly)
    EAnimationStage StageType;

    UPROPERTY(BlueprintReadOnly)
    int32 GlyphCount;

    UPROPERTY(BlueprintReadOnly)
    float TotalDuration;

    UPROPERTY(BlueprintReadOnly)
    TArray<FBakedGlyph> Glyphs;

    bool IsValid() const;
    int32 GetStartedGlyphCount(float StageTime) const;
};
```
