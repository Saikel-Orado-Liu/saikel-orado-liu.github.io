# Runtime C++ API Reference

Complete reference for the Texturge Runtime module (`Texturge`) C++ public API. All classes are located under the `Public/` directory.

## Compilation System

### FAnimationCompiler

**File**: `Public/Animation/AnimationCompiler.h`
**Type**: Non-UObject pure function compiler

#### Public Static Methods

| Method | Signature | Description |
|--------|-----------|-------------|
| **BakeAllStages** | `(UTextAnimationBlueprint*, const FString&) → FBakedAnimation` | Main entry for compiling all stages |
| **BuildScheduleInfos** | `(const FString&) → TArray<FGlyphScheduleInfo>` | Glyph classification and schedule info |
| **ExtractCurves** | `(UGlyphAnimation*) → FGlyphCurveSet` | Curve extraction (with caching) |
| **ConvertFloatChannelToRichCurve** | `(const FMovieSceneFloatChannel&, FFrameRate) → FRichCurve` | Engine channel to RichCurve conversion |
| **BakeStage** | `(EAnimationStage, UGlyphAnimation*, TArray<FGlyphScheduleInfo>&) → FBakedStage` | Single stage bake |
| **BakeStageWithCurves** | `(EAnimationStage, const FGlyphCurveSet&, TArray<FGlyphScheduleInfo>&) → FBakedStage` | Test helper bake |
| **ComputeTextFingerprint** | `(const FString&) → uint64` | Text fingerprint (CityHash64) |
| **ComputeBlueprintFingerprint** | `(UTextAnimationBlueprint*) → uint64` | Blueprint fingerprint |

#### Constants

```cpp
static constexpr int32 MinFramesBetweenRebakes = 3;
```
