# Editor C++ API 参考

TexturgeEditor 模块 (`TexturgeEditor`) 的 C++ API 参考。所有类仅编辑器环境可用。

## 模块注册

### FTexturgeEditorModule

**文件**: `Public/TexturgeEditor.h`

编辑器模块主类，在 `StartupModule()` 中注册所有编辑器扩展：

- 编辑器命令
- 预览标签页生成器
- 工具栏菜单扩展
- `UTextAnimationBlueprint` 的 Kismet 编译器上下文
- `UTextAnimInstance` 的 Blueprint 类型覆盖
- PropertyEditor 自定义详情面板
- Sequencer GlyphAnimationTrackEditor

## 编辑器框架

### FTextAnimationBlueprintEditor

**文件**: `Public/Editor/TextAnimationBlueprintEditor.h`
**基类**: `FBlueprintEditor`

文本动画蓝图的主编辑器，包含 7 个标签页：

| 标签页 | 说明 |
|--------|------|
| AnimationDesigner | 动画设计器视口（主面板） |
| TrackList | 轨道列表面板 |
| Timeline | 时间轴/Sequencer 面板 |
| Details | 细节属性面板 |
| PreviewSettings | 预览设置面板 |
| PreviewAnimationList | 预览动画列表 |
| PreviewViewport | 预览视口 |

#### 关键方法

```cpp
void InitTextAnimationEditor(
    const EToolkitMode::Type Mode,
    const TSharedPtr<IToolkitHost>& InitToolkitHost,
    UTextAnimationBlueprint* Blueprint
);

void RegisterTabSpawners(const TSharedRef<FTabManager>& TabManager);
void Tick(float DeltaTime);
void Compile();
TSharedRef<ISequencer> GetSequencer() const;
void ChangeViewedAnimation(UGlyphAnimation* Animation);
FPreviewSourceMediator* GetPreviewSourceMediator() const;
STextAnimationDesignerView* GetDesignerView() const;
```

### STextAnimationDesignerView

**文件**: `Public/Designer/STextAnimationDesignerView.h`

自定义设计视口，基于 UMG SDesignerView 架构：

- `SDesignSurface` — 缩放/平移
- `SZoomPan` — 缩放平移控制
- `SPaintSurface` — 绘制表面
- `SRuler` — 标尺
- `SDesignerToolBar` — 工具栏
- `STransformHandle` — 变换手柄
- `SDisappearingBar` — 信息栏

## 预览系统

### FPreviewSourceMediator

**文件**: `Public/Preview/TexturgePreviewSourceMediator.h`

中央仲裁器，管理三种预览源：

| 预览源 | 枚举 | 说明 |
|--------|------|------|
| None | — | 无预览 |
| StagePreview | EAnimationStage | 阶段预览 |
| GlyphAnimation | UGlyphAnimation* | 字形动画预览 |

```cpp
void RequestSource(EPreviewSource Source, EAnimationStage Stage, UGlyphAnimation* Animation);
void RegisterObserver(IPreviewObserver* Observer);
void TickPreview(float DeltaTime);
```

内部维护烘焙缓存和观察者模式，供面板间数据同步。

### UMovieSceneGlyphAnimationTrack

**文件**: `Public/...` (Runtime 模块)
**基类**: `UMovieSceneTrack`

### UMovieSceneGlyphAnimationSection

**文件**: `Public/...` (Runtime 模块)
