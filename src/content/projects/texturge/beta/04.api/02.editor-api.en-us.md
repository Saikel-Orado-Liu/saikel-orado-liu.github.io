# Editor C++ API Reference

C++ API reference for the TexturgeEditor module (`TexturgeEditor`). All classes are editor-only.

## Module Registration

### FTexturgeEditorModule

**File**: `Public/TexturgeEditor.h`

Main editor module class, registers all editor extensions in `StartupModule()`:

- Editor commands
- Preview tab spawner
- Toolbar menu extensions
- Kismet compiler context for `UTextAnimationBlueprint`
- Blueprint type override for `UTextAnimInstance`
- PropertyEditor custom detail panels
- Sequencer GlyphAnimationTrackEditor

## Editor Framework

### FTextAnimationBlueprintEditor

**File**: `Public/Editor/TextAnimationBlueprintEditor.h`
**Base Class**: `FBlueprintEditor`

Main editor for Text Animation Blueprints, contains 7 tabs:

| Tab | Description |
|-----|-------------|
| AnimationDesigner | Animation designer viewport (main panel) |
| TrackList | Track list panel |
| Timeline | Timeline/Sequencer panel |
| Details | Details property panel |
| PreviewSettings | Preview settings panel |
| PreviewAnimationList | Preview animation list |
| PreviewViewport | Preview viewport |

#### Key Methods

```cpp
void InitTextAnimationEditor(
    const EToolkitMode::Type Mode,
    const TSharedPtr<IToolkitHost>& InitToolkitHost,
    UTextAnimationBlueprint* Blueprint
);

void RegisterTabSpawners(const TSharedRef<FTabManager>& TabManager);
void Tick(float DeltaTime);
void Compile();
TSharedRef<ISequencer> GetSequencer() const;
void ChangeViewedAnimation(UGlyphAnimation* Animation);
FPreviewSourceMediator* GetPreviewSourceMediator() const;
STextAnimationDesignerView* GetDesignerView() const;
```

### STextAnimationDesignerView

**File**: `Public/Designer/STextAnimationDesignerView.h`

Custom designer viewport based on UMG SDesignerView architecture:

- `SDesignSurface` — Zoom/pan
- `SZoomPan` — Zoom pan control
- `SPaintSurface` — Paint surface
- `SRuler` — Ruler
- `SDesignerToolBar` — Toolbar
- `STransformHandle` — Transform handle
- `SDisappearingBar` — Info bar

## Preview System

### FPreviewSourceMediator

**File**: `Public/Preview/TexturgePreviewSourceMediator.h`

Central arbiter managing three preview sources:

| Preview Source | Enum | Description |
|----------------|------|-------------|
| None | — | No preview |
| StagePreview | EAnimationStage | Stage preview |
| GlyphAnimation | UGlyphAnimation* | Glyph animation preview |

```cpp
void RequestSource(EPreviewSource Source, EAnimationStage Stage, UGlyphAnimation* Animation);
void RegisterObserver(IPreviewObserver* Observer);
void TickPreview(float DeltaTime);
```

Maintains internal bake cache and observer pattern for inter-panel data sync.
