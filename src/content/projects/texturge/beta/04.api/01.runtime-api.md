# Runtime C++ API 参考

Texturge Runtime 模块 (`Texturge`) 的 C++ 公共 API 完整参考。所有类位于 `Public/` 目录下。

## 编译系统

### FAnimationCompiler

**文件**: `Public/Animation/AnimationCompiler.h`
**类型**: 非 UObject 纯函数编译器

#### 公开静态方法

| 方法 | 签名 | 说明 |
|------|------|------|
| **BakeAllStages** | `(UTextAnimationBlueprint*, const FString&) → FBakedAnimation` | 编译所有阶段的主入口 |
| **BuildScheduleInfos** | `(const FString&) → TArray<FGlyphScheduleInfo>` | 字形分类与调度信息构建 |
| **ExtractCurves** | `(UGlyphAnimation*) → FGlyphCurveSet` | 曲线提取（带缓存） |
| **ConvertFloatChannelToRichCurve** | `(const FMovieSceneFloatChannel&, FFrameRate) → FRichCurve` | 引擎通道到 RichCurve 的转换 |
| **BakeStage** | `(EAnimationStage, UGlyphAnimation*, TArray<FGlyphScheduleInfo>&) → FBakedStage` | 单阶段烘焙 |
| **BakeStageWithCurves** | `(EAnimationStage, const FGlyphCurveSet&, TArray<FGlyphScheduleInfo>&) → FBakedStage` | 测试辅助烘焙 |
| **ComputeTextFingerprint** | `(const FString&) → uint64` | 文本指纹（CityHash64） |
| **ComputeBlueprintFingerprint** | `(UTextAnimationBlueprint*) → uint64` | 蓝图指纹 |

#### 常量

```cpp
static constexpr int32 MinFramesBetweenRebakes = 3;
```

## 动画资产

### UGlyphAnimation

**文件**: `Public/Animation/GlyphAnimation.h`
**基类**: `UMovieSceneSequence`

字形动画序列资产，存储逐字符动画轨道数据。

| 方法 | 签名 | 说明 |
|------|------|------|
| **GetDuration** | `() → FFrameTime` | 获取动画时长 |
| **GetTrackTypes** | `() → TSet<FName>` | 获取轨道类型集合 |
| **HasTrackType** | `(FName) → bool` | 是否有指定轨道类型 |

**内部属性**:
```cpp
UMovieScene* MovieScene;
FGlyphCurveSet CachedExtractedCurves;
uint64 CachedExtractedFingerprint;
```

### UGlyphAnimationLayer

**文件**: `Public/Animation/GlyphAnimationLayer.h`

#### 工厂方法

```cpp

    UGlyphAnimation* Animation,
    ETextAnimationBlendMode BlendMode,
    TArray<FGlyphScheduleInfo> Schedule,
    EStagePlayDirection PlayDirection = Forward,
    int32 NumberOfLoops = 1
);

static UGlyphAnimationLayer* CreateLayerFromText(
    UGlyphAnimation* Animation,
    const FString& Text,
    ETextAnimationBlendMode BlendMode,
    EStagePlayDirection PlayDirection = Forward,
    int32 NumberOfLoops = 1
```

### UGlyphAnimationFactory

**文件**: `Public/Animation/GlyphAnimationFactory.h`

单次烘焙输出的多层合并工厂。

#### 工厂方法

```cpp
static UGlyphAnimationFactory* CreateFactory(
    UGlyphAnimationLayer* BaseLayer,
    TArray<FGlyphScheduleInfo> Schedule
);

static UGlyphAnimationFactory* CreateFactoryFromText(
    UGlyphAnimationLayer* BaseLayer,
    const FString& Text
);
```

#### 图层管理

```cpp
void SetLayers(const TArray<UGlyphAnimationLayer*>& Layers);
void AddLayer(UGlyphAnimationLayer* Layer);
```

#### 烘焙

```cpp
FBakedStage Bake();
```

Factory 同时继承 Layer 的所有调度控制和字形曲线微调方法。
