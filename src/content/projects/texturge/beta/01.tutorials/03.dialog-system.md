# 对话系统

本教程展示如何使用 Texturge 的 `UDialogWidget` 构建 RPG 风格的对话界面，支持逐字打字动画、说话者信息与交互控制。

## 概述

`UDialogWidget` 是基于 `UUserWidget` 的对话控件，内建了完整的逐字打字动画管线。它可选择性地集成 CommonUI，适用于需要对话系统的各类项目。

## 核心功能

| 功能 | 说明 |
|------|------|
| 逐字打字 | 文本按字符逐个显示，支持打字机效果 |
| 说话者信息 | 显示说话者名称与头像 |
| 交互控制 | 跳过 / 自动播放 / 等待用户输入 |
| 多格式文本 | 支持内嵌多格式标签与动画混合 |
| 对话完成事件 | 对话完成后触发委托 |

## 步骤 1：创建对话控件

1. 在内容浏览器中右键 → **用户界面 → Widget Blueprint**
2. 父类选择 `DialogWidget`
3. 命名为 `WBP_Dialog`

## 步骤 2：设计对话 UI

在 UMG 设计器中搭建对话界面。推荐布局：

```
┌─────────────────────────────────────────┐
│  [Portrait]  说话者名称                   │
│              ┌─────────────────────────┐ │
│              │ 对话文本持续逐字显示...     │ │
│              └─────────────────────────┘ │
│                          [继续 →]        │
└─────────────────────────────────────────┘
```

> [!TIP]
> 使用 Canvas Panel 或 Overlay 作为根节点，以便灵活定位头像与文本区域。

## 步骤 3：调用对话 API

在拥有 DialogWidget 的 UI 逻辑中，通过以下 API 控制对话：

### 设置对话内容

```cpp
// Blueprint
DialogWidget->SetDialogText(
    FText::FromString("欢迎来到冒险者的世界！"),
    false  // bUseRichText: 是否启用多格式文本
);
```

### 设置说话者

```cpp
DialogWidget->SetSpeakerName(FText::FromString("村长"));
DialogWidget->SetSpeakerPortrait(SpeakerPortraitTexture);
```

### 开始打字动画

```cpp
// 使用预设名称与持续时间
DialogWidget->StartTyping(
    FName("Normal"),  // 预设名称（在 TextAnimationDataAsset 中配置）
    2.0f,             // 持续时间（秒）
    0.5f              // 开始延迟（秒）
);
```

### 交互方法

| 方法 | 功能 |
|------|------|
| `StartTyping()` | 开始打字动画 |
| `SkipToEnd()` | 立即显示全部文本 |
| `IsTyping()` | 返回是否正在打字中 |
| `OnDialogComplete` | 对话完成委托 |

## 预设系统

`StartTyping` 的预设名称对应 `TextAnimationDataAsset` 中的条目，允许对话系统在不同语境使用不同动画风格：

| 预设示例 | 场景 |
|----------|------|
| Normal | 普通对话 |
| Shout | 激动/大声说话 |
| Whisper | 悄悄话/低语 |
| System | 系统提示信息 |
| Narration | 旁白叙述 |

每种预设绑定不同的 `TextAnimationBlueprint`，实现不同的视觉效果。

## 步骤 4：处理对话流程

典型的对话管理逻辑：

```
函数 ShowNextDialog()
  1. 从对话数据表中获取当前行
  2. 调用 SetSpeakerName / SetPortrait
  3. 调用 SetDialogText
  4. 调用 StartTyping（预设 Normal，时长根据文本长度计算）

事件 OnDialogComplete
  → 等待用户点击 → ShowNextDialog()
  → 或 auto-advance → 延迟后 ShowNextDialog()
```

## CommonUI 集成

如果项目使用 CommonUI，`DialogWidget` 可以自动绑定 CommonUI 的输入动作（如跳过、确认），无需额外配置。

## 实现细节

### 内部架构

```
UDialogWidget
  ├── UTextAnimator（懒加载 GetOrCreateAnimator）
  │   ├── SetRichText / SetPlainText
  │   ├── SetAnimationData
  │   └── StartAnimating / TickAnimation
  ├── UImage（说话者头像）
  ├── UTextBlock / UAnimatedRichTextBlock（对话文本）
  └── UTextBlock（说话者名称）
```

### 动画管道

```
SetDialogText + StartTyping
  → Animator::SetRichText + SetAnimationData
  → Animator::StartAnimating（开始逐字显示）
  → 每帧 TickAnimation(DeltaTime)
  → Slate OnPaint 逐字形渲染
  → 全部字符显示完毕 → OnDialogComplete
```

## 高级用法

### 中途切换说话者

```cpp
// 暂停当前打字
if (DialogWidget->IsTyping())
    DialogWidget->SkipToEnd();

// 设置新说话者并开始新对话
DialogWidget->SetSpeakerName(FText::FromString("冒险者"));
DialogWidget->SetDialogText(FText::FromString("我接受这个任务！"));
DialogWidget->StartTyping(FName("Normal"), 1.5f);
```

### 多格式文本对话

```cpp
DialogWidget->SetDialogText(
    FText::FromString("<typewriter>这是一句</><red>红色</><typewriter>的对话</>"),
    true  // 启用 RichText
);
```
