# Dialog System

This tutorial demonstrates how to build an RPG-style dialog interface using Texturge's `UDialogWidget`, supporting character-by-character typing animation, speaker information, and interaction controls.

## Overview

`UDialogWidget` is a dialog widget based on `UUserWidget` with a built-in per-character typing animation pipeline. It optionally integrates with CommonUI and is suitable for any project requiring a dialog system.

## Core Features

| Feature | Description |
|---------|-------------|
| Per-Character Typing | Text reveals character by character with typewriter effect |
| Speaker Info | Display speaker name and portrait |
| Interaction Control | Skip / auto-play / wait for user input |
| Rich Text | Supports embedded rich text tags and animation blending |
| Dialog Complete Event | Delegate triggered when dialog finishes |

## Step 1: Create Dialog Widget

1. Right-click in Content Browser → **User Interface → Widget Blueprint**
2. Parent class: `DialogWidget`
3. Name it `WBP_Dialog`

## Step 2: Design Dialog UI

Build the dialog interface in UMG Designer. Recommended layout:

```
┌─────────────────────────────────────────┐
│  [Portrait]  Speaker Name                │
│              ┌─────────────────────────┐ │
│              │ Dialog text reveals...   │ │
│              └─────────────────────────┘ │
│                          [Continue →]    │
└─────────────────────────────────────────┘
```

> [!TIP]
> Use Canvas Panel or Overlay as the root node to flexibly position the portrait and text area.

## Step 3: Call the Dialog API

In the UI logic that owns the DialogWidget, control dialogs through the following API:

### Set Dialog Content

```cpp
// Blueprint
DialogWidget->SetDialogText(
    FText::FromString("Welcome to the world of adventurers!"),
    false  // bUseRichText: whether to enable rich text
);
```

### Set Speaker

```cpp
DialogWidget->SetSpeakerName(FText::FromString("Village Elder"));
DialogWidget->SetSpeakerPortrait(SpeakerPortraitTexture);
```

### Start Typing Animation

```cpp
// Use a preset name and duration
DialogWidget->StartTyping(
    FName("Normal"),  // Preset name (configured in TextAnimationDataAsset)
    2.0f,             // Duration (seconds)
    0.5f              // Start delay (seconds)
);
```

### Interaction Methods

| Method | Function |
|--------|----------|
| `StartTyping()` | Start typing animation |
| `SkipToEnd()` | Immediately reveal all text |
| `IsTyping()` | Returns whether currently typing |
| `OnDialogComplete` | Dialog completion delegate |

## Preset System

The preset name in `StartTyping` corresponds to entries in `TextAnimationDataAsset`, allowing the dialog system to use different animation styles in different contexts:

| Preset Example | Scene |
|----------------|-------|
| Normal | Regular conversation |
| Shout | Excited/loud speech |
| Whisper | Whispering/quiet speech |
| System | System messages |
| Narration | Narrative text |

Each preset binds a different `TextAnimationBlueprint` for distinct visual effects.

## Step 4: Handle Dialog Flow

Typical dialog management logic:

```
Function ShowNextDialog()
  1. Get current row from dialog data table
  2. Call SetSpeakerName / SetPortrait
  3. Call SetDialogText
  4. Call StartTyping (preset Normal, duration based on text length)

Event OnDialogComplete
  → Wait for user click → ShowNextDialog()
  → Or auto-advance → ShowNextDialog() after delay
```

## CommonUI Integration

If your project uses CommonUI, `DialogWidget` can automatically bind CommonUI input actions (skip, confirm) with no additional configuration needed.

## Implementation Details

### Internal Architecture

```
UDialogWidget
  ├── UTextAnimator (lazy-loaded via GetOrCreateAnimator)
  │   ├── SetRichText / SetPlainText
  │   ├── SetAnimationData
  │   └── StartAnimating / TickAnimation
  ├── UImage (speaker portrait)
  ├── UTextBlock / UAnimatedRichTextBlock (dialog text)
  └── UTextBlock (speaker name)
```

### Animation Pipeline

```
SetDialogText + StartTyping
  → Animator::SetRichText + SetAnimationData
  → Animator::StartAnimating (begin per-character reveal)
  → TickAnimation(DeltaTime) each frame
  → Slate OnPaint renders per-glyph
  → All characters revealed → OnDialogComplete
```

## Advanced Usage

### Mid-Conversation Speaker Switch

```cpp
// Pause current typing
if (DialogWidget->IsTyping())
    DialogWidget->SkipToEnd();

// Set new speaker and begin new dialog
DialogWidget->SetSpeakerName(FText::FromString("Adventurer"));
DialogWidget->SetDialogText(FText::FromString("I accept this quest!"));
DialogWidget->StartTyping(FName("Normal"), 1.5f);
```

### Rich Text Dialogs

```cpp
DialogWidget->SetDialogText(
    FText::FromString("<typewriter>This is a</><red>red</><typewriter> dialog</>"),
    true  // Enable RichText
);
```
