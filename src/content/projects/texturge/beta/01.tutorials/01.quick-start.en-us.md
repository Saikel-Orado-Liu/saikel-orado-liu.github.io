# Quick Start

This tutorial guides you through creating your first typewriter animation effect with Texturge Beta in 10 minutes.

## Prerequisites

- Unreal Engine 5.7 or later
- Texturge Beta plugin installed and enabled

## Step 1: Create a Text Animation Blueprint

Right-click in the Content Browser, select **Texturge → Text Animation Blueprint**.

<figure class="img-placeholder"><figcaption>content-browser-create-asset.avif — Right-click menu to create a Text Animation Blueprint</figcaption></figure>

Name the asset, e.g., `TABP_Typewriter`. Double-click to open the Text Animation Blueprint Editor.

## Step 2: Add an Opacity Track

The Text Animation Blueprint Editor has a four-panel layout: **Design Viewport**, **Track List**, **Timeline**, and **Details Panel**.

In the left **Track List** panel, click **Add Track** and select **Opacity**.

| Property | Value | Description |
|----------|-------|-------------|
| Track Type | Opacity | Controls glyph opacity |
| Application Mode | PerCharacter | Apply animation independently per character |
| Invert Opacity | true (checked) | Initially hidden → gradually revealed |

## Step 3: Add Keyframes

Add two keyframes on the timeline:

| Time | Value | Interpolation |
|------|-------|---------------|
| 0.00s | 0.0 | Linear |
| 1.00s | 1.0 | Linear |

> [!TIP]
> Hold `Ctrl` and click on the timeline to quickly add keyframes. Drag keyframes to adjust time and value.

## Step 4: Configure Preview Text

Find the **Preview Settings** area at the bottom of the track list:

- **Preview Text**: Enter `Hello Texturge!`
- **Preview Font**: Select your font asset
- **Preview Color**: Choose a text color

The Design Viewport shows a real-time preview. You should see each character fade from fully transparent to fully opaque.

## Step 5: Use in UMG

1. Open or create a UMG Widget Blueprint
2. Drag **Animated Text Block** from the Widget Palette
3. In the Details panel, set:
   - **Text Animation Blueprint** → Select `TABP_Typewriter`
   - **bAutoPlay** → `true` (auto-play)
   - Set display text in the **Text** property

<figure class="img-placeholder"><figcaption>animated-text-widgets-comparison.avif — AnimatedTextBlock Details panel configuration</figcaption></figure>

## Step 6: Blueprint Playback Control

You can also control animation manually via Blueprint:

1. Get the AnimatedTextBlock reference in the Widget's Event Graph
2. Call the following nodes:

| Node | Function |
|------|----------|
| **Play** | Start animation playback |
| **Pause** | Pause animation |
| **Resume** | Resume playback |
| **Stop** | Stop and reset |
| **Skip to End** | Skip animation to the end |
| **Is Animating** | Returns whether currently playing |

### Character Reveal Events

Bind the `OnCharacterRevealedBP` delegate to trigger custom logic per-character (e.g., play typing sounds):

```
Event OnCharacterRevealed
  → Play Sound 2D (TypingSound)
```

## Preset Animations

Texturge provides 9 preset animations in plugin content that can be used directly:

| Preset | Effect | Primary Track |
|--------|--------|---------------|
| FadeIn | Fade in | Opacity |
| Typewriter | Typewriter | Opacity (inverted) |
| SlideIn | Slide in | Translation |
| Scale | Scale effect | Scale |
| Bounce | Bounce | Translation + Scale |
| Shake | Shake | Translation + Rotation |
| Wave | Wave | Translation (segmented) |
| ColorGradient | Color gradient | Color |
| Rotation | Rotation | Rotation |

Show plugin content: Content Browser → Settings → Check **Show Plugin Content**.
