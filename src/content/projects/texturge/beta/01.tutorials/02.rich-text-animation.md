# 多格式文本动画

本教程展示如何使用多格式文本标签（Rich Text Tags）在单个文本块中混合多种动画效果。

## 概念概述

Texturge 的 `AnimatedRichTextBlock` 支持在文本中嵌入自定义标签，为不同段落、词语甚至字符应用不同的文本动画蓝图。这在对话系统、教程提示和动态 UI 等场景中极为实用。

## 步骤 1：创建动画蓝图

首先创建两个文本动画蓝图：

### TABP_Typewriter（打字机效果）

| 设置 | 值 |
|------|-----|
| 轨道 | Opacity |
| 应用模式 | PerCharacter |
| 反转不透明度 | true |
| 关键帧 1 | (0.0, 0.0) |
| 关键帧 2 | (0.3, 1.0) |

### TABP_BounceIn（弹入效果）

| 设置 | 值 |
|------|-----|
| 轨道 1 | Opacity — 反转，关键帧 (0.0,0.0)→(0.3,1.0) |
| 轨道 2 | Translation — PerCharacter |
| 关键帧 Translation | (0.0, (0,50))→(0.3, (0,0)) |
| 轨道 3 | Scale — PerCharacter |
| 关键帧 Scale | (0.0, (0.5,0.5))→(0.15, (1.3,1.3))→(0.3, (1,1)) |

## 步骤 2：创建动画数据资产

在内容浏览器中，右键选择 **其他 → 数据资产**（Data Asset），选择 `TextAnimationDataAsset` 作为类。

<figure class="img-placeholder"><figcaption>dataasset-config.avif — 数据资产配置界面</figcaption></figure>

在细节面板中添加两个条目（Entries）：

| 标签名称（Tag Name） | 动画类型（Type） |
|---------------------|-----------------|
| `typewriter` | `TABP_Typewriter` |
| `bounce` | `TABP_BounceIn` |

## 步骤 3：设置多格式文本控件

1. 在 UMG Widget 中添加 **Animated Rich Text Block**
2. 设置 **Animation Data** → 选择刚才创建的 DataAsset
3. 设置 **bAutoPlay** → `true`

## 步骤 4：编写标记文本

在 **Text** 属性中，使用自定义标签标记不同部分：

```xml
<typewriter>Hello, </><bounce>World!</>
```

这会让 "Hello, " 以打字机效果逐字显示，而 "World!" 以弹入效果出现。

## 标签语法详解

Texturge 支持丰富的标签语法：

### 开闭标签

```xml
<typewriter>这段文本用打字机动画</>
```

### 使用 id 属性

```xml
<anim id="typewriter">用 id 指定动画</>
```

### 混合标准样式标签

```xml
<typewriter><Large>大字打字机效果</></>
```

标准 UMG 多格式文本样式（`<Large>`、`<Bold>` 等）仍然正常工作，可以与动画标签嵌套使用。

### 多个动画区域

```xml
<typewriter>你好，</><bounce>欢迎来到</><typewriter>Texturge！</>
```

每个 `<>...</>` 块独立运行自己的动画。

## 参数覆盖

在 DataAsset 的条目中，`Parameter Overrides` 映射允许你为特定标签覆盖动画蓝图变量：

| 参数 | 值 | 效果 |
|------|-----|------|
| Duration | 0.5 | 加速打字速度 |
| CPS | 30.0 | 每秒 30 字符 |

## 播放模式

`AnimatedRichTextBlock` 的 `bSequentialPlayback` 属性控制区块间的播放行为：

| 模式 | 行为 |
|------|------|
| 并行（false） | 所有动画块同时播放 |
| 顺序（true） | 按标签出现顺序逐个播放 |

顺序播放模式非常适合对话系统，确保多个说话者的文本依次呈现。

## 处理流程

多格式文本动画的求值流程：

1. `FTagParser` 将标签文本解析为 `FTagNode` 树
2. `FRenderTreeBuilder` 构建渲染树并按 EntryIndex 匹配动画
3. `UTextAnimator` 管理并行/顺序播放逻辑
4. 每个 `FTextRun::OnPaint()` 根据所在区块查询对应的 `FAnimationFrameData`
5. Slate 渲染器逐字形应用动画状态

## 调试技巧

| 问题 | 检查 |
|------|------|
| 标签不生效 | 确认标签名称与 DataAsset 中完全一致（区分大小写） |
| 动画不播放 | 检查 bAutoPlay 或确认已调用 Play() |
| 样式标签不工作 | 确认 StyleSet 已正确设置 |
| 性能问题 | 减少并行区块数量，使用顺序播放 |
