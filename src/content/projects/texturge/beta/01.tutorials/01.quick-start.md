# 快速入门

本教程将引导你在 10 分钟内使用 Texturge Beta 创建第一个打字机动画效果。

## 前置条件

- Unreal Engine 5.7 或更高版本
- Texturge Beta 插件已安装并启用

## 步骤 1：创建文本动画蓝图

在内容浏览器中右键点击，选择 **Texturge → 文本动画蓝图**（Text Animation Blueprint）。

<figure class="img-placeholder"><figcaption>content-browser-create-asset.avif — 右键菜单创建文本动画蓝图</figcaption></figure>

为资产命名，例如 `TABP_Typewriter`。双击打开文本动画蓝图编辑器。

## 步骤 2：添加不透明度轨道

文本动画蓝图编辑器是一个四面板布局：**设计视口**、**轨道列表**、**时间轴**和**细节面板**。

在左侧的**轨道列表**面板中，点击 **添加轨道**（Add Track），选择 **Opacity**。

| 属性 | 值 | 说明 |
|------|-----|------|
| 轨道类型 | Opacity | 控制字形不透明度 |
| 应用模式 | PerCharacter | 每个字符独立应用动画 |
| 反转不透明度 | true（勾选） | 初始隐藏 → 逐渐显示 |

## 步骤 3：添加关键帧

在时间轴上添加两个关键帧：

| 时间 | 值 | 插值类型 |
|------|-----|----------|
| 0.00s | 0.0 | Linear |
| 1.00s | 1.0 | Linear |

> [!TIP]
> 你可以通过按住 `Ctrl` 并单击时间轴来快速添加关键帧。拖动关键帧可调整时间和值。

## 步骤 4：配置预览文本

在轨道列表底部找到**预览设置**区域：

- **Preview Text**：输入 `Hello Texturge!`
- **Preview Font**：选择你的字体资产
- **Preview Color**：选择文本颜色

设计视口会实时显示预览效果。你应该看到每个字符从完全透明渐变到完全不透明。

## 步骤 5：在 UMG 中使用

1. 打开或创建一个 UMG Widget Blueprint
2. 从控件面板拖入 **Animated Text Block**
3. 在细节面板中设置：
   - **Text Animation Blueprint** → 选择 `TABP_Typewriter`
   - **bAutoPlay** → `true`（自动播放）
   - 在 **Text** 属性中设置显示文本

## 步骤 6：Blueprint 播放控制

你也可以通过 Blueprint 手动控制动画：

1. 在 Widget 的 Event Graph 中获取 AnimatedTextBlock 引用
2. 调用以下节点：

| 节点 | 功能 |
|------|------|
| **Play** | 开始播放动画 |
| **Pause** | 暂停动画 |
| **Resume** | 恢复播放 |
| **Stop** | 停止并重置 |
| **Skip to End** | 跳过动画到末尾 |
| **Is Animating** | 返回是否正在播放 |

### 字符揭示事件

绑定 `OnCharacterRevealedBP` 委托可在每个字符显示时触发自定义逻辑（如播放打字音效）：

```
Event OnCharacterRevealed
  → Play Sound 2D (TypingSound)
```

## 预设动画

Texturge 在插件内容中提供了 9 个预设动画，可直接使用：

| 预设 | 效果 | 主要轨道 |
|------|------|----------|
| FadeIn | 渐入 | Opacity |
| Typewriter | 打字机 | Opacity（反转） |
| SlideIn | 滑入 | Translation |
| Scale | 缩放 | Scale |
| Bounce | 弹跳 | Translation + Scale |
| Shake | 抖动 | Translation + Rotation |
| Wave | 波浪 | Translation（分段） |
| ColorGradient | 渐变色彩 | Color |
| Rotation | 旋转 | Rotation |

显示插件内容：内容浏览器 → 设置 → 勾选 **Show Plugin Content**。
