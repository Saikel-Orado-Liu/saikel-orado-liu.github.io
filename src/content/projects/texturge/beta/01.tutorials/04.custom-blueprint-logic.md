# 自定义 Blueprint 动画逻辑

本教程展示如何通过覆盖 `BuildDefaultAnimation` BlueprintNativeEvent 实现自定义动画生成逻辑——这是 Beta 版本最强大的新功能之一。

## 概述

在 Alpha 版本中，动画行为完全由轨道配置决定。Beta 版本引入了 `UTextAnimInstance::BuildDefaultAnimation` BlueprintNativeEvent，允许你在蓝图中动态生成动画数据。

## 核心概念

### BuildDefaultAnimation

```cpp
UFUNCTION(BlueprintNativeEvent, Category = "Texturge|Animation")
FBakedStage BuildDefaultAnimation(int32 GlyphCount, const FString& Text);
```

此函数接收字形数量和文本内容，返回一个 `FBakedStage` 结构体。默认实现通过 `UGlyphAnimationFactory` 生成动画，但你可以在蓝图中完全覆盖此行为。

### 架构优势

- **编译期执行**：动画在编译时烘焙，运行时零开销
- **指纹缓存**：仅当文本或蓝图变量变化时重新烘焙
- **完整数据访问**：可访问文本内容、字形调度信息和曲线数据

## 步骤 1：创建文本动画蓝图

创建 `TextAnimationBlueprint` 资产，命名为 `TABP_CustomWave`。

## 步骤 2：添加 Blueprint 变量

在蓝图的 Class Defaults 中添加变量。Texturge Beta 支持六种蓝图变量类型：

| 变量名 | 类型 | 默认值 | 说明 |
|--------|------|--------|------|
| WaveAmplitude | float | 10.0 | 波浪振幅 |
| WaveFrequency | float | 0.5 | 波浪频率 |
| CharDuration | float | 0.1 | 每字符持续时间 |
| TintColor | FLinearColor | (1,1,1,1) | 文字颜色（可选） |
| StartDirection | FVector | (0,0,0) | 入场方向（可选） |
| bSkipSpaces | bool | true | 跳过空格（可选） |

> [!NOTE]
> 支持的变量类型：**float** / **int32** / **bool** / **FVector** / **FLinearColor** / **FVector2D**。六种类型均可通过 `SetBlueprintVariable` 在运行时更新。

## 步骤 3：覆盖 BuildDefaultAnimation

1. 打开蓝图的事件图
2. 在 Functions 列表中覆盖 `BuildDefaultAnimation`
3. 实现自定义逻辑：

### Blueprint 逻辑流程

```
Event BuildDefaultAnimation (GlyphCount, Text)
  → BuildScheduleInfos(Text) → ScheduleInfos 数组
  → 创建 UGlyphAnimationLayer（使用 Opacity 轨道动画）
  → 创建 UGlyphAnimationFactory
  → 设置基础层
  → 遍历每个字形 Index:
     → 计算基于 Index 的正弦波偏移: sin(Index * WaveFrequency) * WaveAmplitude
     → SetTranslationAt(Index, FVector2D(0, 正弦值))
     → SetStartDelayAt(Index, Index * CharDuration)
  → AddLayer（翻译位移层）
  → Factory->Bake() → FBakedStage
  → Return 烘焙阶段
```

### 关键步骤详解

#### 1. 构建调度信息

```cpp
TArray<FGlyphScheduleInfo> Schedule = BuildScheduleInfos(Text);
```

此静态方法为文本中每个字符生成 `FGlyphScheduleInfo`，自动分类 CJK 字符、标点、空白等。

#### 2. 创建图层

```cpp
UGlyphAnimationLayer* BaseLayer = UGlyphAnimationLayer::CreateLayer(
    BaseAnimation,      // UGlyphAnimation 资产（如 FadeIn）
    Additive,           // 混合模式
    Schedule            // 调度数组
);
```

#### 3. 自定义字形属性

通过 `UGlyphAnimationFactory` 的字形级调整方法：

| 方法 | 效果 |
|------|------|
| `SetStartDelayAt(Index, Delay)` | 设置字形开始延迟 |
| `SetTranslationAt(Index, Offset)` | 翻译位移 |
| `SetScaleAt(Index, Scale)` | 缩放调整 |
| `SetRotationAt(Index, Degrees)` | 旋转角度 |
| `SetOpacityAt(Index, Alpha)` | 不透明度微调 |
| `SetColorAt(Index, Color)` | 颜色微调 |
| `SkipAt(Index, bSkip)` | 跳过动画 |
| `SetSeedJitterAt(Index, Jitter)` | 随机抖动种子 |

#### 4. 烘焙

```cpp
FBakedStage Result = Factory->Bake();
return Result;
```

`Bake()` 执行三步：每层独立烘焙 → 复制到 `FPerLayerCurves` → Factory 后处理。

## 示例：波浪效果

```
函数 CustomWaveAnimation(文字, 振幅, 频率):
  调度 = BuildScheduleInfos(文字)
  基础层 = 创建图层（透明度渐入, Additive, 调度）
  工厂 = 创建工厂（基础层, 调度）

  对每个索引 i:
    正弦值 = Sin(i * 频率) * 振幅
    工厂.SetTranslationAt(i, (0, 正弦值))
    工厂.SetStartDelayAt(i, i * 0.08)

  返回 工厂.Bake()
```

效果：每个字符依次出现（延迟递增），同时上下波浪浮动。

## 示例：随机入场效果

```
函数 RandomEntrance(文字):
  调度 = BuildScheduleInfos(文字)
  基础层 = 创建图层（透明度, Override, 调度）
  工厂 = 创建工厂（基础层, 调度）

  对每个索引 i:
    随机角度 = Random(-30, 30)  // -30° ~ 30°
    随机X = Random(-100, 100)
    随机Y = Random(-50, 50)
    随机延迟 = Random(0, 0.5)
    工厂.SetRotationAt(i, 随机角度)
    工厂.SetTranslationAt(i, (随机X, 随机Y))
    工厂.SetStartDelayAt(i, 随机延迟)

  返回 工厂.Bake()
```

## 阶段控制

`BuildDefaultAnimation` 返回的 `FBakedStage` 默认对应 **Default 阶段**。如需自定义 Intro 和 Outro 阶段：

1. 在 `UTextAnimationBlueprint` 中配置 `GlyphAnimations` 数组
2. 分别指定 Intro / Default / Outro 三阶段的 `UGlyphAnimation` 资产
3. `FAnimationCompiler::BakeAllStages` 自动处理三阶段烘焙

## 最佳实践

| 建议 | 原因 |
|------|------|
| 每次调用 `BuildScheduleInfos` | 确保调度信息与当前文本同步 |
| 使用 `CreateFactoryFromText` | 简化文本到工厂的转换 |
| 避免在烘焙中使用随机 | 指纹缓存会复用结果；使用 `SeedJitter` 代替 |
| 保持烘焙函数为纯函数 | 确保给定相同输入始终返回相同输出 |
| 预计算而非运行时计算 | 所有自定义逻辑在编译期执行 |

## 运行时参数更新

虽然烘焙在编译期完成，但可以通过 `SetBlueprintVariable` 动态更新变量：

```cpp
// 运行时更新波浪振幅
AnimInstance->SetBlueprintVariable(FName("WaveAmplitude"), 20.0f);
```

变量更新会触发重新烘焙（受 3 帧冷却保护）。
