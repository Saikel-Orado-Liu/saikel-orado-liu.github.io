`FTexturgeBakeConfig` controls all bake pipeline parameters. Thoughtful configuration balances quality, memory usage, and bake time.

## Core Parameters

| Parameter | Default | Description |
|-----------|---------|-------------|
| `Resolution` | 64 | SDF texture size per glyph (pixels) |
| `Padding` | 2 | Spacing between glyphs in atlas to prevent edge bleed |
| `SDFPrecision` | 8 | SDF bit depth (8 or 16) |
| `AtlasSize` | 2048 | Maximum atlas edge length |
| `MaxAtlases` | 4 | Maximum atlas count; error if exceeded |
| `CharacterSet` | BMP | Character encoding range |

## Recommended Configs

**Small UI Text (12-24pt)**
```cpp
Config.Resolution = 32;
Config.Padding = 1;
Config.SDFPrecision = 8;
```

**Large 3D Text (48-128pt)**
```cpp
Config.Resolution = 128;
Config.Padding = 4;
Config.SDFPrecision = 16;
```

**CJK Fonts (thousands of characters)**
```cpp
Config.Resolution = 48;
Config.AtlasSize = 4096;
Config.MaxAtlases = 8;
```

## Choosing a Character Set

`CharacterSet` determines which glyphs are baked:

1. `ETexturgeCharSet::BMP` — Unicode Basic Multilingual Plane (65,535 characters). Covers Latin, Cyrillic, and Greek.
2. `ETexturgeCharSet::Custom` — Manually specify a list of codepoints to include.
3. `ETexturgeCharSet::FromStringTable` — Auto-extract used characters from a `UStringTable`. Recommended for localization projects.
