The bake pipeline converts any TTF/OTF font file into an SDF texture atlas that the GPU can sample directly. The entire process runs asynchronously inside the editor and supports batch processing.

## Pipeline Stages

1. **Font Parsing** — Load the font file via FreeType, extracting all visible glyph indices and their outline point data. Supports the full Unicode BMP range (U+0000 to U+FFFF).
2. **SDF Generation** — Compute the distance field for each glyph outline. Defaults to 8-bit SDF; upgrade to 16-bit in config for higher precision.
3. **Atlas Packing** — Use the MaxRects algorithm to tightly pack glyphs into one or more atlases. Default atlas size is 2048×2048.
4. **Data Table Generation** — Output a `FTexturgeGlyphData` table recording UV regions, advance width, and bearing for each glyph.

## Triggering a Bake Manually

Right-click a `UTexturgeFontAsset` in the editor and select **"Rebake Font Atlas"**. Or trigger programmatically:

```cpp
FTexturgeBakeConfig Config;
Config.FontPath = TEXT("/Game/Fonts/MyFont");
Config.Resolution = 64;
Config.Padding = 2;
UTexturgeBakerSubsystem::Get()->BakeFont(Config);
```

## Async Baking

Bake operations run on a background thread by default. Use `FTexturgeBakeCompleteDelegate` for the completion callback:

```cpp
Subsystem->OnBakeComplete.AddLambda([](UTexture2D* Atlas, UDataTable* Table) {
    UE_LOG(LogTexturge, Log, TEXT("Bake complete: %d glyphs"), Table->GetRowMap().Num());
});
```
