# 烘焙参数配置

烘焙管线的可配置参数分布在三个层级：逐字形的 `FGlyphScheduleInfo`、逐图层的 `UGlyphAnimationLayer`、聚合工厂 `UGlyphAnimationFactory`。全局设置通过 `UTexturgeSettings` 暴露。

> Texturge 不存在 `FTexturgeBakeConfig` 结构体或 `UTexturgeConfig` DataAsset。所有配置均通过上述类与方法实现。

## 字形调度信息

`FGlyphScheduleInfo` 控制每个字形在动画中的时间与行为：

| 参数 | 说明 |
|------|------|
| `Delay` | 字形相对于动画起点的延迟（秒） |
| `bSkip` | 是否跳过该字形（不参与动画） |
| `ValueScale` | 所有 21 通道曲线值的全局缩放倍率 |
| `ValueOffset` | 所有 21 通道曲线值的全局偏移量 |
| `SeedJitter` | 随机抖动种子值，用于曲线伪随机化 |

在 `UGlyphAnimationLayer` 中通过以下方法批量配置：

```cpp
Layer->SetAllGlyphDelay(0.05f);      // 所有字形延迟 0.05 秒
Layer->SkipAllWhitespace(true);      // 跳过所有空白字符
Layer->SetDelayAt(3, 0.5f);          // 第 3 个字形的延迟设为 0.5 秒
Layer->SkipAt(5, true);              // 跳过第 5 个字形
```

## 图层配置

`UGlyphAnimationLayer` 提供三类配置：

### Play Mode（播放模式）

通过 `SetPlayMode(EPlayMode)` 设置：

- `Forward` — 正向播放
- `Reverse` — 反向播放
- `PingPong` — 来回循环

### 调度计划查询（6 个分类查询方法）

用于检查字形在调度计划中的状态，精确方法名依实现而定，涵盖是否延迟、是否跳过、是否活跃等分类。

### 曲线微调（10 个 get/set 方法对）

用于获取和设置各通道的全局微调参数，涵盖缩放、偏移、抖动种子等 10 类调参接口。

## 工厂配置

`UGlyphAnimationFactory` 是多图层烘焙的执行容器：

1. **创建工厂** — 通过静态方法创建：
   ```cpp
   UGlyphAnimationFactory* Factory = UGlyphAnimationFactory::CreateFactory();
   // 或从文本创建
   UGlyphAnimationFactory* Factory = UGlyphAnimationFactory::CreateFactoryFromText(Text);
   ```

2. **添加图层** — 通过 `AddLayer(UGlyphAnimationLayer*)` 逐个添加图层：
   ```cpp
   Factory->AddLayer(Layer1);
   Factory->AddLayer(Layer2);
   ```
   或通过 `SetLayers(TArray<UGlyphAnimationLayer*>)` 批量设置。

3. **图层排序** — 图层添加顺序决定烘焙与求值的优先级。后添加的图层在求值时覆盖/混合到前序图层之上。

4. **执行烘焙** — `Factory->Bake()` 返回 `FBakedAnimation`，内部调用 `BakeStageWithCurves` 进行逐层烘焙。

## 插件全局设置

`UTexturgeSettings` 是 `UDeveloperSettings` 子类，分类为 `"Plugins/Texturge"`。通过以下方式访问：

```cpp
const UTexturgeSettings* Settings = UTexturgeSettings::Get();
```

当前该类为配置空壳 —— 结构已准备好供未来扩展，尚未包含运行时可调参数。所有烘焙参数均通过上述类的方法在编译时确定。

## 典型配置流程

1. 创建 `UGlyphAnimationLayer` 实例，通过 `SetPlayMode()` 设置播放方向。
2. 调用 `SetAllGlyphDelay()`、`SkipAllWhitespace()` 等配置逐字形调度。
3. 通过曲线微调方法调整各通道的缩放/偏移/抖动参数。
4. 创建 `UGlyphAnimationFactory`，将所有图层 `AddLayer()` 添加后调用 `Bake()`。
5. 在 `BuildDefaultAnimation` 蓝图事件中组合上述逻辑，编译时自动执行。
