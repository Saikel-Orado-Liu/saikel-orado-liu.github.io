Texturge's multi-layer system lets the same text span multiple visual layers. Each layer independently configures color, offset, animation curves, and blend mode.

## Creating Layers

1. Open a `UTexturgeAsset` and click **Add Layer** in the **Layers** panel.
2. Name the layer (e.g., "Fill", "Outline", "Shadow").
3. Drag to reorder — layers higher in the list render on top.

## Layer Properties

Each layer exposes these configurable properties:

```cpp
FTexturgeLayerConfig Layer;
Layer.LayerName = TEXT("Outline");
Layer.Color = FLinearColor::Black;
Layer.Offset = FVector2D(2.0f, 0.0f);  // pixel offset
Layer.SDFThreshold = 0.5f;              // SDF sample threshold
Layer.BlendMode = ETexturgeBlend::Alpha;
Layer.Opacity = 0.8f;
```

## Typical Layer Stacks

1. **Basic 2D Effect**
   - Layer 1: Shadow (black, offset 3px, Alpha 0.3)
   - Layer 2: Outline (black, threshold expanded, Alpha 1.0)
   - Layer 3: Fill (white, Alpha 1.0)

2. **Glow Effect**
   - Layer 1: Glow (bright color, lowered threshold for outward spread, Additive)
   - Layer 2: Fill (main color, Alpha blend)

## Independent Animation Control

Each layer has its own animation curves. For example, animate the outline width pulsation on the Outline layer without affecting Fill:

```cpp
Layer.AnimationCurve = OutlinePulseCurve;  // drives only this layer's SDFThreshold
```
