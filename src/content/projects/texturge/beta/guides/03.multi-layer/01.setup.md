# 多图层动画设置

Texturge 的多图层系统允许每个字形拥有多组独立的动画曲线数据（`FPerLayerCurves`），各组按指定的 `ETextAnimationBlendMode` 合并为最终的字形动画状态。

> NOTE
>
> Texturge 不存在 SDF 阈值与像素图层的概念。多图层是对 21 通道曲线数据的多层叠加与混合。

## 核心概念

1. 每个 `FBakedGlyph` 内部存储 `TArray<FPerLayerCurves> Layers` —— 即该字形各图层的动画曲线数据。
2. `FBakedGlyph::Evaluate()` 遍历所有图层，逐一调用 `FPerLayerCurves::Evaluate()` 并按照 `BlendModes` 数组中对应索引的混合模式合并结果。
3. 最终输出为 `FGlyphAnimationState`，包含 21 个通道的当前帧值。

## 创建图层资产

`UGlyphAnimationLayer` 是图层的 UObject 包装，通过以下方式创建：

```cpp
UGlyphAnimationLayer* Layer = UGlyphAnimationLayer::CreateLayer();
// 或基于文本初始化
UGlyphAnimationLayer* Layer = UGlyphAnimationLayer::CreateLayerFromText(Text);
```

每个图层独立存储其曲线数据、调度计划与微调参数。

## 配置图层

### Scheduling（调度计划）

1. 使用 `SetAllGlyphDelay(float)` 设置统一延迟。
2. 使用 `SkipAllWhitespace(bool)` 控制空白字符参与。
3. 使用 `SetDelayAt(int32, float)` 和 `SkipAt(int32, bool)` 进行逐字形精确控制。

### Curve Tweaks（曲线微调）

10 组 get/set 方法对，用于调整：
- 各通道的全局缩放、偏移、抖动种子
- 特定字形位置的曲线复写值

### Play Mode（播放模式）

```cpp
Layer->SetPlayMode(EPlayMode::Forward);
Layer->SetPlayMode(EPlayMode::Reverse);
Layer->SetPlayMode(EPlayMode::PingPong);
```

## 组装工厂

1. 创建 `UGlyphAnimationFactory`：
   ```cpp
   UGlyphAnimationFactory* Factory = UGlyphAnimationFactory::CreateFactoryFromText(Text);
   ```

2. 按顺序添加图层：
   ```cpp
   Factory->AddLayer(PositionLayer);    // 先添加的图层优先生效
   Factory->AddLayer(ColorAnimLayer);
   Factory->AddLayer(ShadowLayer);
   ```

3. 调用 `Bake()` 生成 `FBakedAnimation`：
   ```cpp
   FBakedAnimation Result = Factory->Bake();
   ```

## 在 BuildDefaultAnimation 中组合

`UTextAnimInstance::BuildDefaultAnimation` 是实现多图层逻辑的标准位置。默认 C++ 实现已封装完整的创建→配置→烘焙流程：

```cpp
FBakedAnimation UMyTextAnimInstance::BuildDefaultAnimation_Implementation(
    int32 GlyphCount, const FString& Text)
{
    UGlyphAnimationLayer* BaseLayer = UGlyphAnimationLayer::CreateLayerFromText(Text);
    BaseLayer->SetAllGlyphDelay(0.05f);

    UGlyphAnimationLayer* Overlay = UGlyphAnimationLayer::CreateLayerFromText(Text);
    Overlay->SetPlayMode(EPlayMode::PingPong);

    UGlyphAnimationFactory* Factory = UGlyphAnimationFactory::CreateFactoryFromText(Text);
    Factory->AddLayer(BaseLayer);
    Factory->AddLayer(Overlay);

    return Factory->Bake();
}
```

## 数据最终形态

烘焙后，每个 `FBakedGlyph` 包含：

```
FBakedGlyph
  ├── Layers[0]: FPerLayerCurves (21 channels) + BlendMode::Override
  ├── Layers[1]: FPerLayerCurves (21 channels) + BlendMode::Additive
  └── Layers[2]: FPerLayerCurves (21 channels) + BlendMode::Multiply
```

运行时 `FBakedGlyph::Evaluate()` 按索引顺序遍历各 `FPerLayerCurves`，分别求值并按对应 `BlendModes` 合并。
