# 图层混合模式

`ETextAnimationBlendMode` 枚举定义了 `FPerLayerCurves` 求值结果合并到 `FGlyphAnimationState` 时的运算方式。混合在 `FPerLayerCurves::Evaluate()` 内部按通道粒度执行。

## 四种混合模式

### Additive（加法混合）

将当前层的通道值累加到已有状态上：

```
OutState.Channel += LayerResult.Channel
```

**适用场景**：
- 抖动效果叠加（位置抖动 + 旋转抖动）
- 多动画组合（基础位移动画 + 额外波浪动画）
- 发光层叠加

```cpp
// 基础层设定位置，叠加层添加随机抖动
BaseLayer: Location.X = 100 → 200  // 从左到右
ShakeLayer: Location.X = -5 → +5   // Additive 混合 → 实际位置 = 95 → 205
```

### Override（覆盖混合）

用当前层通道值直接替换已有状态（常用于第一层或需要绝对控制的层）：

```
OutState.Channel = LayerResult.Channel
```

**适用场景**：
- 第一层设定基准变换
- 某层需要完全控制特定通道（如颜色绝对值）
- 重置前序叠加效果

```cpp
// 第一层：主位置动画
MainLayer: Location.X = 100 → 200  // Override → 位置 = 100 → 200
```

### Multiply（乘法混合）

将当前层通道值与已有状态相乘：

```
OutState.Channel *= LayerResult.Channel
```

**适用场景**：
- 强度调制（动画速度包络）
- 渐隐渐显控制
- 全局缩放衰减

```cpp
// 第二层：全局透明度包络
EnvelopeLayer: Color.A = 0.0 → 1.0 → 0.0  // Multiply → 先淡入后淡出
```

### CrossFade（淡入淡出混合）

在两阶段过渡期间平滑混合两个图层的输出：

```
OutState.Channel = Lerp(FromLayer.Channel, ToLayer.Channel, CrossfadeAlpha)
```

**适用场景**：
- 图层间平滑切换
- 阶段过渡动画（Intro → Default → Outro）
- 动态图层替换

可通过 `UTextAnimationStageController` 的 `bCrossfadeEnabled` 与 `CrossfadeDuration` 控制全局跨阶段淡入淡出行为。

## 逐通道混合流程

`FPerLayerCurves::Evaluate(float LocalTime, FGlyphAnimationState& InOutState)` 的内部流程：

1. 对 21 个通道逐一从 `FRichCurveKey` 数组构建 `FRichCurve`。
2. 在 `LocalTime` 处插值求值，得到每个通道的当前值。
3. 根据当前层的 `ETextAnimationBlendMode` 将各通道值合并到 `InOutState`：
   ```
   for Channel in 0..20:
       Value = CurveEval(Channel, LocalTime)
       switch BlendMode:
           Additive:  InOutState[Channel] += Value
           Override:  InOutState[Channel] = Value
           Multiply:  InOutState[Channel] *= Value
           CrossFade: InOutState[Channel] = Lerp(Prev, Value, Alpha)
   ```

## 多层混合示例

```
Layer 0: Override   — 设定基准位置、缩放、颜色
Layer 1: Additive   — 添加微小的位置与旋转抖动
Layer 2: Multiply   — 全局 Alpha 包络控制透明度
Layer 3: Additive   — 阴影偏移动画
```

`FBakedGlyph::Evaluate()` 按索引顺序依次调用各 `FPerLayerCurves::Evaluate()`，最终输出合并后的 `FGlyphAnimationState`。

## 设计建议

1. **首层使用 Override** 建立基准值，避免意外叠加。
2. **中间层使用 Additive** 叠加辅助动画，便于独立调整。
3. **尾层使用 Multiply** 进行全局调制，如统一淡入淡出。
4. **CrossFade** 适合需要动态切换图层的场景，如根据条件启用不同动画预设。
