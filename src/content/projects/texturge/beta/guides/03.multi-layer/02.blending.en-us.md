Texturge supports three layer blend modes, specified via the `ETexturgeBlend` enum. Blending runs per-pixel in the GPU Pixel Shader.

## Alpha Blend (Default)

Standard transparency blending, suitable for most fill and stroke layers.

```cpp
Layer.BlendMode = ETexturgeBlend::Alpha;
// Result = Src * SrcAlpha + Dst * (1 - SrcAlpha)
```

**Use cases**: Text fill, stroke, shadow overlay.

## Additive Blend

Adds layer color to the background, producing glow and highlight effects.

```cpp
Layer.BlendMode = ETexturgeBlend::Additive;
// Result = Src + Dst
```

**Use cases**: Glow halos, neon effects, additive glow layers.

## Multiply Blend

Multiplicative color mode that darkens the lower layers.

```cpp
Layer.BlendMode = ETexturgeBlend::Multiply;
// Result = Src * Dst
```

**Use cases**: Drop shadows, texture overlays, grunge effects.

## Blend Order

Layers blend **top to bottom** sequentially:

1. Render Layer 1 to a temporary RT as the initial canvas.
2. Layer 2 blends with the current RT according to its BlendMode.
3. Continue through all layers; the final result writes to the target RenderTarget.

## Example: Neon Text

```cpp
// Layer 1: Soft glow spread (Additive)
Layer1.BlendMode = ETexturgeBlend::Additive;
Layer1.Color = FLinearColor(0.0f, 0.3f, 1.0f, 0.3f); // blue glow
Layer1.SDFThreshold = 0.35f; // lower threshold for outward spread

// Layer 2: Main fill (Alpha)
Layer2.BlendMode = ETexturgeBlend::Alpha;
Layer2.Color = FLinearColor::White;
Layer2.SDFThreshold = 0.5f;
```
