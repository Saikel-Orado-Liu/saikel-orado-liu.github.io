Texturge provides a built-in performance stats system. Combined with Unreal Insights, you can pinpoint GPU and CPU bottlenecks.

## Enabling Performance Stats

1. Enable `Texturge.Performance.Stats` in Project Settings.
2. Use the console command `Texturge.Stats 1` to display real-time stats on screen.
3. Stats include: active Player count, visible glyph count, draw call count, and atlas memory usage.

```cpp
// Manual stat gathering in code
FTexturgePerformanceStats Stats;
UTexturgeSubsystem::Get()->GatherStats(Stats);
UE_LOG(LogTexturge, Log, TEXT("Active Players: %d, Visible Glyphs: %d"), 
    Stats.ActivePlayers, Stats.VisibleGlyphs);
```

## Unreal Insights Integration

Texturge inserts UE_TRACE markers on critical paths:

- `Texturge::Tick` — Player logic update duration
- `Texturge::UploadGlyphBuffer` — GPU buffer upload duration
- `Texturge::BakeGlyph` — Single glyph bake duration

Filter by `Texturge` in Unreal Insights Trace Channel to view the timeline.

## Common Performance Issues

1. **Excessive Draw Calls** — Check if each Player renders independently rather than batching. Enable `bUseInstancedRendering` to merge draw calls for Players sharing the same material.
2. **High Atlas VRAM** — Use `stat TexturgeMemory` to inspect per-atlas video memory. Consider lowering Resolution or using SDF8.
3. **Heavy CPU Tick** — With many Players, use `FTickFunction` rather than manual per-frame Tick. By default, Texturge uses a unified tick manager for batch updates.
