# 从 Texturge Alpha 迁移

Texturge Beta 引入了全新的动画编译管线与数据结构。本文档帮助你从 Alpha 版本平滑升级。

## 架构变更概览

| 领域 | Alpha | Beta |
|------|-------|------|
| 核心资产 | 旧版动画资产 | `UTextAnimationBlueprint` (UBlueprint) |
| 动画轨道 | 旧版轨道系统 | `UGlyphAnimation` (MovieSceneSequence) |
| 烘焙数据 | 旧版数据格式 | `FBakedAnimation` / `FBakedStage` / `FBakedGlyph` |
| 烘焙管线 | 内联函数 | `FAnimationCompiler` 静态方法 |
| 图层系统 | 单层或无图层 | `UGlyphAnimationLayer` + `UGlyphAnimationFactory` |
| 混合模式 | 有限或不存在 | `ETextAnimationBlendMode` (4 种) |
| 三阶段 | 不支持 | Intro / Default / Outro |
| 运行时控制器 | 旧版 Player | `UTextAnimationStageController` |
| 富文本 | 基础支持 | `UTextAnimator` + `UTextAnimationDataAsset` |
| 本地化 | 不支持或基础集成 | `ULocalizationSubsystem` + `FSemanticAnchor` |
| 指纹缓存 | 不支持 | MD5 文本/蓝图指纹 |

## 关键类映射

### 蓝图与资产

| Alpha | Beta |
|-------|------|
| 旧版动画蓝图资产 | `UTextAnimationBlueprint` |
| 旧版动画实例 | `UTextAnimInstance` |
| 旧版轨道 | `UGlyphAnimation` (MovieSceneSequence) |
| 旧版图层（如有） | `UGlyphAnimationLayer` |

### 编译与烘焙

| Alpha | Beta |
|-------|------|
| 旧版编译函数 | `FAnimationCompiler::BakeAllStages()` |
| 旧版调度 | `BuildScheduleInfos()` → `TArray<FGlyphScheduleInfo>` |
| 旧版烘焙 | `UGlyphAnimationFactory::Bake()` |
| 旧版数据容器 | `FBakedAnimation` / `FBakedGlyph` |

### 运行时

| Alpha | Beta |
|-------|------|
| 旧版 Player | `UTextAnimationStageController` |
| 旧版 UMG 控件 | `UAnimatedTextBlock` |
| 旧版富文本播放器 | `UTextAnimator` |

## 迁移步骤

1. **备份项目** — 升级前创建完整备份。

2. **更新插件** — 移除 Alpha 版本插件，放入 Beta 版本。

3. **重新生成项目文件** — 右键 `.uproject` → **Generate Visual Studio project files**，重新编译。

4. **重建动画蓝图** — Alpha 资产格式与 Beta 不兼容。需手动重建：
   - 创建 `UTextAnimationBlueprint` 替代旧版资产。
   - 将旧版轨道数据迁移到 `UGlyphAnimation` MovieSceneSequence。
   - 使用 `UGlyphAnimationLayer` 重建图层配置。

5. **迁移 BuildDefaultAnimation** — 如果覆盖了旧版编译事件，需改为覆盖 `BuildDefaultAnimation(int32 GlyphCount, const FString& Text)`。

6. **更新 UMG 引用** — 将旧的 Player 引用替换为 `UTextAnimationStageController` 用法：
   ```cpp
   // Alpha
   OldPlayer->Play();
   // Beta
   StageController->Initialize(CDO, Text);
   StageController->Play();
   ```

7. **配置本地化** — 如有本地化需求，迁移到 `ULocalizationSubsystem`：
   ```cpp
   LocalizationSubsystem->SetLanguage(TEXT("zh-Hans"));
   ```

8. **更新富文本标签** — 将旧的标签系统迁移到 `UTextAnimationDataAsset` + `FAnimationEntry` 结构。

9. **重新编译所有动画蓝图** — 在编辑器中打开每个 `UTextAnimationBlueprint` 并执行 **Compile**。

10. **测试所有动画** — 在 `STextAnimationDesignerView` 的预览模式中逐一验证每个动画效果。

## 不再存在的概念

以下 Alpha 概念在 Beta 中无对应物（这些从未存在于真实架构中）：

- ~~`UTexturgeAsset` / `UTexturgeFontAsset`~~ — 不存在，Beta 无这类资产。
- ~~`FTexturgePlayer` / `UTexturgePlayer`~~ — 不存在，使用 `UTextAnimationStageController`。
- ~~`UTexturgeBakerSubsystem`~~ — 不存在，烘焙通过 `FAnimationCompiler` 完成。
- ~~`FTexturgeBakeConfig`~~ — 不存在，配置通过 `UGlyphAnimationLayer` 方法。
- ~~`UTexturgeSubsystem`~~ — 不存在，全局功能在 `FTexturgeModule` 中。
- ~~`UTexturgeRenderer` / `ATexturgeWorldActor`~~ — 不存在，仅支持 UMG UI 渲染。
- ~~SDF 字体图集~~ — Beta 以逐字形曲线动画为核心，不涉及字体纹理烘焙。

## 常见问题

**Q: 迁移后动画效果不同？**
A: Beta 的动画数据流完全重写，某些微调参数映射方式不同。在 `STextAnimationDesignerView` 中逐步调整 `UGlyphAnimationLayer` 的 10 组微调参数直至效果满意。

**Q: 旧资产可以降级回 Alpha 吗？**
A: 不可以。迁移是单向操作，请确保迁移前已备份。

**Q: 我的项目有自定义 C++ 代码怎么办？**
A: 检查所有 `#include` 引用，将 Alpha 类名替换为 Beta 对应类名（见上表）。编译后修复剩余的 API 差异。
