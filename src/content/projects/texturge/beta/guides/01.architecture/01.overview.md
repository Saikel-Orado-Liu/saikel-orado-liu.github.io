# Texturge Beta 架构总览

Texturge 是一个 UE5 文本动画引擎插件，核心目标是将静态文本转化为可逐字形驱动的动画，通过 UMG 控件在 UI 中高性能呈现。

## 模块划分

Texturge 由两个核心模块构成：

1. **Texturge（Runtime）模块** — 运行时动画引擎，包含 UMG 控件、富文本解析、本地化与 Unicode 支持。
2. **TexturgeEditor（Editor）模块** — 编辑器工具集，提供 Blueprint 动画编辑器、设计视口、细节面板定制与 Sequencer 轨道编辑。

> NOTE
>
> Texturge 不存在独立的 Baker 或 Renderer 模块。动画编译在 Editor 模块中完成，运行时渲染由 UMG/Slate 原生管线处理。

## 数据流

```
UTextAnimationBlueprint (设计师资产)
  ├── 含 UGlyphAnimation 轨道 (MovieSceneSequence)
  ├── 编译触发 FAnimationCompiler::BakeAllStages(BP, Text)
  │    ├── BuildScheduleInfos(Text) → TArray<FGlyphScheduleInfo>
  │    ├── CDO->BuildDefaultAnimation(GlyphCount, Text) [BP 事件]
  │    │    └── (默认实现) CreateLayer → CreateFactory → AddLayer → Bake()
  │    │         └── UGlyphAnimationFactory::Bake()
  │    │              ├── 逐层烘焙：BakeStageWithCurves
  │    │              ├── 应用 GlyphCurveOverrides
  │    │              ├── 逐字形逐层：FBakedGlyph::AddLayer()
  │    │              └── 后处理（计划表/微调）
  │    └── 组装 FBakedAnimation (Intro/Default/Outro)
  └── 输出：UTextAnimationBlueprintGeneratedClass

运行时：
  UAnimatedTextBlock (UMG)
    └── UTextAnimationStageController::TickAnimation(dt)
         └── FBakedGlyph::Evaluate(StageTime, OutState)
              └── FPerLayerCurves::Evaluate(LocalTime, InOutState)
                   └── 21 通道：BuildRichCurveFromKeys → Eval → BlendMode 合并
    └── OnPaint 读取 FGlyphAnimationState 逐字形 → Slate 绘制
```

1. 用户创建 `UTextAnimationBlueprint` 资产并配置 `UGlyphAnimation` 轨道。
2. 编译时 `FAnimationCompiler::BakeAllStages()` 对指定文本执行完整烘焙管线。
3. `BuildDefaultAnimation` BP 事件创建图层与工厂，调用 `UGlyphAnimationFactory::Bake()` 生成曲线数据。
4. 编译结果存储在 `UTextAnimationBlueprintGeneratedClass` 中，运行时无需重新烘焙。
5. 运行时通过 `UTextAnimationStageController` 驱动 `FBakedGlyph::Evaluate()` 计算逐字形动画状态。

## 核心数据结构

```
FBakedAnimation (非 USTRUCT)
  ├── TUniquePtr<FBakedStage> Intro
  ├── TUniquePtr<FBakedStage> Default
  └── TUniquePtr<FBakedStage> Outro
       └── FBakedStage (USTRUCT)
            ├── TArray<FBakedGlyph> Glyphs
            ├── float Duration
            └── int32 GlyphCount
                 └── FBakedGlyph (USTRUCT)
                      ├── TArray<FPerLayerCurves> Layers
                      ├── TArray<FPerLayerCurves> ComponentLayers
                      ├── TArray<ETextAnimationBlendMode> BlendModes
                      └── Evaluate() → FGlyphAnimationState&
                           └── FPerLayerCurves (USTRUCT)
                                ├── 21 × TArray<FRichCurveKey>
                                └── ETextAnimationBlendMode
```

## 21 通道动画状态

`FGlyphAnimationState` 包含 21 个浮点通道，覆盖字形变换的全部属性：

- `Location.X`, `Location.Y` — 位置偏移
- `Scale.X`, `Scale.Y` — 缩放
- `Rotation` — 旋转角度
- `Color.R`, `Color.G`, `Color.B`, `Color.A` — 颜色
- `Visible` — 可见性
- `ShadowOffset.X`, `ShadowOffset.Y` — 阴影偏移
- `ShadowColor.R`, `ShadowColor.G`, `ShadowColor.B`, `ShadowColor.A` — 阴影颜色
- `ShadowVisible` — 阴影可见性
- `LetterSpacing` — 字间距
- `LineHeightPercentage` — 行高百分比
- `HorizontalAlignment` — 水平对齐
- `GradientPosition` — 渐变位置
- `GradientColor.R`, `GradientColor.G`, `GradientColor.B` — 渐变颜色

## 三阶段系统

每个动画包含三个独立阶段：

1. **Intro** — 入场动画（例如文字淡入、飞入）。
2. **Default** — 主体动画（例如逐字打字机效果、波浪效果）。
3. **Outro** — 退场动画（例如文字淡出）。

`UTextAnimationStageController` 按序播放三个阶段，支持循环与跨阶段淡入淡出。

## 编辑器工作流

```
[Blueprint 编辑器] → [设计视口] → [编译] → [预览]
```

1. 打开 `UTextAnimationBlueprint` 进入 `FTextAnimationBlueprintEditor`，共含 7 个选项卡。
2. 在 `STextAnimationDesignerView` 设计视口中配置 `UGlyphAnimation` 轨道与图层。
3. 点击 **Compile** 触发 `FAnimationCompiler::BakeAllStages()`。
4. 通过 `FPreviewSourceMediator` 在视口中实时预览动画效果。
