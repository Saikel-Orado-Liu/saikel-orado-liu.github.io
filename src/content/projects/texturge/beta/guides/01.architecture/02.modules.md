# Texturge 模块详解

Texturge 插件包含两个模块：`Texturge`（Runtime）与 `TexturgeEditor`（Editor）。不存在独立的 Baker、Renderer 或 GPU 管线模块。

## Texturge 模块（Runtime）

### 模块概述

- **Module Class**: `FTexturgeModule`，实现 `IModuleInterface`
- **加载阶段**: `Default`（游戏启动时加载）

### 子系统与关键类

**动画蓝图系统**

- `UTextAnimationBlueprint` — `UBlueprint` 子类，设计师面向资产。属性包含 `GlyphAnimations`、`Tracks`、`CompileCount`。方法：`CreateAnimInstance()`、`GetTotalDuration()`、`GetTrackById()`。
- `UTextAnimInstance` — 编译后蓝图 CDO。关键 `BlueprintNativeEvent`：`BuildDefaultAnimation(int32 GlyphCount, const FString& Text)`。方法：`SetBlueprintVariable()`（5 个重载）、`BuildScheduleInfos()`、`GetAnimationByName()`、`ResolveAnimationReferences()`、`NeedsRebake()`。
- `UTextAnimationBlueprintGeneratedClass` — 持有编译输出的生成类，包含烘焙动画数据。

**烘焙数据**

- `FAnimationCompiler` — 静态方法结构体。入口：`BakeAllStages(UTextAnimationBlueprint*, const FString&) → TUniquePtr<FBakedAnimation>`。其他方法：`BuildScheduleInfos()`、`ExtractCurves()`、`BakeStage()`、`BakeStageWithCurves()`、`ComputeTextFingerprint()`、`ComputeBlueprintFingerprint()`。
- `FBakedAnimation` — 非 USTRUCT。含 `TUniquePtr<FBakedStage>` 的 Intro/Default/Outro 三个阶段。方法：`GetStage()`、`HasStage()`、`GetFirstValidStage()`、`GetNextStageAfter()`、`GetTotalDuration()`。
- `FBakedStage` — USTRUCT。含 `TArray<FBakedGlyph>` Glyphs、`float Duration`、`int32 GlyphCount`。方法：`IsValid()`、`GetStartedGlyphCount()`。
- `FBakedGlyph` — USTRUCT。含 `TArray<FPerLayerCurves>` Layers、`TArray<FPerLayerCurves>` ComponentLayers、`TArray<ETextAnimationBlendMode>` BlendModes。核心方法：`Evaluate(float StageTime, float TotalDuration, FGlyphAnimationState&)`。
- `FPerLayerCurves` — USTRUCT。含 21 个 `TArray<FRichCurveKey>` 通道 + `ETextAnimationBlendMode`。方法：`Evaluate()`、`IsEmpty()`、`GetEffectiveDuration()`。

**运行时控制器**

- `UTextAnimationStageController` — UObject。阶段播放控制。属性：`CurrentStage`、`PlaybackState`、`PlayDirection`、`bLoop`、`bCrossfadeEnabled`、`CrossfadeDuration`。方法：`Initialize()`、`Play()`、`Pause()`、`Resume()`、`Stop()`、`RevealAll()`、`TickAnimation()`、`EvaluateAllGlyphs()`、`EvaluateGlyph()`。委托：`StageStarted`、`StageCompleted`、`AllStagesCompleted`。

**UMG 控件**

- `UAnimatedTextBlock` — UMG 文本控件。`OnPaint` 读取逐字形 `FGlyphAnimationState` 并通过 Slate 绘制。

**富文本系统**

- `UTextAnimator` — UObject，富文本打字机引擎。方法：`SetPlainText()`、`SetRichText()`、`SetAnimationData()`、`SetAnimationBlueprint()`、`StartAnimating()`、`TickAnimation()`、`Pause()`、`Resume()`、`Stop()`、`SkipToEnd()`。
- `UTextAnimationDataAsset` — UDataAsset。含 `TArray<FAnimationEntry>` Entries。
- `FAnimationEntry` — USTRUCT。含 `FString TagName`、`TSoftObjectPtr<UTextAnimationBlueprint>` Type、6 组 TMap 参数复写。
- `FTagParser` — 静态解析器。方法：`Parse(const FString&) → FTagNode`。
- `FRenderTreeBuilder` — 静态构建器。方法：`Build(FTagNode) → FRenderNode`、`SerializeToDisplayText()`、`SerializeSubstring()`。

**本地化**

- `ULocalizationSubsystem` — UGameInstanceSubsystem。支持 15 种语言。方法：`SetLanguage()`、`RelocateAnchors()`、`ClearCache()`、`ScanStringTableAssets()`。
- `FSemanticAnchor` — LCS 锚定，确保翻译后动画逐字符对应。
- `FCharBreakIterator` — CJK 感知断字迭代器。

**设置**

- `UTexturgeSettings` — UDeveloperSettings，分类 `"Plugins/Texturge"`。当前为配置空壳，通过 `UTexturgeSettings::Get()` 访问。

### Build.cs 依赖

```
PublicDependencyModuleNames: Core, CoreUObject, Engine, UMG, Slate, SlateCore, MovieScene, MovieSceneTracks
PrivateDependencyModuleNames: InputCore
```

## TexturgeEditor 模块（Editor）

### 模块概述

- **Module Class**: `FTexturgeEditorModule`，实现 `IModuleInterface`
- **加载阶段**: `PostEngineInit`（仅编辑器环境加载）
- **职责**: 注册 Sequencer 轨道编辑器、细节面板定制、编辑器命令

### 关键编辑器类

**蓝图编辑器**

- `FTextAnimationBlueprintEditor` — `FBlueprintEditor` 子类，含 7 个选项卡。方法：`InitTextAnimationEditor()`、`Compile()`、`GetSequencer()`、`ChangeViewedAnimation()`、`SetActivePreviewSource()`、`GetPreviewSourceMediator()`。

**设计视口**

- `STextAnimationDesignerView` — 主设计视口控件，实现 `IUMGDesigner` 接口，支持缩放、平移、网格与标尺。

**预览仲裁**

- `FPreviewSourceMediator` — 三方源仲裁（None / StagePreview / GlyphAnimation）。方法：`RequestSource()`、`RegisterObserver()`、`TickPreview()`、`InvalidateBakeCache()`、`SetActiveOverrides()`（4 个重载）。

**Sequencer 集成**

- `FMovieSceneGlyphAnimationTrack` — Sequencer 轨道。
- `FMovieSceneGlyphAnimationSection` — Sequencer 片段。
- `UGlyphAnimationTrackEditor` — Sequencer 轨道编辑器 UI，由 `FTexturgeEditorModule` 注册。

**细节面板定制**

- `FAnimatedTextBlockDetails` — `UAnimatedTextBlock` 细节面板。
- `FTextAnimationInstanceDetails` — `UTextAnimInstance` 细节面板。
- `FAnimationEntryDetails` — `FAnimationEntry` 细节面板。

### Build.cs 依赖

```
PublicDependencyModuleNames: Texturge, UnrealEd, BlueprintGraph, KismetCompiler, Sequencer, MovieSceneTools, PropertyEditor, DetailCustomizations
PrivateDependencyModuleNames: Slate, SlateCore, EditorStyle, LevelEditor, ToolMenus
```
