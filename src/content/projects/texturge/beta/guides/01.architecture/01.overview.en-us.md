Texturge is a UE5 text animation engine plugin. Its core goal is to convert static text into GPU-driven animated texture sequences, rendered at high performance in both UI and 3D contexts.

## Module Breakdown

Texturge consists of four core modules:

1. **Runtime Module** — Handles playback and control at runtime, parsing bake data and executing per-character animation on the GPU.
2. **Editor Module** — Editor tooling, including asset factories, preview viewports, and animation curve editors.
3. **Baker Module** — The offline bake pipeline that rasterizes vector glyphs into SDF texture atlases.
4. **Renderer Module** — A rendering proxy layer that unifies UMG and World Space rendering paths.

## Data Flow

```
[TTF/OTF] → [Baker] → [SDF Atlas] → [Runtime] → [GPU Animation] → [Renderer] → [Screen]
```

1. Import a font file; the Baker bakes each glyph into an SDF texture and packs them into an atlas.
2. Runtime reads the atlas and animation config, driving animation on the GPU via Material Parameter Collections.
3. Renderer submits the result to UMG or World Space Mesh.

## Key Design Decisions

- **Full GPU Pipeline** — All animation computation happens on the GPU; CPU handles only logic scheduling and parameter passing.
- **Data Asset Driven** — Every configuration (font, animation curves, blend modes) is persisted as a `UTexturgeAsset`.
- **Deep UE5 Integration** — Compatible with Slate/UMG, Material Instances, Niagara, and Sequencer.
