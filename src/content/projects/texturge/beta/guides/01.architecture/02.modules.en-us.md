## Runtime Module (`TexturgeRuntime`)

Runtime is the main animation engine, loading config from Data Assets and executing animation on the GPU.

1. Create an `FTexturgePlayer` instance and bind a `UTexturgeAsset`.
2. Call `Play()` to start and `Tick()` to advance playback each frame.
3. Internally tracks per-glyph state via `FTexturgeGlyphState` arrays (position, scale, rotation, opacity).
4. Animation curve data is pushed to GPU buffers via `FRenderCommand`, driving Material Custom Nodes.

```cpp
UTexturgePlayer* Player = NewObject<UTexturgePlayer>();
Player->Init(TexturgeAsset);
Player->Play();
```

## Baker Module (`TexturgeBaker`)

Baker is an offline tool that bakes font glyphs into an SDF atlas.

1. Parses TTF/OTF files with FreeType to extract glyph outlines.
2. Computes SDF (Signed Distance Field) for each glyph, exporting to a `UTexture2D` atlas.
3. Generates a `.tga` data table recording UV regions and metrics for each glyph in the atlas.

## Editor Module (`TexturgeEditor`)

Provides Slate-based editor UI:

- **TexturgeAssetFactory** — Creates new `UTexturgeAsset` objects.
- **STexturgePreview** — Real-time animation preview.
- **STexturgeCurveEditor** — Keyframe animation curve editing.

## Renderer Module (`TexturgeRenderer`)

A unified rendering proxy layer:

- `UTexturgeUMGWidget` for UMG contexts.
- `ATexturgeWorldActor` for World Space rendering.
- Both modes share the same Material and animation pipeline.
