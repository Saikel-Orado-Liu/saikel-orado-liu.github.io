# Texturge Modules in Detail

The Texturge plugin consists of two modules: `Texturge` (Runtime) and `TexturgeEditor` (Editor). There is no separate Baker, Renderer, or GPU pipeline module.

## Texturge Module (Runtime)

### Module Overview

- **Module Class**: `FTexturgeModule`, implements `IModuleInterface`
- **Loading Phase**: `Default` (loaded at game startup)
- **Log Category**: `LogTexturge`

### Animation Blueprint System

| Class | Description |
|:---|:---|
| `UTextAnimationBlueprint` | `UBlueprint` subclass. Properties: `GlyphAnimations` (`TArray<UGlyphAnimation*>`), `Tracks` (@deprecated compatibility), `StageTransitionConfig`, `VariableNameToGuidMap`, `CompileCount`. Methods: `CreateAnimInstance()`, `GetTotalDuration()`, `GetTrackById()` |
| `UTextAnimInstance` | Compiled Blueprint CDO + bake cache holder. **BlueprintNativeEvent**: `BuildDefaultAnimation(int32 GlyphCount, const FString& Text)`. 4 Blueprint variable setters (float / FVector / FLinearColor / FVector2D), static `BuildScheduleInfos()`, `GetAnimationByName()`, `GetCharacterCount()`, `EvaluateBaked(float)` |
| `UTextAnimationBlueprintGeneratedClass` | `UBlueprintGeneratedClass` subclass holding compilation output (CompiledTracks / CompiledFrameRate / CompiledTotalDuration / CompiledCharacterInterval) |

### Baked Data Layer

| Class | Description |
|:---|:---|
| `FAnimationCompiler` | Pure-function compiler (static methods). Entry point: `BakeAllStages(UTextAnimationBlueprint*, const FString&, const FAnimInstanceCustomizer& = nullptr) → FBakedAnimation`. Others: `BuildScheduleInfos()`, `ExtractCurves()` / `ExtractCurvesRef()` (zero copy), `ConvertFloatChannelToRichCurve()`, `BakeStage()`, `BakeStageWithCurves()`, `ComputeTextFingerprint()`, `ComputeBlueprintFingerprint()`, `MinFramesBetweenRebakes = 3` |
| `FBakedAnimation` | Not a USTRUCT. `TUniquePtr<FBakedStage>` Intro/Default/Outro stages + dual fingerprints. Methods: `GetStage()` / `HasStage()` / `GetFirstValidStage()` / `GetNextStageAfter()` / `GetTotalDuration()` |
| `FBakedStage` | USTRUCT. `StageType` / `GlyphCount` / `TotalDuration` / `Glyphs`. Methods: `IsValid()` / `GetStartedGlyphCount()` |
| `FBakedGlyph` | USTRUCT. `OriginalIndex` / `StartTime` / `Duration` / `bIsStatic` / `DefaultState` / `bHideFirstFrame` / `LayerCurves` / `FactoryOverride`. Core method: `Evaluate(StageTime, OutState)` |
| `FPerLayerCurves` | USTRUCT. 21 `TArray<FRichCurveKey>` + `BlendMode` + `PlayDirection` + `NumberOfLoops` + `PlaySpeedMultiplier` + `LayerDuration`. Methods: `Evaluate()` / `IsEmpty()` / `GetEffectiveDuration()` |
| `FGlyphCurveSet` | Not a USTRUCT (21 `FRichCurve`s), internal C++ temporary computation only |
| `FGlyphCurveOverride` | USTRUCT. Ordered tweak steps for 10 properties (`FGlyphFloatOverrideStep` / `FGlyphVec2OverrideStep` / `FGlyphColorOverrideStep`) |
| `FGlyphScheduleBuilder` | Pure static scheduling utility (`AddPerGlyphDelay` / `SkipWhitespace` / `SetDelayAt` / `SkipAt`) |

### Layers & Factory

| Class | Description |
|:---|:---|
| `UGlyphAnimationLayer` | Layer wrapper (73 Blueprint functions): deep-copied curve copy + scheduling + glyph tweaks + animation clipping. Chainable API returning itself |
| `UGlyphAnimationFactory` | Multi-layer merge baker (69 Blueprint functions): layer management + global scheduling + tweaks + `Bake()` three-step pipeline |
| `UGlyphAnimation` | `UMovieSceneSequence` subclass. `GetDuration()` / `GetTrackTypes()` / `HasTrackType()` |

### Runtime Controllers

| Class | Description |
|:---|:---|
| `UTextAnimationStageController` | Stage playback engine. Playback: `Play()` / `Pause()` / `Resume()` / `Stop()` / `RevealAll()` / `SetPlayDirection()` / `SetLoop()` / `TickAnimation()` / `EvaluateAllGlyphs()`. Queries: `IsPlaying()` / `IsComplete()` / `GetCurrentStage()` / `GetStageTime()` / `GetRevealedGlyphCount()` / `GetTotalGlyphCount()`. Injection: `Initialize()` / `PublishBakedAnimation()`. Delegates: `OnGlyphRevealed` / `OnStageChanged` / `OnAnimationComplete` |
| `UTextAnimator` | Rich text typewriter engine (plain C++ methods only, zero Blueprint functions). `SetPlainText()` / `SetRichText()` / `SetAnimationData()` / `SetAnimationBlueprint()` / `SetPlaybackMode()` / `SetCPS()` / `SetPlayMode()` / `SetPlaySpeedMultiplier()` / `SetSequentialPlayback()` / `SetMaxLoopCount()` / `StartAnimating()` / `TickAnimation()` / `Pause()` / `Resume()` / `Stop()` / `SkipToEnd()` / `GetCurrentFrameDataArray()` etc. |

### UMG Widgets

| Class | Description |
|:---|:---|
| `UAnimatedTextBlock` | `UTextBlock` subclass. 12 Blueprint functions (6 playback + 6 Blueprint variables) + 2 Blueprint delegates. Properties: `TextAnimationBlueprint` / `ParameterOverrides` / `bAutoPlay` / `bLoopPlayback` |
| `UAnimatedRichTextBlock` | `URichTextBlock` subclass. 6 playback Blueprint functions + 2 Blueprint delegates. Properties: `AnimationData` / `bAutoPlay` / `bLoopPlayback` / `bSequentialPlayback` |
| `UEventSoundComponent` | `UActorComponent` subclass. Character sound mapping + punctuation delay + animator binding |

### Rich Text System

| Class | Description |
|:---|:---|
| `UTextAnimationDataAsset` | `UDataAsset`. `Entries` (`TArray<FAnimationEntry>`) |
| `FAnimationEntry` | USTRUCT. `TagName` (FName) + `Type` (`TObjectPtr<UTextAnimationBlueprint>`) + 6 override maps + `bHideFirstFrame` |
| `FTagParser` | Parser. `Parse(const FString&, FString& OutPlainText) → TSharedPtr<FTagNode>` |
| `FRenderTreeBuilder` | Builder. `Build(ParseRoot, PlainText, DataAsset) → FRenderNode`, `SerializeToDisplayText()`, `SerializeSubstring()` |
| `FRichTextMarshaller` | Private Marshaller, per-glyph rich text rendering (per-line independent ModelString since UE5.8, line terminator prefix computation) |

### Localization & Unicode

| Class | Description |
|:---|:---|
| `ULocalizationSubsystem` | `UGameInstanceSubsystem`. `SetLanguage()` (broadcasts `OnLanguageChanged`), static `RelocateAnchors()` (exact match + LCS approximation + confidence dedup, `MaxTextLength = 10000`) |
| `FSemanticAnchor` | USTRUCT. `AnchorId` / `ContextualSnippet` / `SourceOffset` |
| `FCharBreakIterator` | `IBreakIterator` implementation, precomputes break point arrays (CJK / Surrogate Pair / Emoji cluster safe) |
| `Texturge::Unicode` | Namespace utilities: `IsCJK()` / `IsCJKPunctuation()` / `IsHiragana()` / `IsKatakana()` / `IsHangulSyllables()` / surrogate pair composition |
| `Texturge::GlyphRender` | Namespace utilities: `ApplyTint()` (PBM physical pigment mixing), `SRGBToLinearChannel()` / `LinearToSRGBChannel()`, `BuildGlyphTransform()`, `IsSdfFont()` etc. |

### Settings

| Class | Description |
|:---|:---|
| `UTexturgeSettings` | `UDeveloperSettings`, category `"Plugins/Texturge"`, currently no configuration items, static `Get()` access only |

## TexturgeEditor Module (Editor)

### Module Overview

- **Module Class**: `FTexturgeEditorModule`, implements `IModuleInterface`
- **Loading Phase**: `Default` (editor environments only)
- **Responsibilities**: registers Sequencer track editors, Details panel customization, editor commands (`FTexturgeEditorCommands`)
- **Log Category**: `LogTexturgeEditor`

### Blueprint Editor

| Class | Description |
|:---|:---|
| `FTextAnimationBlueprintEditor` | `FBlueprintEditor` subclass. Designer / Graph dual modes + 7 tabs. Methods: `InitTextAnimationEditor()` / `Compile()` / `GetSequencer()` / `ChangeViewedAnimation()` / `SetActivePreviewSource()` / `GetPreviewSourceMediator()` / `GetPreviewSceneConfig()` / `AddTrack()` / `RemoveTrack()` etc. |
| `FTextAnimBPDesignerMode` / `FTextAnimBPGraphMode` | `FBlueprintEditorApplicationMode` subclasses, register tab factories |
| `FTextAnimationBlueprintCompilerContext` | `FKismetCompilerContext` subclass (Private/Compiler). `ValidateTrackData()` / `FixupVariableGUIDs()` / `CopyAssetDataToClass()` |
| `UTextAnimationBlueprintFactory` | `UFactory`, creates assets from the Content Browser |
| `UAssetDefinition_TextAnimationBlueprint` | Asset definition (display name / color / category / open behavior) |

### Design Viewport & Preview

| Class | Description |
|:---|:---|
| `STextAnimationDesignerView` | Main design viewport (`STextAnimationDesignSurface` + `FGCObject` + `IUMGDesigner`). `SetPreviewFrameDataOverride()` / preview size / font metrics |
| `FPreviewSourceMediator` | Preview source arbitration (None / StagePreview / GlyphAnimation). `RequestSource()` / `RegisterObserver()` / `TickPreview()` / `InvalidateBakeCache()` / `SetActiveOverrides()` (4 groups) |
| `FTexturgePreviewBakeCache` | Preview bake cache (dual keys: TextFingerprint + BlueprintFingerprint) |
| `UTexturgePreviewSceneConfig` | Preview scene configuration (27 fields, persisted in `EditorPerProjectUserSettings`) |
| `STextAnimationPreviewWidget` / `STextAnimationPreviewList` / `STextAnimationList` / `STextAnimationGraphPreview` | Preview and list Slate widgets (Private/Designer) |

### Sequencer Integration

| Class | Description |
|:---|:---|
| `UMovieSceneGlyphAnimationTrack` | Main Sequencer track (`UMovieSceneNameableTrack`, multi-line support) |
| `UMovieSceneGlyphAnimationSection` | Sub-track section (`FTextAnimationSubTrackData`) |
| `FGlyphAnimationTrackEditor` | Sequencer track editor UI (`FMovieSceneTrackEditor` subclass, Private/TrackEditors), registered by `FTexturgeEditorModule` |

### Details Panel Customization

| Class | Description |
|:---|:---|
| `FAnimatedTextBlockDetails` | `UAnimatedTextBlock` details (`IDetailCustomization`, parameter rows + Reset) |
| `FTextAnimationInstanceDetails` | `UTextAnimInstance` details (`IDetailCustomization`, category sorting only) |
| `FAnimationEntryDetails` | `FAnimationEntry` details (`IPropertyTypeCustomization`) |
| `UTextAnimationTrackProxy` | Track property editing proxy |
| `AnimParamTraitsHelpers.h` | `AnimParamNeedsReset` / `AnimParamReset` / `AnimParamSync` templates |
