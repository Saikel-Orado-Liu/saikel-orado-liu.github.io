Texturge deeply integrates with UE5's localization framework, using `UStringTable` and `FText` for runtime language switching.

## Setup Steps

1. **Create a StringTable** — In the Content Browser, create a `UStringTable` and add key-value pairs for each language.
2. **Link to TexturgeAsset** — Set the `StringTableSource` property on your `UTexturgeAsset` to point to that StringTable.
3. **Use FText Key References** — Reference text by Key instead of hardcoded strings in animations.
4. **Bake the Required Character Set** — When baking fonts, choose `FromStringTable` mode to auto-extract glyphs needed for all languages.

```cpp
TexturgeAsset->StringTableSource = MyStringTable;
TexturgeAsset->TextKey = TEXT("welcome_message");
```

## Runtime Language Switching

Call `RefreshLocalizedText()` after switching culture:

```cpp
FInternationalization::Get().SetCurrentCulture(TEXT("ja"));
TexturgePlayer->RefreshLocalizedText();  // instantly update to Japanese text
```

## Coordinating Animation with Localization

1. Text length varies across languages. Set `AutoFitMode` to `ETexturgeFit::ScaleToFit` for automatic scaling.
2. Use the `PerCultureDuration` map to specify different animation durations per language:

```cpp
Asset->PerCultureDuration.Add(TEXT("en"), 2.0f);
Asset->PerCultureDuration.Add(TEXT("de"), 2.5f);  // German text is typically longer
```

## Development Tips

- Toggle **Preview Culture** in the editor to preview your animation in different languages in real time.
- Enable `bEnableRTLSupport` for RTL languages (Arabic, Hebrew) to automatically reverse text direction.
