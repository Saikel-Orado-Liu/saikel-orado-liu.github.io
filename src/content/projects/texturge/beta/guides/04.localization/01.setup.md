# 多语言本地化设置

Texturge 通过 `ULocalizationSubsystem` 提供运行时语言切换能力，借助 `FSemanticAnchor` 的 LCS 算法确保动画逐字符对应在翻译后保持不变。

> NOTE
>
> Texturge 不使用 UE5 原生 `UStringTable` 进行本地化。自有 `ULocalizationSubsystem` 与语义锚定机制独立于引擎本地化框架。

## 支持的语言

`ULocalizationSubsystem` 支持 15 种语言：

| 语言 | 代码 |
|------|------|
| 英语 | en |
| 简体中文 | zh-Hans |
| 日语 | ja |
| 韩语 | ko |
| 西班牙语 | es |
| 葡萄牙语 | pt |
| 阿拉伯语 | ar |
| 波兰语 | pl |
| 德语 | de |
| 俄语 | ru |
| 法语 | fr |
| 巴西葡萄牙语 | pt-BR |
| 土耳其语 | tr |
| 拉丁美洲西班牙语 | es-419 |
| 意大利语 | it |

## 配置流程

1. **准备多语言文本** — 为项目中的每个文本片段准备 15 种语言的翻译。
2. **关联本地化数据** — 文本通过插件的本地化管线注册到 `ULocalizationSubsystem`。
3. **设置当前语言** — 运行时调用 `SetLanguage()` 切换显示语言。
4. **验证锚定正确性** — 使用语义锚定确保动画按字符匹配，不受翻译影响。

## 运行时语言切换

```cpp
ULocalizationSubsystem* Localization = GetGameInstance()->GetSubsystem<ULocalizationSubsystem>();
Localization->SetLanguage(TEXT("ja"));     // 切换至日语
Localization->SetLanguage(TEXT("zh-Hans")); // 切换至简体中文
Localization->SetLanguage(TEXT("ar"));      // 切换至阿拉伯语
```

切换语言后系统自动触发以下操作：
1. `RelocateAnchors()` — 重新计算语义锚定映射
2. `ClearCache()` — 清除旧的缓存数据
3. 必要时调用 `ScanStringTableAssets()` 刷新资产引用

## 语义锚定机制

`FSemanticAnchor` 使用 **LCS（最长公共子序列）算法** 进行跨翻译文本锚定。

### 问题场景

翻译前后的文本长度可能不同：
- 英文 "Hello"（5 字符）→ 简体中文 "你好"（2 字符）
- 每个字符在动画中都有独立的曲线数据

### 锚定原理

1. 编译时基于原始语言文本生成逐字形动画曲线。
2. 语言切换后，`FSemanticAnchor` 通过 LCS 算法匹配新旧文本的字符序列。
3. 未被匹配的字符跳过动画，新增加的字符采用默认状态或从相邻字符继承。

### 效果保证

- 原有字符的动画曲线在新语言中继续保持。
- 删除/新增的字符不会导致动画数据错位或崩溃。
- 各语言下动画起始/结束时间点保持一致。

## 本地化资产配置

插件的 `.uplugin` 文件中包含 7 个本地化目标，每个覆盖 15 种语言：

1. Texturge 核心运行时文本
2. 编辑器 UI 文本
3. 资产类型名称与工具提示
4. 细节面板标签
5. Sequencer 轨道名称
6. 蓝图节点显示名称
7. 错误消息与日志文本

预配置的本地化目标无需手动创建，插件加载时自动注册。

## Unicode 支持

Texturge 内部使用 Unicode 工具类进行字符分类（字母、数字、标点、空白、组合字符等），确保 CJK 与 RTL 文本正确处理。
