The Texturge dialog system can be timeline-controlled via Level Sequencer, ideal for character conversations in cutscenes.

## Adding a Sequencer Track

Use cases: Integrating a Texturge dialog actor into a Level Sequence timeline for cutscene conversations.

1. Place an `ATexturgeDialogActor` in the level.
2. Create a **Level Sequence** asset and open it.
3. Drag the `ATexturgeDialogActor` into the Sequencer timeline.
4. Click **+ Track** and select `Texturge > Dialog Track`.

## Keyframe Operations

Use cases: Showing and hiding dialog text at specific time points on the Sequencer timeline.

### Showing a Dialog
1. At the desired time on the Dialog Track, press `Enter` to add a keyframe.
2. Right-click the keyframe and select **Properties**.
3. Set **Dialog Asset** to a `UTexturgeDialogDataAsset`.
4. Check **Show On Key** — the dialog appears at the keyframe.

### Hiding the Dialog Box
1. Add a keyframe at the time when the dialog should disappear.
2. Uncheck **Show On Key**.

## Syncing with Animation

Use cases: Aligning dialog keyframes with character animations, lip-sync, and camera cuts.

A typical cutscene dialog setup:

1. Align character animations with dialog keyframes in Sequencer.
2. Dialog timing stays in sync with lip-sync animations and camera cuts.
3. Example timeline:

```yaml
00:00 - Camera zooms to Character A
00:02 - Show dialog "Hello, traveler."
00:05 - Hide dialog, camera pans to Character B
00:06 - Show dialog "Welcome to our village."
```

## Runtime Control

Use cases: Responding to dialog lifecycle events (shown, hidden, option selected) during Sequencer playback.

During Sequencer playback, the dialog system responds via these events:

1. **OnDialogShown**: Fired when a dialog is shown — useful for triggering voiceover.
2. **OnDialogHidden**: Fired when a dialog is hidden — clean up UI state.
3. **OnDialogOptionSelected**: Fired when a branch option is chosen.

Bind these events in the Level Blueprint to implement audio sync, expression switching, and other advanced features.

> TIP
>
> Use the `OnDialogShown` event to trigger character voiceover playback, and `OnDialogHidden` to stop audio when the dialog box disappears. This keeps audio perfectly in sync with the Sequencer timeline.
