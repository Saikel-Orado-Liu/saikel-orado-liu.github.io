# Sequencer 集成

`UGlyphAnimation` 是 `MovieSceneSequence` 的子类，天然支持在 UE5 Sequencer 中编辑。你可以通过关键帧精确控制每个字符的 21 个动画通道，实现文字动画与镜头、角色动作的完美同步。

## 打开 UGlyphAnimation

1. 在 Content Browser 中找到 `UGlyphAnimation` 资产（通常在 `UTextAnimationBlueprint` 的 **GlyphAnimations** 数组中被引用）。
2. 双击资产即可在 Sequencer 中打开。
3. Sequencer 时间轴将显示 `FMovieSceneGlyphAnimationTrack` 轨道。

## FMovieSceneGlyphAnimationTrack

`FMovieSceneGlyphAnimationTrackEditor` 是 TexturgeEditor 模块提供的自定义 Sequencer 轨道类型。每个 `UGlyphAnimation` 在此轨道中管理其 21 通道的关键帧数据。

1. 展开轨道以查看所有子通道。
2. 常见的可关键帧通道包括：
   - **Location.X / Location.Y** — 逐字位置偏移
   - **Scale.X / Scale.Y** — 逐字缩放
   - **Rotation** — 逐字旋转
   - **Color.R / Color.G / Color.B / Color.A** — 逐字颜色
   - **Visible** — 逐字可见性

## 添加与编辑关键帧

### 添加关键帧

1. 将播放头移动到目标时间点。
2. 选中目标通道（如 Location.X）。
3. 按 `Enter` 添加关键帧。
4. 在关键帧上右键选择 **Properties** 设置值。
5. 或直接拖动关键帧调整位置与值。

### 编辑通道曲线

1. 选中通道，Sequencer 曲线编辑器将在底部显示曲线图。
2. 拖拽关键帧调整切线，实现缓入缓出效果。
3. 右键切线可选择自动、线性、常量等插值类型。
4. 通过 `UGlyphAnimation::HasTrackType()` 在代码中查询某通道是否已添加关键帧。

## 预览动画

### 实时预览

1. 在 Designer 标签页（`STextAnimationDesignerView`）打开时，Sequencer 中的修改可实时反映到预览视口。
2. `FPreviewSourceMediator` 管理预览源切换：
   - **None** — 无预览
   - **StagePreview** — 按阶段预览（Intro/Default/Outro）
   - **GlyphAnimation** — 预览单个 UGlyphAnimation 轨道
3. 播放 Sequencer 时间轴即可看到文字动画效果。

### 预览文本

1. 在 Designer 视口顶部的文本输入框中输入预览文本。
2. 预览文本决定编译时 `FAnimationCompiler::BakeAllStages()` 的输入。
3. 改变预览文本后点击 **Refresh** 重新烘焙并更新预览。

## 在 Level Sequencer 中使用

### 将文字动画嵌入过场

1. 打开 Level Sequence 资产。
2. 在关卡中放置包含 `UAnimatedTextBlock` 的 Widget（通过 UMG 添加到视口）。
3. 在 Level Sequencer 中添加 **Event Track** 或使用蓝图函数触发文字动画。
4. 在特定时间点调用 `UAnimatedTextBlock::Play()` 启动文字动画。
5. 将文字动画的 Intro/Default/Outro 时长与镜头切换、角色动画对齐。

### 时间对齐示例

```
Level Sequencer 时间轴示例：
00:00 — 镜头拉近角色
00:02 — 触发 Play()，文字 Intro 阶段开始
00:03 — 文字 Default 阶段（逐字显示），持续约 2 秒
00:05 — 文字 Outro 阶段，文字消散
00:06 — 镜头切换到下一场景
```

## 通过蓝图同步 Sequencer

`UTextAnimationStageController` 的方法可在蓝图或 C++ 中调用，与 Sequencer 播放状态联动：

1. **Play()** — Sequencer 播放到触发点时启动阶段播放
2. **Pause()** — 暂停动画以等待交互输入
3. **Resume()** — 继续播放
4. **RevealAll()** — 立即跳过动画显示所有文字
5. **SetPlayDirection(EPlayMode)** — 设置播放方向（`Forward`、`Reverse`、`PingPong`）
6. **SetLoop(bool)** — 控制 Default 阶段是否循环

使用 `EvaluateGlyph(int32 Index, float Time)` 可查询特定字符在特定时间点的状态，用于与 Sequencer 中的其他元素（灯光、特效）进行精确同步。
