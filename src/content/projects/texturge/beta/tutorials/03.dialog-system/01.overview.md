# 对话系统概述

Texturge 的对话系统围绕富文本标签映射和逐字打字播放管道构建。核心思路：对话文本用标签标记 → 标签映射到动画蓝图 → 逐字播放。

## 核心组件

适用场景：了解对话系统中各组件（UAnimatedRichTextBlock、UTextAnimationDataAsset、UTextAnimator）的职责与协作关系。

### 对话文本的承载者

`UAnimatedRichTextBlock` 是对话文本的 UI 承载控件。它是 `URichTextBlock` 的子类，内部集成了标签→动画的解析与渲染。

### 标签映射

`UTextAnimationDataAsset` (`UDataAsset`) 将标签名映射到 `UTextAnimationBlueprint`：

- `Entries` — `TArray<FAnimationEntry>` 映射表
- 每个 `FAnimationEntry` 包含 `TagName`、`Type`（指向 `UTextAnimationBlueprint*`）和 6 个参数覆盖映射

### 逐字打字管道

`UTextAnimator` 实现了富文本逐字打字的管道控制：

- `SetPlainText()` / `SetRichText()` — 设置显示文本
- `SetAnimationData(UTextAnimationDataAsset*)` — 绑定标签映射
- `SetAnimationBlueprint(UTextAnimationBlueprint*)` — 直接绑定动画蓝图（绕过标签）
- `StartAnimating()` — 开始逐字显示
- `TickAnimation()` — 驱动每帧动画更新
- `GetCurrentFrameData()` — 获取当前帧的渲染数据
- `Pause()`、`Resume()`、`Stop()`、`SkipToEnd()` — 播放控制

## 基本使用流程

适用场景：从零搭建一个可播放对话的 UMG Widget 并驱动逐字显示。

### 创建对话 DataAsset

1. Content Browser 右键 > Miscellaneous > Data Asset > 选择 `UTextAnimationDataAsset`。
2. 命名 `DA_Dialog` 并打开。
3. 添加 Entries：
   - TagName: `"speak"` → Type: `TAB_Speak`（一段字符渐入动画）
   - TagName: `"shout"` → Type: `TAB_Shout`（一段字符弹跳动画）
   - TagName: `"whisper"` → Type: `TAB_Whisper`（一段字符淡入动画）

### 构建对话 Widget

1. 创建 UMG Widget Blueprint（如 `WBP_DialogBox`）。
2. 添加 `UAnimatedRichTextBlock` 控件。
3. 设置 **Text Animation Data Asset** 为 `DA_Dialog`。
4. 可选添加角色名文本块、头像 Image 控件等装饰元素。

### 编写对话文本

在 `UAnimatedRichTextBlock` 的 Text 属性或运行时通过代码设置：

```
<speak>你好，旅行者。欢迎来到我们的村庄。</speak>
```

或者切换语气：

```
<shout>站住！你是谁？</shout> <speak>…抱歉，这里最近不太平。</speak>
```

### 运行时驱动对话

1. 在 Level Blueprint 中获取 `UAnimatedRichTextBlock` 的引用。
2. 调用 `Play()` 开始播放动画。
3. 文本将逐字以标签对应的动画效果显示。

## 阶段式对话编排

适用场景：实现对话框弹出→文字打印→对话框淡出三段式效果。

使用 `UTextAnimationStageController` 可实现三段式对话编排：

1. **Intro** (`EAnimationStage::Intro`) — 对话框弹出，角色名浮现
2. **Default** (`EAnimationStage::Default`) — 文字逐字打印，可选循环待机动画
3. **Outro** (`EAnimationStage::Outro`) — 对话框淡出，文字消散

阶段通过 `FBakedAnimation` 的三个 `FBakedStage` 指针存储，`UTextAnimationStageController` 按 Intro → Default → Outro 顺序推进。

## 常用控制方法

适用场景：快速查阅 UAnimatedRichTextBlock 和 UTextAnimator 的播放控制 API。

### UAnimatedRichTextBlock 方法

- `Play()` — 启动动画播放
- `Pause()` — 暂停当前播放
- `Resume()` — 从暂停位置恢复
- `Stop()` — 停止播放并重置
- `SkipToEnd()` — 立即显示全部文字（跳过打字动画）

> NOTE
>
> 调用 `SkipToEnd()` 后，所有字符的状态直接置为可见，不会再逐字播放过渡效果。如需保留动画序列，请使用 `Stop()` 后再重新播放。

### UTextAnimator 方法

- `StartAnimating()` — 开始逐字打字
- `TickAnimation()` — 每帧更新
- `SkipToEnd()` — 跳过打字过程

## 本地化支持

适用场景：为对话系统配置多语言显示，确保 CJK 和拉丁字符正确排版。

通过 `ULocalizationSubsystem`（`UGameInstanceSubsystem`）切换语言：

1. 调用 `GetGameInstance()->GetSubsystem<ULocalizationSubsystem>()` 获取子系统。
2. 调用 `SetLanguage()` 切换当前语言。
3. 支持 15 种语言，`FCharBreakIterator` 确保 CJK 字符正确断行。

> TIP
>
> 切换语言后无需重建 `UAnimatedRichTextBlock` 控件。本地化文本自动适配，但需要确保目标语言的字体资产已正确配置。
