Texturge includes a built-in dialog system for managing multi-line text display, branching options, and character portraits.

## Core Components

### `ATexturgeDialogActor`
The main dialog actor responsible for managing the dialog queue, character data, and UI.

### `UTexturgeDialogDataAsset`
A data asset that defines all parameters for a single dialog segment:

```cpp
UPROPERTY(EditAnywhere)
FText SpeakerName;

UPROPERTY(EditAnywhere)
UTexture2D* Portrait;

UPROPERTY(EditAnywhere)
FText Content;

UPROPERTY(EditAnywhere)
TArray<FTexturgeDialogOption> Options;
```

### `UTexturgeDialogSubsystem`
A global subsystem that manages dialog state machines and event broadcasting.

## Basic Usage Flow

1. Create a `UTexturgeDialogDataAsset` and fill in the dialog content.
2. Place an `ATexturgeDialogActor` in the level.
3. Call `Start Dialog` in Blueprint, passing in the dialog data.
4. Dialogs play in sequence and support rich text tag animations.
5. When branching options trigger, handle selection logic via event callbacks.

## Branching Dialogs

The `FTexturgeDialogOption` struct supports defining options and next segments:

```cpp
UPROPERTY(EditAnywhere)
FText OptionText;

UPROPERTY(EditAnywhere)
UTexturgeDialogDataAsset* NextDialog;
```

1. Set `NextDialog` to another dialog asset.
2. Upon user selection, the system jumps to the corresponding branch.
3. Leave `NextDialog` empty to end the dialog on that option.

## Character Expressions

Use the `Portrait` property to specify a portrait, and switch between dialog segments to change expressions. Update the portrait at runtime by setting the corresponding property.
