Texturge Beta is a text animation engine plugin for Unreal Engine 5. This guide walks you through installation and basic configuration.

## Installation Steps

Use cases: First-time setup of the Texturge plugin in a UE5 project.

1. Place the `Texturge` folder into your project's `Plugins/` directory. Create the directory if it doesn't exist.
2. Launch the project. UE5 will detect the new plugin. Select **Yes** to compile.
3. After compilation, open `Edit > Plugins`, search for "Texturge", and confirm the plugin is enabled.
4. Restart the editor for the plugin to fully take effect.

## Project Configuration

Use cases: Setting default font, animation parameters, and C++ module dependencies.

1. Open `Edit > Project Settings > Texturge`.
2. Set **Default Font** to a font asset in your project.
3. Adjust **Default Animation Speed** as needed (recommended starting value: `1.0`).
4. Add `TexturgeRuntime` to your module dependencies. Edit `[ProjectName].Build.cs`:

```cpp
PublicDependencyModuleNames.AddRange(new string[] {
    "Core", "CoreUObject", "Engine",
    "TexturgeRuntime"
});
```

> NOTE
>
> The plugin module is named `"TexturgeRuntime"` in your build configuration. `TexturgeEditor` should only be used in editor-specific code via `PrivateDependencyModuleNames`.

## Verifying Installation

Use cases: Confirming the plugin is functional after completing the setup.

1. Place an `ATexturgeActor` in any level.
2. Select the Actor and locate the **Rich Text** property in the Details panel.
3. Enter test text and run PIE to see the result.
4. If text renders correctly and tag-based animations work, the setup is successful.
