# 创建第一个动画

本节将引导你创建第一个文字动画：从创建动画蓝图资产到在 UMG 中播放。

## 创建 TextAnimationBlueprint 资产

适用场景：开始创建你的第一个文字动画蓝图资产。

`UTextAnimationBlueprint` 是 Texturge 的核心创作资产。每个动画蓝图定义一组 `UGlyphAnimation` 轨道，编译后生成 `UTextAnimInstance`。

1. 在 Content Browser 中右键，选择 **Animation > Text Animation Blueprint**。
2. 命名资产，如 `TAB_Wave`。
3. 双击打开 Text Animation Blueprint Editor。

<figure class="img-placeholder"><figcaption>images/create-text-animation-blueprint.png — 右键菜单创建 Text Animation Blueprint — Creating a Text Animation Blueprint from context menu</figcaption></figure>

## 熟悉编辑器

适用场景：首次打开 Text Animation Blueprint Editor 时了解各面板功能。

`FTextAnimationBlueprintEditor` 包含 7 个标签页：

1. **Designer** — WYSIWYG 设计视口 (`STextAnimationDesignerView`)，支持缩放/平移/网格。
2. **Graph** — 蓝图事件图，编写 `BuildDefaultAnimation` 等事件逻辑。
3. **Preview** — 预览运行时效果。
4. **Details** — 所选对象的属性面板。
5. 其余标签页包括 Timeline、Compiler Results 等辅助面板。

<figure class="img-placeholder"><figcaption>images/editor-layout.png — Text Animation Blueprint Editor 布局 — Text Animation Blueprint Editor layout</figcaption></figure>

## 添加 GlyphAnimation 轨道

适用场景：将关键帧动画轨道绑定到动画蓝图中。

`UGlyphAnimation` 是 MovieSceneSequence 子类，存储单个逐字动画轨道的关键帧数据。

1. 在编辑器 Details 面板中找到 **GlyphAnimations** 数组。
2. 点击 **+** 添加一个新元素。
3. 点击元素展开，选择已有的 `UGlyphAnimation` 资产或点击 **Create New** 创建新资产。
4. 新创建的 `UGlyphAnimation` 可以双击打开 Sequencer 进行关键帧编辑。

> TIP
>
> 建议在 `UGlyphAnimation` 中为每个阶段（Intro/Default/Outro）分别设置关键帧区间，使动画蓝图能正确区分三段式播放。

## 配置预览文本

适用场景：在编辑器中设置测试文本以实时预览动画效果。

在 Designer 视图中：

1. 切换到 **Designer** 标签页。
2. 在视口上方的预览文本框中输入测试文本，如 "Hello World"。
3. 预览文本将用于 `FAnimationCompiler::BakeAllStages()` 编译时生成 `FBakedAnimation`。
4. 调整视口缩放和网格以查看全部字符。

## 编译动画蓝图

适用场景：完成动画配置后编译蓝图生成运行时烘焙数据。

1. 点击工具栏的 **Compile** 按钮。
2. 编译器调用 `FAnimationCompiler::BakeAllStages(Blueprint, Text)` 生成烘焙数据。
3. 编译成功后，`UTextAnimInstance` CDO 的 `BuildDefaultAnimation(GlyphCount, Text)` 事件生成最终 `FBakedAnimation`。
4. 检查 **CompileCount** 属性确认编译次数递增。
5. 在 Preview 标签页观察动画效果。

> NOTE
>
> 预览文本仅用于编辑器中的实时预览，不会影响运行时 `UAnimatedTextBlock` 的实际显示文本。运行时的文本由 `Text` 属性独立控制。

## 在 UMG 中使用

适用场景：将编译好的动画蓝图绑定到 UMG Widget 中进行界面呈现。

### 创建 Widget

1. Content Browser 右键 > User Interface > Widget Blueprint，命名如 `WBP_HelloWorld`。
2. 打开 Widget Designer，从 Palette 搜索 **Animated Text Block**。
3. 将 `UAnimatedTextBlock` 拖入画布。
4. 调整控件尺寸和位置。

<figure class="img-placeholder"><figcaption>images/umg-widget-setup.png — UMG Widget 中设置 UAnimatedTextBlock — Setting up UAnimatedTextBlock in UMG Widget</figcaption></figure>

### 绑定动画蓝图

1. 选中 `UAnimatedTextBlock`，在 Details 面板找到 **Anim Instance Class** 属性。
2. 将其设置为之前编译好的 `TAB_Wave`。
3. 设置 **Text** 属性为运行时要显示的文本。
4. 编译保存 Widget。

### 通过参数覆盖微调

`UAnimatedTextBlock` 持有一个 `UAnimParameterOverrides` 实例，可在 Details 面板中按实例覆盖蓝图默认参数：

- **FloatOverrides** — 浮点参数覆盖
- **IntOverrides** — 整数参数覆盖
- **BoolOverrides** — 布尔参数覆盖
- **VectorOverrides** — 向量参数覆盖
- **ColorOverrides** — 颜色参数覆盖
- **Vector2DOverrides** — 二维向量参数覆盖

## 测试运行

适用场景：在 PIE 中验证动画蓝图在游戏中的实际播放效果。

1. 打开一个关卡，将 `WBP_HelloWorld` 添加到视口。可通过 Level Blueprint `Event BeginPlay` > `Create Widget` > `Add to Viewport`。
2. 运行 PIE（`Alt+P`）。
3. 文字应按照动画蓝图中定义的方式播放动画。

如果在 Designer 标签页预览时调用 `Play()`，动画将在 Editor 内直接播放。

## 运行时控制

适用场景：在蓝图或 C++ 中动态控制动画的播放、暂停和参数覆盖。

在蓝图或 C++ 中通过以下 `UAnimatedTextBlock` 方法控制动画：

- `Play()` — 播放动画
- `Pause()` — 暂停动画
- `Resume()` — 从暂停位置恢复
- `Stop()` — 停止并重置
- `SkipToEnd()` — 立即跳到动画结尾
- `SetBlueprintVariable()` — 运行时覆盖蓝图参数（6 个重载，分别对应 Float/Int/Bool/Vector/Color/Vector2D）

> NOTE
>
> `SetBlueprintVariable()` 的 `VariableName` 必须与 `UTextAnimInstance` 蓝图中定义的变量名称完全一致（区分大小写），否则参数覆盖无效。

至此，你已经完成了从创建资产到运行时播放的完整流程。
