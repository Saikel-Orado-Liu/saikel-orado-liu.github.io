# 安装与配置

Texturge Beta 是 Unreal Engine 5.6+ 的文字动画引擎插件。本文档引导你完成安装、启用与项目配置。

## 安装插件

适用场景：首次将 Texturge 添加到 UE5 项目时的安装步骤。

### 从本地文件夹安装

1. 将 `Texturge` 插件文件夹放入项目的 `Plugins/` 目录（目录不存在则手动创建）
2. 启动项目，UE5 检测到新插件后选择**是**编译插件

    ![编译插件截图：UE5 检测到新插件后弹出提示，选择“是”开始编译](images/plugin-compile-prompt.avif)

3. 编译完成后打开 **编辑 > 插件**，搜索 "Texturge"
4. 确认 **Texturge** 插件已启用
5. 重启编辑器使插件完全生效

### 从 Fab 商城安装

1. 在 Fab 商城中搜索 "Texturge"

    ![Fab 商城图片：Texturge 产品页，包含安装与添加到账户库入口](images/fab-marketplace.avif)

2. 将插件添加到 Epic Games 账户库
3. 通过 Epic Games Launcher 安装到目标引擎版本
4. 在项目 **编辑 > 插件** 中启用插件

> [!NOTE]
> 插件支持平台：Win64 / Mac / Linux。无额外依赖模块。

## 启用插件

适用场景：安装后需要在插件管理器（Plugin Manager）中激活插件。

1. 打开 **编辑 > 插件**
2. 搜索 "Texturge"
3. 勾选 **Texturge** 复选框
4. 点击右下角 **立即重启** 重启编辑器

    ![插件管理器截图：搜索框输入 "Texturge"，下方列表高亮 Texturge 插件行且勾选框已勾选，右下角"立即重启"按钮](images/plugin-manager-checkbox.avif)

> [!IMPORTANT]
> **启用"显示插件内容"**：默认情况下，内容浏览器不显示插件资产。启用插件后，点击内容浏览器左上角 **设置** 菜单，勾选 **显示插件内容**，才能在 `Plugins/Texturge/Content/` 下找到预设、演示等插件资产（如 `TextAnimation/Preset/` 下的 16 个预设动画蓝图）。否则插件资产不可见，会被误认为"插件缺失预设"。

![显示插件内容截图：内容浏览器左上角“设置”菜单中勾选“显示插件内容”](images/show-plugin-content.avif)

## 项目设置

适用场景：配置 Texturge 的全局默认参数。

1. 打开 **编辑 > 项目设置 > 插件 > Texturge**
2. `UTexturgeSettings::Get()` 访问当前配置——当前无配置项，所有配置通过动画资产与蓝图变量管理

## C++ 模块依赖

适用场景：在 C++ 代码中引用 Texturge 类型时需要的 Build.cs 配置。

```cpp
PublicDependencyModuleNames.AddRange(new string[] {
    "Core", "CoreUObject", "Engine",
    "Texturge"
});
```

> [!NOTE]
> 模块名为 `"Texturge"`（非 `"TexturgeRuntime"`）。`TexturgeEditor` 仅供编辑器代码使用（编辑器工具类/模块），运行时构建不包含。

## 验证安装

适用场景：安装完成后确认插件功能正常。

### 在 UMG 中验证

1. 内容浏览器右键 > **用户界面 > Widget 蓝图**，创建控件
2. 打开**控件设计器**，在**面板**中搜索 **动画文本块**
3. 将**动画文本块**控件（`UAnimatedTextBlock`）拖入画布
4. 在**细节**面板确认 **文本动画蓝图** 与 **实例参数覆盖** 属性存在
5. 编译保存控件

    ![UMG 控件设计器截图：左侧"面板"搜索框输入 "动画文本块"，列表中高亮显示该控件，右侧画布中放置了一个实例](images/umg-palette-animated-text.avif)

### 在关卡中验证（备选）

1. 创建测试关卡，打开**关卡蓝图**
2. `事件 BeginPlay` → `创建控件`（指定包含**动画文本块**控件的 Widget 蓝图）→ `添加到视口`
3. 调用 `播放` 节点
4. 运行 PIE（`Alt+P`），确认文字逐字动画播放

> [!TIP]
> 如果控件设计器**面板**中找不到 **动画文本块**，请确认 Texturge 插件已启用并重启编辑器。若编译报错，检查项目引擎版本（需要 UE 5.6+）与 Build.cs 模块依赖。
