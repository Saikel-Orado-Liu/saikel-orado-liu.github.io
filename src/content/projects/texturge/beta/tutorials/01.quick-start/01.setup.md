# 安装与配置

Texturge Beta 是 Unreal Engine 5 的文字动画引擎插件。本文档将引导你完成安装、启用与项目配置。

## 安装插件

适用场景：首次将 Texturge 添加到 UE5 项目时的安装步骤。

### 从本地文件夹安装

1. 将 `Texturge` 插件文件夹放入项目的 `Plugins/` 目录。如果该目录不存在，请手动创建。
2. 启动项目，UE5 会提示检测到新插件。选择**是**以编译插件。
3. 编译完成后，打开 `Edit > Plugins`，在搜索框中输入 "Texturge"。
4. 确认 **Texturge** 和 **TexturgeEditor** 两个模块均已勾选启用。
5. 重启编辑器以使插件完全生效。

<figure class="img-placeholder"><figcaption>images/plugin-folder-location.png — 插件文件夹在项目中的位置 — Plugin folder location in project directory</figcaption></figure>

### 从 Fab 商城安装

1. 在 Fab 商城中搜索 "Texturge"。
2. 将插件添加到你的 Epic Games 账户库中。
3. 通过 Epic Games Launcher 安装到目标引擎版本。
4. 在项目的 `Edit > Plugins` 中启用插件。

## 启用插件

适用场景：安装后需要在 Plugin Manager 中激活插件功能。

1. 打开 `Edit > Plugins`。
2. 在左侧分类中找到 **Animation** 或使用顶部搜索栏搜索 "Texturge"。
3. 勾选 **Texturge** 插件复选框。
4. 点击右下角 **Restart Now** 重启编辑器。

<figure class="img-placeholder"><figcaption>images/plugin-manager-checkbox.png — 插件管理器中启用 Texturge — Enabling Texturge in Plugin Manager</figcaption></figure>

## 项目设置

适用场景：配置 Texturge 的全局默认参数。

1. 打开 `Edit > Project Settings > Plugins > Texturge`。
2. 通过 `UTexturgeSettings::Get()` 可访问当前配置（目前为空白壳，预留扩展）。

<figure class="img-placeholder"><figcaption>images/project-settings-panel.png — 项目设置中的 Texturge 面板 — Texturge settings panel in Project Settings</figcaption></figure>

## C++ 模块依赖

适用场景：在 C++ 代码中引用 Texturge 类型时需要添加的 Build.cs 配置。

如需在 C++ 代码中使用 Texturge，请在 `[ProjectName].Build.cs` 中添加模块依赖：

```cpp
PublicDependencyModuleNames.AddRange(new string[] {
    "Core", "CoreUObject", "Engine",
    "Texturge"
});
```

> NOTE
>
> 模块名为 `"Texturge"`，而非 `"TexturgeRuntime"`。`TexturgeEditor` 仅供编辑器代码使用，应放入 `PrivateDependencyModuleNames`。

## 验证安装

适用场景：安装完成后确认插件各功能模块正常工作。

### 在 UMG 中验证

1. 在 Content Browser 中创建一个 UMG Widget Blueprint（右键 > User Interface > Widget Blueprint）。
2. 打开 Widget Designer，在 Palette 面板中搜索 "Animated Text Block"。
3. 将 `UAnimatedTextBlock` 拖入画布。
4. 在 Details 面板中找到 **Anim Instance Class** 属性，确认其存在。
5. 编译保存 Widget。

<figure class="img-placeholder"><figcaption>images/umg-palette-animated-text.png — UMG Palette 中的 Animated Text Block 控件 — Animated Text Block in UMG Palette</figcaption></figure>

### 在关卡中验证（备选）

1. 创建一个测试关卡。
2. 打开 Level Blueprint，在 Event Graph 中添加 `Event BeginPlay`。
3. 搜索 `UK2Node_PrintWithAnimation` 节点，添加到图表。
4. 连接执行流并对齐默认文本参数。
5. 运行 PIE（`Alt+P`），确认节点可正常编译执行。

如果以上步骤均无报错，说明 Texturge 已正确安装并可用。

> TIP
>
> 如果 UMG Palette 中找不到 "Animated Text Block"，请确认 Texturge 和 TexturgeEditor 两个模块均已启用并重启编辑器。
