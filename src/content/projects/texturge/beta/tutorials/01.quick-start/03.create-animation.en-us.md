This guide walks you through creating your first text animation — a per-character pop-in effect.

## Creating a Texturge Actor

Use cases: Placing and configuring a text animation actor in a level for the first time.

1. In the **Place Actors** panel, search for `TexturgeActor` and drag it into the level.
2. In the Details panel, fill in the **Rich Text** property:

```
<wave>Welcome to Texturge Beta!</wave>
```

3. Run PIE (`Alt+P`) and watch characters wave in one by one.

> TIP
>
> You can use any built-in tag in the **Rich Text** property — `<wave>`, `<shake>`, `<color>`, `<size>`, and `<speed>` are all available out of the box.

## Adjusting Animation Parameters

Use cases: Fine-tuning per-character delay, start delay, and other animation timing properties.

1. Select the TexturgeActor and locate the **Animation Config** category.
2. Modify these properties:
   - **Letter Delay**: `0.05` (interval between each character, in seconds)
   - **Start Delay**: `0.2` (wait time before the animation begins)
3. Run PIE again to see how parameter changes affect animation pacing.

## Triggering Animation via Blueprint

Use cases: Driving animation playback from Blueprint or C++ logic, such as on level start or in response to events.

1. Open the **Level Blueprint**.
2. In the Event Graph, add an `Event BeginPlay` node.
3. Drag in a reference to your TexturgeActor and call `Play Text Animation`.
4. Set **Animation Name** to `"wave"`.
5. Run PIE — the animation plays automatically on level start.

```cpp
// Equivalent C++ call
ATexturgeActor* TextActor = GetTexturgeActor();
if (TextActor)
{
    TextActor->PlayAnimation(TEXT("wave"));
}
```

> NOTE
>
> The animation name passed to `PlayAnimation()` must match the tag name used in your DataAsset entries exactly (case-sensitive).

You now know the basics of creating, configuring, and triggering text animations from code.
