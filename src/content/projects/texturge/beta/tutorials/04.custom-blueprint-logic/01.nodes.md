# 蓝图节点参考

Texturge 提供了丰富的蓝图可调用方法，覆盖动画播放控制、参数覆盖和调试输出。

## UAnimatedTextBlock 控制节点

`UAnimatedTextBlock` 是 `UTextBlock` 的子类，暴露以下蓝图可调用方法：

### Play
启动动画播放。动画从 `UTextAnimationStageController` 的当前 `EStagePlaybackState` 推进。

- 无参数。
- 内部调用 `UTextAnimationStageController::Play()`。

### Pause
暂停当前播放的动画，内部状态保持。

- 无参数。
- 内部调用 `UTextAnimationStageController::Pause()`。
- 暂停后 `EStagePlaybackState` 变为 `Paused`。

### Resume
从暂停位置恢复播放。

- 无参数。
- 内部调用 `UTextAnimationStageController::Resume()`。

### Stop
停止动画并将所有字形重置为初始状态。

- 无参数。
- 内部调用 `UTextAnimationStageController::Stop()`。
- 调用后 `EStagePlaybackState` 变为 `Stopped`。

### SkipToEnd
立即跳到动画结尾，所有字符瞬间显示。

- 无参数。
- 等同于逐字打字场景中的"跳过"操作。

## SetBlueprintVariable

`UAnimatedTextBlock::SetBlueprintVariable()` 有 6 个重载，允许在运行时覆盖动画蓝图中的参数：

1. **SetBlueprintVariable (Float)** — `(FName VariableName, float Value)`
2. **SetBlueprintVariable (Int)** — `(FName VariableName, int32 Value)`
3. **SetBlueprintVariable (Bool)** — `(FName VariableName, bool Value)`
4. **SetBlueprintVariable (Vector)** — `(FName VariableName, FVector Value)`
5. **SetBlueprintVariable (Color)** — `(FName VariableName, FLinearColor Value)`
6. **SetBlueprintVariable (Vector2D)** — `(FName VariableName, FVector2D Value)`

变量名须与 `UTextAnimInstance` 蓝图中定义的变量名称匹配。

内部调用 `UTextAnimInstance::SetBlueprintVariable()`（对应 5 个重载）。

## UTextAnimationStageController 节点

`UTextAnimationStageController` 的蓝图可调用方法可直接在蓝图图表中使用：

### Initialize
初始化阶段控制器，绑定动画蓝图和目标文本。

- 通常在 `UAnimatedTextBlock` 内部自动调用。
- 也可手动调用以重新初始化。

### Play / Pause / Resume / Stop
标准播放控制，与 `UAnimatedTextBlock` 上的同名方法功能相同。

### RevealAll
跳过当前阶段的动画，立即显示所有字符。

### SetPlayDirection
设置播放方向模式。

- 参数：`EPlayMode` 枚举（`Forward`、`Reverse`、`PingPong`）

### SetLoop
设置 Default 阶段是否循环。

- 参数：`bool`

## UK2Node_PrintWithAnimation

`UK2Node_PrintWithAnimation` 是一个特殊的蓝图节点，用于以动画方式打印调试文本。

1. 在蓝图 Event Graph 中右键搜索 "Print With Animation"。
2. 将节点连接到执行流。
3. 设置 **In Text** 输入为要打印的字符串。
4. 节点执行时，文本将以动画效果显示在屏幕上。

适用于快速调试动画效果而不需要完整的 UMG Widget 设置。

## UAnimParameterOverrides 节点

`UAnimParameterOverrides` 是 `UAnimatedTextBlock` 上的实例化 `UObject`，提供 6 个参数覆盖映射：

- **FloatOverrides** (`TMap<FName, float>`)
- **IntOverrides** (`TMap<FName, int32>`)
- **BoolOverrides** (`TMap<FName, bool>`)
- **VectorOverrides** (`TMap<FName, FVector>`)
- **ColorOverrides** (`TMap<FName, FLinearColor>`)
- **Vector2DOverrides** (`TMap<FName, FVector2D>`)

这些映射可在 UMG Details 面板中直接配置，按实例覆盖蓝图 CDO 中的默认值。

## UAnimatedRichTextBlock 控制节点

`UAnimatedRichTextBlock` 暴露与 `UAnimatedTextBlock` 相同的基础控制方法：

- `Play()` — 启动所有标签段落的动画
- `Pause()` — 暂停播放
- `Resume()` — 恢复播放
- `Stop()` — 停止并重置
- `SkipToEnd()` — 跳过打字动画
