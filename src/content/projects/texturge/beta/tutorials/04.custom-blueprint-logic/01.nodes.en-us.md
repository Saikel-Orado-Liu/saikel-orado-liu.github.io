Texturge provides a range of Blueprint nodes covering animation playback, state queries, and configuration updates.

## Animation Control

### `Play Text Animation`
Plays a text animation by name.

1. **Target**: A reference to `ATexturgeActor`.
2. **Animation Name**: The name of the animation (e.g., `"wave"`, `"shake"`).
3. Returns the animation duration on success, or `0.0` on failure.

### `Stop Text Animation`
Immediately stops the current animation and resets text state.

### `Pause Text Animation` / `Resume Text Animation`
Pauses and resumes the animation. Playback progress is maintained internally and resumes from the paused position.

## Text & Configuration

### `Set Rich Text`
Dynamically replaces text content at runtime. New text is applied immediately and supports tag-based animation.

### `Set Animation Speed`
Adjusts the global animation speed multiplier, affecting all tags.

```cpp
// Equivalent C++ call
TextActor->SetRichText(TEXT("<wave>Live-updated text</wave>"));
TextActor->SetAnimationSpeed(1.5f);
```

## Query Nodes

### `Is Animation Playing`
Returns a boolean indicating whether an animation is currently playing.

### `Get Current Animation Name`
Returns the name (`FName`) of the currently playing animation.

### `Get Visible Character Count`
Returns the number of currently visible characters — useful for progress bars or UI logic.

## Batch Operations

### `Play Text Animation On All`
Plays an animation on all `ATexturgeActor` instances in the scene. Ideal for global transition effects.

1. Specify the animation via **Animation Name**.
2. Optionally skip actors that have already finished playing.
