# 事件系统

Texturge 通过 BlueprintNativeEvent 和阶段回调在动画生命周期的关键节点提供扩展点。

## BuildDefaultAnimation 事件

`BuildDefaultAnimation` 是 `UTextAnimInstance` 上的 `BlueprintNativeEvent`，在编译动画蓝图时调用。你可以重写此事件来自定义烘焙逻辑。

### 签名

```cpp
UFUNCTION(BlueprintNativeEvent, Category = "Text Animation")
FBakedAnimation BuildDefaultAnimation(int32 GlyphCount, const FString& Text);
```

### 参数

- **GlyphCount** — 文本中的实际字符数（不含标签标记）
- **Text** — 编译时的目标文本字符串

### 返回值

返回 `FBakedAnimation` 结构，包含三个阶段的 `FBakedStage` 指针（Intro、Default、Outro）。

### 重写方法

1. 在 `UTextAnimationBlueprint` 的 **Graph** 标签页中打开事件图。
2. 在 **My Blueprint** 面板中找到 **Functions** 分类。
3. 找到 `BuildDefaultAnimation` 并点击 **Override**。
4. 在事件图中，你可以：
   - 根据 `GlyphCount` 动态调整每阶段的 `FGlyphScheduleInfo`。
   - 根据 `Text` 内容选择不同的动画曲线。
   - 调用 `UGlyphAnimationFactory::Bake()` 进行自定义烘焙。
5. 返回修改后的 `FBakedAnimation`。

### 使用场景

- 根据文本长度动态调整动画速度（短文本快、长文本慢）
- 根据文本内容切换不同的动画风格（对话文本 vs 标题文本）
- 为特定字符（如标点符号）设置不同的时序延迟

## 阶段转换事件

`UTextAnimationStageController` 在阶段切换时触发内部回调，可通过 C++ 或蓝图绑定响应：

### 阶段切换流程

1. `EStagePlaybackState::Stopped` → 调用 `Play()` → `EStagePlaybackState::Playing`
2. Intro 阶段 `FBakedGlyph::Evaluate()` 逐帧评估。
3. Intro 完成后自动推进到 Default 阶段。
4. 调用 `Stop()` 或在 Default 完成后进入 Outro 阶段。
5. Outro 完成后 → `EStagePlaybackState::Complete`

### 绑定阶段事件

在 `UTextAnimationStageController` 上：

1. 获取控制器引用（通过 `UAnimatedTextBlock` 的内部控制器）。
2. 在 C++ 中重写阶段切换通知，或在蓝图中通过 Tick 轮询 `EStagePlaybackState`。
3. 根据状态执行相应逻辑：
   - 状态为 `Playing` 时更新 UI 指示器
   - 状态为 `Complete` 时推进对话到下一句

## 动画完成检测

### 通过 RebuildAnimation 脉冲

`UTextAnimInstance::NeedsRebake()` 查询当前动画是否需要重新烘焙。在文本或参数改变后返回 `true`，触发 `FAnimationCompiler::BakeAllStages()` 重新编译。

### 通过 EvaluateBaked 查询

`UTextAnimInstance::EvaluateBaked(float Time, EAnimationStage Stage)` 评估特定时间点的烘焙数据，可用于：
- 检测阶段是否已播放完成
- 在关卡蓝图中查询当前字符渲染状态

### 通过 GetAnimationByName 查找

`UTextAnimInstance::GetAnimationByName(FName Name)` 按名称查找 `UGlyphAnimation` 资产，用于运行时动态切换动画轨道。

## C++ 委托绑定示例

在 C++ 中通过 `UTextAnimationStageController` 获取阶段状态：

```cpp
UTextAnimationStageController* Controller = AnimatedTextBlock->GetStageController();
if (Controller)
{
    // Evaluates all glyphs at current time
    Controller->TickAnimation(DeltaTime);

    // Query individual glyph state at a specific time
    FGlyphAnimationState State = Controller->EvaluateGlyph(GlyphIndex, CurrentTime);

    // Publish baked data to render thread
    Controller->PublishBakedAnimation();
}
```

## 蓝图事件图绑定

在 Widget Blueprint 或 Level Blueprint 的 Event Graph 中：

1. 获取 `UAnimatedTextBlock` 引用。
2. 在 Event Graph 中使用 **Event Tick** 节点轮询动画状态。
3. 调用 `GetStageController()` 获取 `UTextAnimationStageController`。
4. 使用 `ResolveAnimationReferences()` 确保所有动画引用有效。

## 常用事件驱动场景

1. **打字音效** — 在 Tick 中检测 `FBakedGlyph::Evaluate()` 返回值中 `Visible` 通道从 0 变为 >0 时播放音效。
2. **对话推进** — 检测 `EStagePlaybackState::Complete` 后自动加载下一段对话。
3. **UI 闪烁提示** — 进入 Default 阶段后，通过 `SetLoop(true)` 并调整 Color 通道实现呼吸灯效果。
4. **跳过功能** — 绑定输入事件调用 `SkipToEnd()`，跳过当前打字动画。
