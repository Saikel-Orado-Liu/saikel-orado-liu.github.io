Texturge exposes key lifecycle points through event delegates, making it easy to respond to animation and dialog state changes in Blueprint or C++.

## Animation Events

Use cases: Responding to animation lifecycle events — started, character revealed, and finished.

### `On Animation Started`
Broadcast when an animation starts. Carries the **Animation Name** parameter.

1. Bind this event in Blueprint to play sound effects.
2. Use the animation name to branch into different initialization logic.

```cpp
// C++ binding example
TextActor->OnAnimationStarted.AddDynamic(this, &AMyActor::HandleAnimStarted);

void AMyActor::HandleAnimStarted(FName AnimName)
{
    UE_LOG(LogTemp, Log, TEXT("Animation started: %s"), *AnimName.ToString());
}
```

### `On Character Revealed`
Broadcast each time a character transitions from hidden to visible. Parameters: **Character Index** and **Character** (single-character string).

1. Use this to trigger per-character typing sound effects.
2. `Character Index` increments from 0.

### `On Animation Finished`
Broadcast when the animation fully completes — useful for chaining follow-up logic.

> NOTE
>
> `On Animation Finished` only fires for the top-level animation sequence. If using multi-stage playback (Intro → Default → Outro), bind to `OnDialogEnded` or poll `EStagePlaybackState::Complete` instead.

## Dialog Events

Use cases: Responding to dialog lifecycle events — started, option selected, and ended.

### `On Dialog Started`
Fired when a dialog begins. Parameter: `UTexturgeDialogDataAsset`.

### `On Dialog Option Selected`
Fired when the user selects a branch option. Parameter includes the selected option's struct data.

1. Use **Option Index** to determine which option was chosen.
2. Execute corresponding game logic (affection changes, quest triggers, etc.).

> TIP
>
> Use **Option Index** to branch logic in your event handler, rather than comparing option text strings. This avoids localization issues when switching languages.

### `On Dialog Ended`
Broadcast when the dialog fully ends. Ideal for restoring player control or triggering follow-up narrative.

## Delegate Binding

Use cases: Wiring up event dispatchers in the Blueprint Event Graph to handle animation and dialog callbacks.

In the Event Graph, right-click an `ATexturgeActor` reference and expand the **Event Dispatchers** category to see all available events. Drag an event onto the graph to create a binding node.
