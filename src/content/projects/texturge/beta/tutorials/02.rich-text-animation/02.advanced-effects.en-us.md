Once you're comfortable with basic tags, you can compose and parameterize them for richer effects.

## Per-Character Delay Control

Use the `delay` attribute to fine-tune per-character timing:

```
<wave delay=0.1>Slow wave</wave>
<shake delay=0.02>Fast shake</shake>
```

1. Smaller `delay` values produce tighter pacing between characters.
2. Different tags can use different `delay` values for mixed rhythms.

## Segmented Animation

Mix multiple tags in a single text block for segmented effects:

```
<shake>SHOCK!</shake> <wave>Take it easy...</wave> <color=#888888>A calm ending.</color>
```

## Custom Animation Curves

1. In the `Content Browser`, right-click and create `Texturge > Animation Curve`.
2. In the curve editor, define a **Time(0-1)** to **Offset(0-1)** mapping.
3. Example: an ease-out curve can use a bezier with a flat start, steep middle, and flat end.
4. Reference the curve in a tag:

```
<wave curve=/Game/Curves/EaseOut>Using a custom curve</wave>
```

## UMG Integration

Tag-based animation is also supported in UMG `RichTextBlock`:

1. Create a `RichTextBlock` widget.
2. Point **Text Style Set** to a Texturge data table.
3. Bind the text content to a string containing tags.
4. At runtime, the text block will automatically parse and animate.

## Performance Tips

1. Avoid spawning many TexturgeActors in a single frame.
2. For long texts, split into segments under 50 characters each.
3. Use the **Cull Distance** property to disable animation updates for distant actors.
