# 高级效果

掌握基础标签映射后，你可以通过 `UGlyphAnimation` 关键帧编辑、`FGlyphScheduleInfo` 逐字排程和多阶段编排创建更丰富的文字动画效果。

## UGlyphAnimation 深层编辑

适用场景：在 Sequencer 中对文字动画进行关键帧级别的精确编辑。

`UGlyphAnimation` 是 `MovieSceneSequence` 子类，可在 Sequencer 中打开进行精确的关键帧编辑。

1. 在 Content Browser 中双击 `UGlyphAnimation` 资产。
2. Sequencer 界面将打开，显示该动画的时间轴。
3. 通过 `GetDuration()` 获取当前时间轴总长度。
4. 通过 `GetTrackTypes()` 和 `HasTrackType()` 查询当前包含的通道类型。

### 可编辑的 21 个动画通道

`UGlyphAnimation` 提供 21 个可关键帧编辑的动画通道：

| 通道 | 说明 |
|------|------|
| Location.X / Location.Y | 字符位置偏移 |
| Scale.X / Scale.Y | 字符缩放 |
| Rotation | 字符旋转角度 |
| Color.R/G/B/A | 字符颜色（RGBA） |
| Visible | 字符可见性（0/1） |
| ShadowOffset.X / ShadowOffset.Y | 阴影偏移 |
| ShadowColor.R/G/B/A | 阴影颜色 |
| ShadowVisible | 阴影可见性 |
| LetterSpacing | 字符间距 |
| LineHeightPercentage | 行高百分比 |
| HorizontalAlignment | 水平对齐 |
| GradientPosition | 渐变位置 |
| GradientColor.R/G/B | 渐变颜色 |

> TIP
>
> 最常用的通道组合是 Location + Scale + Rotation + Color + Visible，覆盖了大部分文字动画需求。其余通道（如 ShadowOffset、GradientPosition）适用于特效场景。

## 逐字时序控制

适用场景：调整每个字符的播放延迟和时序排程，控制逐字动画节奏。

### FGlyphScheduleInfo

每个字符的播放时序通过 `FGlyphScheduleInfo` 结构控制，可在 `UGlyphAnimationLayer` 上配置。

1. 使用 `UGlyphAnimationLayer::CreateLayer()` 或 `CreateLayerFromText()` 创建新层。
2. 配置逐字延迟：
   - `SetAllGlyphDelay(float Delay)` — 为层中所有字形设置统一的播放延迟。
   - `SkipAllWhitespace(bool bSkip)` — 控制是否跳过空白字符的动画延迟。
3. 使用 10 组曲线微调 get/set 方法调整每个字符的时间偏移、数值缩放和随机抖动。

### 逐字延迟示例

```cpp
// 创建层并设置延迟
UGlyphAnimationLayer* Layer = UGlyphAnimationLayer::CreateLayer();
Layer->SetAllGlyphDelay(0.05f);  // 每个字符间隔 0.05 秒
Layer->SkipAllWhitespace(true); // 空白字符跳过动画
```

对于 10 个字符的文本，总动画时长为 `10 × 0.05 = 0.5` 秒。

> NOTE
>
> `SkipAllWhitespace(true)` 仅跳过空白字符的延迟，但不跳过它们的渲染。空白字符仍会占据版面空间，只是不参与逐字排程。

## 多阶段编排

适用场景：为动画设置 Intro → Default → Outro 三段式播放流程。

Texturge 支持将动画分为三个阶段：Intro → Default → Outro。通过 `EAnimationStage` 枚举定义：

- `EAnimationStage::Intro` — 文本首次出现时的入场动画
- `EAnimationStage::Default` — 文本完整显示后的循环或静止状态
- `EAnimationStage::Outro` — 文本退出时的出场动画

`FBakedAnimation` 结构持有三个 `FBakedStage` 指针，分别对应上述阶段。

## 多图层合成

适用场景：将多个 UGlyphAnimationLayer 烘焙合并为复合动画效果。

### UGlyphAnimationFactory

`UGlyphAnimationFactory` 负责将多个 `UGlyphAnimationLayer` 烘焙合并为最终动画。

1. 调用 `UGlyphAnimationFactory::CreateFactory()` 或 `CreateFactoryFromText(Text)` 创建工厂。
2. 使用 `AddLayer(UGlyphAnimationLayer*)` 逐个添加图层。
3. 或使用 `SetLayers(TArray)` 批量设置所有图层。
4. 调用 `Bake()` 执行烘焙，生成合并后的 `FBakedAnimation`。

每个图层独立定义其曲线和时序，合并时根据 `ETextAnimationBlendMode`（Additive、Override、Multiply、CrossFade）决定如何混合。

> NOTE
>
> 默认混合模式为 `Override`，后添加的图层会覆盖前一层相同通道的值。如需叠加效果，请使用 `Additive` 模式。

## 运行时阶段控制

适用场景：在蓝图或 C++ 中动态控制三段式播放的进度与方向。

`UTextAnimationStageController` 控制基于阶段的播放流程。

1. 调用 `Initialize()` 初始化控制器。
2. 使用 `Play()` 开始播放，默认从 Intro 阶段开始。
3. 使用 `SetPlayDirection(EPlayMode)` 控制方向：`Forward`、`Reverse`、`PingPong`。
4. 使用 `SetLoop(bool)` 决定是否循环播放。
5. 通过 `TickAnimation()` 每帧更新 `EvaluateAllGlyphs()` 评估所有字符状态。
6. 调用 `RevealAll()` 跳过动画直接显示全部文字。

### 阶段状态查询

`EStagePlaybackState` 枚举在运行时反映当前播放状态：

- `Stopped` — 未播放
- `Playing` — 播放中
- `Paused` — 已暂停
- `Complete` — 播放完成

## 性能建议

适用场景：优化长文本或多字符动画场景下的运行时性能。

1. `FBakedGlyph::Evaluate()` 每帧为每个字符评估 21 通道的 `FPerLayerCurves`。长文本 (>100 字符) 考虑按需更新而非每帧全量评估。
2. `FAnimationCompiler::BakeAllStages()` 是编辑器时操作，编译成本不影响运行时性能。
3. 预编译所有静态文本的 `FBakedAnimation`，避免运行时重复烘焙。
4. `FCharBreakIterator` 处理 CJK 字符时的断行逻辑有额外开销。纯 ASCII 文本动画性能最优。

> TIP
>
> 对于长文本（>100 字符），建议拆分为多个段落，每段使用独立的 `UAnimatedRichTextBlock` 控件，并按需更新而非全量 Tick。
