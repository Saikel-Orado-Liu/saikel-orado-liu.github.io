# 基础标签

Texturge 的富文本动画系统通过 `UTextAnimationDataAsset` 将 XML 标签映射到 `UTextAnimationBlueprint`。

设计流程：创建标签名 → 绑定 Animation Blueprint → 在 `UAnimatedRichTextBlock` 中通过标签触发动画。

## 组件概述

适用场景：了解 Texturge 富文本动画系统各组件之间的协作关系。

### UAnimatedRichTextBlock

`UAnimatedRichTextBlock` 是 `URichTextBlock` 的子类，支持通过富文本标签触发逐字动画。它使用 `UAnimatedRichTextBlockDecorator` 进行标签解析，结合 `UTextAnimationDataAsset` 完成标签到动画的查找。

### UTextAnimationDataAsset

`UTextAnimationDataAsset` 是一个 `UDataAsset`，维护标签名称到动画蓝图的映射表。其 `Entries` 是一个 `TArray<FAnimationEntry>`，每个条目包含：

- **TagName** — 标签名称，如 `"wave"`、`"shake"`。对应用户在文本中写入的 `<wave>` 标签。
- **Type** — 指向 `UTextAnimationBlueprint` 的引用。
- **6 个参数覆盖映射** — Float、Int、Bool、Vector、Color、Vector2D 的默认参数覆盖。

## 创建 DataAsset

适用场景：首次创建标签到动画蓝图的映射资产。

1. 在 Content Browser 中右键，选择 **Miscellaneous > Data Asset**。
2. 在弹出的类选择对话框中搜索并选择 `UTextAnimationDataAsset`。
3. 命名为 `DA_DialogAnimations`。
4. 双击打开 DataAsset 编辑器。

> TIP
>
> 建议按用途命名 DataAsset，例如 `DA_DialogAnimations`（对话用）、`DA_UIAnimations`（界面用），便于团队协作时快速定位。

## 配置标签映射

适用场景：在 DataAsset 中添加和配置标签到动画蓝图的映射条目。

1. 在 DataAsset 编辑器中展开 **Entries** 数组。
2. 点击 **+** 添加一个新元素。
3. 设置 **TagName** 为 `"wave"`。
4. 设置 **Type** 指向之前创建的 `TAB_Wave` 动画蓝图。
5. （可选）配置参数覆盖映射，为每个 `FAnimationEntry` 设置默认曲线参数。
6. 重复以上步骤添加更多标签，如 `"shake"` → `TAB_Shake`、`"bounce"` → `TAB_Bounce`。

## 使用 UAnimatedRichTextBlock

适用场景：在 UMG Widget 中配置富文本动画控件并编写动画标签文本。

### 在 UMG 中设置

1. 创建或打开一个 UMG Widget Blueprint。
2. 从 Palette 搜索 **Animated Rich Text Block** 并拖入画布。
3. 选中控件，在 Details 面板中找到 **Text Animation Data Asset** 属性。
4. 将其设置为刚才创建的 `DA_DialogAnimations`。
5. 在 **Text** 属性中写入包含标签的富文本。

### 富文本格式

在 `UAnimatedRichTextBlock` 的 Text 属性中使用标准 XML 标签语法：

```
<wave>Hello World!</wave>
```

当设置 `DA_DialogAnimations` 且其中包含 `TagName = "wave"` 的 `FAnimationEntry` 时，文本 "Hello World!" 将使用 `TAB_Wave` 动画蓝图进行渲染。

### 标签解析流程

1. `UAnimatedRichTextBlockDecorator` 拦截富文本解析过程。
2. `FTagParser` 解析标签生成解析树。
3. `FRenderTreeBuilder` 将解析树重构为包含动画层的渲染树。
4. `UTextAnimationDataAsset` 的 `Entries` 被查找以匹配 TagName。
5. `UTextAnimInstance` 被创建并驱动每个字符的动画。

## 组合多个标签

适用场景：在同一段文本中使用不同动画标签实现分段差异化动画效果。

在同一段文本中可以使用多个标签实现分段动画：

```
<wave>欢迎来到</wave> <shake>地下城！</shake>
```

1. 不同标签段落使用各自的动画蓝图独立播放。
2. 过渡处字符按各自的时间线推进，不互相干扰。
3. 未包裹在标签内的纯文本静态显示。

> NOTE
>
> 未使用标签包裹的纯文本不会触发任何动画，以静态方式直接渲染。如需逐字显示效果，必须将文本置于 `<tag>` 与 `</tag>` 之间。

## 注意事项

适用场景：排查标签解析失败、动画不播放等常见配置错误。

1. 标签名称区分大小写。`<wave>` 有效，`<Wave>` 不会匹配到 TagName 为 `"wave"` 的条目。
2. 标签必须正确闭合。`<wave>text` 缺少 `</wave>` 会导致解析失败。
3. `UAnimatedRichTextBlock` 依赖 `UAnimatedRichTextBlockDecorator` 进行标签拦截。确保 Widget 的 Decorator Classes 中包含该装饰器。
4. 配置 DataAsset 时，`TagName` 字符串不包含尖括号。
