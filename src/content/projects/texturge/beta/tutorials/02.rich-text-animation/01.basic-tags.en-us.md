# Basic Tags

Texturge's rich text animation system maps animation tags (`<anim id="...">`) to `UTextAnimationBlueprint` through `UTextAnimationDataAsset`.

Design flow: create the tag mapping → configure the data asset → trigger animations through tags in `UAnimatedRichTextBlock`.

## Component Overview

Applies to: understanding how the components of the rich text animation system cooperate.

### UAnimatedRichTextBlock

`UAnimatedRichTextBlock` is a `URichTextBlock` subclass that triggers per-glyph animations through rich text tags. A private `FRichTextMarshaller` handles parsing and render-tree construction, and `UTextAnimator` drives multi-entry animation playback. Style sets, decorators, data tables, and other capabilities are inherited from the engine's `URichTextBlock`.

### UTextAnimationDataAsset

`UTextAnimationDataAsset` is a `UDataAsset` maintaining the tag mapping table. `Entries` is a `TArray<FAnimationEntry>`, and each entry contains:

- **TagName** — the tag identifier, e.g. `"wave"`, `"shake"`, corresponding to `<anim id="wave">` in the text
- **Type** — an asset reference to a **text animation blueprint** (`UTextAnimationBlueprint`)
- **6 parameter override maps** — entry-level default parameter overrides for Float, Int, Bool, Vector, Color, Vector2D
- **bHideFirstFrame** — entries not yet started are transparent during sequential playback

## Creating a Data Asset

Applies to: creating the tag-to-animation-Blueprint mapping asset for the first time.

1. Right-click in the Content Browser → **Miscellaneous > Data Asset**
2. In the class picker, search for and select **Text Animation Data Asset** (`UTextAnimationDataAsset`)
3. Name it `DA_DialogAnimations`
4. Double-click to open the data asset editor

> [!TIP]
> Name data assets by purpose, e.g. `DA_DialogAnimations` (for dialog), `DA_UIAnimations` (for UI), so the team can locate them quickly.

## Configuring Tag Mappings

Applies to: adding tag-to-animation-Blueprint mapping entries in the data asset.

1. Expand the **Entries** array and click **+** to add an element
2. Set **TagName** to `"wave"`
3. Set **Type** to the `TAB_Wave` animation Blueprint created earlier
4. (Optional) Configure parameter override maps to provide default Blueprint variable values for the entry
5. Add more tags: `"shake"` → `TAB_Shake`, `"bounce"` → `TAB_Bounce`

## Using UAnimatedRichTextBlock

Applies to: configuring the rich text animation widget in UMG and writing tagged animation text.

### Setup in UMG

1. Create or open a UMG Widget Blueprint
2. Search for **Animated Rich Text Block** in the **Palette** and drag it onto the canvas
3. Set **Animation Data Asset** to `DA_DialogAnimations` in the **Details** panel
4. Write rich text containing tags in the **Text** property

### Rich Text Format

Standard XML tag syntax — **the tag name is `anim`, and the animation id is specified via the `id` attribute**:

```
<anim id="wave">Hello World!</>
```

When the data asset contains an entry with `TagName = "wave"`, the text "Hello World!" is rendered with the `TAB_Wave` animation Blueprint.

### Tag Parsing Flow

1. `FTagParser` parses the text into an `FTagNode` tree (strips tags, outputs plain text)
2. `FRenderTreeBuilder` builds the render tree using the data asset (`<anim>` matches → `AnimationLayer` nodes)
3. Each `AnimationLayer` node instantiates the corresponding entry's animation instance (driven by `UTextAnimator`)
4. Style tags (StyleLayer) are delegated to the UE5 rich text style system

## Combining Multiple Tags

Applies to: per-segment differentiated effects using different animation tags in the same text.

```
<anim id="wave">Welcome to</> <anim id="shake">the dungeon!</>
```

1. Different tag segments play independently with their own animation blueprints
2. Transition glyphs advance on their own timelines without interfering with each other
3. Plain text outside tags displays statically (`bSequentialPlayback` controls sequential vs. simultaneous multi-entry playback)

> [!NOTE]
> `<anim>` tags that do not match any entry log a warning and are processed as StyleLayer (tag preserved, no animation). Plain text not wrapped in tags does not trigger animation.

## Notes

Applies to: troubleshooting common configuration errors such as tag parse failures and animations not playing.

1. **Tag matching ignores case** — `<anim id="Wave">` matches `TagName = "wave"` (`ClassifyNode` uses `ESearchCase::IgnoreCase`)
2. Tags must be closed properly — a missing `</>` in `<anim id="wave">text` is auto-closed with a warning
3. The `id` attribute is required — `<anim>` without `id` is classified as StyleLayer (no animation)
4. When configuring the data asset, `TagName` contains no angle brackets — it is only an identifier (e.g. `"wave"`)
5. Tag names are limited to 32 characters, only `[A-Za-z0-9_-]`
