Texturge provides an XML-tag-based animation system. Embed tags in the **Rich Text** property to drive animation effects.

## Common Built-in Tags

Use cases: Quickly referencing the syntax and behavior of all standard animation tags.

### `<wave>`
Per-character wave effect — characters float up and down in sequence.

```
<wave>This text will have a wave animation</wave>
```

### `<shake>`
Per-character shake effect, ideal for emphasis or impact scenes.

```
<shake>Warning! System Error!</shake>
```

### `<color>`
Colors specified text using hex values.

```
<color=#FF4444>This text is red</color>
```

### `<size>`
Scales text size relative to the default font size.

```
<size=1.5>Larger text</size>, <size=0.7>Smaller text</size>
```

### `<speed>`
Controls animation playback speed multiplier.

```
<speed=2.0>This text animates twice as fast</speed>
```

## Combining Tags

Use cases: Nesting multiple tags to create compound animation effects on the same text.

Tags can be nested:

```
<wave><color=#44AAFF><size=1.2>Blue wavy large text</size></color></wave>
```

1. Nesting order applies from outer to inner.
2. Inner tag scope is bounded by outer tags.
3. Ensure proper tag closure to prevent parse failures.

## Notes

Use cases: Avoiding common pitfalls when writing rich text animation tags.

1. Tag names are case-sensitive — `<Wave>` is invalid.
2. Attribute values do not use quotes: `<color=#FF0000>`, not `<color="#FF0000">`.
3. Unsupported tags are silently ignored; raw text renders normally.

> NOTE
>
> Text placed outside of any tag pair will render without animation. For animated results, wrap your text in a valid animation tag.
