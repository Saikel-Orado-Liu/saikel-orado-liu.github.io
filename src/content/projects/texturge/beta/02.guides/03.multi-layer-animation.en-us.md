# Multi-Layer Animation

Multi-layer animation composition is one of Texturge Beta's core innovations. It allows combining multiple independent `UGlyphAnimation` assets into a single composite animation, with each layer evaluated independently and composited via a specified blend mode.

## Core Concepts

### Layer (UGlyphAnimationLayer)

A layer wraps one `UGlyphAnimation` asset and carries independent blend mode and schedule configuration.

```cpp
UGlyphAnimationLayer* Layer = UGlyphAnimationLayer::CreateLayer(
    Animation,      // UGlyphAnimation asset
    BlendMode,      // Blend mode
    Schedule,       // Glyph schedule array
    PlayDirection,  // Play direction
    NumberOfLoops   // Loop count
);
```

### Factory (UGlyphAnimationFactory)

The factory accepts multiple layers and performs merged baking. It also provides per-glyph micro-adjustment interfaces.

```cpp
UGlyphAnimationFactory* Factory = UGlyphAnimationFactory::CreateFactory(
    BaseLayer,  // Base layer (required)
    Schedule    // Shared schedule array
);

Factory->AddLayer(SecondLayer);
Factory->AddLayer(ThirdLayer);

FBakedStage Result = Factory->Bake();
```

## Blend Modes

Four blend modes determine how layers composite together:

### Additive

Formula: `Result = Base + Layer`

| Property | Behavior |
|----------|----------|
| Opacity | Layer.Opacity added to Base.Opacity |
| Translation | Layer.PositionOffset added to Base.PositionOffset |
| Rotation | Layer.Rotation added to Base.Rotation |
| Scale | Layer.Scale multiplied by Base.Scale (multiplicative) |
| Color | Layer.Color added to Base.Color (additive blending) |

> [!TIP]
> Additive is the most commonly used mode. Use a base layer for the primary animation, with additive layers for subtle vibrations, flickers, etc.

### Override

Formula: `Result = Layer` (valued properties override; unvalued keep Base)

If the layer has valid curve data for a channel, that channel completely replaces the base layer; otherwise the base value is kept.

### Multiply

Formula: `Result = Base * Layer`

All property values (including color) are multiplicatively blended. Suitable for darkening effects or intensity attenuation.

### CrossFade

Interpolates between Base and Layer by the specified weight:

`Result = Lerp(Base, Layer, Weight)`

Use case: Stage transition animations (e.g., Intro → Default → Outro).

## Layer Configuration

Each `UGlyphAnimationLayer` is independently configured:

| Property | Type | Description |
|----------|------|-------------|
| Animation | UGlyphAnimation* | Referenced animation asset |
| BlendMode | ETextAnimationBlendMode | Blend mode |
| Schedule | TArray\<FGlyphScheduleInfo\> | Glyph schedule array |
| PlayDirection | EStagePlayDirection | Forward / Reverse / PingPong |
| NumberOfLoops | int32 | Loop count (0 = infinite) |

## Per-Glyph Micro-Adjustment

`UGlyphAnimationFactory` provides per-glyph micro-adjustment interfaces:

| Method | Parameters | Description |
|--------|------------|-------------|
| SetGlyphOpacity | Index, Multiplier | Opacity multiplier |
| SetGlyphLetterSpacing | Index, Value | Letter spacing |
| SetGlyphRotation | Index, Multiplier | Rotation multiplier |
| SetGlyphTranslation | Index, Offset | Translation offset |
| SetGlyphScale | Index, Multiplier | Scale multiplier |
| SetGlyphShear | Index, Value | Shear value |
| SetGlyphPivot | Index, Value | Pivot point |
| SetGlyphShadowOffset | Index, Value | Shadow offset |
| SetGlyphColor | Index, Multiplier | Color multiplier |
| SetGlyphShadowColor | Index, Multiplier | Shadow color multiplier |

Micro-adjustments are applied during the factory post-processing stage (Bake step 3).

## Independent Evaluation Architecture

Beta's key design decision: **defer independent evaluation to runtime**.

```
No curve merging (Beta choice):
  Layer 0 Curves ─┐
  Layer 1 Curves ─┼─→ Runtime independent Eval → BlendMode composite → Final state
  Layer 2 Curves ─┘

Curve merging (deprecated):
  Layer 0 + 1 + 2 → Merge → Merged curve → Eval → Final state
```

### Benefits

| Independent Eval | Curve Merge |
|------------------|-------------|
| No cubic interpolation approximation errors | Approximation errors during merge |
| Runtime adjustable blend weights | Cannot adjust after merge |
| Debuggable per-layer contributions | Cannot distinguish layer contributions |
| Selectively enable/disable layers | Must re-merge |

## Glyph Schedule System

Each glyph has independent scheduling parameters via `FGlyphScheduleInfo`:

| Read-Only Fields (system-filled) | Read-Write Fields (designer-set) |
|----------------------------------|---------------------------------|
| GlyphIndex | **StartDelay** — Delay start time |
| GlyphString | **bSkipAnimation** — Skip animation |
| bIsWhitespace | **ValueScale** — Curve value scale |
| bIsPunctuation | **ValueOffset** — Curve value offset |
| bIsCJK | **bRequiresUniqueCurves** — Needs unique curves |
| bIsDecorator | **SeedJitter** — Random jitter seed |

### Batch Operations

`FGlyphScheduleBuilder` provides static batch operations:

```cpp
// Incrementally delay all glyphs by 0.1 seconds
FGlyphScheduleBuilder::SetPerGlyphDelay(Schedule, 0.1f);

// Skip animation for all whitespace characters
FGlyphScheduleBuilder::SkipWhitespace(Schedule);

// Set delay for a specific glyph
FGlyphScheduleBuilder::SetDelayAt(Schedule, 5, 0.5f);
```

## Stage Transitions

Texturge supports three stages:

```
  Intro Stage → [CrossFade] → Default Stage → [CrossFade] → Outro Stage
      ↑                              ↑                            ↑
  UGlyphAnimation              UGlyphAnimation              UGlyphAnimation
  (GlyphAnimations[0])         (GlyphAnimations[1])         (GlyphAnimations[2])
```

`FStageTransitionConfig` controls inter-stage transition parameters:

| Property | Description |
|----------|-------------|
| IntroToDefaultCrossFade | Intro→Default crossfade weight curve |
| DefaultToOutroCrossFade | Default→Outro crossfade weight curve |
| EasingFunc | Easing function type |

## Example: Composite Animation

```cpp
// Build a "typewriter + wave" composite animation
TArray<FGlyphScheduleInfo> Schedule = BuildScheduleInfos(Text);

// Base layer: opacity typewriter effect
UGlyphAnimationLayer* TypewriterLayer = UGlyphAnimationLayer::CreateLayer(
    TypewriterAnim, Additive, Schedule
);

// Additive layer: wave displacement effect
UGlyphAnimationLayer* WaveLayer = UGlyphAnimationLayer::CreateLayer(
    WaveAnim, Additive, Schedule
);

UGlyphAnimationFactory* Factory = UGlyphAnimationFactory::CreateFactory(
    TypewriterLayer, Schedule
);
Factory->AddLayer(WaveLayer);

// Micro-tweak: enlarge the first character
Factory->SetGlyphScale(0, FVector2D(1.5f, 1.5f));

FBakedStage Result = Factory->Bake();
```
