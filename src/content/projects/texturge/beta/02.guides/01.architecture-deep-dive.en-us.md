# Architecture Deep Dive

This article provides an in-depth analysis of Texturge Beta's module structure, core data flow, and key architectural decisions to help developers fully understand the plugin's internals.

## Module Architecture

Texturge is divided into two modules:

| Module | Type | Dependencies |
|--------|------|-------------|
| **Texturge** | Runtime | Core, CommonUI, CoreUObject, DeveloperSettings, Engine, InputCore, MovieScene, MovieSceneTracks, Slate, SlateCore, UMG, UniversalObjectLocator |
| **TexturgeEditor** | Editor | Texturge + Sequencer/SequencerCore + KismetCompiler + BlueprintGraph + PropertyEditor + UMGEditor + ToolMenus + AssetDefinition, etc. |

## Core Data Flow

Texturge's data flow is split into two phases: **compile-time baking** and **runtime evaluation**.

### Compile-Time Baking

```
SetText("Hello 世界") + UTextAnimationBlueprint
  │
  ├─ FAnimationCompiler::BuildScheduleInfos(Text)
  │   └─ Character classification → TArray<FGlyphScheduleInfo>
  │      ├─ Is whitespace?
  │      ├─ Is punctuation?
  │      ├─ Is CJK character?
  │      └─ Is decorator?
  │
  ├─ FAnimationCompiler::BakeAllStages(BP, Text)
  │   ├─ Path A: CDO->BuildDefaultAnimation(GlyphCount, Text)
  │   │   └─ Default impl: BuildScheduleInfos → CreateLayer → CreateFactory → AddLayer → Bake()
  │   │
  │   └─ Path B (fallback): GlyphAnimations[] → Layer → Factory → Bake()
  │
  └─ FBakedAnimation
      ├─ IntroStage (FBakedStage)
      ├─ DefaultStage (FBakedStage)
      ├─ OutroStage (FBakedStage)
      ├─ TextFingerprint (CityHash64)
      └─ BlueprintFingerprint (GeneratedClass + CompileCount + Track/Section signatures)
```

### Runtime Evaluation

```
UTextAnimationStageController::TickAnimation(DeltaTime)
  │
  └─ EvaluateAllGlyphs(OutStates)
      │
      └─ For each FBakedGlyph:
          ├─ FBakedGlyph::Evaluate(StageTime, OutState)
          │   ├─ FGlyphAnimationState::Identity()  ← Initial state
          │   └─ For each FPerLayerCurves Layer:
          │       ├─ BuildRichCurveFromKeys (all 21 channels)
          │       ├─ Eval(CurrentTime) → Channel values
          │       └─ BlendMode compose
          └─ OutState passed to Slate
              └─ SAnimatedTextBlock::OnPaint() renders per-glyph
```

## Key Data Structures

### FBakedAnimation (non-USTRUCT, C++ only)

Complete baked animation result with three-stage data and fingerprint info.

| Field | Type | Description |
|-------|------|-------------|
| SourceText | FString | Source text |
| GlyphCount | int32 | Number of glyphs |
| TextFingerprint | uint64 | Text fingerprint (CityHash64) |
| BlueprintFingerprint | uint64 | Blueprint fingerprint |
| IntroStage | TUniquePtr\<FBakedStage\> | Intro stage |
| DefaultStage | TUniquePtr\<FBakedStage\> | Default stage |
| OutroStage | TUniquePtr\<FBakedStage\> | Outro stage |

### FBakedGlyph (USTRUCT, BlueprintType)

Per-glyph runtime baked data.

| Field | Type | Description |
|-------|------|-------------|
| OriginalIndex | int32 | Index in original text |
| Character | FString | The character itself |
| StartTime | float | Animation start time |
| Duration | float | Animation duration |
| bIsStatic | bool | Whether static glyph |
| DefaultState | FGlyphAnimationState | Default render state |
| LayerCurves | TArray\<FPerLayerCurves\> | Multi-layer curve data |

### FGlyphAnimationState (USTRUCT, BlueprintType)

Runtime render state for a single glyph. Default is Identity state:

| Property | Type | Default |
|----------|------|---------|
| PositionOffset | FVector2D | (0, 0) |
| Scale | FVector2D | (1, 1) |
| Rotation | float | 0.0 |
| Shear | FVector2D | (0, 0) |
| Pivot | FVector2D | (0.5, 0.5) |
| Color | FLinearColor | White |
| Opacity | float | 1.0 |
| ShadowOffset | FVector2D | (0, 0) |
| ShadowColor | FLinearColor | Transparent |
| LetterSpacing | float | 0.0 |

## Key Architectural Decisions

### 1. 21-Channel TArray<FRichCurveKey> Storage

FRichCurve is not a USTRUCT and cannot be marked UPROPERTY. Direct key-value storage ensures BlueprintNativeEvent compatibility.

### 2. Per-Layer Independent Evaluation

Each `FPerLayerCurves` evaluates independently before compositing via BlendMode, rather than pre-merging curves. This avoids Cubic interpolation approximation errors and curve merge precision loss.

### 3. Deep-Copy Isolation

Each layer holds an independent curve copy, preventing cross-contamination and shared reference side effects.

### 4. Fingerprint Caching

| Detection Target | Method | Purpose |
|------------------|--------|---------|
| Text | CityHash64(Text) | Text change detection |
| Blueprint | CityHash64(GeneratedClass + CompileCount + Track/Section signatures) | Blueprint change detection |

### 5. 3-Frame Cooldown

`MinFramesBetweenRebakes = 3` prevents frequent re-baking during rapid parameter changes.

### 6. CompileCount Forced Invalidation

UE's reinstancing may reuse ClassPtr addresses; CompileCount ensures forced cache invalidation in this case.

## Immutable Architecture Rules

The following rules must never be violated in the Beta version:

- Never introduce `FAnimationLayerSetup` or any intermediate wrapper type
- `FBakedGlyph` must always use 21 `TArray<FRichCurveKey>`, never `FGlyphCurveSet` for storage
- `BuildDefaultAnimation` must return `FBakedStage`
- Never restore curve merging (MergeSingleCurve / MergeLayerCurves)
- Never restore Identity curve key injection (InsertGuardKeys)
- Never delete CompileCount from fingerprint
- Never delete MinFramesBetweenRebakes cooldown

## Class Relationship Diagram

```
UTextAnimationBlueprint (Asset)
  ├── TArray<FTextAnimationTrack> Tracks[ ]
  ├── TArray<UGlyphAnimation*> GlyphAnimations[ ]
  ├── FStageTransitionConfig StageTransitionConfig
  └── TMap<FName, FGuid> VariableNameToGuidMap
  │
  └── Compile → UTextAnimInstance (Generated Class)
      ├── FBakedAnimation CachedBakedAnimation
      ├── BuildDefaultAnimation() BlueprintNativeEvent
      └── EvaluateBaked(InTime) → TArray<FGlyphAnimationState>
      │
      └── Runtime Control → UTextAnimationStageController
          ├── Play / Pause / Resume / Stop
          ├── EvaluateAllGlyphs()
          └── OnStageChanged / OnAnimationComplete Delegate

UTextAnimator (Animation Pipeline)
  └── Rich text orchestration + per-frame evaluation

UAnimatedTextBlock / UAnimatedRichTextBlock (UMG Widgets)
  └── Slate render layer applies animation data per-glyph
```
