# 架构深入解析

本文深入解析 Texturge Beta 的模块结构、核心数据流与关键架构决策，帮助开发者全面理解插件内部机制。

## 模块架构

Texturge 分为两个模块：

| 模块 | 类型 | 依赖 |
|------|------|------|
| **Texturge** | Runtime | Core, CommonUI, CoreUObject, DeveloperSettings, Engine, InputCore, MovieScene, MovieSceneTracks, Slate, SlateCore, UMG, UniversalObjectLocator |
| **TexturgeEditor** | Editor | Texturge + Sequencer/SequencerCore + KismetCompiler + BlueprintGraph + PropertyEditor + UMGEditor + ToolMenus + AssetDefinition 等 |


## 核心数据流

Texturge 的数据流分为两个阶段：**编译期烘焙**和**运行时求值**。

### 编译期烘焙

```
SetText("Hello 世界") + UTextAnimationBlueprint
  │
  ├─ FAnimationCompiler::BuildScheduleInfos(Text)
  │   └─ 字符分类 → TArray<FGlyphScheduleInfo>
  │      ├─ 是否为空白字符
  │      ├─ 是否为标点符号
  │      ├─ 是否为 CJK 字符
  │      └─ 是否为装饰器
  │
  ├─ FAnimationCompiler::BakeAllStages(BP, Text)
  │   ├─ 路径 A: CDO->BuildDefaultAnimation(GlyphCount, Text)
  │   │   └─ 默认实现：BuildScheduleInfos → CreateLayer → CreateFactory → AddLayer → Bake()
  │   │
  │   └─ 路径 B（回退）: GlyphAnimations[] → Layer → Factory → Bake()
  │
  └─ FBakedAnimation
      ├─ IntroStage (FBakedStage)
      ├─ DefaultStage (FBakedStage)
      ├─ OutroStage (FBakedStage)
      ├─ TextFingerprint (CityHash64)
      └─ BlueprintFingerprint (GeneratedClass + CompileCount + Track/Section签名)
```

### 运行时求值

```
UTextAnimationStageController::TickAnimation(DeltaTime)
  │
  └─ EvaluateAllGlyphs(OutStates)
      │
      └─ For each FBakedGlyph:
          ├─ FBakedGlyph::Evaluate(StageTime, OutState)
          │   ├─ FGlyphAnimationState::Identity()  ← 初始状态
          │   └─ For each FPerLayerCurves Layer:
          │       ├─ BuildRichCurveFromKeys (所有21通道)
          │       ├─ Eval(CurrentTime) → 通道值
          │       └─ BlendMode 合成
          └─ OutState 传递给 Slate
              └─ SAnimatedTextBlock::OnPaint() 逐字形渲染
```

## 关键数据结构

### FBakedAnimation（非 USTRUCT，C++ only）

完整烘焙动画结果，包含三阶段数据和指纹信息。

| 字段 | 类型 | 说明 |
|------|------|------|
| SourceText | FString | 源文本 |
| GlyphCount | int32 | 字形数量 |
| TextFingerprint | uint64 | 文本指纹（CityHash64） |
| BlueprintFingerprint | uint64 | 蓝图指纹 |
| IntroStage | TUniquePtr\<FBakedStage\> | 入场阶段 |
| DefaultStage | TUniquePtr\<FBakedStage\> | 默认阶段 |
| OutroStage | TUniquePtr\<FBakedStage\> | 退场阶段 |

### FBakedGlyph（USTRUCT, BlueprintType）

单个字形的运行时烘焙数据。

| 字段 | 类型 | 说明 |
|------|------|------|
| OriginalIndex | int32 | 在原始文本中的索引 |
| Character | FString | 字符本身 |
| StartTime | float | 动画开始时间 |
| Duration | float | 动画持续时间 |
| bIsStatic | bool | 是否为静态字形 |
| DefaultState | FGlyphAnimationState | 默认渲染状态 |
| LayerCurves | TArray\<FPerLayerCurves\> | 多层曲线数据 |

### FPerLayerCurves（USTRUCT, BlueprintType）

单层 21 通道独立曲线存储。每个通道存储为 `TArray<FRichCurveKey>`：

| 分类 | 通道 |
|------|------|
| Float 属性 | Opacity, LetterSpacing, Rotation |
| Vector2D 属性 | TranslationX/Y, ScaleX/Y, ShearX/Y, PivotX/Y, ShadowOffsetX/Y |
| Color 属性 | ColorR/G/B/A, ShadowColorR/G/B/A |
| 层配置 | BlendMode, PlayDirection, NumberOfLoops, LayerDuration |

### FGlyphAnimationState（USTRUCT, BlueprintType）

运行时单个字形的渲染状态。默认值为 Identity 状态：

| 属性 | 类型 | 默认值 |
|------|------|--------|
| PositionOffset | FVector2D | (0, 0) |
| Scale | FVector2D | (1, 1) |
| Rotation | float | 0.0 |
| Shear | FVector2D | (0, 0) |
| Pivot | FVector2D | (0.5, 0.5) |
| Color | FLinearColor | White |
| Opacity | float | 1.0 |
| ShadowOffset | FVector2D | (0, 0) |
| ShadowColor | FLinearColor | Transparent |
| LetterSpacing | float | 0.0 |

## 核心架构决策

### 1. 21 通道 TArray<FRichCurveKey> 存储

FRichCurve 不是 USTRUCT，不能标记 UPROPERTY。因此采用直接存储键值的方案，确保 BlueprintNativeEvent 兼容性。

### 2. 逐层独立求值

每个 `FPerLayerCurves` 独立求值后通过 BlendMode 合成，而非预先合并曲线。这样做避免了 Cubic 插值逼近误差和曲线合并的精度损失。

### 3. 深度拷贝隔离

各层持有独立的曲线副本，防止交叉污染和共享引用导致的副作用。

### 4. 指纹缓存系统

| 检测对象 | 方法 | 用途 |
|----------|------|------|
| 文本 | CityHash64(Text) | 文本变化检测 |
| 蓝图 | CityHash64(GeneratedClass + CompileCount + Track/Section signatures) | 蓝图变化检测 |

### 5. 3 帧冷却

`MinFramesBetweenRebakes = 3` 防止参数快速变化时频繁重新烘焙。

### 6. CompileCount 强制失效

UE 引擎重实例化（Reinstancing）可能复用 ClassPtr 地址，CompileCount 确保此时缓存强制失效。

## 不可变架构规则

以下规则在 Beta 版本中绝对不可违反：

- 绝不引入 `FAnimationLayerSetup` 或任何中间包装类型
- `FBakedGlyph` 始终使用 21 `TArray<FRichCurveKey>`，不允许使用 `FGlyphCurveSet` 存储
- `BuildDefaultAnimation` 必须返回 `FBakedStage`
- 绝不恢复曲线合并（MergeSingleCurve / MergeLayerCurves）
- 绝不恢复 Identity 曲线键注入（InsertGuardKeys）
- 绝不删除 CompileCount 指纹组件
- 绝不删除 MinFramesBetweenRebakes 冷却

## 类关系图

```
UTextAnimationBlueprint (资产)
  ├── TArray<FTextAnimationTrack> Tracks[ ]
  ├── TArray<UGlyphAnimation*> GlyphAnimations[ ]
  ├── FStageTransitionConfig StageTransitionConfig
  └── TMap<FName, FGuid> VariableNameToGuidMap
  │
  └── 编译 → UTextAnimInstance (生成类)
      ├── FBakedAnimation CachedBakedAnimation
      ├── BuildDefaultAnimation() BlueprintNativeEvent
      └── EvaluateBaked(InTime) → TArray<FGlyphAnimationState>
      │
      └── 运行时控制 → UTextAnimationStageController
          ├── Play / Pause / Resume / Stop
          ├── EvaluateAllGlyphs()
          └── OnStageChanged / OnAnimationComplete 委托

UTextAnimator（动画管线）
  └── 多格式文本编排 + 逐帧求值

UAnimatedTextBlock / UAnimatedRichTextBlock（UMG 控件）
  └── Slate 渲染层逐字形应用动画数据
```
