# Localization Guide

Texturge's localization subsystem (`ULocalizationSubsystem`) solves the problem of per-character animation position misalignment in multilingual projects due to varying character counts across translations.

## Problem Scenario

When text is translated, the same sentence may have different character counts across languages:

| Language | Text | Char Count |
|----------|------|------------|
| Chinese | "你好世界" | 4 |
| English | "Hello World" | 11 |
| Japanese | "こんにちは世界" | 7 |

Simple index-based mapping leads to completely mismatched animation effects. Texturge uses a **semantic anchor** system to solve this.

## Semantic Anchors

### FSemanticAnchor Structure

```cpp
USTRUCT(BlueprintType)
struct FSemanticAnchor
{
    FName AnchorId;            // Unique identifier
    FString ContextualSnippet; // Context snippet (for matching)
    int32 SourceOffset;        // Offset in source text
};
```

### Defining Anchors

Mark key semantic positions in source text:

```cpp
TMap<FName, FSemanticAnchor> Anchors;

Anchors.Add("greeting_start", {"greeting_start", "Hello", 0});
Anchors.Add("greeting_end",   {"greeting_end",   "World", 6});
```

## Localization Subsystem

### ULocalizationSubsystem

`GameInstanceSubsystem` manages anchor relocation and language switching:

```cpp
// Get the subsystem
ULocalizationSubsystem* LocSubsystem = GetGameInstance()
    ->GetSubsystem<ULocalizationSubsystem>();

// Switch language
LocSubsystem->SetLanguage("en");
```

### Anchor Relocation

```cpp
TMap<FName, int32> RelocatedOffsets = ULocalizationSubsystem::RelocateAnchors(
    Anchors,        // Source language anchors
    SourceText,     // Source language text
    TargetText      // Target language text
);

// RelocatedOffsets contains the new position for each anchor in the target text
```

### Matching Strategies

1. **Exact Match**: Search for the anchor's context snippet literal in target text
2. **LCS Match** (Longest Common Substring): When exact match fails, use LCS algorithm to find the best match position
3. **Confidence Calculation**: Confidence based on match length and positional consistency

## Workflow

```
1. Editor Time:
   Designer defines semantic anchors
   ↓
2. Compile/Package:
   Extract all source language anchor data
   ↓
3. Runtime Language Switch:
   ULocalizationSubsystem::OnLanguageChanged fires
   ↓
4. Relocation:
   RelocateAnchors() computes target text offsets
   ↓
5. Apply:
   Update position mappings for all text animations
```

## Widget Integration

`UAnimatedTextBlock` and `UAnimatedRichTextBlock` automatically listen for language change events:

> [!NOTE]
> The localization subsystem broadcasts language change events via the `OnLanguageChanged` delegate, and all animated text widgets respond automatically.

## StringTable Integration

Texturge supports integration with UE's StringTable system:

1. Define multilingual text in StringTables
2. Reference StringTable keys in text animation blueprints
3. When switching languages at runtime, automatically update text and relocate anchors

## Cache Management

```cpp
// Clear relocation cache (typically called automatically on language switch)
LocSubsystem->ClearCache();
```

The system maintains a cached mapping of anchors → target offsets, avoiding redundant computation when the language doesn't change.

## Best Practices

| Recommendation | Reason |
|----------------|--------|
| Choose semantically meaningful anchors | Avoid placing anchors on function words (the, is, of) |
| Use sufficiently long context snippets | LCS matching needs enough length for accuracy |
| Keep anchor IDs consistent across languages | Ensures correct cross-language mapping |
| Set additional text direction for RTL | Arabic, etc. need right-to-left rendering |
| Add anchor metadata to translation database | Helps translators understand anchor semantic intent |

## Limitations

| Limitation | Description |
|------------|-------------|
| One-to-many mapping | One source anchor may split into multiple parts in target |
| Semantic shift | Semantic unit position may shift significantly after translation |
| Merge/split | Translation may cause character merging or splitting |
