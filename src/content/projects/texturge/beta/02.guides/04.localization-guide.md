# 本地化指南

Texturge 的本地化子系统（`ULocalizationSubsystem`）解决了多语言项目中逐字动画因字符数变化导致动画位置错位的问题。

## 问题场景

当文本被翻译后，同一句话在不同语言中的字符数可能不同：

| 语言 | 文本 | 字符数 |
|------|------|--------|
| 中文 | "你好世界" | 4 |
| 英文 | "Hello World" | 11 |
| 日语 | "こんにちは世界" | 7 |

简单的按索引映射会导致动画效果完全不匹配。Texturge 使用**语义锚点**系统解决此问题。

## 语义锚点

### FSemanticAnchor 结构

```cpp
USTRUCT(BlueprintType)
struct FSemanticAnchor
{
    FName AnchorId;           // 唯一标识符
    FString ContextualSnippet; // 上下文片段（用于匹配）
    int32 SourceOffset;        // 源文本中的偏移位置
};
```

### 定义锚点

在源文本中标记关键语义位置：

```cpp
TMap<FName, FSemanticAnchor> Anchors;

Anchors.Add("greeting_start", {"greeting_start", "Hello", 0});
Anchors.Add("greeting_end",   {"greeting_end",   "World", 6});
```

## 定位子系统

### ULocalizationSubsystem

`GameInstanceSubsystem` 管理锚点重定位和语言切换：

```cpp
// 获取子系统
ULocalizationSubsystem* LocSubsystem = GetGameInstance()
    ->GetSubsystem<ULocalizationSubsystem>();

// 切换语言
LocSubsystem->SetLanguage("en");
```

### 锚点重定位

```cpp
TMap<FName, int32> RelocatedOffsets = ULocalizationSubsystem::RelocateAnchors(
    Anchors,        // 源语言锚点
    SourceText,     // 源语言文本
    TargetText      // 目标语言文本
);

// RelocatedOffsets 包含每个锚点在目标文本中的新位置
```

### 匹配策略

1. **精确匹配**：在目标文本中查找锚点的上下文片段字面值
2. **LCS 匹配**（最长公共子串）：当精确匹配失败时，使用 LCS 算法寻找最佳匹配位置
3. **置信度计算**：基于匹配长度和位置一致性计算置信度

## 工作流程

```
1. 编辑器时期：
   设计者定义语义锚点
   ↓
2. 编译/打包时：
   提取所有源语言锚点数据
   ↓
3. 运行时语言切换：
   ULocalizationSubsystem::OnLanguageChanged 触发
   ↓
4. 重定位：
   RelocateAnchors() 计算目标文本偏移
   ↓
5. 应用：
   更新所有文本动画的位置映射
```

## Widget 集成

`UAnimatedTextBlock` 和 `UAnimatedRichTextBlock` 自动监听语言切换事件：

> [!NOTE]
> 本地化子系统通过 `OnLanguageChanged` 委托广播语言切换事件，所有动画文本控件自动响应。

## StringTable 集成

Texturge 支持与 UE 的 StringTable 系统集成：

1. 在 StringTable 中定义多语言文本
2. 在文本动画蓝图中引用 StringTable 键
3. 运行时切换语言时，自动更新文本并重新定位锚点

## 缓存管理

```cpp
// 清除重定位缓存（通常在切换语言时自动调用）
LocSubsystem->ClearCache();
```

系统维护一个锚点→目标偏移的缓存映射，语言不变时避免重复计算。

## 最佳实践

| 建议 | 原因 |
|------|------|
| 选择有语义意义的锚点 | 避免在函数词（的、了、是）上设置锚点 |
| 使用足够长的上下文片段 | LCS 匹配需要足够长度确保准确性 |
| 在不同语言间保持锚点 ID 一致 | 确保跨语言映射的正确性 |
| 为 RTL 语言额外设置文本方向 | 阿拉伯语等需要从右到左渲染 |
| 在翻译数据库中添加锚点元数据 | 方便翻译人员理解锚点的语义意图 |

## 限制

| 限制 | 说明 |
|------|------|
| 一对多映射 | 源文本的一个锚点可能在目标文本中被拆分为多个部分 |
| 语义偏移 | 翻译后语义单元的位置可能大幅偏移 |
| 合并/拆分 | 翻译可能导致字符合并或拆分 |
