# 多层动画合成

多层动画合成是 Texturge Beta 的核心创新之一。它允许将多个独立的 `UGlyphAnimation` 资产组合成一个复合动画，每层独立求值后通过指定的混合模式合成最终效果。

## 核心概念

### 图层 (UGlyphAnimationLayer)

一个图层包装一个 `UGlyphAnimation` 资产，并携带独立的混合模式和调度配置。

```cpp
UGlyphAnimationLayer* Layer = UGlyphAnimationLayer::CreateLayer(
    Animation,      // UGlyphAnimation 资产
    BlendMode,      // 混合模式
    Schedule,       // 字形调度数组
    PlayDirection,  // 播放方向
    NumberOfLoops   // 循环次数
);
```

### 工厂 (UGlyphAnimationFactory)

工厂接受多个图层并执行合并烘焙。它同时提供字形级的微调接口。

```cpp
UGlyphAnimationFactory* Factory = UGlyphAnimationFactory::CreateFactory(
    BaseLayer,  // 基础图层（必选）
    Schedule    // 共享调度数组
);

Factory->AddLayer(SecondLayer);
Factory->AddLayer(ThirdLayer);

FBakedStage Result = Factory->Bake();
```

## 混合模式

四种混合模式决定了图层之间如何合成：

### Additive（叠加）

公式：`Result = Base + Layer`

| 属性 | 行为 |
|------|------|
| 不透明度 | Layer.Opacity 加到 Base.Opacity 上 |
| 位移 | Layer.PositionOffset 加到 Base.PositionOffset 上 |
| 旋转 | Layer.Rotation 加到 Base.Rotation 上 |
| 缩放 | Layer.Scale 乘以 Base.Scale（乘法叠加） |
| 颜色 | Layer.Color 加到 Base.Color 上（加法混合） |

> [!TIP]
> Additive 是最常用模式。用基础层定义主要动画，叠加层添加细微振动、闪烁等效果。

### Override（覆盖）

公式：`Result = Layer`（有值属性覆盖，无值属性保持 Base）

如果图层在某通道有有效曲线数据，该通道完全替代基础层；否则基础层值保持不变。

### Multiply（正片叠底）

公式：`Result = Base * Layer`

所有属性值（包括颜色）进行乘法混合。适合用于暗化效果或强度衰减。

### CrossFade（交叉渐变）

根据指定的权重值在 Base 和 Layer 之间插值：

`Result = Lerp(Base, Layer, Weight)`

适用场景：阶段转换动画（如 Intro → Default → Outro）。

## 图层配置

每个 `UGlyphAnimationLayer` 独立配置：

| 属性 | 类型 | 说明 |
|------|------|------|
| Animation | UGlyphAnimation* | 引用的动画资产 |
| BlendMode | ETextAnimationBlendMode | 混合模式 |
| Schedule | TArray\<FGlyphScheduleInfo\> | 字形调度数组 |
| PlayDirection | EStagePlayDirection | Forward / Reverse / PingPong |
| NumberOfLoops | int32 | 循环次数（0=无限） |

## 字形级微调

`UGlyphAnimationFactory` 提供针对单个字形的微调接口：

| 方法 | 参数 | 说明 |
|------|------|------|
| SetGlyphOpacity | Index, Multiplier | 不透明度倍率 |
| SetGlyphLetterSpacing | Index, Value | 字间距 |
| SetGlyphRotation | Index, Multiplier | 旋转倍率 |
| SetGlyphTranslation | Index, Offset | 位移偏移量 |
| SetGlyphScale | Index, Multiplier | 缩放倍率 |
| SetGlyphShear | Index, Value | 切变值 |
| SetGlyphPivot | Index, Value | 轴心点 |
| SetGlyphShadowOffset | Index, Value | 阴影偏移 |
| SetGlyphColor | Index, Multiplier | 颜色倍率 |
| SetGlyphShadowColor | Index, Multiplier | 阴影颜色倍率 |

微调在 Factory 后处理阶段（Bake 的第三步）应用。

## 独立求值架构

Beta 的关键设计决策：**将独立求值推迟到运行时**。

```
不合并曲线（Beta 选择）:
  Layer 0 Curves ─┐
  Layer 1 Curves ─┼─→ 运行时独立 Eval → BlendMode 合成 → 最终状态
  Layer 2 Curves ─┘

合并曲线（已废弃）:
  Layer 0 + 1 + 2 → Merge → 合并曲线 → Eval → 最终状态
```

### 优势

| 独立求值 | 曲线合并 |
|----------|----------|
| 无 Cubic 插值逼近误差 | 合并时引入逼近误差 |
| 支持运行时动态调整混合权重 | 混合后不可调整 |
| 调试时可见每层独立贡献 | 无法区分各层贡献 |
| 可选择性禁用/启用单层 | 需重新合并 |

## 字形调度系统

每个字形通过 `FGlyphScheduleInfo` 拥有独立的调度参数：

| 只读字段（系统填充） | 读写字段（设计者设置） |
|---------------------|----------------------|
| GlyphIndex | **StartDelay** — 延迟开始时间 |
| GlyphString | **bSkipAnimation** — 跳过动画 |
| bIsWhitespace | **ValueScale** — 曲线值缩放 |
| bIsPunctuation | **ValueOffset** — 曲线值偏移 |
| bIsCJK | **bRequiresUniqueCurves** — 需要独立曲线 |
| bIsDecorator | **SeedJitter** — 随机抖动种子 |

### 批量操作

`FGlyphScheduleBuilder` 提供静态批量操作：

```cpp
// 所有字形延迟递增 0.1 秒
FGlyphScheduleBuilder::SetPerGlyphDelay(Schedule, 0.1f);

// 跳过所有空白字符的动画
FGlyphScheduleBuilder::SkipWhitespace(Schedule);

// 为指定字形设置延迟
FGlyphScheduleBuilder::SetDelayAt(Schedule, 5, 0.5f);
```

## 阶段转换

纹理动画支持三个阶段：

```
  Intro Stage → [CrossFade] → Default Stage → [CrossFade] → Outro Stage
      ↑                              ↑                            ↑
  UGlyphAnimation              UGlyphAnimation              UGlyphAnimation
  (GlyphAnimations[0])         (GlyphAnimations[1])         (GlyphAnimations[2])
```

`FStageTransitionConfig` 控制阶段间的转换参数：

| 属性 | 说明 |
|------|------|
| IntroToDefaultCrossFade | Intro→Default 渐变权重曲线 |
| DefaultToOutroCrossFade | Default→Outro 渐变权重曲线 |
| EasingFunc | 缓动函数类型 |

## 示例：复合动画

```cpp
// 构建"打字机+波浪"的复合动画
TArray<FGlyphScheduleInfo> Schedule = BuildScheduleInfos(Text);

// 基础层：不透明度打字机效果
UGlyphAnimationLayer* TypewriterLayer = UGlyphAnimationLayer::CreateLayer(
    TypewriterAnim, Additive, Schedule
);

// 叠加层：波浪位移效果
UGlyphAnimationLayer* WaveLayer = UGlyphAnimationLayer::CreateLayer(
    WaveAnim, Additive, Schedule
);

UGlyphAnimationFactory* Factory = UGlyphAnimationFactory::CreateFactory(
    TypewriterLayer, Schedule
);
Factory->AddLayer(WaveLayer);

// 微调：让第一个字放大
Factory->SetGlyphScale(0, FVector2D(1.5f, 1.5f));

FBakedStage Result = Factory->Bake();
```
