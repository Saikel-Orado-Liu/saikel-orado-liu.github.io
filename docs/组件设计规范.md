# 组件设计规范

> 配套总纲：`docs/网页设计规范.md`（V4.0）｜交互面：`动效设计规范.md`
> 组织方式：按「视觉组件」分节，每节 = 结构 + 规格表 + 状态机 + 明暗对照 + 实现文件。
> **最终值以代码为准**（ui-spec.css 为最终覆盖层）；本文件与代码冲突时先修代码再改文档。

## 1. 导航栏 `.navbar`

### 1.1 结构

```
header.navbar.plate
└── .navbar-inner（z:3）
    ├── .navbar-main > a.navbar-brand（logo 32px + .navbar-title）
    ├── nav.navbar-nav > ul（凹槽） > li > a > span
    └── .navbar-widget > [button.theme-toggle, .lang-switcher]
```

### 1.2 规格

| 属性 | 值 |
| --- | --- |
| 容器 | `max-width: 1280px; width: calc(100% - 48px); margin: 0 auto; border-radius: md; min-height: 4rem; position: relative`（跟随滚动） |
| 板材质 | 板·暗/亮（`plate` 类复用） |
| 凹槽 ul | `flex; gap: 2px; padding: 3px; border-radius: full` |
| 链接 a | `padding: 0.4rem 0.875rem; font-size: base(16px); font-weight: bold; color: on-surface-variant; transform: translate(2px,2px)` |
| 标题 | `font-size: xl(20px)`（Pad 隐藏）；logo 32px |

### 1.3 状态机（文字）

| 类 | 位置 | 时长/曲线 |
| --- | --- | --- |
| 默认 | `translate(2px,2px)`（沉入凹槽） | 0.2s `--ease-spring` |
| `.nav-lift` | `translate(1px,-1px)` | 0.2s ⛓0.35s spring |
| `.nav-hover-lift` | `translate(2px,-3px)` | 0.2s ⛓0.15s spring |
| `.nav-pressed` | `translate(2px,2px)` | 0.08s ease |
| `.active` | 文字白（`--on-accent` 语义），`z:20`；自身有强调板（滑块接管时禁用静态背景） | — |
| `.nav-dim` | 滑块离开后恢复暗色 | — |

移动端（≤640px）：滑块隐藏，`.active` 静态强调板承担选中态；菜单纵向全宽。

### 1.4 滑块（JS 创建，`nav-slider.ts`）

| 属性 | 值 |
| --- | --- |
| 几何 | `top: 3px; height: calc(100% - 6px); border-radius: full; z:2`（文字 z:3） |
| 材质 | 强调板·暗/亮 |
| 定位基准 | `<li>` rect（不受 `<a>` transform 影响） |
| 位移 | 默认 Y:-2px / hover -5px / 按下 0 |

### 1.5 主题切换 `.theme-toggle` / 语言切换 `.lang-trigger`

| 属性 | 值 |
| --- | --- |
| 尺寸 | 36×36px，`border-radius: md`（12px） |
| 材质 | 强调板·暗/亮 |
| 交互 | hover `translate(-2px,-2px)` 0.2s spring / active `translateY(0)` 0.06s |
| 语言下拉 | 板·暗/亮外层 + 凹槽 ul + 垂直滑块（同 lang-slider），展开 0.2/0.25s 零过冲 |

## 3. Card `.card`（板级规范面）

| 属性 | 值 |
| --- | --- |
| 几何 | `padding: space-xl(32px); border-radius: md; position: relative; isolation: isolate; overflow: hidden`（有丝带 → visible） |
| 内容保护 | `.card > * { z:3 }` |
| 布置 | Tailwind：`flex flex-col gap-0` + `.card-body`（`flex:1; padding: space-sm 0 space-md`）/ `.card-body-featured`（`space-md 0 space-sm`） |

### 3.1 内嵌图标 `.card-icon-embed`

```css
text-shadow: -2px -2px 0 rgba(0,0,0,.33), 1.5px 1.5px 0 rgba(255,255,255,.06);
transform: translate(-1px,-1px);
/* 亮色：暗影 = color-mix(primary, #000 22%)，高光纯白 */
```

### 3.2 折叠丝带 `.card-ribbon`

| 参数 | 值 |
| --- | --- |
| 几何 | `--f:10px; --c:-4.5px; --d:5.5px; --r:14px; --y:8px`；`inset: auto calc(-1*--f) --y auto`；clip-path 折角 |
| 材质 | `background: --md-sys-color-primary` + 折痕 `inset 0 -d 0 rgba(0,0,0,.3)`；文字白（亮色 `--on-accent`） |
| 阴影层 | `.card-ribbon-shadow`（z:5，暗 rgba(0,0,0,.42)/亮 .18，blur 1.5px） |
| hover | `padding-left` +18px；文字 `translateX(-18px)`；⏱0.2s |
| active | `padding-left` +36px + `rotate(-4deg)`；⏱0.15s |

### 3.3 卡片内标签 `.card .tag`（下凹式）

| 属性 | 暗色 | 亮色 |
| --- | --- | --- |
| 基底 | `bg 50% + base`（≈#1c1c1c） | `bg + accent 33%` |
| 边框 | top/left `text10%` / right/bottom `text15%` | top/left `bg+acc20%` / right/bottom 纯白 1 |
| 阴影 | `2px 4px 3px 0 text20%` + `inset 2px 3px 0 0 rgba(0,0,0,.45)` + `inset -1px -2px 6px text10%` | 同左（亮色版色值） |
| 文字 | `translate(1px,2px)`；hover 凸起（转 `.tag` 强调容器）+ active 按回 |

## 4. 按钮 `.btn`

| 属性 | 值 |
| --- | --- |
| 形状 | `border-radius: full; inline-flex; gap: 4px; overflow: hidden; isolation: isolate` |
| Padding | `0.7rem 1.4rem 0.55rem 1.6rem`（右下厚度补偿 0.15rem≈2.4px） |
| 字号 | `16px/500/1.4`；内容 `<span>` z:3 |

### 4.1 `.btn-primary`（强调板）

| 状态 | transform | L2 柔影 | 高光 |
| --- | --- | --- | --- |
| 默认 | — | `6px 10px 2px 0 rgba(0,0,0,.30)`（亮 .12） | 0.5 |
| hover | `translate(-4px,-4px)` 0.2s spring | `8px 12px 8px 0 rgba(0,0,0,.40)`（亮 .18） | 1 |
| active | `translate(2px,2px)` 0.06s | `3px 6px 2px 0 rgba(0,0,0,.80)`（亮 .33） | 0.4 |
| 松手 | `transition:none` 瞬回 | — | — |

### 4.2 `.btn-outline`（板·暗/亮）

- 暗：基底 `--clr-primary-bg`，文字 `--clr-primary-text`，L1 `2px 4px 0 0 text20%`
- 亮：基底 `bg97+acc3`，文字 `--md-sys-color-primary`（= `--link-color`），L1 `bg94+acc6`
- 噪声颗粒更细：60px tile / contrast5 / opacity 0.5
- 高光比 primary 克制：默认 0.15 → hover 0.5 → active 0.05

## 7. 文章排版 `.article-content`（720px 窄列）

### 7.1 标题

| 级别 | 字号 | 字重 | margin | 颜色 |
| --- | --- | --- | --- | --- |
| h1 | 5xl 48px | 700 | `24px 0 24px` | on-background |
| h2 | 3xl 32px | 700 | `32px 0 16px` | on-surface |
| h3 | 2xl 24px | **600**（V4.0 修复） | `24px 0 16px` | on-surface |
| h4–h6 | lg/base/sm | 700 | `16px 0 8px`（V4.0 补齐） | on-surface |

全部 `scroll-margin-top: calc(var(--header-height) + var(--space-lg))`。

### 7.2 列表

| 类型 | 规则 |
| --- | --- |
| 顶层 `ul` | disc；`padding-left: 32px`；li margin-bottom 8px；行高 1.75 |
| 顶层 `ol` | 步骤圆圈：`counter`；32px 圆形（强调板材质）；竖线 ::before 2px outline-variant，top 20px；`li padding-left: 64px` |
| 内嵌 `ol ol/ul ol` | 默认 decimal；`::marker` 加粗；清除圆圈伪元素 |

### 7.3 表格（板级）

| 属性 | 值 |
| --- | --- |
| 外层 | `width:100%; radius: md; overflow: hidden; font-size: sm`；板·暗/亮材质 |
| th | center / bold / `padding-top: 10px` / `border-bottom: 2px`；**强调板**背景（含噪点 70px）；文字 `--on-accent` |
| td | `padding: 8px 16px; border-bottom 1px outline-variant; font-weight: 500`；末行无边 |
| 行内 code | 同 markdown-alert code；`font-size: 1em; top: 0; left: 1px` |

### 7.4 行内代码 / 代码块

- 行内 `code`：小型控件材质（70px 噪点 overlay .5 + `160deg text8→45%`）；`color: --md-sys-color-primary`；基线 `top:-2px; left:-1px`
- `pre code`：重置 static
- `.shiki/.astro-code`：纸面样式（暗：`base-bg` + 155deg 微光 + 100px 噪点 .18 + 三层悬浮影 0.02~0.2；亮：白纸渐变 + tint 噪点）——由 shiki 双主题变量驱动 `--shiki-light*`

### 7.5 图片与 Lightbox

| 项 | 规则 |
| --- | --- |
| 图片 | `display:block; margin: 0 auto; radius: md; box-shadow: 0 2px 8px / 0 8px 24px / 0 16px 48px`（亮色 α 0.05/0.04/0.02） |
| 独图段落 | `p:has(> img:only-child)` 加 base 底 + 纸噪点 ::after |
| Lightbox | 单击 `img`；覆盖层 85% 黑；Escape/点击关闭；`cursor: zoom-in`；**待办**：补 `role="dialog"` + aria-modal（见 §10 已知项） |

### 7.6 Alert

| 类型 | 竖条色 | 图标 | 布局 |
| --- | --- | --- | --- |
| NOTE | #2196F3 | bxs-info-circle | `padding: 16px 24px; radius: md`；板材质；标题 bold + heading-shadow；末子元素 margin 0 |

## 9. 文档系统组件

### 9.1 三栏布局 `.doc-layout`

| 断点 | 列 |
| --- | --- |
| ≥1200 | `minmax(0,250px) 1fr minmax(0,250px)` gap 24px；max-width 1280px |
| 860–1199 | 左 + 主（右隐藏） |
| <860 | 主（两侧隐藏） |

侧边栏 `sticky top:24px`；inner.card `max-height: calc(100vh - header - 48px)`；`.doc-main { min-width: 0 }`。

### 9.2 文档树 `.doc-tree`

- 链接：`padding: 8px; radius: 18px; font-size: sm; border-left: 2px`；默认透明噪点
- hover/active：转**强调板**（`bg accent87+13` + 三层）+ `translate(-5px,-5px)`；active 按压 `translate(1px,2px)`
- 章节容器：凹槽材质（radius: `--shape-lg`）

### 9.3 前后篇导航 `.doc-pager-card`

- 双列 grid（mobile 单列）；板·暗/亮（几何已 V4.0 归位）
- 箭头 24px + feDropShadow 内嵌；亮色对齐 card-icon-embed
- 标签：`xs / 400 / on-surface-variant`；标题：`base / 600 / on-surface`
- 空态：`已是最先/已是最后` 占位卡（pointer-events:none）

### 9.4 TOC（`.doc-toc-group` 凹槽 + 垂直滑块）

- 组容器：凹槽·暗/亮（radius: `--shape-lg`; padding: 8px）
- H2 链接：强调板材质（tag-accent 同款）≥ 全静态（仅 ::after 高光 0.5→0.75 hover）
- H3：`padding-left: 24px; font-size: sm; weight: 500`；激活时仅 color 过渡
- 滑块：`.doc-toc-slider`（`top/height` 动画 0.4/0.3s）+ highlight 0.5→1

## 11. 使用规范（writer-facing）

1. **新组件优先复用**：能在 ui-spec.css 现有板/凹槽/强调板材质上实现的，不新增材质类
2. **命名**：kebab-case；前缀按模块（`doc-`/`navbar-`/`card-`）
3. **样式位置**：全局追加 ui-spec.css（最终覆盖层）；页面级 scoped `<style>` 仅允许布局微调
4. **暗色优先**：先写暗色，再写 `:root.light-style` 覆盖；几何参数明暗必须一致
5. **动效**：全部走 `--duration-*` / `--ease-*` 令牌；交互三态（default/hover/active）缺一不可（静态组件除外，需注释原因）
6. **无障碍**：文字 ≥4.5:1；焦点环 token；触控 ≥24px；见 `无障碍设计规范.md`
7. **验证**：`pnpm build` 通过 + 截图矩阵（明暗 × 桌面/移动）+ 探针无横向溢出
