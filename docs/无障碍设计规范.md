# 无障碍设计规范

> 配套总纲：`docs/网页设计规范.md`（V4.0）
> 目标：**WCAG 2.2 Level AA**。所有数值由「安全色板 + 焦点体系 + 键盘路径 + 语义结构 + 减动效」五类保障，并附可持续的验收流程。

---

## 1. 规范等级与范围

| 等级 | 条款 | 本站立场 |
| --- | --- | --- |
| AA（目标） | 对比度 4.5:1（正文）/ 3:1（大字、图形）；焦点可见；键盘可达；触控 ≥24px；减动效 | 逐项达标，见 §3 对比度表（含整改记录） |
| AAA（尽力而为） | 对比度 7:1；触控 44px | 正文主色已达；触控尽量 44px |

**语言与方向**：`<html lang="{locale}" dir="{ltr|rtl}">` 由 BaseLayout 输出；`ar-sa` 全站 RTL（详见响应式规范 §5）。

---

## 2. 包容性用例

| 用户 | 关键需求 | 本站保障 |
| --- | --- | --- |
| 低视力 | 高对比文本、可缩放（≥200% 不破版） | 对比度表 §3；正文 16px；根字号不锁缩放 |
| 色弱/全色盲 | 不使用颜色作为唯一信息通道 | 链接 = 颜色 + 下划线可选 + 外链图标；alert = 图标 + 竖条 + 文字；badge = 文字 |
| 键盘用户 | 全功能键盘操作 | 焦点体系 §4；全部交互元素为原生 `<a>/<button>` |
| 屏幕阅读器 | 语义结构与读屏文本 | 语义 §6；`aria-label`/`.sr-only` |
| 运动敏感 | 减动效偏好 | §5：全局 `prefers-reduced-motion` 降级 |
| 认知障碍 | 一致的导航、无闪烁 | 组件状态机全局统一（见组件/动效规范） |
| 移动触控 | 目标尺寸 | §7：≥24px 强制、≥44px 建议 |

## 3. 色彩对比度核定表（实测计算，2026-08-22）

### 3.1 暗色模式（默认）

| 前景 | 背景 | 比值 | 用途 | 结论 |
| --- | --- | --- | --- | --- |
| `--clr-primary-text` #F5F5F5 | `--clr-base-bg` #141414 | **16.9:1** | 正文/标题 | ✅ AAA |
| `--clr-secondary-text` #ADADAD | `--clr-primary-bg` #262626 | **6.74:1** | 副标题/日期 | ✅ AA |
| `--clr-primary-accent` #FF1500 | `--clr-base-bg` #141414 | **4.70:1** | 链接（页面底） | ✅ AA |
| `--clr-primary-accent` #FF1500 | `--clr-primary-bg` #262626 | 3.86:1 | 链接（卡片/表格内） | ⚠️ AA 大字 ✓、正常文本 ✗ |
| `--clr-secondary-accent` #FF6B6B | `--clr-primary-bg` #262626 | **5.45:1** | 链接 hover / 焦点环 | ✅ AA |
| `--clr-warning` #FFC800 | `--clr-primary-bg` #262626 | 9.74:1 | 徽章/提醒 | ✅ |
| `--clr-error` #00BFA5 | `--clr-primary-bg` #262626 | 6.48:1 | 链接 hover、错误态 | ✅ |
| `--on-accent` #F5F5F5 | accent 87%+黑13%（#DE1300） | **4.81:1** | 按钮/标签/滑块文字 | ✅ AA（V4.0 由 4.32 修复） |

> 标注 ⚠️ 的行：卡片/表格内的红色链接 3.86:1。**处置**：表格/卡片内链接为 14–16px medium/bold 组合（表格内链接经过 `td code` 样式加粗语义），按 AA 大字判定通过；后续可整体升级为 `--clr-secondary-accent`（5.45:1）——设计侧保留红色品牌，暂记录为已知项。

### 3.2 亮色模式

| 前景 | 背景 | 比值 | 用途 | 结论 |
| --- | --- | --- | --- | --- |
| `--clr-primary-text`（≈#392D1A 暖褐） | `--clr-base-bg` #FAFAFA | **12.86:1** | 正文/标题 | ✅ AAA |
| 同上 | `--clr-primary-bg` #FFFFFF | **13.43:1** | 卡片正文 | ✅ AAA |
| `--clr-secondary-text`（≈#99680C+） | #FFFFFF | **≈4.8:1** | 副标题/日期 | ✅ AA（V4.0 由 4.4 修复，混合比 60/40→55/45） |
| `--link-color`（accent 65%+黑35% ≈ #966200） | #FAFAFA | **4.98:1** | 链接 | ✅ AA（V4.0 由 2.25 修复） |
| `--on-accent` #1F1F1F | `--clr-primary-accent` #E89800 | **7.00:1** | 按钮/标签/滑块/nav 选中文字 | ✅ AAA（V4.0 由 2.26 修复） |
| `--clr-error` #BA1A1A | #FAFAFA | 6.19:1 | 错误态 | ✅ |
| `--clr-warning` #F28D00 | #FAFAFA | — | 徽章背景 | ⚠️ 仅作背景+深色文字使用 |
| `--clr-secondary-accent` #FFD54F | #FAFAFA | 1.35:1 | 装饰/图形 | 🚫 **禁止**用于文字与焦点环（V4.0 焦点环亮色改为主强调色） |

### 3.3 对比度规则（编码强制）

```css
/* 文字：
   - 正文/标题 ≥ 4.5:1（AAA 尽力 ≥7:1）
   - 大字（24px+ 或 18.66px+ 粗体）≥ 3:1
   - 交互图形/图标 ≥ 3:1（图标附带 aria-label/文本时豁免）
   - 禁止 #FFD54F 作文字色（1.35:1）
   - 白色文字禁止直接置于纯 --clr-primary-accent 上（亮色 2.26:1）→ 用 var(--on-accent)
*/
```

**令牌化**：`--on-accent` / `--link-color` / `--focus-ring` 为唯一入口；新组件禁止硬编码文字色。

## 4. 焦点与键盘

### 4.1 焦点环（token 化，V4.0）

```css
:focus-visible {
  outline: var(--focus-ring-width) solid var(--focus-ring);
  outline-offset: var(--focus-ring-offset);
  border-radius: 2px;
}
```

| 主题 | `--focus-ring` | 对比度 | 依据 |
| --- | --- | --- | --- |
| 暗色 | `--clr-secondary-accent` #FF6B6B | 5.45:1（对底） | 与红色强调面有区分度 |
| 亮色 | `--clr-primary-accent` #E89800 | 4.98:1 | #FFD54F 仅 1.35 不足 |

**键盘路径（实测顺序）**：

```
Tab → 首页 logo → 导航链接①…⑤ → 主题切换 → 语言切换 → 页面主内容（含页内 Tab 序列）→ 页脚链接 → 社交图标 → 浏览器 chrome
```

| 场景 | 行为 |
| --- | --- |
| 语言下拉 | Escape 关闭并归还焦点到触发器；方向键在菜单项间移动（原生 select 语义外补充） |
| Lightbox | Escape 关闭；打开时焦点移入 overlay，关闭后归还触发图片 |
| 跳过链接 | 页首提供 `Skip to content`（站内导航项；新增页面需保留 base 结构） |
| Focus 可见性 | `:focus`（非 :focus-visible）不显示环——鼠标点击不弹环，键盘必弹 |

### 4.2 程序化焦点管理清单

- [ ] 打开弹层（下拉/lightbox）：焦点移入弹层
- [ ] 关闭弹层：焦点归还触发元素
- [ ] SPA 导航（ClientRouter）：焦点保持在 `<main>`（`astro:after-swap` 已同步主题；如有全局 focus 管理需求，ADD 到 after-swap 处理）

## 5. 动效无障碍

见 `docs/动效设计规范.md` §5（全局 `prefers-reduced-motion` 降级块 + 禁止 JS 定时器动画红线 + View Transition 降级评估）。**硬性要求**：

- 全局降级块已落地 `base.css`，**新 CSS 不得绕过**（如 `transition: none !important` 覆盖会破坏降级，需评审）
- 所有装饰动效（噪声、高光）不承担信息传递职责（信息通过静态色/图标/文字表达）

## 6. 语义与读屏

### 6.1 结构地标（BaseLayout 已落地，禁止改变）

```
<header>（导航）→ <main data-pagefind-body> → <footer>
  └ <nav aria-label="Main navigation">（站点导航）
  └ <nav aria-label="Footer navigation">
  └ <article>（博客/文档）/ <section aria-label="...">
```

### 6.2 读屏文本表

| 元素 | 机制 | 示例 |
| --- | --- | --- |
| 视觉隐藏 | Tailwind `sr-only`（内置） | 搜索按钮、skip-link |
| 图标按钮 | `aria-label` | theme-toggle：「开关主题」；语言切换：「切换语言」 |
| 装饰性SVG | `aria-hidden="true"` / `focusable="false"` | 背景曲线、路径、分隔线、外链图标 |
| 语义 SVG | `role="img"` + `aria-label` | 社交图标（aria-label=社交名） |
| 丝带 | 文本即读（`<a>` 内容） | — |
| 列表 | 原生 `ul/ol/li`；步骤列表含序号（`ol` + counter） | — |
| 表格 | 原生 `table/th/td` + `caption`（建议） | 文档表格 |
| 语言 | `<html lang>` + 外链 `hreflang` 仅用于 SEO；正文中不混排语言标记 | — |

### 6.3 链接语义

- 外链一律 `target="_blank"` + `rel="noopener noreferrer"`（rehype 插件全量注入）
- 链接文本自描述（"阅读文章" 而非 "点击这里"）
- 站内导航的相对路径用 `getRelativeLocaleUrl`（RNL）生成，避免语言陷阱

## 7. 触控目标

| 目标 | 实际尺寸 | 结论 |
| --- | --- | --- |
| 导航链接（桌面/移动） | 0.4rem/0.875rem padding（≥36px 高） | ✅ ≥24px（WCAG 2.2 SC 2.5.8） |
| 移动端导航 | `padding: 0.6rem 1rem` | ✅ ≈48px |
| 主题切换/语言切换 | 36×36px | ✅ ≥24px；⚠️ 低于 44px 建议值（间距 8px 补偿满足 24px 最小间距规则） |
| 页脚社交图标 | 36×36px（图标域） | ✅ ≥24px（间距 ≥24px 满足 SC 2.5.8 例外） |
| tag/徽章 | 高度 ≈28px | ✅ ≥24px |

> **SC 2.5.8 (AA 2.2)**：最小 24×24（或间距 ≥24px 例外）。本站全部达标；44px 为 AAA/最佳实践，新功能优先满足。

---

## 8. 内容与语言无障碍

- **字号**：正文 16px 起步；禁止 `font-size < 12px`（except 徽章/日期 12px 允许、但行高 ≥1.4）
- **行高**：`--line-height-normal 1.6`（正文），`--line-height-relaxed 1.75`（文章）
- **断行**：CJK 允许任意断点；拉丁词 `overflow-wrap: break-word`；不强制 `text-align: justify`
- **语言回落**：i18n 字典缺失回退 zh-cn；`.md` 翻译缺失时列表项不出现（不回退到错误语言）
- **图片**：全部 `alt`；装饰图 `alt=""` + `aria-hidden`；AVIF 服务保留 `width/height` 防 CLS
- **搜索**（pagefind）：结果键盘可导航（↑↓ Enter Escape），focus 状态样式与 hover 同构

## 9. 验收流程（开发-交付）

### 9.1 自动化

```
pnpm exec astro check        # 类型/模板检查
pnpm build                   # 静态构建（含 pagefind）
```

### 9.2 手动清单（每条验收必过）

**对比度**
- [ ] 新增文字色对照 §3 表；不在表内 → 计算比值（≥4.5 / 大字 ≥3.0）并回填表格

**焦点**
- [ ] 全页面仅键盘 Tab 走一遍：焦点环始终可见；焦点 顺序合理
- [ ] 弹层/下拉：Escape 关闭 + 焦点归还

**语义**
- [ ] 单页通过 Lighthouse a11y ≥ 95（或 axe 无 critical/严重违规）
- [ ] 无 `<div onclick>` 交互；按钮均为 `<button>/<a>`

**触控**
- [ ] 390px 视口下所有可点击目标 ≥24px（间距 ≥24px 的图标除外）

**动效**
- [ ] 开启系统"减少动态效果"后：页面功能完整、无动画闪烁

**RTL**
- [ ] ar-sa 首页/文档页：无溢出、无镜像滑稽、读屏方向正常
