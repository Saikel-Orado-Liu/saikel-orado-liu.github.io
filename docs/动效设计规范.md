# 动效设计规范

> 配套总纲：`docs/网页设计规范.md`（V4.0）
> 立场：动效是本站点表现力的核心资产。拟物材质（亚克力板/凹槽滑块）只有在动起来时才成立——按钮按下必须"沉入"，浮起必须"回弹"。本节定义全部动效的**唯一事实源**。

---

## 1. 动效哲学

### 1.1 物理隐喻

整个站点是一个**桌面上的亚克力板系统**，光源固定从左上入射。动效必须遵守以下物理法则：

| 法则 | 表现 | 反例（禁止） |
| --- | --- | --- |
| 重力 | hover 升起、按下落下；松手瞬间回位 | 东西自己飘走 |
| 惯性 | 升起用弹性缓动（过冲 3%），落回用零过冲 | 用同一个缓动曲线处理升/降 |
| 约束 | 凹槽内的滑块不能过冲（槽有边界） | 滑块 out-of-groove 摆动 |
| 厚度 | 位移方向 = 光入射方向的反方向（左上抬起 = 光从右上照下的板） | 向任意方向乱飞 |
| 连续 | 状态切换是同一块板在移动，不是两块板闪现 | hover 时突然换底色（无过渡的 background 跳变） |

### 1.2 动效层级

| 层级 | 时长 | 对象 | 目的 |
| --- | --- | --- | --- |
| **即时反馈** | 0.06–0.08s | 按下（active） | 贴手，物理"接触"感 |
| **快速过渡** | 0.15s | 颜色、高光、link 色 | 不打断阅读的强反馈 |
| **标准交互** | 0.2s | hover 抬起、文字浮起、卡片动效 | 主要交互节奏 |
| **机械运动** | 0.3–0.4s | 滑块位移、宽度/高度、阴影、View Transition | 机械部件运动，需要"可见的移动" |
| **瞬移（0s）** | 0s | 松手回位、页面加载定位 | 物理回弹无需动画（避免回弹动画堆积） |

## 2. 动效令牌（唯一来源：`src/styles/tokens.css`）

| 令牌 | 值 | 用途 |
| --- | --- | --- |
| `--duration-fast` | 0.06s | 按下/瞬时反馈 |
| `--duration-short` | 0.15s | 快速过渡 |
| `--duration-medium` | 0.2s | 标准交互 |
| `--duration-long` | 0.3s | 滑块 width/height |
| `--duration-slow` | 0.4s | 滑块位移/阴影/高光 |
| `--ease-standard` | `cubic-bezier(0.4, 0, 0.2, 1)` | 零过冲（受约束运动） |
| `--ease-spring` | `cubic-bezier(0.34, 1.3, 0.64, 1)` | 弹性过冲（抬起/浮起） |
| `--ease-emphasized-decelerate` | `cubic-bezier(0.05, 0.7, 0.1, 1)` | 大位移入场（预留） |

> **命名纪律**：transition / animation 中**禁止**直接写数字时长与曲线（`0.2s`、`cubic-bezier(0.4,0,0.2,1)` 字面量）——历史代码允许分阶段迁移，但**新代码**必须引用令牌。已发现的断引用（Hero.astro 引用未定义令牌导致头像过渡失效）已在 V4.0 修复，禁止回退。

### 2.1 曲线语义决策表

| 场景 | 曲线 | 理由 |
| --- | --- | --- |
| 滑块 `left/top` 位移 | `--ease-standard` | 凹槽约束，过冲会"撞槽" |
| 滑块 `width/height` | `--ease-standard` | 同上 |
| 滑块 hover `transform`（抬升） | `--ease-standard` 0.25s | 机械抬升，不允许弹性过冲（板体是刚体） |
| **文字**浮起 | `--ease-spring` 0.2s | 文字是"实体"，允许微过冲（+3%） |
| 按钮/标签 hover 抬升 | `--ease-spring` 0.2s | 同上 |
| 按下 | `--ease-standard`-family但不弹 → 实际 `ease` 0.06s | 快切，接触感 |
| 高光 opacity | `ease` | opacity 不做弹性（避免闪光） |
| View Transition | `ease-out` 0.35s | 掩码展开，入场减速 |

## 3. 组件动效矩阵（完整）

> 标注：⏱=duration，⛓=delay，⭕=曲线。所有 transform 位移均为**光入射方向的反方向**（左上浮起、右下沉入）。

### 3.1 导航凹槽滑块（`.nav-slider` / `.lang-slider`）

| 属性 | 值 |
| --- | --- |
| `left` / `top` | ⏱0.4s `--ease-standard` |
| `width` / `height` | ⏱0.3s `--ease-standard` |
| `transform`（hover 抬升） | ⏱0.25s `--ease-standard`（⛓0 无延迟） |
| `box-shadow` | ⏱0.4s ease |
| `border-color` | ⏱0.4s ease |
| 高光层 `opacity` | ⏱0.4s ease（0.5 ↔ 1） |

**滑块双层抬起**（`translateY` 由 JS `setSlider()` 控制）：

| 状态 | Y | lifted class | 高光 |
| --- | --- | --- | --- |
| 默认 | `-2px` | 无 | 0.5 |
| hover | `-5px` | `yes` | 1 |
| 按下 | `0` | 移除 | 0.5 |
| 松手 | `none` 瞬回 | — | — |

**文字状态机**（纯 class 驱动，CSS delay 实现"滑块先到、文字后浮"）：

| Class | transform | delay |
| --- | --- | --- |
| base `a` | `translate(2px, 2px)`（沉入凹槽） | — |
| `.nav-lift` | `translate(1px, -1px)` | ⛓0.35s 弹簧 |
| `.nav-hover-lift` | `translate(2px, -3px)` | ⛓0.15s 弹簧 |
| `.nav-hover-lift.instant-hover` | `translate(1px, -5px)` | ⛓0.05s 弹簧 |
| `.nav-hover-lift.instant-return` | `translate(1px, -5px)` | ⛓0.15s 弹簧 |
| `.nav-pressed` | `translate(2px, 2px)` | 0.08s ease |
| `.nav-pressed.instant-press` | `translate(1px, 1px)` | 0.08s ease |

**交互时序**（这是最精细的动效，改前必读 `src/scripts/nav-slider.ts`）：

| 触发 | 滑块 | 文字 |
| --- | --- | --- |
| 页面加载 | 瞬移取位 `-2px` | `.nav-lift` 无动画 |
| hover active | 无滑动，升 `-5px` + lifted | `.instant-hover` ⛓0.05s 浮起 |
| hover 普通项 | 滑到目标，升 `-5px` + lifted | `.nav-hover-lift` ⛓0.15s 浮起 |
| 回到 active | 滑回 active，升 `-5px` + lifted | `.instant-return` ⛓0.15s 浮起 |
| mouse leave | ⛓150ms 滑回 active `-2px` | 立即下沉（delay 0s !important） |
| 按下 | 降至 `0`，移除 lifted | `.nav-pressed` 0.08s |
| 松手 | `transition:none` 瞬回 | 瞬回 |

### 3.2 按钮 / 标签

| 组件 | 状态 | transform | 曲线 | 高光 |
| --- | --- | --- | --- | --- |
| `.btn-primary/.btn-outline` | hover | `translate(-4px,-4px)` | ⏱0.2s 弹簧 | opacity 0.5→1 |
| | active | `translate(2px,2px)` | ⏱0.06s ease | →0.4/0.05 |
| | 松手 | `transition:none` | 瞬回 | 瞬回 |
| `.tag` | hover | `translate(-1px,-2px)` | ⏱0.2s 弹簧 + 背景切 Primary Container | opacity 0.2→1 |
| | active | `translate(0,0)` | ⏱0.06s ease | →0.05 |
| `.tag-accent` | **全静态** | 无 | `transition: none` | 固定 0.5 |
| `.theme-toggle` | hover | `translate(-2px,-2px)` | ⏱0.2s 弹簧 | 0.5→1 |
| | active | `translateY(0)` | ⏱0.06s ease | 0.5→0.4 |
| `.doc-pager-card` | hover | `translate(-4px,-4px)` + L2 柔影扩展 | ⏱0.2s 弹簧 | 0.5→0.67 |
| | active | `translate(2px,2px)` | ⏱0.06s ease | →0.05 |

### 3.3 丝带（`.card-ribbon`）

| 状态 | 行为 | 值 |
| --- | --- | --- |
| hover | `padding-left` +18px（左伸），文字 `translateX(-18px)` 抵消 | ⏱0.2s ease / ⏱0.2s ease |
| active | `padding-left` +36px + `rotate(-4deg)` | ⏱0.15s ease + 弹簧 |

> 丝带的"阴影元素"`.card-ribbon-shadow` 必须与丝带同步位移（padding-left 同步值），否则露出叠影。

### 3.4 下拉菜单（`.lang-dropdown`）

| 属性 | 展开 | 收起 |
| --- | --- | --- |
| `opacity` | 0→1，⏱0.2s `--ease-standard` | 1→0 |
| `translateY` | -12px→0，⏱0.25s `--ease-standard` | 反向 |
| `pointer-events` | none→auto | auto→none（先隐藏再收回） |

### 3.5 TOC 滑块（`.doc-toc-slider`）

与语言下拉垂直滑块同体系；**JS inline-style 驱动**（`toc-slider.ts` 的 `setTextHover()`）：

| 场景 | inline transform | inline transition |
| --- | --- | --- |
| hover H2（已在 H2） | `translate(-1px,-6px)` | 0.2s ⛓0.05s 弹簧 |
| hover H2（从 H3 回来） | `translate(-3px,-6px)` | 0.2s ⛓0.05s 弹簧 |
| hover H3 | `translate(-5px,-5px)` | 0.2s ⛓0.05s 弹簧 |
| 离开回落 | 清空 | 0.2s ⛓0.05s 弹簧 |
| 按下 | `translate(-1px,1px)` / `(-2px,1px)` | 0.08s ease |
| 松手仍在 hover | 恢复 hover 位 | 0s（瞬回） |

| 触发 | 滑块 |
| --- | --- |
| 页面加载 | 瞬移定位 H2（`translateY(0)`） |
| hover H3 | 滑到 H3，升 `(-1px,-6px)` + lifted |
| 离开 | ⛓150ms 防抖回 H2 + 回落 |
| 按下 | `translateY(0)` 0.06s |

### 3.6 链接 / 文字 / 头像

| 对象 | 属性 | 值 |
| --- | --- | --- |
| `a` 通用 | `color` | ⏱150ms ease |
| `.article-content a::after` 外链图标 | `opacity` | ⏱150ms ease |
| `.hero-avatar` | `transform/box-shadow` | ⏱`--duration-medium` `--ease-standard`（V4.0 修复令牌引用） |
| `:focus-visible` | outline 颜色 | 无动画（避免闪烁） |

### 3.7 噪点与高光（opacity-only）

| 层 | 规则 |
| --- | --- |
| `::after` 漫反射高光 | 过渡 ⏱0.3–0.4s ease；禁止 transform 动画（会与基底错位） |
| `::before` 噪点 | 从不做动画（性能 + 避免噪点"流动"） |

> **性能红线**：噪点 background-image/repeat 禁止参与 transition；阴影动画仅允许 box-shadow（纯色无模糊半径突变）；**禁止** `filter` / `backdrop-filter` / `clip-path` 动画（重排 + 糊化）。

## 4. View Transition（主题切换）

| 参数 | 值 |
| --- | --- |
| API | `document.startViewTransition`（theme.ts 驱动） |
| 动画 | 圆形辐射 `::view-transition-new(root)`：mask `radial-gradient` 从鼠标点扩散 |
| 时长 | 0.35s `ease-out` |
| 羽化 | ±32px（64px 宽边界） |
| 半径变量 | `--vt-radius`（@property 0→`--vt-size`），`--vt-pos-x/y` 为鼠标坐标 |
| 兜底 | 无 ViewTransition 支持时直接切换（theme.ts 已处理） |

**要点**：
- `--vt-radius` 必须用 `@property` 注册（`<length>`）才可插值
- 文档页 `DocHeader` 使用 `view-transition-name: none` 排除固定 UI 闪烁
- 客户导航（ClientRouter）：`astro:after-swap` 先同步主题/locale，再初始化滑块与背景，防闪烁

## 5. 动效与无障碍（mandatory）

```css
@media (prefers-reduced-motion: reduce) {
  *, *::before, *::after {
    animation-duration: 0.01ms !important;
    animation-iteration-count: 1 !important;
    transition-duration: 0.01ms !important;
    scroll-behavior: auto !important;
  }
}
```

（已落地于 `src/styles/base.css`；`html { scroll-behavior: smooth }` 同步被覆盖为 auto。）

| 场景 | 降级策略 |
| --- | --- |
| 滑块/文字状态机 | 瞬时到最终态（transition 0.01ms 等效无动画），功能不变 |
| View Transition 主题切换 | `startViewTransition` 内动画被全局降级 → 近乎瞬切，可接受（主题切换本身是状态而非装饰） |
| `html scroll-behavior` | auto（锚点跳转无平滑滚动） |
| 新动效 | 一律通过 transition/animation 声明实现（可被上述块覆盖）；**禁止** JS 定时器驱动的"动画循环"（requestAnimationFrame 轮换类），reduced-motion 无法拦截 |

## 6. RTL 语义

| 维度 | 规则 |
| --- | --- |
| 位移方向 | **不镜像**。浮起/按压是 Z 轴物理动作，与 RTL 无关 |
| 滑块 | 滑块从"当前位置"滑向"目标位置"，方向由几何差自然决定；禁止为 RTL 写 `left→right` 翻转 |
| 下拉 | `translateY(-12px)→0` 不翻转；展开锚点 `right: 0` 改 `inset-inline-end: 0` |
| 外链图标 | `margin-left` → `margin-inline-start`（RTL 下镜像到左侧） |
| 检收 | ar-sa 页面：滑块、下拉、丝带 hover 不越界、不镜像 |

## 7. 动效验收清单（新交互必查）

- [ ] 用时令牌（duration-*/ease-*），无字面量
- [ ] 升/降成对：升用弹簧、降用零过冲或瞬回
- [ ] active 按下 ≤0.08s，有"接触感"
- [ ] hover 抬起位移方向 = 左上（`-x,-y`）
- [ ] 高光/阴影类只做 opacity/box-shadow，不做位移错位
- [ ] 凹槽内滑块无过冲（`--ease-standard`）
- [ ] `prefers-reduced-motion` 下功能完整、无动画
- [ ] 无 `filter/backdrop-filter/clip-path` 动画（性能红线）
- [ ] 无 `transition` 作用于 `display/visibility`（布局跳变）
